# [dotOp] [rocMLIR] Add triton_gpu.memref_to_tensor

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#147](https://github.com/ROCm/triton/pull/147) · **Merged:** 2023-03-06 · **Author:** @zhanglx13

**Inclusion reason:** keyword 'mfma'

## Summary (from upstream PR description)

This PR adds the triton_gpu.memref_to_tensor op, which converts the result of blockwise_gemm_v2 into a tensor with #mfma encoding.
Now the IR after blockwise_gemm_v2 looks like
%48 = triton_gpu.memref_to_tensor %47 : memref<4xvector<16xf32>, #gpu.address_space<private>> -> 
tensor<128x256xf32, #triton_gpu.mfma<{nonKDim = 32, warpsPerCTA = [2, 4], xdlopsPerWarp = [2, 2]}>>
%49 = triton_gpu.convert_layout %48 : 
    (tensor<128x256xf32, #triton_gpu.mfma<{nonKDim = 32, warpsPerCTA = [2, 4], xdlopsPerWarp = [2, 2]}>>) -> 
    tensor<128x256xf32, #blocked1>
%50 = arith.truncf %49 : tensor<128x256xf32, #blocked1> to tensor<128x256xf16, #blocked1>
tt.store %32, %50 {cache = 1 : i32, evict = 1 : i32} : tensor<128x256xf16, #blocked1>
