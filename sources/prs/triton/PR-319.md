# Add waves_per_eu as kernel parameter

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#319](https://github.com/ROCm/triton/pull/319) · **Merged:** 2023-10-06 · **Author:** @oplavsic

**Inclusion reason:** kernel path 'python/triton/compiler/compiler.py'; keyword 'attention'

## Summary (from upstream PR description)

Add ROCM specific kernel parameter waves_per_eu. This parameter will be used to set llvm amd gpu backend attribute "amdgpu-waves-per-eu" which gives compiler hint on how many waves should be executing on single SIMD unit. Default value is 0, and in that case attribute won't be set at all.
