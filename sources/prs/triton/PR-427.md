# Add view_slice ttgir instruction

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#427](https://github.com/ROCm/triton/pull/427) · **Merged:** 2024-01-02 · **Author:** @oplavsic

**Inclusion reason:** kernel path 'python/test/unit/language/test_core_amd.py'

## Summary (from upstream PR description)

This instruction represents view of the slice of the tensor in registers. Syntax of the operation is the same as for extract_slice op. However, unlike 'extract_slice' which slices in shared memory, 'view_slice' specifically slices within registers.
Slice of the tensor is required to have the same layout as the original tensor. In a way, semantics of the 'view_slice' operation is a combination of the 'extract_slice' and 'view' operations semantics.
This PR adds support for slicing tensors in blocked layout.
