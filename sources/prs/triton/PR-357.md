# fp8 type support

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#357](https://github.com/ROCm/triton/pull/357) · **Merged:** 2023-11-02 · **Author:** @scxiao

**Inclusion reason:** kernel path 'python/test/unit/language/test_core_amd.py'; keyword 'gemm'

## Summary (from upstream PR description)

This PR is to add amd fp8 data type to triton, which includes the following changes:

Added two amd fp8 data formats (fp8e4b8 and fp8e5b16) to triton, so triton thinks these types legal.
Provided type conversions between fp8 and fp16 and vice versa.
Changed FlashAttention to switch between fp16 and fp8 flexible by a switch input type.

Changes to gemm to support different types are in PR #373.
