## Summary (from upstream PR description)

this pr prevents an issue with a large bias tensor leading to segfaults on some configs due to pointer arithmetic overflow. Triton is unable to address tensors with elements larger than int32 max
we add an assert to the op to catch cases in the future.
the solution is to split the forward test in to one with bias and one with out with appropritate config
