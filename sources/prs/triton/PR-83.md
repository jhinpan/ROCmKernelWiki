## Summary (from upstream PR description)

This resolves issues with the masked load and store implementations to avoid executing the load or store respectively when the maskVal is false.
This enables 100% functional correctness for the softmax and layernorm forward pass tutorials.
This also updates test_core_amd.py with some unit tests that were enabled by this (and some that should have been enabled in the past).
Finally, some tweaks were made to the layernorm tutorial to reflect the current state of atomics support for AMDGPU and to improve performance on AMDGPU.
