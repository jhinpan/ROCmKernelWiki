# Add rotating tensor, icache flush, and bias to GEMM tuning script

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#588](https://github.com/ROCm/triton/pull/588) · **Merged:** 2024-06-10 · **Author:** @scxiao

**Inclusion reason:** kernel path 'scripts/amd/gemm/README.md'; keyword 'gemm'

## Summary (from upstream PR description)

This PR is to add three new features to the gemm tuning script tune_gemm.py

added --rotating_tensor <value> to use different memory blocks in each iteration when running gemm performance, size in MB, default is 0MB, so no rotating tensor by default.
added --icache_flush to flush icache in each iteration when running GEMM performance. Rotating tensor and icache flush are to make perf numbers closer to real applications.
added --bias_vector to turn on bias add to output matrix. The bias vector contains the same number of elements as the number of rows of the output matrix. Each element is added to all elements of the corresponding row of the output matrix.
