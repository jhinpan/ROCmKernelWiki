# Add non-slicing 2step pingpong

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#815](https://github.com/ROCm/triton/pull/815) · **Merged:** 2025-05-28 · **Author:** @jungpark-mlir

**Inclusion reason:** kernel path 'third_party/amd/lib/TritonAMDGPUToLLVM/DotOpToLLVM/MFMA.cpp'; keyword 'mfma'

## Summary (from upstream PR description)

2-step pingpong splits op group into 2 clusters in the pingpong pass
-> mem_cluster : async_copy/tt.load, dot cluster : local_load and dot_scaled.
and once 2-step pingpong is detected in the lowering to llvm, it changes mfma lowering order so k-dim becomes the outer-most loop.
This gives pingpong scheduling more flexibility of dividing series of mfma instructions without slicing ops while divide the k-dim which helps backend handle register pressure more easily.
