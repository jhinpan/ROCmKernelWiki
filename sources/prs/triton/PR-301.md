# Enable usage of block pointer semantics for AMD gpus

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#301](https://github.com/ROCm/triton/pull/301) · **Merged:** 2023-08-24 · **Author:** @jayfurmanek

**Inclusion reason:** kernel path 'python/test/unit/language/test_block_pointer.py'; keyword 'attention'

## Summary (from upstream PR description)

This commit enables usage of block pointer semantics by enabling rewrite_tensor_pointer_pass that rewrites block pointer loads/stores to legacy loads/stores.
This PR also

updates the FA fwd kernel from upstream, except that qk's type is set to float32 since it gives better perfomance
disables bwd kernel in test_op and benchmark. Will add support for bwd kernel in #303
tests fail for seqlen = 8192 and 16384 since the standard torch implementation runs out of memory (https://github.com/ROCmSoftwarePlatform/frameworks-internal/issues/5154).

Now we can use the tutorial to get perf numbers for fwd kernel:
fused-attention-batch4-head48-d64-fwd:

0   1024.0  80.377951
1   2048.0  85.872829
2   4096.0  88.415275
3   8192.0  88.601049
4  16384.0  88.486372
