# [dotOP] [rocMLIR] Add unit tests for pull requests targeting the dot-rocMLIR branch

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#155](https://github.com/ROCm/triton/pull/155) · **Merged:** 2023-03-07 · **Author:** @zhanglx13

**Inclusion reason:** kernel path 'python/setup.py'; keyword 'mfma'

## Summary (from upstream PR description)

This PR adds a github workflow for each PR targeting the dot-rocMLIR branch. It includes the following three unit tests:

TritonGPU/combine.mlir: the result and acc of tt.dot should be converted to have #mfma encoding.

This pass was changed to remove-layout-conversions here: 0ec277e.


TritonGPU/decompose-conversions.mlir: the conversion from #blocked to #dot_op should be decomposed to conversion from #blocked to #lds and conversion from #lds to #dot_op.
Conversion/tritongpu_to_rock.mlir: here we introduced blockwise_gemm_v2  and triton_gpu.memref_to_tensor and related ops from the rock dialect.

It also enables TRITON_USE_ROCM by default so that USE_ROCM is defined. The old logic sets TRITON_USE_ROCM only when hip is found in the system, which is not the case for github runner images.
