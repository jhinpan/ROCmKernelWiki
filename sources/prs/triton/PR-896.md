# [AMD] Optimize chained multiplications for WMMA (#7374)

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#896](https://github.com/ROCm/triton/pull/896) · **Merged:** 2025-11-06 · **Author:** @ptrojahn

**Inclusion reason:** kernel path 'test/Conversion/amd/wmma-v1-shortcut.mlir'; keyword 'wmma'

## Summary (from upstream PR description)

First, the initial multiplication can be transposed to create a column-major result layout, as is required for the first operand of the second multiplication. To minimize data movement for the convert_layout to the dot_op layout, we need to differentiate between two cases:

WMMA v1 (gfx11) The result of the first WMMA operation is stored in two columns: lane 0-15 and lane 16-31, with the even rows in the first set and the odd rows in the second set of lanes. For the operands to the second dot, we need to duplicate the data in the upper 16 lanes. We can achieve this without using any shared memory by exchanging the values of the upper and lower 16 lanes through shuffleXor(16) and some select()ing. An overview of WMMA v1 can be found here:
https://gpuopen.com/learn/wmma_on_rdna3/

|        0       |        1       |         |        0       |        0       |
+----------------+----------------+   ===>  +----------------+----------------+
|        2       |        3       |         |        1       |        1       |
