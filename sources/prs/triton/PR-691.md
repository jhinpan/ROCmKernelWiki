This PR adds advanced benchmarking for kernels inside perf-kernels. Aim is to have more representative and comparable benchmark results by taking shapes from actual llms. model_configs.json holds the configs for various models, which we can then read and use to derive inside the kernel files (model_benchmark_configs()). One can run the model benchmark for example for flash-attention as:
python python/perf-kernels/flash-attention.py -model all
to run the kernel with all the models inside model_configs.json. Or as:
python python/perf-kernels/flash-attention.py -model llama3_8B -b 2 -sq 1024
to run a specific model with specified batch size and sequence length (which otherwise are 1 and max_context_length from the model config). Same applies for other kernels (gemm.py, rmsnorm.py, softmax.py).
