# HIP: Add RUNPATH to compiled so files.

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#510](https://github.com/ROCm/triton/pull/510) · **Merged:** 2024-03-19 · **Author:** @xinyazhang

**Inclusion reason:** kernel path 'python/triton/common/build.py'

## Summary (from upstream PR description)

Fix a problem reported by Pytorch CentOS docker creation failed due to Triton compilation, ImportError: libamdhip64.so.6
Analysis of this problem:

Some Triton libraries do not have /opt/rocm/lib in their RUNPATH. This leaves ld with only two options to find the libamdhip64.so.6 file: LD_LIBRARY_PATH and /etc/ld.so.conf.
LD_LIBRARY_PATH may not contain /opt/rocm/lib
/etc/ld.so.conf.d/* files are being deprecated by ROCM and not reliable. RUNPATH is the new preferred way by ROCM to locate ROCM libraries, to support parallel installations.
