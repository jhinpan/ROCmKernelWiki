# Apply pr 7954 from upstream to enable gfx11xx dot_scaled for gpt-oss model support

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#923](https://github.com/ROCm/triton/pull/923) · **Merged:** 2026-02-07 · **Author:** @hongxiayang

**Inclusion reason:** kernel path 'python/test/unit/language/test_core.py'

## Summary (from upstream PR description)

The gfx12xx was enabled to support gpt-oss models but gfx11xx support was added later after gpt-oss model day 0.
The code change to support gfx11xx is in pr 7954 (triton-lang#7954) from triton upstream.
vllm uses pytorch/rocm7.1_internal_testing branch in its base docker build.
However, that branch does not have pr-7954.
As a result, we have many vllm issues that can not run gpt-oss using the upstream dockers.
This PR is cherry-pick PR 7954 to this branch so that upstream vllm can support gfx11xx devices in gpt-oss model serving.
