## Summary (from upstream PR description)

Added USE_ROCM and DEBUG_ROCM definitions to add ROCDL dialect support and switch off some NVPTX related output generation
Added ROCDL dialect support
Added ROCDL passes to compiler pipelines
Temporarily hacked tests since switch for ROCm mode is not introduced yet
Switched default configuration in the fork/branch to build with ROCm/AMDGPU support
Introduced the env variable "MI_GPU_ARCH" to specify the HW to build for. Default value is "gfx90a"

Please note that NVPTX related test lines hacked out with changing "CHECK:" to "XHECK:" to make FileCheck ignore it.
