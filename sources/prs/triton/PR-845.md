# Fa grid fix

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#845](https://github.com/ROCm/triton/pull/845) · **Merged:** 2025-07-25 · **Author:** @Chi-Chu319

**Inclusion reason:** kernel path 'fa/flash-attention.py'; keyword 'attention'

## Summary (from upstream PR description)

This pr boost the perf of the fa in causal case.
I changed the grid layout from (seq, head, batch) to (head, seq, batch). This way we go over the head dim first. Assuming head is always a multiple of 8, we have every XCD dealing with head // 8 of heads, along with seq and batch.
for example, XCD0 gets (0, :, :) , XCD1 gets (1,:,:) so on and so forth. This ensures that each XCD get entire sequence so the causal imbalanced is relieved.
Further, we xcd remap the head dim, therefore, XCD0 gets ([0, heads//8], :, :),  XCD1 gets ([heads//8, (heads//8) * 2], :, :), This way, the k heads are shared with in XCDS. for example if we have 64 q head and 8 k heads, we idealy want first 8 heads on the same XCD, so they can keep the shared k head in the cache, instead of loading it for all the XCDs (8 times more bandwidth)
