# [dotOp] [rocMLIR] Add Rock dialect

**Repository:** [ROCm/triton](https://github.com/ROCm/triton) · **PR:** [#135](https://github.com/ROCm/triton/pull/135) · **Merged:** 2023-02-22 · **Author:** @zhanglx13

**Inclusion reason:** kernel path 'include/triton/Dialect/Rock/IR/GemmSize.h'; keyword 'mfma'

## Summary (from upstream PR description)

This PR copied Rock dialect related directories from https://github.com/jungpark-mlir/rocMLIR.git@mergebase3.
rocMLIR is currently in the middle of syncing with LLVM 16 release in ROCm/rocMLIR#977.
This PR further resolves conflicts caused by the diff between LLVM 16 and LLVM 17. The latter is used in triton.
Now triton can build successfully with Rock dialect added. The following PR should be able to add rock ops and use its lowering passes.
