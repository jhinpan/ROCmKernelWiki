## Summary (from upstream PR description)

Refactoring plot_layout.py
This PR refactored extensively on the plot_layout.py. The tool plot_layout.py is very powerful for developers to visualize and understand different layouts in Triton. Over the time it has been further developed to support various new layouts, e.g. scaled dot layout, kGroup > 1, and naturally it becomes more bloated. Therefore, this PR aims to alleviate some problems:

Make the tool more modular and extendible by separating out different layouts to separate files. This allows better modularity and readability.
Updated some assertion failure messages s.t. it's easier for the user to understand what is the problem.
Improved the handling of pdflatex failure. pdflatex sometimes quietly hangs when there is error in the .tex file. The subprocess is updated to allow explicit failure.
Updated some command-line capability:

The command line somewhat abuses single dash which does not conform with convention. The PR tried to restore them following the convention where only single character can use single dash, everything else uses double dash, and underscore is replaced with single dash.
Promoted the options of blocked, dot, lds, wmma to the required positional argum
