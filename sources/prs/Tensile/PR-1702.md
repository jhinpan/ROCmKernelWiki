# DirectToVgpr + TailLoop support, plus small fixes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1702](https://github.com/ROCm/Tensile/pull/1702) · **Merged:** 2023-03-30 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

enabled DirectToVgpr + TailLoop for NN, TN, TT
changed noTailLoop logic to apply noTailLoop only for NT
changed the range of AssertFree0ElementMultiple and Free1. Added 16 to cover I8 case
refactored code for deciding the width of global read in TailLoop to use wider load if applicable
fixed mismatch issue with TailLoop + MatrixInstB > 1
added reject condition for DirectToVgpr + InnerUnroll>1
improved reject condition for DirectToLds + numBytes<4
added reject condition for DirectToLds + numBytes<4 + PrefetchGlobalRead=2
fixed incorrect condition checks for DirectToVgpr or NoTailLoop with LocalReadVectorWidth==-1

moved LocalReadVectorWidth==-1 check code before checking DirectToVgpr, NoTailLoop


added more test cases for DirectToVgpr + TailLoop and optimized test cases to avoid increasing test duration
optimized DirectToLds test cases to reduce the test duration
unified aStr, bStr generation code in mfmaIter and fixed lint errors
