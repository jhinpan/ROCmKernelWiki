# Optimizations to solve() function and more performance tests.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#838](https://github.com/ROCm/Tensile/pull/838) · **Merged:** 2020-03-31 · **Author:** @sdquiring

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.yaml'; keyword 'gemm'

## Summary (from upstream PR description)

Runtime optimizations:

solution->solve() optimized by moving debug options to default off and reserving space to avoid reallocations.
PropertyMatching can now use a binary search and early loop exit based on the first dimension of the key.
PropertyMatching no longer uses the batch size as a dimension of its distance metric.
CachingLibrary can now keep track of statistics regarding hits & misses.
Raw performance of the PropertyMatching lookup has been increased by moving virtual calls to templated calls & reducing datatype conversions.

Developer focused optimizations:

RunGEMMKernelTest now caches CPU reference results which significantly speeds up running the HostLibraryTests.
Moved the ParallelMap Python function to a separate Parallel.py file.  It's still accessible via Common.ParallelMap.
