# Add support for hpa fp16 in fp32 out

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1174](https://github.com/ROCm/Tensile/pull/1174) · **Merged:** 2020-11-05 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

Summary of changes:


Add kernels for fp16 in to fp32 out with some tests.


Add some additional data type checks to allow ASM half/bfloat input kernels to perform calculations in fp32 with HPA and keep fp32 as output.


Add some additional data type checks to allow SOURCE half/bfloat input kernels to perform calculations in fp32 with HPA and keep fp32 as output.


Insert generator checks to allow fp16->fp32 asm kernel generation


Allow tensile_client to call for fp16->fp32 kernels


Allow tensile_client to validate fp16->fp32 kernels


**Updated: ** kernel naming to include characters representing <Input/Dest/Compute> type format, ONLY for BSS and HSS:
    Cijk_Ailk_Bljk_BSS_BH
                   ^^^ ^^
    OperationType_<Bfloat16/FP32/FP32>_<UseBeta/HPA>



*This is due to naming conflicts with other existing kernels of the same input type. Cannot blanket change this for every kernel now because we would have to change existing logic and avoid duplicating kernels.

Adjust LDS occupancy calculations to take into acct SRVW when staging output elements.
Add pre_checkin tests for 'hsgemm' and 'bfloat16s' kernels.
Add tuning Configs for 'hsgemm' and 'bfloat16s' kernels.
