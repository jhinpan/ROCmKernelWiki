# DGEMM optimizations + some bug fixes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1489](https://github.com/ROCm/Tensile/pull/1489) · **Merged:** 2022-03-25 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Components/ComputeStoreVgprs.py'; keyword 'mfma'

## Summary (from upstream PR description)

Optimized setprio location for PGR=2 (improve HPL performance)
Added setprio for PGR=1 (to improve multi GCD performance on HPL)
Enabled DirectToVgprB + VectorWidth=2
Enabled LocalReadVectorWidth=2 for B for DGEMM NT case (except for odd N)
Enabled init Acc register optimization for DirectToVgpr and added logic to disable it for small K
Enabled single NoLoadLoop opt for StoreCInUnroll/DirectToVgpr
Fixed mismatch issue with PGR=2 + DirectToVgprA + MT96x64 (incorrect Global read scheduling)
Removed add 0 code when LdsOffset = 0 with DirectToVgprA
Optimized m0 clamp restore code for StoreCInUnroll
Re-organized StoreCInUnroll Addr/GprIndex inc code to support more Tile patterns
Re-organized code to enable init Accvgpr opt other than StoreCInUnroll
Fixed mismatch issue with PGR=2 + DirectToVgpr + LoopIters=1 (incorrect lwEndMfmaIndex)
Fixed mismatch issue with PGR=2 + DirectToLds (schedule Global read before local read)
Fixed mismatch issue with PGR=2 + DirectToLds (incorrect local write offset in NLL)
Fixed mismatch issue with PGR=2 + DirectToVgpr + DirectToLds (wrong waitcnt)
Fixed mismatch issue with DirectToLds + NumLoadsCoalesced > 1 (incorrect offset conversion)
Fixed mismatch iss
