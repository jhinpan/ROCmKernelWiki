# LdsPad optimization + new parameters for local read related optimizations

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1803](https://github.com/ROCm/Tensile/pull/1803) · **Merged:** 2023-11-02 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

supported auto LdsPad calculation for TileMajorLds + MI16x16
improved auto LdsPad calculation for UnrollMajorLds + MI16x16 + VectorWidth
changed LdsBlockSizePerPad to LdsBlockSizePerPadA,B to specify LBSPP separately
added new parameter ClusterLocalRead to turn on/off wider local read opt for TileMajorLDS
added new parameter ExtraLatencyForLR to add extra interval between local read and wait
changed default value of LdsPadA,B,LdsBlockSizePerPadA,B from 0 to -1
fixed mismatch issue with LdsPad + LdsBlockSizePerPad!=0 and TailLoop
fixed mismatch issue with LdsPad + LdsBlockSizePerPad!=0 and SplitLds
improved s_nop insertion for packing code (use only 1 s_nop instruction)
increased interval between local write and barrier only in case we have enough loop iteration
optimized pack code insertion not to insert second pack code in case miLatencyLeft is small
fixed incorrect reject condition check for DirectToLds + LdsBlockSizePerPad=-1 case
added new logic to check LDS size with auto LdsPad(=1) and change LdsPad to 0 if LDS overflows
updated test cases according to parameter changes for LdsPad, LBSPP and ClusterLocalRead
