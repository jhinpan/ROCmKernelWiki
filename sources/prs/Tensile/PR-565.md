# Add function for resume traning.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#565](https://github.com/ROCm/Tensile/pull/565) · **Merged:** 2019-06-26 · **Author:** @endurehero

**Inclusion reason:** kernel path 'Tensile/ClientWriter.py'; keyword 'gemm'

## Summary (from upstream PR description)

Target: enable tensile to contiunously tune automatically when unexpected interruptions happened.
Backgroud: under the current mechanism, there are two ways to deal with the abnormal interruption of trainiing.
1) Start training from the begining, but it will throw away previous results.
2) Set "ForceRedoBenchmarkProblems" to False to save the results of the training and manually modify the config yaml file, remove the trained part from the config yaml file, and then retrain based on the modified config yaml file.
both of the above methods are cumbersome  and time consuming. this commit can automatically continue training based on the previous training results, avoiding repeated training without manual intervention.
Usage: a new globalParameter named "ResumeBenchmarkProblem" has been added in config yaml file.
1) ResumeBenchmarkProblem=False, consistent with normal training procedures.
2) ResumeBenchmarkProblem=True, read 00_Data.csv and start from the untrained part.
