# Serialization changes to reduce library size

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1605](https://github.com/ROCm/Tensile/pull/1605) · **Merged:** 2022-10-31 · **Author:** @benjaminulmer

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.yaml.gz'; keyword 'kernel'

## Summary (from upstream PR description)

The grid-based solution selection we're working to support requires orders of magnitude more sizes in the library than we normally have in rocBLAS (~100k vs 1-10k). This PR makes some changes to the serialization so this increase in sizes won't be as impactful on the final file size.
This PR has three changes:
1) Removing code-gen parameters from solutions
The only code-gem parameter that was used was the library logic index, so this has been retained as its own dedicated field.
2) Making SingleSolutionLibrary just an index
This changes the serialization for the solution indices from {value: {Type: Single, Value: <idx>}} to just {index: <idx>}. I'm not totally happy with the current implementation of this, though, and would appreciate feedback with ideas or suggestions.
3) Remove the speed for GridBased libraries
GridBased libraries do not need the speed entry for breaking ties, so it has been removed for just that library type
