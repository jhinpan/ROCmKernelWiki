# Refactor argument parsing in TensileCreateLibrary

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1951](https://github.com/ROCm/Tensile/pull/1951) · **Merged:** 2024-07-04 · **Author:** @bstefanuk

**Inclusion reason:** kernel path 'Tensile/ClientWriter.py'

## Summary (from upstream PR description)

Previously, argument parsing consumed 117 LOC in TensileCreateLibrary (TCL), this PR moves the argument parsing logic into a module, updates help strings, default behaviour, and adds other utilities for displaying deprecation warning.
Outcomes

New action called DeprecatedOption throws a warning if a deprecated option is used.

Notable changes

Parsing was moved into a module under TensileCreateLib/, this is intended as a temporary name for the module until the TensileCreateLibrary main refactor is complete, at which point the program entrypoint will be contained within the module, and it can be renamed to TensileCreateLibrary/. Current usage of imports throughout the project obfuscates the use of TCL as a file vs. directory module, and thereby we can't use both a file and folder that have the same module name without larger import refactors that are beyond the scope of this ticket.
