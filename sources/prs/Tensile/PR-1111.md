# Reduce stagger_u extended test sizes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1111](https://github.com/ROCm/Tensile/pull/1111) · **Merged:** 2020-08-04 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'Tensile/Tests/extended/stagger_u/big_skinny_A_NN.yaml'

## Summary (from upstream PR description)

Currently the extended/stagger_u tests take a long time to complete. There are 50 test sizes for each benchmark file. The intent of these tests is to validate that stagger U offsets are calculated correctly for A/B matrices that exceed 2GB in any one dimension (e.g. big & skinny).
The tests really only need to show that once the 2GB threshold is crossed, the reference validations pass and we don't get a memory access violation.
Proposed changes will reduce the number of size steps we take to get from below 2GB to over 2GB,  from 50 steps to 14 steps.
