# implement WaveSeperateGlobalRead feature

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#983](https://github.com/ROCm/Tensile/pull/983) · **Merged:** 2020-05-27 · **Author:** @TonyYHsieh

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

sync previous global memory pattern when transposeLDS is enabled.
This feature ask each wave to load separate region.
Original global read pattern is [w0,w1,w2,w3,w0,w1,w2,w3,w0,w1,w2,w3,w0,w1,w2,w3].
When this feature is enabled, read pattern becomes [w0,w0,w0,w0,w1,w1,w1,w1,w2,w2,w2,w2,w3,w3,w3,w3].
