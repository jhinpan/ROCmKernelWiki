## Summary (from upstream PR description)

This PR is to add lazy library loading support in a multi-GPU ( with different architectures) configuration.
Summary of proposed changes:

Extended LazyLoadingInit enum to support specific architectures
Extended RegexPattern to support the same.

rocBLAS TensileHost class will use the LazyLoadingInit enumeration to intialize lazy loading for a specific set of architectures or all architectures. rocBLAS changes are implemented in https://github.com/ROCmSoftwarePlatform/rocBLAS-internal/pull/2040
