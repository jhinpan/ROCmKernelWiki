# Bounds Check and Test Refactor

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#740](https://github.com/ROCm/Tensile/pull/740) · **Merged:** 2019-12-03 · **Author:** @sdquiring

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'gemm'

## Summary (from upstream PR description)

Added bounds check mode:

When validating all elements, the new client can fill the locations surrounding the input/output data with invalid data, and check that the data was not used/overwritten.

Refactoring pytest:

All YAML-only tests are now automatically found and run via the
single test_config test function.
YamlBuilder now constructs documents via an object graph rather than
via text.
All tests that need a build directory can use one specified via the
command line.
