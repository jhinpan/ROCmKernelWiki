## Summary (from upstream PR description)

In general batch use cases, we deference array of buffer pointer to get buffer pointer for each batch.
do not de-reference buffer A/B when alpha is 0 or K size is 0 to avoid memory violation in this corner case.
do not de-reference buffer C when beta is 0 to avoid memory violation in this corner case.
We select a HGEMM kernel to see performance difference.
This change has no performance impact as show in below figure.
