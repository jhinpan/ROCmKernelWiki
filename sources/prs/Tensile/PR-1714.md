# Adding support for FP16 Alt Round Near Zero Mode

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1714](https://github.com/ROCm/Tensile/pull/1714) · **Merged:** 2023-04-28 · **Author:** @yoichiyoshida

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

Current FP16 Alt implementation truncates conversions between FP32 and BF16 in the intermediate step. This PR adds support for a second FP16 Alt implementation which rounds from FP32 to BF16.
