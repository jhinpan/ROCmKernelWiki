# Move MinKForGSU from globalparameter to BenchmarkCommonParameter to support larger GSU

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1701](https://github.com/ROCm/Tensile/pull/1701) · **Merged:** 2023-09-18 · **Author:** @amgddm

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'gemm'

## Summary (from upstream PR description)

The parameter MinKForGSU is a global parameter whose default value is 256. This default value works fine for big matrix GEMM like HPL related GEMM. However, it doesn't work well for small matrix GEMM since it prevents GEMM from using larger GlobalSplitU. It checks the validation of a solution by the following statement in file Contractions.py.
value =  globalparameter['MinKForGSU'] * state['GlobalSplitU']
The parameter MinKForGSU is put into BenchmarkCommonParameter. The condition above is changed to
value =  state['MinKForGSU'] * state['GlobalSplitU']
