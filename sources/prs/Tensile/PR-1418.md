# Added parameter which controls the number of files kernels are split into to improve compile speed

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1418](https://github.com/ROCm/Tensile/pull/1418) · **Merged:** 2021-10-13 · **Author:** @lringham

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'kernel'

## Summary (from upstream PR description)

Added a parameter to control the number of files that kernels are merged into to better parallelize kernel compilation

Regardless of the parallel-jobs value, not all cores were being used to compile kernels when all kernels were in one src file.
Merging the kernels into a few src files allowed the compiler to fulled parallelize compilation
Can be controlled with --num-merged-files command line arg


Fixed various spelling mistakes
Fixed warning related to EmbedLibrary not being found in globalParameters
