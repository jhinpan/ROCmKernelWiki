# Reduce max sgpr usage by improving temporary register re-use

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1691](https://github.com/ROCm/Tensile/pull/1691) · **Merged:** 2023-03-14 · **Author:** @AlexBrownAMD

**Inclusion reason:** kernel path 'Tensile/KernelWriterAssembly.py'; keyword 'kernel'

## Summary (from upstream PR description)

The recent change to 64-bit offsets reorganized the order in which some sgprs were allocated. In general, the change to 64-bit offsets did not increase the total number of required registers. But due to some quirks in the way the the register pool does allocations, the change in order meant register re-use could be affected.
A few kernels tuned into rocblas were affected, increasing the number of sgprs required over the maximum. This change updates the way some temp registers are allocated to improve register re-use. This change fixes the rocblas build.
As a future work on this, I'd like to improve the register pool code to fix a few strange cases I discovered while debugging this issue. For now, this change should unblock testing and rocblas build.
