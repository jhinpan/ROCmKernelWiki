# Prebuild client and skip build step when running tox/pytest.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1143](https://github.com/ROCm/Tensile/pull/1143) · **Merged:** 2020-08-22 · **Author:** @AlexBrownAMD

**Inclusion reason:** kernel path 'Tensile/ClientExecutable.py'

## Summary (from upstream PR description)

Add option to use a pre-built client when running tests. Tests run in tox (CI) now default to first running a build step, then using the pre-built client.
This change should fix the sporadic errors we've seen on CI, since the cmake/make step is skipped. It should also speed up single-threaded runtime a bit by avoiding those calls.
In this change I've also increased the number of pytest threads to 4, which should work now, and would significantly speed up runtime.
