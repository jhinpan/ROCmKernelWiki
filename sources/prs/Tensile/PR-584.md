# add 'Device 66af' for Radeon VII

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#584](https://github.com/ROCm/Tensile/pull/584) · **Merged:** 2019-06-27 · **Author:** @zaliu

**Inclusion reason:** kernel path 'Tensile/Configs/miopen/boiler/library_logic_hip_only.yml'; keyword 'gemm'

## Summary (from upstream PR description)

Resolves SWDEV-190051 along with rocBLAS PR#595

when /usr/share/misc/pci.ids is missing on the system, Radeon VII presents itself as 'Device 66af', not 'Vega 20'. This fix brings 'Device 66af' into the 'Vega 20' fold.
