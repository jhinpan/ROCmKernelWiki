## Summary (from upstream PR description)

Reduce kernel arguments by applying offsets to pointers on host side.
Can't be done for general batch case where pointers are in a buffer, offset code is still present to support general batch kernels used by rocBLAS.
Updated DGEMM NN custom kernel to work with new arguments.
Cleaned up some offset code that is no longer being used.
