# hip kernel for vega20 hgemm when k odd

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#289](https://github.com/ROCm/Tensile/pull/289) · **Merged:** 2018-07-20 · **Author:** @amcamd

**Inclusion reason:** kernel path 'Tensile/TensileCreateLibrary.py'; keyword 'gemm'

## Summary (from upstream PR description)

Call HIP kernel in place of assembly kernel for vega20 and hgemm when k is odd.
Note that the HIP kernel is only called in the rocblas/build/release/Tensile/Tensile.cpp file. You will not see this in the Tensile/build/4_LibraryClient/build/Tensile/Tensile.cpp file. This is because in Tensile you build for a specific schedule, which may be vega10, r9nano, or hip. In rocBLAS you build for multiple schedules, vega10+r9nano+hip.
