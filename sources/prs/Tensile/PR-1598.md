# Assembly syntax and coverage for DirectToLds has changed

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1598](https://github.com/ROCm/Tensile/pull/1598) · **Merged:** 2022-09-30 · **Author:** @AlexBrownAMD

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'gemm'

## Summary (from upstream PR description)

When using lds modifier, destination vgpr must now be omitted. The lds modifier only applies to global loads that would have a single register as their destination, so DirectToLds no longer works with dgemm/cgemm/xgemm. Also doesn't work with hgemm since that case currently requires GRVW=4.
Updated solution reject cases and added additional warnings if DTL is somehow disabled when requested, or requested on hardware that doesn't support it.
Updated test cases: re-enabled working test suites, and moved broken tests to disabled folder.
