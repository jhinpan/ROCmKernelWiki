# new feature StoreRemap to optimize MatrixInstruction store performance

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#993](https://github.com/ROCm/Tensile/pull/993) · **Merged:** 2020-06-02 · **Author:** @jichangjichang

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

This new feature is used to optimize MatrixInstruction store patterns to enhance performance.
MI output data between each threads are along N dims. But global memory is along M dim continous. That mean global write between each threads are not continous. Therefore, store performance for MI instruction is poor.
How StoreRemap works in final store stage:

Put all thread output data into LDS.
All thread read data from LDS along M dims. (match global Memory continous direction)
All thread write out data into global memory.

"StoreRemapVectorWidth":      [0,1,2,4,8]
0:   Disable StoreRemap (default)
1~8: Enable StoreRemap and set the global write vector width
