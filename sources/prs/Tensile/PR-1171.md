**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1171](https://github.com/ROCm/Tensile/pull/1171) · **Merged:** 2020-09-29 · **Author:** @solaslin

## Summary (from upstream PR description)

Fixing the logic for comparing Alpha with 1.0 (F32) or 0x3c003c00 (Packed F16)? (HGEMM <H,H,H>)

NO HPA: Clearly should cmp with 0x3c003c00
HPA = True,

If non-PK: The cvt_f32_f16 happens very late when GlobalWrite, so should cmp with 0x3c003c00 when testing OptNLL (before GW)
If PK: The cvt_f32_f16 is done very early only once (right after the arguments are loaded), so should cmp with 1.0 (already cvt-ed)
