## Summary (from upstream PR description)

Status: local pre_checkin passed. rocblas-test integration test gfx900/gfx908 passed
Optimize VGPR consumption for MI kernels in the store path. Allowing opportunity for more parameters combinations (eg MT256x256) or more occupancy if not LDS-bound:

Removed declaring C-tile vgprs to allow for generating extreme cases such as MT256x256 kernels
Opportunistically use all VGPRs until the next occupancy level in C-tile store stage. Shown to improve efficiency

Minors:

Refactored code gen so optimized NoLoadLoop uses the same pipelined store just as the ordinary code path
All store paths will reuse registers from the register pool for storing C-tiles
Added more test problem sizes to catch edge under Tensile/Tests/pre_chechin/mfma and remove duplicates
