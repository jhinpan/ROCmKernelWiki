# Update to merge script allowing mfma and non-mfma solution for sizes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1316](https://github.com/ROCm/Tensile/pull/1316) · **Merged:** 2021-04-07 · **Author:** @JeremyAdamHart

**Inclusion reason:** kernel path 'Tensile/Tests/unit/test_mergeLogic.py'; keyword 'mfma'

## Summary (from upstream PR description)

This change allows for a MFMA and non-MFMA solution to both be present in a logic file for a given problem size. When the option --add_mfma_tag is used, a SolutionTag will be prepended to problem key, resulting in a different key for the MFMA and non-MFMA versions, regardless of whether the sizes match. This tag is only present during the merging process, and is removed before the new logic file is written.
This feature can be used with ContractionProblem::setArithmeticUnit to select which type of kernel is used.
