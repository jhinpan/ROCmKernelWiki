# make implicit hardware target feature defaults explicit

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1151](https://github.com/ROCm/Tensile/pull/1151) · **Merged:** 2020-08-31 · **Author:** @zaliu

**Inclusion reason:** kernel path 'Tensile/KernelWriterAssembly.py'; keyword 'kernel'

## Summary (from upstream PR description)

Make implicit hardware target feature defaults explicit:

for gfx803, xnack OFF
for gfx900, xnack OFF
for gfx906, xnack OFF, sram-ecc OFF (sram-ecc ON for hip-clang as per Austin's comments)
for gfx908, xnack OFF, sram-ecc ON

Add -mno-xnack -Xarch_gfx906 -msram-ecc -Xarch_gfx908 -msram-ecc for hip-clang.
Add gfx-specific target feature defaults as listed above to assembler command line.
Note that all current Tensile-generated assembly kernels follow the official documentation.  In particular for gfx906, sram-ecc is OFF.
After changing gfx906's sram-ecc to ON for hip-clang, rocblas-test passed fully on all 3 gfx platforms.
Many thanks to @cgmb for sharing his pre-3.12 cmake workaround.
