## Summary (from upstream PR description)

Revive PR 987 #987
Defer the full call to TensileCreateLibrary to 'make' time instead of 'cmake' time
Allow the script to generate a manifest file and use the contents to create new target dependencies
To be used with new client only (see HostLibraryTests CMake for usage example)
Projects migrating to the new client should use TensileCreateLibraryFiles from TensileConfig.cmake
Results in less time wasted regenerating library files when not necessary
