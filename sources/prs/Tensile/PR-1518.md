## Summary (from upstream PR description)

Added a new example config file with the intention that it be referenced in the Tensile wiki for new users to familiarize themselves with Tensile.
The current config file that is referenced as an example in the wiki does not run as is. It contains deprecated parameters, poorly specified parameters, and requires over an hour to execute on a 6900xt once fixed. It also is not commented. This new config file hopes to address these shortcomings.
Following approval, the Tensile wiki will have to be updated accordingly.
