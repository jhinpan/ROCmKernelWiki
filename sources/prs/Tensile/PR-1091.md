# GSU for BF16/FP16 high precision accumulation

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1091](https://github.com/ROCm/Tensile/pull/1091) · **Merged:** 2020-08-07 · **Author:** @TonyYHsieh

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.dat.gz'; keyword 'gemm'

## Summary (from upstream PR description)

In order to use GSU for BF16/FP16 high precision accumulation,
we need user to provide workspace memory for accumulation.

add workspace parameter in ContractionProblem
add required workspace method, so user can query
how much wospace each solution required
filter kernel by available worksapce for findBestSolution.
GSU kernel has beta kernel, normal kernel and conversion kernel.
beta kernel: handle kernel part
normal kernel: accumulate F32 data to workspace
conversion kernel: convert WS F32 to D FP16/BF16 buffer
