# don't allocate vgpr in globalWriteBatch

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1359](https://github.com/ROCm/Tensile/pull/1359) · **Merged:** 2021-07-01 · **Author:** @TonyYHsieh

**Inclusion reason:** kernel path 'Tensile/KernelWriterAssembly.py'; keyword 'gemm'

## Summary (from upstream PR description)

globalWriteBatch will allocate most of vgpr in order to do batch write.
So allocate vgpr in globalWriteBatch is easily to met vpgr overflow.
We should allocate all needed vgpr outside of globalWriteBatch.
