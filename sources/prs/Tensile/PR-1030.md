# Add new predicates and run-time settings

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1030](https://github.com/ROCm/Tensile/pull/1030) · **Merged:** 2020-06-19 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.dat'; keyword 'mfma'

## Summary (from upstream PR description)

Add predicate and client setting for deterministic mode. Setting deterministic mode means that kernels with globalSplitU >1 will not be considered.
Add predicate and client setting for arithmetic unit { Any, VALU, MFMA }. Selecting VALU means that kernels with matrix instructions will not be considered. MFMA means that kernels with matrix instructions will be considered. Any means both will be considered.
Add predicate and client setting for kernel language { Any, Assembly, Source}. Setting Assembly means that asm kernels will be considered. Setting Source means that source kernels will be considered. Setting Any means that both will be considered.
Update predicate for CD strides equal, such that the predicate will always be attached and check the desired value.
