# Initial version of DirectToVgpr support for DGEMM

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1390](https://github.com/ROCm/Tensile/pull/1390) · **Merged:** 2021-08-11 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

This is a new feature called DirectToVgpr.
By setting this, local read/write code is removed and global read values are directly used by MFMA instructions.
This is for DGEMM MFMA only with this initial version.
I tried the following parameters for verification.
For DirectToVgprA,
- MatrixInstruction:
- [16, 16, 4, 1, 1, 2,8, 4,1]  # 128x128
- SourceSwap: [True, False]
- PrefetchGlobalRead: [True] #[True, False]
- ThreadTile:
- [  8, 32 ]
- WorkGroup:
- [ 16, 16, 1 ]
- PrefetchLocalRead: [True]
- GlobalSplitU: [1]
- DepthU:  [ 8, 16 ]
- LdcEqualsLdd: [True]
- StoreVectorWidth: [1, 2]  (need to disable AtomicAddC for 2)
- VectorWidth: [1,2]
- GlobalReadVectorWidth: [1,2]
- DirectToLds: [True, False]   (This is VectorWidth 2 only)
- DirectToVgprA: [True]
- ScheduleIterAlg: [2, 3]
- PersistentKernel: [0, 1]
For DirectToVgprB,
- MatrixInstruction:
- [16, 16, 4, 1, 1, 8,2, 1,4]  # 128x128
- SourceSwap: [True, False]
- PrefetchGlobalRead: [True] #[True, False]
- ThreadTile:
- [  8, 32 ]
- WorkGroup:
- [ 16, 16, 1 ]
- PrefetchLocalRead: [True]
- GlobalSplitU: [1]
- DepthU:  [ 8, 16 ]
- LdcEqualsLdd: [True]
- StoreVectorWidth: [1, 2]  (need to disable AtomicAddC for 2)
- VectorWidth: [1,2]
