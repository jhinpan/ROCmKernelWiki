# Update state that was previously mutated internal to function

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1987](https://github.com/ROCm/Tensile/pull/1987) · **Merged:** 2024-07-26 · **Author:** @davidd-amd

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'kernel'

## Summary (from upstream PR description)

When running Tensile there were an incorrect number of solutions after a call to writeKernels. The previous implementation mutated kernels/solutions internal to writeKernels. writeKernels was updated but didn't account for the state change. This PR returns the newly computed solutions and kernels so that the calling code can update the local object.
