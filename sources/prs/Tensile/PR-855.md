# Pr2 bf16 optimize

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#855](https://github.com/ROCm/Tensile/pull/855) · **Merged:** 2020-03-17 · **Author:** @aazz44ss

**Inclusion reason:** kernel path 'Tensile/Code.py'; keyword 'mfma'

## Summary (from upstream PR description)

bf16 optimize


delay packing
in bf16, waitcnt 0 in packing will cause bubbles. there is no need to wait ds_read and do packing immediately.
Moving packing from localReadDo to makeSubIterSchedule can hide lds latency.


workgroup interleave
since bf16 NT has too many instructions to have good interleaving with mfma(4 ds_read + 2 v_or for packing / mfma), using 2 WG to interleave fetch instruction and mfma instruction will have better performance in some problem size.
