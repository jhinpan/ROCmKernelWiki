# Add new merge script

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1021](https://github.com/ROCm/Tensile/pull/1021) · **Merged:** 2020-06-16 · **Author:** @amdkila

## Summary (from upstream PR description)

The new merge script has the following features:

Default behavior: Merge in tuned kernels for previously tuned sizes only if the efficiency has improved. This also removes unused kernels

e.g. python avoid-regressions.py  asm_full  incremental_logic_dir  output_dir

Old behavior: Merge in tuned kernels for previously tuned sizes regardless of improvements in efficiency

e.g. python avoid-regressions.py  asm_full  incremental_logic_dir  output_dir  true
Recommended usage: Use the first option always. Only use the 2nd option if you're working on a GPU with lower peak performance than another GPU with the same architecture, i.e. MI50 vs. MI60 tuning
