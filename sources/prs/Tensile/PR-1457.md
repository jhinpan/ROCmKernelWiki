# Add LD_PRELOAD for asan RT if used

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1457](https://github.com/ROCm/Tensile/pull/1457) · **Merged:** 2022-01-10 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'Tensile/cmake/TensileConfig.cmake'

## Summary (from upstream PR description)

Clang / Hipcc  C++ toolchains building Tensile may have added ASAN options to support the feature. Binaries must either link ASAN libraries or pre-load them.
Tensile doesn't officially support the ASAN feature yet, so this patch implements the pre-load route.
Consumers of Tensile who wish to use ASAN shall set the environment variable ENABLE_ADDRESS_SANITIZER=true for Tensile to build without error using the new toolchain options.
