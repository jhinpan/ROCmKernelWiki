**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#742](https://github.com/ROCm/Tensile/pull/742) · **Merged:** 2019-12-21 · **Author:** @amdkila

## Summary (from upstream PR description)

This allows users to pass in the architecture they want to use when building rocBLAS
---> e.g. If on vega10, use gfx900 flag (-a gfx900) to only generate Vega 10 kernels
---> See this rocBLAS PR: ROCm/rocBLAS#847
Also adds a couple of missing cmake variables to new Tensile client
This works with both old and new Tensile clients
This works in combination with the Tensile_LOGIC (-l flag)
