# Upgrades to Tensile BenchmarkProblems

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1497](https://github.com/ROCm/Tensile/pull/1497) · **Merged:** 2022-04-13 · **Author:** @benjaminulmer

## Summary (from upstream PR description)

This PR has four main changes to the BenchmarkProblems process, two of which---3 and 4---are closely related.

Support for a new config format being used by the SolutionSelection workgroup
An additional way to specify solution parameters: GroupForkParameters ForkParameter Groups
Ability to run BenchmarkProblems with no sizes---this changes the old behaviour of using default sizes if none are specified
Ability to use Solutions generated from a previous run with a new set of sizes

1: New Config Format
The main Tensile app now accepts a new config format in addition to the standard one, specified by using the --alternate-format option. The new format is actually two yaml files, with the size list separated out into its own file. The PR includes an example for each of these files.
For the "main" config file, it has a similar structure to the regular Tensile config files. The main difference is it only supports a single benchmark problem, with the fields that would normally be specific to a certain benchmark problem (e.g. BenchmarkCommonParameters and ForkParameters) instead being top level fields. Additionally, the "ProblemType" part of the config is labelled as such.
