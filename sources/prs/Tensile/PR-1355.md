# Split LDS optimization

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1355](https://github.com/ROCm/Tensile/pull/1355) · **Merged:** 2021-06-28 · **Author:** @rosenrodt

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

Furthering #1214's development, this patch boosts performance when DepthULdsDivisor > 1, meaning during accumulation loop you want to split the data intended for writing into LDS by a factor of DepthULdsDivisor

Schedule load instructions in the unroll loop earlier
Improves performance in higher occupancy kernel via s_setpro in appropriate places
Extends support for int8/fp32c/fp64
Fix kernel generation when DepthULdsDivisor = 4
