# New cmake structure for cobalt

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#35](https://github.com/ROCm/Tensile/pull/35) · **Merged:** 2016-10-31 · **Author:** @pfultz2

**Inclusion reason:** kernel path 'CobaltGen/Cobalt.py'; keyword 'gemm'

## Summary (from upstream PR description)

This setups a new cmake structure for cobalt. With this, the user would first install cobalt:
mkdir build
cd build
cmake ..
cmake --build .
cmake --build . --target install

Then the user would have the cobalt command available to run cobalt benchmarking:
cobalt benchmark -b cl -i $PROBLEMS_DIR -o $SOLUTIONS_DIR

In addition, the cobalt command can be ran without installing by running this command from the cobalt directory:
python CobaltGen/Cobalt.py benchmark -b cl -i $PROBLEMS_DIR -o $SOLUTIONS_DIR

This will benchmark the kernels from the problems set and then output solutions xml files. Then a library or application can then use this solutions xml files to generate the cobalt lib, using add_cobalt_lib cmake functions. So in the users CMakeLists.txt, it could look like this:
find_package(Cobalt)
add_cobalt_lib(SomeCobaltLib
    SOLUTIONS ${SOLUTIONS_DIR}
    BACKEND OpenCL_1.2
)

find_library(OPENCL_LIB OpenCL)
target_link_libraries(SomeCobaltLib ${OPENCL_LIB})

add_executable(main main.cpp)
target_link_libraries(main SomeCobaltLib)
