## Summary (from upstream PR description)

Updates to enable runtime switch to run the tile aware metric selection method.
In this version it is enabled using the switch ENABLE_DEBUG_SELECTION=1.
To add the summation sweeps to create the linear summation model used by the TAM selection run the tool
./TensileGenerateSummations existing_logic_dir output_dir
The updated logic will be added to output_dir/final
