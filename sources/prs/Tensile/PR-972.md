# re-factory Tensile to support all Matrix Instruction

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#972](https://github.com/ROCm/Tensile/pull/972) · **Merged:** 2020-05-12 · **Author:** @TonyYHsieh

**Inclusion reason:** kernel path 'Tensile/Code.py'; keyword 'mfma'

## Summary (from upstream PR description)

1. Support Matrix Instructions
  - FP32 MI32x32x1x2 and MI32x32x2x1
  - FP32 MI16x16x1x4 and MI16x16x4x1
  - FP32 MI4x4x1x16
  - BF16 MI32x32x2x2 and MI32x32x4x1
  - BF16 MI16x16x2x4 and MI16x16x8x1
  - BF16 MI4x4x2x16
  - FP16 MI32x32x4x2 and MI32x32x8x1
  - FP16 MI16x16x4x4 and MI16x16x16x1
  - FP16 MI4x4x4x16
2. Support arbitrary MI waves in one workgroup
3. add disable option for LdsBlockSizePerPad
4. Support TransportLDS in NN/NT/TN/TT
5. Support to put multi-wave in M dimension
