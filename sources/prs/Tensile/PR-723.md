# Replace std::call_once() with local static variables

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#723](https://github.com/ROCm/Tensile/pull/723) · **Merged:** 2019-11-12 · **Author:** @leekillough

**Inclusion reason:** kernel path 'Tensile/Source/lib/include/Tensile/DataTypes.hpp'

## Summary (from upstream PR description)

Initializing local static variables, which is guaranteed thread-safe in C++11 and later, is faster than explicitly calling std::call_once().
    void DataTypeInfo::RegisterAllTypeInfoOnce()
    {
        static int call_once = (registerAllTypeInfo(), 0);
    }

This is simpler and faster than explicitly calling std::call_once(), since the compiler has special ways of optimizing local static initialization.
The first time RegisterAllTypeInfoOnce() is called, it will call registerAllTypeInfo() once in a thread-safe way. After that, there is almost no overhead in later calls to RegisterAllTypeInfoOnce(), while in the original code, it will call std::call_once() every time.
