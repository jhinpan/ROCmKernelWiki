# Optimizations for TailLoop, complex MFMA, removing extra moves for MIArchVgpr, etc.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1661](https://github.com/ROCm/Tensile/pull/1661) · **Merged:** 2023-02-16 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'mfma'

## Summary (from upstream PR description)

optimized TailLoop code

set 0 only for A or B instead of setting 0 both


optimized complex data type related code

removed redundant negation code for complex type
removed extra fixed vgpr allocation for alpha calculation. Use temporary vgpr instead.
unified CGEMM and ZGEMM code in MulMIoutAlphaToArch


optimized ShiftVectorComponents code to remove redundant mov for permute in case src and dst are the same vgpr
optimized ShiftVectorComponents code to remove redundant mov in MIAV case
removed redundant shift code (0 bit shift)
optimized ComputeStoreVgprsMFMA to remove * 1 code when MIWG[0]=1
optimized cmp_lt + v_cndmask code to use v_min instead
extended the range of GlobalSplitU to 4096 (to support larger DepthU with LocalSplitU)
extended the range of StaggerUStride to 2048 (to support larger DepthU with LocalSplitU)
fixed typo
