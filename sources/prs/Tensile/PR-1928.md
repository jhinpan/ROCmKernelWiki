# XCC-based workgroup remapping for stream-k kernels

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1928](https://github.com/ROCm/Tensile/pull/1928) · **Merged:** 2024-06-05 · **Author:** @AlexBrownAMD

**Inclusion reason:** kernel path 'Tensile/AsmUtils.py'; keyword 'gemm'

## Summary (from upstream PR description)

By default, workgroups are scheduled in a round-robin fashion. This change adds a mode to reorganize workgroups based on which XCC it is running on for better locality of tiles and improved cache hit rate.
