# Waitcnt optimization for DirectToVgpr support

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1399](https://github.com/ROCm/Tensile/pull/1399) · **Merged:** 2021-08-25 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/KernelWriter.py'; keyword 'mfma'

## Summary (from upstream PR description)

This is the second version of DirectToVgpr support.
This is to delay waitcnt for global read of DirectToVgpr side.
Before change, waitcnt vmcnt is generated before local write.
However, in DirectToVgpr case, we can delay waitcnt and execute it just before MFMA (referring the result of DirectToVgpr global read).
In DirectToVgprA case, we need to swap the order of global read (B first, then A) to support this waitcnt optimization.
I tried Lint and Tensile Client Test (no issue).
