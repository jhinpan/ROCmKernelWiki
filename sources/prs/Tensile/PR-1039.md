# Support GRVW up to 8 for fp16/bf16 NT B matrix MI kernel

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1039](https://github.com/ROCm/Tensile/pull/1039) · **Merged:** 2020-06-22 · **Author:** @jichangjichang

**Inclusion reason:** kernel path 'Tensile/SolutionStructs.py'; keyword 'kernel'

## Summary (from upstream PR description)

support GRVW8 for NT B matrix

shift-ptr correction for MI kernel B matrix can be larger then MIOutputVectorWidth size.
(For A matrix shift-ptr design, data are corrected in single thread. It is limited by MIOutputVectorWidth size.
But for B matrix, the data are corrected by re-calculating coordination. It doesn't have MIOutputVectorWidth limitation.)
Now GLVB=8 is rejected by MIOutputVectorWidth condition check.
Modify reject condition and GLVA calculation to support GRVW=8 for B matrix.
