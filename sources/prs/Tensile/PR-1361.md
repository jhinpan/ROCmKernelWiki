# Aldebaran dgemm misc optimization

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1361](https://github.com/ROCm/Tensile/pull/1361) · **Merged:** 2021-06-18 · **Author:** @jichangjichang

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'gemm'

## Summary (from upstream PR description)

Improve weighted performance of HPL Dgemm 512 sizes from 89.43% to 91.94%.
Trained HPL 512 sizes with both atomic and non-atomic, weighted performance can reach 93.07%
Including below features:

optSingleColVgpr enhancement to reduce valu instructions
two low priority slot per unroll loop.
use lds to init Acc Registers to reduce valu instructions for 2 waves optimization cases.
set low priority beforw sgpr shadowinit of init wave to minimize the impact of unroll loop wave
new kernel parameter "MIArchVgpr" to let MatrixInstruction use arch vgpr only.
merge valu copy and computing alpha valu together as one valu for "MIArchVgpr" alpha case
Remove all handles for DisableVgprOverlapping.
