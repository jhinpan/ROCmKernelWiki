**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1351](https://github.com/ROCm/Tensile/pull/1351) · **Merged:** 2021-05-26 · **Author:** @aazz44ss

## Summary (from upstream PR description)

Reduce MFMA Bubbles

schedule globalReadInc code
schedule sync for 1LDSB

Increase Memory Performance for PGR2

can schedule localread in the front of loop if vgprBuffer = iterations
widely distribute global read and localwrite in the loop with new parameters GRPM, LWPM

New Parameters
GlobalReadPerMfma (range from 0.01 to 5.00)
Example:
2 denotes to 2 globalReadInst per mfma
0.5 denotes to 0.5 globalReadInst per mfma, means 1 globalReadInst per 2 mfma
LocalWritePerMfma (range from 0.01 to 5.00)
Example:
2 denotes to 2 localwrite per mfma
0.5 denotes to 0.5 localwrite per mfma, means 1 localwrite per 2 mfma
