# Cache abbreviations used to compute kernel names

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1984](https://github.com/ROCm/Tensile/pull/1984) · **Merged:** 2024-08-09 · **Author:** @davidd-amd

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

One of the most expensive operations in Tensile is the cost of calling Solution.getNameFull. In part, this function is expensive because we currently map each solution parameter key to an abbreviated name using only the capital letters of the parameter name. This is an O(N) operation and applied to every kernel parameter for every kernel. These abbreviations do not change during runtime, so we are redundantly computing the abbreviations.
In this PR, we compute all possible parameter abbreviations in Common once and use them later. This has a measurable improvement on the turnaround time for TensileCreateLibrary.
