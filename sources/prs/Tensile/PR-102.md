# no NaN propagation when beta==0

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#102](https://github.com/ROCm/Tensile/pull/102) · **Merged:** 2017-08-03 · **Author:** @amcamd

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

Set C <- alpha * A * B when beta == 0. Do not set C <- alpha * A * B + beta * C . This is to conform with the BLAS standard. With this change any NaN values in input C will not propagate to output C when beta == 0.
