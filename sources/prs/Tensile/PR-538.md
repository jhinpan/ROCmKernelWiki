# Drop Python 2 support

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#538](https://github.com/ROCm/Tensile/pull/538) · **Merged:** 2019-05-17 · **Author:** @sdquiring

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'kernel'

## Summary (from upstream PR description)

As we discussed in the Tensile meeting yesterday, some of the failing Jenkins jobs are due to testing both python 2 and 3.  If we drop 2, we can stop it from running on Jenkins and clear up some of the backlog.
There's a parallel PR incoming for rocBLAS which switches the virtual environment created by CMake to a Python 3 based one.
Note that this will intentionally drop support for python 2, there will be syntax errors.  This is intentional in order to prevent any developers from writing code that is incompatible.
