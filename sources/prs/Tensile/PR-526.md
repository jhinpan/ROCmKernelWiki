# Static host code refactor

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#526](https://github.com/ROCm/Tensile/pull/526) · **Merged:** 2019-05-09 · **Author:** @sdquiring

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'gemm'

## Summary (from upstream PR description)

This branch includes:

A new statically built host runtime (under lib) which is under development but which can support SGEMM.

This code uses a YAML-based configuration (generally known as a "kernel library") that replaces the need to generate any host-side code.
There are some additions to the Python code to generate this new configuration file, and to generate code to embed this data into an executable.
Jenkins runs some unit tests on this host library


Python 3 support (thanks Akila)
Adding a Python UnitTests directory (also Akila)
Improved Jenkins integration which includes capturing the test results.

Currently, the new code is not used by default, the older code still works.  The plan is to replace the new code step by step.
Currently this is passing Jenkins:
http://hsautil.amd.com/job/ROCmSoftwarePlatform/job/Tensile/job/static-host-code/
