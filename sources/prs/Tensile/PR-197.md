# fix seemingly random alloc of multiples of 2880*2880*2880 bytes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#197](https://github.com/ROCm/Tensile/pull/197) · **Merged:** 2018-03-29 · **Author:** @zaliu

**Inclusion reason:** kernel path 'Tensile/BenchmarkStructs.py'

## Summary (from upstream PR description)

The seemingly random alloc failure to allocate ~ 286GB was caused by the defaultProblemSizes assuming the default Batched is False.  When Batched is True as specified by the user, and defaultProblemSizes is used, calculation of memory allocation mistook the third dimension as batch index, hence the wrong huge memory size.  One fix is to have a defaultBatchedProblemSizes when Batch is True.
pre-checkin.py passed; nightly.py has no new failures caused by this fix.
