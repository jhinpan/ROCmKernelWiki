# Compiler version dependent capabilities

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#2076](https://github.com/ROCm/Tensile/pull/2076) · **Merged:** 2025-01-07 · **Author:** @davidd-amd

**Inclusion reason:** kernel path 'Tensile/AsmCaps.py'

## Summary (from upstream PR description)

Summary:
On occasion the capabilities cache is out of sync with the test environments used across the different teams. As a result, we can't update tensile to resolve a defect without breaking downstream math ci projects. This change attempts to cope with these environment issues without losing the ability to error out when there is a capability mismatch.
Outcomes:
The AsmCache module is updated to include a function that computes the cache according to the compiler version. Common.py was updated to make use of the new function.
Notable changes:
The added function is called getCapabilitiesCache
Testing and Environment:
Tested using routine CI and local testing.
What testing did you do to ensure this change will integrate successfully?
Using images with clang 18 and clang 19.
