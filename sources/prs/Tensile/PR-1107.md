# Add ContractionProblem properties to compare and hash functions

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1107](https://github.com/ROCm/Tensile/pull/1107) · **Merged:** 2020-07-29 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'Tensile/Source/lib/include/Tensile/ArithmeticUnitTypes.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

Proposed changes:
CachingLibrary caches solutions previously determined for a particular problem, storing them in a table using ContractionProblem objects as a key.
Solutions may be predicated on newly added properties such as KernelLanguage, DeterministicMode and ArithmeticUnitSupport. These properties must be taken into account when hashing and comparing ContractionProblems in the table so that we store and differentiate the correct solution.
This should fix an issue in rocBLAS where turning off atomics mode and then on again could fail to give different solutions when expected.
