## Summary (from upstream PR description)

Due to the very recent introduction of the global parameter "PackBatchDims", the kernel naming was changed to include PBD (among other changes), breaking replacement kernel loading.  This PR restores the loading of the two DGEMM replacement kernels on both gfx906 and gfx908.
