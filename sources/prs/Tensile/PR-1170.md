# Solution fitness metric

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1170](https://github.com/ROCm/Tensile/pull/1170) · **Merged:** 2020-10-15 · **Author:** @JeremyAdamHart

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'; keyword 'gemm'

## Summary (from upstream PR description)

Moved content of findBestSolution functions into findBestSolutionWithFitness, which also returns a value indicating how close the solution is to a pretuned problem size. When the fitness is equal to zero, the problem size has been pretuned for. For the Euclidean Distance selection metric, this is just the euclidean distance. The findBestSolution function now calls findBestSolutionWithFitness and discards the fitness value.
I also added a test to verify that the fitness is 0 for a pretuned size and isn't 0 for a non-pretuned size.
This has been tested on Ubuntu 18.04 with a Radeon VII graphics card.
