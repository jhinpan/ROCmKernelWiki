# Summation dimension mirroring

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#852](https://github.com/ROCm/Tensile/pull/852) · **Merged:** 2020-11-19 · **Author:** @timlathy

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

This is a work-in-progress PR to add two new tensor contraction problem parameters, MirrorDimsA and MirrorDimsB, which accept a list of summation dimension indexes to mirror (i.e. iterate end-to-start).
Fully implemented:

CPU Reference. Tested on one and multiple summation dimensions.

Partially implemented:

Source kernel generation. Supported cases are listed in Tensile/Tests/extended/mirror_dims. Support for pack summation dims, zero padding, certain other configurations is not ready yet.
Assembly kernel generation. Limited to MirrorDimsA for cases with a single summation dimension.

For source kernels, we modify initial global read offsets and increments. For assembly kernels, tile assignment is changed instead.
