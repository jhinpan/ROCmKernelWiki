# Ldd support for GEMM

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#503](https://github.com/ROCm/Tensile/pull/503) · **Merged:** 2019-03-29 · **Author:** @yoichiyoshida

**Inclusion reason:** kernel path 'Tensile/ClientWriter.py'; keyword 'gemm'

## Summary (from upstream PR description)

Add support for defining strides during tuning for GEMM. The new (optional) format for tuning is:

Exact: [ i, j, k, l, ldd, ldc, lda, ldb ], where ldd, ldc, lda, and ldb are optional. If 1 leading dimension is defined, all 4 must be defined.
Range: [ [i], [j], [k], [l], [ldd], [ldc], [lda], [ldb] ], where ldd, ldc, lda, and ldb are optional. If 1 leading dimension is defined, all 4 must be defined.

Due to limitations with the current implementation, the output kernel definitions do not include the strides used for tuning, and still works as previous with kernel selection based solely on m, n and k.
