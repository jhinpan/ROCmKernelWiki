# Small portability changes.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#715](https://github.com/ROCm/Tensile/pull/715) · **Merged:** 2019-11-06 · **Author:** @trey-ornl

**Inclusion reason:** kernel path 'Tensile/Source/lib/CMakeLists.txt'

## Summary (from upstream PR description)

These changes are needed for Tensile to work on my cluster. Tensile requires CMake version 3, but the command cmake points to version 2 on many computers. Changing to cmake3 targets the newer version. Tensile requests a specific version of LLVM, 7.0, which eliminates other working versions, such as the one on my cluster that comes with AOCC, AOCC.LLVM.2.0.0.B191.2019_07_19. Thus I eliminated the requirement for specific version 7.0.
