# Fix multiple Github api calls for integration tests

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1365](https://github.com/ROCm/Tensile/pull/1365) · **Merged:** 2021-06-08 · **Author:** @benjaminulmer

**Inclusion reason:** kernel path 'Tensile/Tests/integration/test_integration.py'

## Summary (from upstream PR description)

Previously, each worker in the integration tests would make an api.github.com call which would occasionally exceed the api rate limit. This PR adds checks to ensure the api call is only made once per test session. This should help mitigate the issue of ever exceeding the rate limit.
Tested locally both with and without multiple test workers (-n 4 and -n 0 when calling pytest).
