# Add gfx900:xnack-, gfx1032, gfx1034, gfx1035

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1595](https://github.com/ROCm/Tensile/pull/1595) · **Merged:** 2022-09-23 · **Author:** @cgmb

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'rope'

## Summary (from upstream PR description)

This change enables Tensile to be built for a few more architectures. None of the architectures being added are relevant to the official binaries distributed by AMD, but they're useful for users building from source. I'd have added gfx1013, gfx1033, and gfx1036 as well, but I'm not sure what names put in the architecture map.
The addition of gfx1031 in #1511 really was a really helpful guide in making this change.


The miscommunication relating to whether gfx900 should be gfx900 or gfx900:xnack- was never properly resolved and so many of the libraries that depend on rocBLAS use gfx900:xnack- in their default configuration.
This change allows both gfx900 and gfx900:xnack- to be accepted by Tensile, thereby allowing users that are building from source to choose whatever they prefer.


This change allows users to build rocBLAS from source for Navi23, Navi24 and Rembrandt.
