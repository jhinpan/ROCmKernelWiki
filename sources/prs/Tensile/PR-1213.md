# PersistentKernel Refine: Support PKn1, EPS, optimize LW-vmcnt, and sMagicDiv2

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1213](https://github.com/ROCm/Tensile/pull/1213) · **Merged:** 2020-12-14 · **Author:** @solaslin

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'kernel'

## Summary (from upstream PR description)

A PKn1 (PK=-1) will determine a better PK value when launching kernel in host:

Automatically choose a "heuristic" value that can possibly get a better gain: (TilesPerWorkgroup = 1~2)
Not based on any theory, but on some experiment observation, can be used to reduce the kernels





PAP: Support EPS=1 , and fix EPS=1 + PLR

Related code modification: BreakAtEvenIter or ExpandPointerSwap





PAP: Optimize some local write waitcnt vmcnt in PreLoop

Related code modification: PreLoopVmcnt





Fix the insufficient precision when using sMagicDiv, add a new sMagicDivAlg2

Related code modification: sMagicDivAlg2, MagicNumber... , MagicShift...
Division is used when we're mapping the PK-WorkGroup to the MacroTile (need quotient and remainder)
For big problems, such as 144000 MTs, doing a division like 143993/144000 gives the quotient = 1, should be zero
