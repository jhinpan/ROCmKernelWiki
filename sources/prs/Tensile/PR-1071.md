# Improve serialization performance.

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1071](https://github.com/ROCm/Tensile/pull/1071) · **Merged:** 2020-07-10 · **Author:** @sdquiring

## Summary (from upstream PR description)

This is branched from #1057.  Once that is merged, the changes here should be reduced.
This improves the library loading times significantly.  On my test machine, the msgpack version of a recent rocBLAS library loads in under 2.5 seconds, the YAML version loads in around 6.5 seconds.
Changes made to improve performance:

Save results of objectToMap() to reduce redundant work.
Merge language and instruction predicates to reduce total object count.
Use unordered versions of containers.
Limit consistency checks to debug mode.
