# LibraryIO.py refactor and tests

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1312](https://github.com/ROCm/Tensile/pull/1312) · **Merged:** 2021-03-25 · **Author:** @benjaminulmer

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'

## Summary (from upstream PR description)

Refactor of LibraryIO.py:

Removed duplicated code
Separated file reading and data parsing into own functions
Renamed functions to be more descriptive and consistent
Better error messages
Oneline docstrings describing use of each function

Basic tests for LibraryIO:

Currently only test parsing of solution and library logic file data
Tests only check that functions execute without fail: no validation of output is currently done
Main purpose for now is to ensure all library logic file types which can be expected to be in rocBLAS---legacy, DeviceEfficiency, and CUEfficiency---are parsable

Potential future expansions:

More in depth testing (ideas on how to best test these functions welcome)
Better parameter and return types for functions

e.g. Custom objects instead of long lists and tuples
Alternatively, simply document expected values of parameters better


Better error reporting mechanism that doesn't requiring passing data/file source into parsing functions
