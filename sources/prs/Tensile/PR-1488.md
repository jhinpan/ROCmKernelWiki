## Summary (from upstream PR description)

Updating HPA types kernel/library logic names:

The name of the following kernels/lib logics changes (HBH->HHS_BH, BBH->BBS_BH. 4xi8BH->4xi8II_BH).
The value_type in the signature of kernels reflects the correct datatype.
BBB+HPA automatically converts to BBS_BH in Tensile, the same as HHH+HPA conversion to HHS_BH.
