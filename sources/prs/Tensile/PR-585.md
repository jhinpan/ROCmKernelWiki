# adding implementation of tile aware selection

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#585](https://github.com/ROCm/Tensile/pull/585) · **Merged:** 2019-07-01 · **Author:** @wbgilmartin

**Inclusion reason:** kernel path 'lib/configs/SolutionLibraries/KernelsTileLite.yaml'; keyword 'gemm'

## Summary (from upstream PR description)

This implements the library part of the tile aware solution selection for tensile.
adds a granularity selection library as an alternative to exact solution lookup along with the yaml serialization.
implements the granularity computation in ContractionSolution::projectedPerformance.
implements a kernel test in RunGEMMKernelTileSelection_test.cpp and KernelsTileLite.yaml however this is disabled do to the fact that we don't have the python part which constructs the library (enabled with cmake)
