# implement General Batch GEMM in Tensile

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1228](https://github.com/ROCm/Tensile/pull/1228) · **Merged:** 2021-01-28 · **Author:** @TonyYHsieh

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.dat.gz'; keyword 'mfma'

## Summary (from upstream PR description)

Tensile only support stride batch GEMM before this changes.
Our user request this feature to accept array of buffer pointer as input to do batched GEMM.
In order to do that and simply how rocblas call Tensile,
we also modify Tensile to accept offset argument and to support ldc!=ldd for all kernel.
We also need change in rocblas due to Tensile API is changed.
