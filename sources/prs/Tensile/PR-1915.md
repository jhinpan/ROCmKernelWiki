## Summary (from upstream PR description)

Add new settings for debugging / profiling stream-k kernels.
DebugStreamKNoFixup generates a kernel with no fixup step.
DebugStreamKNoPartials generates a kernel that never writes partial results to workspace.
Setting TENSILE_DB2=0x2 skips running the stream-k init kernel.
