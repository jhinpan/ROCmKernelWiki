# Support N = 1 for TN and NN kernel

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1136](https://github.com/ROCm/Tensile/pull/1136) · **Merged:** 2020-08-25 · **Author:** @jichangjichang

**Inclusion reason:** kernel path 'HostLibraryTests/configs/SolutionLibraries/KernelsLite.dat.gz'; keyword 'kernel'

## Summary (from upstream PR description)

Original:

min supported free size of a solution is limited by GRVW

Changes:
-min supported free size is limited by GLVW (actual global load vector width)
-min supported free size is limited only when memory of matrix is in free dim continuous.
-Separate the size checking for Free0 and Free1
Benefit:
-TN kernel have on limitation on M or N size
(can support M=1 or N=1 for any grvw )
-NN kernel only has limitation on M size
(can support N=1 for any grvw )
-TT kernel only has limitation on N size
(can support M=1 for any grvw )
