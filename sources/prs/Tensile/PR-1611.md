## Summary (from upstream PR description)

This is the first pass at an updated version of the merge script. I'm opening this up as a draft PR to serve as a forum to discuss design decisions and request features and functionality. The code still needs some cleanup and polish before it should be considered for merging.
Motivation
The current merge script doesn't integrate with Tensile and therefore cannot use its data structures. This makes the merge script lightweight and portable, but heavily limits the types of operations that can be done within. One example of this issue is with solution equality checking which is overly strict and often results in duplicate solutions in the merged logic files.
Features in current version
The base functionality if forked from the current merge script with two major changes

Solution equality checking is done using SolutionStructs instead of simple dictionary comparison.
Support for the new dictionary format logic files in addition to the ordered list format.
