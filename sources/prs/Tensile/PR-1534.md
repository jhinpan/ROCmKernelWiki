# Decision tree based solution selection and library logic

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1534](https://github.com/ROCm/Tensile/pull/1534) · **Merged:** 2022-06-20 · **Author:** @benjaminulmer

## Summary (from upstream PR description)

Context and motivation
There is ongoing research and development (lead by @wbgilmartin) into using decision tree logic for Tensile solution selection. The full context of this project isn't necessary for understanding this PR; the important fact is that we believe this type of solution selection could improve the performance of rocBLAS for "unknown" sizes. Thus, this PR adds support for this type of solution selection so we can develop solution libraries and more rigorously test our hypothesis.
There are two main components to this PR: 1) the host library code additions for supporting a decision tree based solution library; 2) the TensileCreateLibrary support needed to create Tensile master solution libraries of this type based on a new library logic file format.
Host Library Code
We tried to implement this code in a way that closely mirrors the structure and types used for the existing distance based matching.
