## Summary (from upstream PR description)

rocBLAS-internal PR#124 caused none of the replacement kernels to be seen when building the master branch of rocBLAS.  The reason was PR#124 introduced two new kernel name segments DVO0 and SVW4 to the kernel names.  This PR fixes all 14x2 replacement kernels as well as the Tensile unit test checking the presence of one replacement kernel.
