# Remove unused file in cmake interface

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1597](https://github.com/ROCm/Tensile/pull/1597) · **Merged:** 2022-10-03 · **Author:** @JeremyAdamHart

**Inclusion reason:** kernel path 'Tensile/Source/TensileCreateLibrary.cmake'

## Summary (from upstream PR description)

As far as I can tell, TensileCreateLibrary.cmake isn't actually used anywhere, and TensileCreateLibraryFiles in TensileConfig.cmake is the intended method for creating the library. I've removed this file and the relevant include. The Tensile tuning client, HostLibraryTests and rocBLAS are all verified to work correctly with this file removed without any additional changes.
I've also added some documentation for the steps required to build Tensile with cmake to make the process slightly more transparent. It's a little hidden away in TensileConfig.cmake, if there's a more obvious place to put it let me know and I'll move it there instead.
