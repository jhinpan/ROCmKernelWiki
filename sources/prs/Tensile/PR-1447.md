# Added support for multiprocessing on Windows for TensileCreateLibrary

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1447](https://github.com/ROCm/Tensile/pull/1447) · **Merged:** 2021-11-26 · **Author:** @lringham

**Inclusion reason:** kernel path 'Tensile/Parallel.py'

## Summary (from upstream PR description)

Added support for "spawning" processes in Tensile. This was required to parallelise TensileCreateLibrary (and building rocBLAS) on Windows.
Some results for building a single architecture (gfx906:xnack-) with parallel-jobs set to 1 and different parallelization levels:

Windows

1 thread = 1:05:21
48 threads = 19:39


Linux

48 thread  = 18:29



Tests performed:

Linting / unit / client tests on Linux.
hsaco and co files produced on windows are the same before and after the change
