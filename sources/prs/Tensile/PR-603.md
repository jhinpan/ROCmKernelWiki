# integration of LogicFile for tile aware selection

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#603](https://github.com/ROCm/Tensile/pull/603) · **Merged:** 2019-07-25 · **Author:** @wbgilmartin

**Inclusion reason:** kernel path 'Tensile/BenchmarkProblems.py'

## Summary (from upstream PR description)

This work integrates the logic file and tuning workflow into Tensile for creating the library for the tile aware selection.
This is enabled with TileAwareSelection: true defined in the ProblemType definition of the tuning yaml file. (defaults to false).
If enabled the tensile will perform the tuning to determine the ideal performance for the dedicated Summation sizes. Defaults to K = [32,64,96,128,256,512,1024,2048,4096,8192,16192]. This can be overridden with:
BenchmarkFinalParameters:
- SolutionSummationSizes: [ ... ]
