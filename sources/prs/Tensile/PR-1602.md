# Unify SplitGlobalRead into ThreadSeparateGlobalRead and small fixes

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#1602](https://github.com/ROCm/Tensile/pull/1602) · **Merged:** 2022-10-12 · **Author:** @nakajee

**Inclusion reason:** kernel path 'Tensile/Common.py'; keyword 'gemm'

## Summary (from upstream PR description)

Unified SplitGlobalRead into ThreadSeparateGlobalRead and removed SplitGlobalRead
Added support for DirectToLds + hgemm + NN/NT/TT and removed the reject condition
Added support for DirectToLds + hgemm + GlobalLoadVectorWidth < 4 and removed the reject condition
Added support for DirectToLds + zgemm + NumLoadsCoalesced > 1 and removed the reject condition
Added support for DirectToLds + hgemm(TLU=True only) or sgemm + NumLoadsCoalesced > 1 and removed the reject condition
Updated some comment for DirectToLds + x2/x4 load
Fixed mismatch issue with DirectToVgpr + PrefetchGlobalRead=2 + small tile size
Fixed an error with PersistentKernel=0 + PrefetchAcrossPersistent=1 + PrefetchAcrossPersistentMode=1
Fixed mismatch issue with DirectToVgpr + DirectToLds + only 1 iteration in unroll loop case
Fixed a hang issue with PrefetchGlobalRead=2 + no odd exit + only 1 iteration in unroll loop case
Updated sgemm/hgemm test cases for DirectToLds and ThreadSepareteGlobalRead (add more cases, removed xfail)
Moved back dtl_hgemm.yaml and dtl_tsgr_hgemm.yaml from disabled to extended
