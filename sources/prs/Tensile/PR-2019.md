# Cache asm capabilities for reuse

**Repository:** [ROCm/Tensile](https://github.com/ROCm/Tensile) · **PR:** [#2019](https://github.com/ROCm/Tensile/pull/2019) · **Merged:** 2024-09-16 · **Author:** @davidd-amd

**Inclusion reason:** kernel path 'Tensile/Common.py'

## Summary (from upstream PR description)

Summary:
This PR adds an option to populate a yaml file containing the ASM capabilities and if it exists to re-use it.
Outcomes:
For short, iterative work using tensile this can significantly reduce the runtime. Further, when running the precheckin tests (i.e. tox -e ci) with this option enabled the runtime is reduce from 68 minutes to 56 minutes.
Notable changes:
Adds --asm-cache <path to file> to enable caching asm capabilities.
Testing and Environment:
Tested locally in ub22 image. Running CI pipelines.
