# [MoE] Refactor: extract MoE reduction kernel into standalone module with dedicated test

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#113](https://github.com/ROCm/FlyDSL/pull/113) · **Merged:** 2026-03-01 · **Author:** @aoli26

**Inclusion reason:** kernel path 'kernels/moe_gemm_2stage.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Factor out the MoE reduction kernel compile_moe_reduction from the Stage 2 GEMM module into a dedicated file for better maintainability and independent testing.
Technical Details

Extract compile_moe_reduction() from kernels/moe_gemm_2stage.py into new kernels/moe_reduce.py.
Create tests/kernels/test_moe_reduce.py with pytest parametrized tests and a standalone __main__ + argparse entry point (e.g. python test_moe_reduce.py -t 16384 -k 8 -d 7168).
Remove migrated reduction test code from tests/kernels/test_moe_gemm.py.

Test Plan

pytest tests/kernels/test_moe_reduce.py -v — standalone reduce kernel correctness & perf.
pytest tests/kernels/test_moe_gemm.py::test_moe_stage2_standalone -v -s — end-to-end stage2 (atomic / reduce_torch / reduce_flydsl / reduce_flydsl_with_mask) correctness & perf.
