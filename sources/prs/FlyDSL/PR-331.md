# [gfx1250] Unified MXFP8/MXFP4/A8W4 GEMM kernel

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#331](https://github.com/ROCm/FlyDSL/pull/331) · **Merged:** 2026-04-02 · **Author:** @aoli26

**Inclusion reason:** kernel path 'kernels/gemm_common_gfx1250.py'; keyword 'wmma'

## Summary (from upstream PR description)

Motivation
The gfx1250 GEMM kernels previously had separate implementations for MXFP4 (mxfp4_gemm_gfx1250.py) and MXFP8
(mxfp8_gemm_gfx1250.py), leading to significant code duplication. This PR unifies them into a single kernel supporting FP4, FP8, and add A8W4 (FP8 activation + FP4 weight) data formats support. It also enables LLVM Expert Scheduling Mode 2 by default to eliminate false-positive hardware dependency stalls in the WMMA pipeline.
Technical Details

Unified kernel (kernels/gemm_fp8fp4_gfx1250.py): single compile_mxscale_gemm() entry point with data_format parameter ("fp4", "fp8", "a8w4"), replacing the deleted mxfp4_gemm_gfx1250.py and mxfp8_gemm_gfx1250.py.
Shared utilities (kernels/gemm_common_gfx1250.py): extracted common LDS load/store helpers, pipeline fencing, and
accumulator store routines used by both fp16 and mxscale GEMM kernels.
TDM descriptor advance (tdm_ops.advance_tdm_descriptor()): enables in-place K-dimension advancement of TDM descriptors within the main loop by extracting, offsetting, and re-packing the 64-bit global address in DGROUP0[2:3], avoiding full descriptor reconstruction per iteration.
