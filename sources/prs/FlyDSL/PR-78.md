# Fix Python compatibility and remove hardcoded paths

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#78](https://github.com/ROCm/FlyDSL/pull/78) · **Merged:** 2026-02-02 · **Author:** @jli-melchior

**Inclusion reason:** kernel path 'python/flydsl/compiler/executor.py'; keyword 'kernel'

## Summary (from upstream PR description)

Fix Python version compatibility in meta.py: add support for Python < 3.11 by checking for positions attribute availability
Replace hardcoded MLIR library paths in executor.py with environment variable MLIR_PATH, with clear error message when not set
Update LLVM commit hash and enable ROCM runner in build script

Motivation
This commit addresses two critical issues:

Python version compatibility issue: The original code used the frameInfo.positions attribute introduced in Python 3.11+, causing AttributeError when running on earlier Python versions
Hardcoded path issue: The executor.py had hardcoded MLIR library paths (/root/Projects/llvm-project/build/lib/), preventing the code from running in different environments

These issues hindered the project's portability and usability across different environments and Python versions.
Technical Details
1. Python version compatibility fix (python/flydsl/lang/meta.py)

Added hasattr() check to determine if frameInfo has the positions attribute
For Python 3.11+, use frameInfo.positions.lineno and frameInfo.positions.col_offset
For earlier versions, fall back to frameInfo.lineno and set col_offset = 0

2. Environment variable-driven path conf
