# [Fix][JIT] correctly distinguish Type[...] params in cache key

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#293](https://github.com/ROCm/FlyDSL/pull/293) · **Merged:** 2026-03-26 · **Author:** @sjfeng1999

**Inclusion reason:** kernel path 'python/flydsl/compiler/jit_argument.py'

## Summary (from upstream PR description)

Two issues fixed:


_is_type_param_annotation failed on Python 3.12 because get_origin(Type[X]) returns the builtin type, not typing.Type. Added origin is type check.


_make_cache_key had no special handling for Type[...] params, causing different types (e.g. Float32 vs Float16) to produce identical cache keys and hit the same compiled artifact. Now records the actual class in the key, matching Constexpr behavior.
