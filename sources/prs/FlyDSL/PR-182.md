# Add date-based versioning for nightly and dev release wheels

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#182](https://github.com/ROCm/FlyDSL/pull/182) · **Merged:** 2026-03-10 · **Author:** @kiran-thumma

**Inclusion reason:** kernel path 'setup.py'; keyword 'lds'

## Summary (from upstream PR description)

Motivation
The current nightly wheel names use .dev{commit_count} (e.g., flydsl-0.1.0.dev3522142) for all build types, making it impossible to distinguish nightlies from dev releases by version string alone. This PR adds a date stamp (YYYYMMDD) to wheel names and differentiates the version format based on the release type, improving traceability and compliance with PEP 440 semantics.
Technical Details
Introduces a FLYDSL_RELEASE_TYPE environment variable that controls the wheel version format:



Release type
Version format
Example




nightlies
{base}+{YYYYMMDD}.{git_hash}

0.1.0.dev20260309+a1b2c3d

{base}
0.1.0


(unset)
{base}.dev{commit_count}
0.1.0.dev3522142 (unchanged)
