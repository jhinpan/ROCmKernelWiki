## Summary (from upstream PR description)

Summary

Replace direct arith/vector value manipulation in RDNA f16 and fp8 GEMM kernels with FlyDSL internal fx.Vector / numeric wrappers.
Move RDNA f16 LDS accesses to a vector-typed SmemPtr path so the kernel no longer directly uses vector helpers.
Keep the PR scoped to RDNA GEMM files only; unrelated kernels/preshuffle_gemm.py working-tree changes are not included.
