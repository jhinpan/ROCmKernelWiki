**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#225](https://github.com/ROCm/FlyDSL/pull/225) · **Merged:** 2026-04-01 · **Author:** @yanguahe

## Summary (from upstream PR description)

Motivation
Add a high-performance Flash Multi-Head Attention (FMHA) forward kernel to FlyDSL, targeting AMD Instinct GPUs (MI308X / MI325X / MI350X / MI355X). This kernel is written in FlyDSL's Python DSL and compiled through the MLIR/LLVM pipeline, providing a pure-compiler alternative to hand-written assembly (aiter_asm) kernels.
Key goals:

Provide a maintainable, DSL-based FMHA implementation that can match or exceed aiter_ck (Composable Kernel) library performance
Support both bf16 and fp16 data types
Support both causal and non-causal attention modes
Target multiple AMD GPU architectures: gfx942 (MI308X, MI325X) and gfx950 (MI350X, MI355X)

Technical Details
Kernel Architecture

Tile sizes: BLOCK_M=256, BLOCK_N=64, head_dim=128
MFMA instructions: mfma_f32_32x32x8f16 for GEMM operations
Memory pipeline: DMA-based K double-buffer with V DMA and XOR swizzle for LDS bank conflict avoidance
Causal masking: Tile-level skip via scf.IfOp to avoid unnecessary computation on fully-masked tiles
Numerical options: DAZ (Denormals-Are-Zero), configurable waves_per_eu and flat_work_group_size

Platform-Specific Optimizations

gfx950 (MI350X/MI355X): MaxNumFOp fastmath flag, bf16_trunc_pack
