# [Compiler][Kernel][MI450]Rebase gfx1250 WMMA/mcast/mxfp4 support onto main

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#278](https://github.com/ROCm/FlyDSL/pull/278) · **Merged:** 2026-03-30 · **Author:** @jli-melchior

**Inclusion reason:** kernel path 'kernels/mxfp4_gemm_gfx1250.py'; keyword 'wmma'

## Summary (from upstream PR description)

Motivation
Rebase the pr/v0.1_gfx12 branch onto latest main to bring gfx1250 (MI450) kernel support up-to-date with main's infrastructure changes (new MmaAtomTypeInterface, RDNA4 support, updated ROCDL wrappers, etc.). This consolidates 87 earlier commits into a single
squash commit and preserves the 8 recent feature commits with original authorship.
Technical Details
gfx1250 WMMA GEMM kernels:

Add wmma_gemm_gfx1250.py — f16/bf16/fp8 WMMA GEMM kernel with TDM async copy and multi-stage pipeline
Add wmma_gemm_simple.py — minimal WMMA GEMM for validation
Add mxfp4_gemm_gfx1250.py — MXFP4 (FP4+blockscale) GEMM using WMMA_SCALE instructions
Scale preshuffle optimization for mxfp4 to reduce k-subtile permute overhead

Multicast (mcast) support:

Extend gpu.LaunchFuncOp with cluster_size for workgroup clustering
Add s_set_pc_from_buffer and mcast-related ROCDL wrappers
Add mcast unit tests

ROCDL / dialect extensions:

Add MmaAtomGFX1250_WMMAType with full MmaAtomTypeInterface implementation (getValTypeA/B/C/D, getThrValLayoutA/B/C, etc.)
Add WMMA wrapper functions: wmma_f32_16x16x16_f16, fp8 variants, OPSEL/IU variants
Add wmma_scale_f32_16x16x128_f8f6f4 and wmma_scale_f32_32x16x128_f4
