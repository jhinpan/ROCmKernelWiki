# prune(capi): remove FlyROCDL type wrappers, bind C++ directly

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#313](https://github.com/ROCm/FlyDSL/pull/313) · **Merged:** 2026-03-31 · **Author:** @sjfeng1999

**Inclusion reason:** keyword 'mfma'

## Summary (from upstream PR description)

The FlyROCDL CAPI layer had redundant isa/constructor/accessor functions for MmaAtomCDNA3_MFMA, MmaAtomGFX1250_WMMA, and CopyOpCDNA3BufferCopy types that merely forwarded to C++ methods. The Python bindings for CDNA3 and CopyOp types already bypassed this layer via FLYDSL_REGISTER_TYPE_BINDING; only GFX1250_WMMA still went through CAPI.
Align FlyROCDLDialect.h with the minimal FlyDialect.h pattern (dialect registration + pass registration only) and convert PyMmaAtomGFX1250_WMMAType to use the same direct C++ binding style as every other FlyDSL type.
