# [Tool][fly-opt] Add fly-opt tool and lit-based test suite

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#152](https://github.com/ROCm/FlyDSL/pull/152) · **Merged:** 2026-03-01 · **Author:** @jli-melchior

**Inclusion reason:** kernel path 'test/lit.cfg.py'

## Summary (from upstream PR description)

Motivation
The project lacks a fly-opt tool and a standardized lit-based test suite to perform and verify IR transformations on the Fly dialect.
Technical Details

fly-opt tool (tools/fly-opt/): A command-line driver similar to mlir-opt that registers FlyDialect, FlyROCDLDialect, and all custom passes (fly-canonicalize, fly-layout-lowering, convert-fly-to-rocdl), using MlirOptMain to drive IR transformations.
lit test framework (test/lit.cfg.py): Configures fly-opt and FileCheck paths, supports SHOW_IR environment variable and --param show-ir for inspecting intermediate IR output during test runs.
Bug fix (Passes.td): Added arith::ArithDialect and LLVM::LLVMDialect as dependentDialects for FlyLayoutLoweringPass, fixing crashes when the lowering creates arith.constant or LLVM::LLVMStructType without these dialects being registered.
Test suite (15 .mlir files):

test/LayoutAlgebra/: Type inference verification for layout construction, size/cosize, coordinate, composition, product, divide, and int_tuple operations.
test/Transforms/: Covers fly-canonicalize and fly-layout-lowering passes with 14 lowering patterns (extractors, scalars, compute ops, int_tuple binary ops, layout algebra).
