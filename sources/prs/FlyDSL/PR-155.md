## Summary (from upstream PR description)

Summary

Add tests/python/examples/aot_example.py: a standalone script that pre-compiles MOE GEMM kernels (stage1 + stage2) into the FLIR FileCache
Supports fp8 and int8 dtypes, benchmark shapes from run_benchmark.sh
--run_kernel option to verify compiled kernels actually execute on GPU
--test_bad_tile option to verify invalid tile sizes are properly rejected
Works with FLIR_CACHE_DIR / COMPILE_ONLY / ARCH env vars for cross-compilation workflows

Test plan

 --preset small --in_dtype both --run_kernel passes (fp8 + int8, GPU execution verified)
 --test_bad_tile correctly rejects tile_k=17 with clear error message
 Cache artifacts written to FLIR_CACHE_DIR
 Subsequent test_moe_gemm.py runs with same cache dir hit cache (no recompilation)
