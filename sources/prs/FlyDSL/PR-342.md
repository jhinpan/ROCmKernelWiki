# [FEAT] Add math dialect DSL wrappers

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#342](https://github.com/ROCm/FlyDSL/pull/342) · **Merged:** 2026-04-03 · **Author:** @jli-melchior

**Inclusion reason:** kernel path 'python/flydsl/expr/__init__.py'; keyword 'rope'

## Summary (from upstream PR description)

Motivation
Previously no math API existed in FlyDSL — users had to call raw MLIR bindings directly (e.g. _mlir_math.exp(val)). This brings math ops to the same level as arith with @traced_op traced locations and DSL Numeric type auto-unwrap.
Summary

Add flydsl.expr.math module with @_traced_math_op wrappers for 46 MLIR math dialect ops:

30 unary float ops (exp, log, sqrt, trig, rounding, erf, etc.)
4 unary integer ops (absi, ctlz, cttz, ctpop)
5 binary ops (powf, fpowi, ipowi, atan2, copysign)
2 ternary ops (fma, clampf)
4 predicate ops (isnan, isinf, isfinite, isnormal)
1 multi-result op (sincos)


Register math submodule in flydsl.expr.__init__ for from flydsl.expr import math
DSL Numeric types (Float32, Int32) auto-unwrap via _to_raw()
Class invariance: _traced_math_op preserves Numeric type hierarchy — Float32 in → Float32 out, Int32 in → Int32 out, predicates → Boolean, raw ir.Value passthrough unchanged
fastmath= attribute propagation on all float ops

Test plan

 47 wrapper identity tests (verify wrapping overrides raw MLIR)
 34 IR generation tests (unary float, unary int, binary, ternary, predicate, sincos)
 3 DSL Numeric unwrap tests (Float32, Int32, mixed)
 7 class inva
