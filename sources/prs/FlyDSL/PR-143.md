## Summary (from upstream PR description)

Motivation
Add W4A16 (int4_bf16), pure bf16, and fp8_bf16 (fp8 weight + bf16 activation) support to the MoE 2-stage GEMM kernels. These new dtype paths enable:


W4A16 (int4_bf16): 4-bit weight quantization with bf16 activations and optional per-group (group_size=32) scale dequantization — significantly reduces weight memory footprint while maintaining bf16 compute precision.


bf16: Pure bfloat16 activations and weights, useful as a stage2 compute path in hybrid configurations (e.g., stage1 W4A16 + stage2 bf16).


fp8_bf16: fp8 per-channel quantized weights cast back to bf16 with epilogue scale — simulates fp8 weight storage with bf16 compute.


Technical Details


W4A16/bf16/fp8_bf16 MoE support — Main feature commit
