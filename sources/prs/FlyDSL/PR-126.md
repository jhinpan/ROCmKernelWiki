# [Test] Test both atomic and reduce modes of MoE by default

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#126](https://github.com/ROCm/FlyDSL/pull/126) · **Merged:** 2026-02-12 · **Author:** @aoli26

**Inclusion reason:** kernel path 'kernels/moe_gemm_2stage.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
The CLI main entry (python test_moe_gemm.py) only ran atomic mode by default. This left a coverage gap for the reduce path.
Technical Details

Replaced the boolean --reduce flag with a --gemm2_mode {both,atomic,reduce} option (default: both).
When --gemm2_mode both, the main loop iterates over atomic and reduce in sequence.
Single-mode runs (--gemm2_mode atomic / --gemm2_mode reduce) still work as before.
