# [MoE] simplify moe reduce kernel & add zero buffer flag

**Repository:** [ROCm/FlyDSL](https://github.com/ROCm/FlyDSL) · **PR:** [#129](https://github.com/ROCm/FlyDSL/pull/129) · **Merged:** 2026-02-19 · **Author:** @aoli26

**Inclusion reason:** kernel path 'kernels/moe_gemm_2stage.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
When all output slots are guaranteed valid, the MoE GEMM2 reduce path always zero intermediate buffer is unnecessary overhead. Also cleaned up the reduction kernel code.
Technical Details


zero_intermediate parameter: Added to _MoeGemm2ReduceWrapper and compile_moe_gemm2_ex. Defaults to True. When set to False, skips intermediate.zero_() — safe when the kernel writes every slot.


Simplify reduction kernel:

Replaced manual scf.IfOp + InsertionPoint + YieldOp with plain Python if.
Removed redundant ArithValue() and .value.
