## Summary (from upstream PR description)

Proposed changes
Problem: the result of get_warp_size() is incorrect in host side if GPU is RDNA. but get_warp_size() is widely used in both host and device code. it causes

result is incorrect in host side (e.g. shuffle b)
symbol name mismatch between host code and device code.
Proposal:
Remove template parameter dependent on warp size.
a) Remove max block size in make_kernel
b) Remove blocksize in CShuffleEpilogueProblem
Add function is_wave32() in host side, and use it to adjust the value depend on target GPU

please refer universal-gemm as an example


Ignore redundant parameter
in TileImageToColumnShape, both ThreadTile and WarpTile are defined as template parameter, it causes warp size is implicit defined, in this PR, the last element in WarpTile is ignored.
