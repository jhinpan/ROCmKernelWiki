# Implementing Test Filters for Smoke and Regression Tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1819](https://github.com/ROCm/composable_kernel/pull/1819) · **Merged:** 2025-01-17 · **Author:** @AviralGoelAMD

**Inclusion reason:** keyword 'rope'

## Summary (from upstream PR description)

Title
Test filters for only running subsets of ALL the available tests.
Problem Statement
Developers working with the repository may not always want to run all the available tests. There are tests which complete in a fraction of a second and also tests that takes several minutes. Sometimes only running shorter duration tests may be needed or vice versa.
Solution
We use CMake's Ctest's label property to label every test as either smoke test or regression test depending on the time they take to run which is less than 30 second or more for respective label.
We bind a custom target to run the tests with either smoke or regression label.
make smoke # runs quicker tests
make regression # runs slower tests
Proposed Changes
This change aims to improve the testing workflow by allowing developers to run specific subsets of tests based on their duration.
Two new test filters have been implemented to provide a convenient way to run tests and examples:


Regression Tests: Tests that run for more than 30 seconds are labeled as regression tests.

Run with: make -j regression



Smoke Tests: Tests that run for 30 seconds or less are labeled as smoke tests.

Run with: make -j smoke
