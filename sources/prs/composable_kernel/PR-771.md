# Batchnorm splitk single kernel

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#771](https://github.com/ROCm/composable_kernel/pull/771) · **Merged:** 2023-07-06 · **Author:** @qianfengz

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

This is an implementation of the BatchNorm Forward Multiblock using single kernel, which obsoletes the existing implementation of BatchNorm Forward Multiblock using two-layer kernels. In the implementation

The per-workgroup reduced mean/variance/count data are stored to the workspace using GLC enabled writing (to disable L1 cache) so that consistent data can be shared across workgroups
The multiple workgroups in one reduction group are synchronized (barrier) to ensure all the reduced output of these workgroups are readable from the workspace before second-half reduction
The second-half reduction is completely the same as two-layer kernel implementation
Performance can be improved on both MI200 and MI100 using the single-kernel method

The implementation provides a good example of using cross-workgroup synchronization to simplify the kernel implementation and/or improving operator performance
