## Summary (from upstream PR description)

Proposed changes
This PR has fix and improved the gemm quant pipeline infrastructure with the 3 following aspects:

Fix the dram reading of bquant with the correct sequence aligned with b matrix with the column major pattern
Improve the base pipeline structure and increase the performance for the base pipeline comp v3 for quant gemm.
Improve the instruction use case of the new compiler "and_or" mechanism on using the bit operator instead of the builtin instruction.
