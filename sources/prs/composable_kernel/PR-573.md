## Summary (from upstream PR description)

Due to request from customers, this kernel didn't work when N > 4096.
I have added instances for elementwise normalization to enable kernel when N is large (>4096 ).
When M = 4096 and N =8192, bandwidth now  can reach 993.019GB/s.
Performance time can be 0.188849 ms
