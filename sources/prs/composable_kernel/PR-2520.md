# [CK_TILE] Introduces a new GEMM API that splits the existing basic GEMM class into multiple specialized classes.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2520](https://github.com/ROCm/composable_kernel/pull/2520) · **Merged:** 2025-07-24 · **Author:** @mozga-amd

**Inclusion reason:** kernel path 'example/ck_tile/03_gemm/gemm_basic.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

New GEMM API designed to decompose the existing basic GEMM class into separate, modular classes.

The first will be a basic version, accepting parameters (a, b) as scalars.
The second implements (a, b) and introduces an additional parameter (d) for multi-instance support.
The third implements (a, b, d) for handling multi-value computations.
