# Introduce tree reduction for BlockReduce2dCrossWarpSync

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2588](https://github.com/ROCm/composable_kernel/pull/2588) · **Merged:** 2025-10-22 · **Author:** @MHYangAMD

## Summary (from upstream PR description)

Proposed changes
As @ruanjm's suggestion, tree reduction would provide more precise results.
We introduce a tree reduction version for BlockReduce2dCrossWarpSync.
We also conducted experiments for bencmarking.
All experiments are warmup for 1000 times and repeated for 10000 times.
The results show tree reduction performs on par with sequential reduction. Also, VGPRs usage are almost the same.
