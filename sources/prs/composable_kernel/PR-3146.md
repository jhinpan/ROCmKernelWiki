# [CK_TILE] Move DataTypeTraits into a Common File

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3146](https://github.com/ROCm/composable_kernel/pull/3146) · **Merged:** 2025-11-27 · **Author:** @arai713

**Inclusion reason:** kernel path 'example/ck_tile/03_gemm/gemm_splitk_two_stage_reduce.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

In CK Tile, DataTypeTraits is used to print out the datatype name when given a datatype in examples and test files.
template <typename T>
struct DataTypeTraits;

template <>
struct DataTypeTraits<float>
{
    static constexpr const char* name = "fp32";
};

template <>
struct DataTypeTraits<ck_tile::half_t>
{
    static constexpr const char* name = "fp16";
};

There is duplication of the DataTypeTraits struct across CK Tile. This PR renames typeToStr in the common utility file (include/ck_tile/ops/common/utils.hpp) to DataTypeTraits and removes all duplication of DataTypeTraits .
Upon testing the changed examples/tests, there were a few CK Tile examples that did not compile or validate, some of which have been mentioned here. A separate ticket will be opened for these.
