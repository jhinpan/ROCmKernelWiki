## Summary (from upstream PR description)

Proposed changes
In toy add example, we compare the add kernel performance between ck_tile and babelstream.
Babelstream (w/ non-temporal memory access): ~4300 TFlops on MI300X.
ck_tile (w/o non-temporal memory acees): ~3700 TFlops.
ck_tile (w non-temporal memory acees): ~4200 TFlops.
To make buffer coherence adjustable from users, we propose this change.
