# [CK_TILE] Migrate CK Tile examples to Tests to autorun on CI

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2421](https://github.com/ROCm/composable_kernel/pull/2421) · **Merged:** 2025-07-22 · **Author:** @CongMa13

**Inclusion reason:** kernel path 'test/ck_tile/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
There are lots of examples in example/ck_tile folder. However, there are some problems with them.

These examples are used as both examples and smoke tests of ck tile.
These examples (smoke tests) are not built by CI. Without the CI check, some ck tile PRs were merged into develop even these tests failed.

In this PR,

we migrated the existing smoke tests from example/ck_tile to test/ck_tile
These migrated tests will be built and run by CI.
example/ck_tile was not changed even though it should only contain examples.

The migrated smoke tests in this PR are:

./02_layernorm2d/script/smoke_test.sh
./03_gemm/script/smoke_test_basic.sh
./03_gemm/script/smoke_test_mem_pipeline.sh
./09_topk_softmax/script/smoke_test.sh
./11_add_rmsnorm2d_rdquant/script/smoke_test.sh

Checklist

 I have added tests relevant to the introduced functionality, and the unit tests are passing locally
 I have added the test to REGRESSION_TESTS list defined at the top of CMakeLists.txt in tests/CMakeLists.txt, IF the test takes more than 30 seconds to run.
 I have added inline documentation which enables the maintainers with understanding the motivation
