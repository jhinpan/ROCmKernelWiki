# [CK_BUILDER] Add Description::instance_string() method and update tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3340](https://github.com/ROCm/composable_kernel/pull/3340) · **Merged:** 2025-12-03 · **Author:** @shumway

**Inclusion reason:** kernel path 'experimental/builder/include/ck_tile/builder/reflect/README.md'; keyword 'wmma'

## Summary (from upstream PR description)

This PR updates the reflection feature in CK Builder to put more functionality in the Description class.
The original design we had was to expose the kernel's instance string through a virtual method GetInstanceString.  We want to migrate to using a describe() virtual method on the device op that returns a Description object. The Description object  has a method Description::instance_string(), but also has more insightful methods like Description::detailed() that returns a tree view of kernel features and settings.
This PR implements the Description::instance_string() function and tests it. These tests also document that only our XDL convolutions kernels currently have the ckr::describe<Instance>() factory implemented for Description objects, so we document that and add TODO comments.
Code is tested with refactored and extended instances tests, which are in the regression suite because they take longer to compile. After this PR we can implement the virtual describe() method on our device ops.
