# Modularize ckProfiler operations

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#514](https://github.com/ROCm/composable_kernel/pull/514) · **Merged:** 2022-12-01 · **Author:** @poyenc

**Inclusion reason:** kernel path 'profiler/include/profiler/profile_batched_gemm_add_relu_gemm_add_impl.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Current ckProfiler design enforce us spreading duplicated information (e.g. function declaration, operation description) across many source files. It's error-prone to add new operation, and is build-time-consuming if users only care about few of the operations.
By modularizing the operations, users can simply add/remove corresponding lines in CMakeLists.txt without touching C++ source files, to get a customized profiler.
This PR include following works:

Move headers under profiler/include into profiler/include/profiler (avoid adding profiler itself as an include directory, make include directives more consistent)
Introduce ProfilerOperationRegistry (Meyers Singleton Pattern) to break dependency (from profiler.cpp to other profile_*.cpp)

NOTICE
This PR requires merging PR #516 upfront
