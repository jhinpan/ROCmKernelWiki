# Fused elementwise layernorm

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#468](https://github.com/ROCm/composable_kernel/pull/468) · **Merged:** 2022-10-25 · **Author:** @guangzlu

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

Fused elementwise and normalization, which maybe a key module in some AI modules. (Such as add+layernorm is a key module in transformer)
Y = normalize(elementwise(A,B,...), gamma, beta)
Input matrixes have been made into tuple type.
Optimization in PR#453 had been taken.
Writing and reading of Intermediate results had been reduced.
The performance has improved much compared with my former code in PR#452 , as the table below shows. Tests were done with Rocm5.2.3 on 1 die of MI250.
Current elapse time is the running time need with kernel in this PR , former elapse time is time need  with kernel in PR#452 , unfused elapse time is time need when doing add and layernorm with ck separately.
