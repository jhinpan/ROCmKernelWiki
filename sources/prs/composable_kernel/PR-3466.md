# [CK grouped gemm] Fix grouped gemm two stage HasMainK0BlockLoop

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3466](https://github.com/ROCm/composable_kernel/pull/3466) · **Merged:** 2025-12-23 · **Author:** @johannes-graner

## Summary (from upstream PR description)

Proposed changes
The two stage grouped gemm kernel passed K0*K1 to the gridwise gemm's CalculateHasMainK0BlockLoop function, which expects to only take K0. This fixed numerical issues due to running the loop one more time than correct for shapes in the profile_grouped_gemm.sh test.
This led to some cases where runtime errors were thrown due to some gemms in the group having a k0block_loop and others not having it. This check was added to IsSupportedArgument since it's better to gracefully decline to run than to run and throw errors.
