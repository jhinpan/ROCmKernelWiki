# Add a daily CI stage to test AITER with latest CK.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2598](https://github.com/ROCm/composable_kernel/pull/2598) · **Merged:** 2025-08-01 · **Author:** @illsilin

## Summary (from upstream PR description)

Proposed changes
This adds a new stage in one of daily builds that will run AITER tests with latest CK develop branch.
We pull the latest rocm/pytorch docker image, install the AITER and CK develop branches in it, then execute the tests.
Currently only enabled 1 test on gfx90a nodes. Once we get the gfx942 ci nodes, we'll enable more tests on those.
The main challenge is to install all the necessary packages, add the necessary groups and set the permissions in order to be able to run the tests. This PR takes care of these things.
