# Add 'Permute' device op & example

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#408](https://github.com/ROCm/composable_kernel/pull/408) · **Merged:** 2022-09-20 · **Author:** @poyenc

**Inclusion reason:** kernel path 'example/39_permute/run_permute_bundle_example.inc'; keyword 'kernel'

## Summary (from upstream PR description)

The DevicePermute handles tensor transpose problems like: [N1, N2, ..., NN, H, W] -> [N1, N2, ..., NN, W, H] (swap last 2 dimensions). See steps below:

Merge leading dimensions [(N1 x N2 x ... x NN), H, W] -> [(N1 x N2 x ... x NN), W, H]
Repeat ceil(N1 x N2 x ... x NN) / NPerBlock) times, transpose each slice [NPerBlock , H, W] into [NPerBlock , W, H]
