# Replace buffer load/store intrinsics with builtins

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1876](https://github.com/ROCm/composable_kernel/pull/1876) · **Merged:** 2025-03-05 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck_tile/core.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
The names of the buffer load/store intrinsics are going to change in the future compiler versions, starting with Clang20. One way to avoid compilation errors is to switch from intrinsics to built-ins. Unfortunately, it doesn't look like built-ins available for every intrinsic we use.
I was able to apply the changes to old ck, but not for ck_tile. In ck_tile I just added an alternative header with updated intrinsics names.
I've tested these changes with the Clang20 compiler and made sure that the code builds and the unit tests are passing.
