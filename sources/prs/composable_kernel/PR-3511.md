**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3511](https://github.com/ROCm/composable_kernel/pull/3511) · **Merged:** 2026-01-06 · **Author:** @Snektron

## Summary (from upstream PR description)

Proposed changes
This PR adds the remaining glue logic for implementing the GPU reference algorithm (#3381) with the CK-Builder testing framework (#3471, #3267). It also contains a few small fixes and improvements, but in general the changes are straight forward. It implements the first end-to-end test too!
Design
The design is quite straight forward, it basically fills in the setup made in #3471 and #3267 with the details of #3381.
Implementation
A few things worth noting:

The reference implementation is currently not exactly invoked like an old CK implementation, so I wrote a separate ckt::run() overload.
In order to tell the instance apart I wrote some quick helper concepts, CkConvInstance and RefConvInstance. They match on the MakeArgument/MakeArgumentPointer functions. I think that in the future we might want to replace this with something based on the new description types, but for now this should be fine.
As the reference conv is missing some functionality, ckt::run() checks and throws in the reference conv. As time goes on we will probably want to expand the supported feature set, but its fine for an initial test.
