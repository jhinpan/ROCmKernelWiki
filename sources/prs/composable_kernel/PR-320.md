**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#320](https://github.com/ROCm/composable_kernel/pull/320) · **Merged:** 2022-08-15 · **Author:** @qianfengz

## Summary (from upstream PR description)

The P.R provides

Generic multiple reduction kernel and device interface,  which is able to do multiple reductions from single input data
Examples to calculate mean and mean_square using single multiple reduction kernel
Generic element-wise kernel and device interface, which is able to do element-wise operation with any number of inputs and outputs
Examples to implement batchnorm-forward and batchnorm-infer using generic kernels.


The batchnorm-forward can be implemented using two kernel calls when updateMovingMean/Variance and saveResultMean/InvVariance are not required
The batchnorm-forward can be implemented using three kerne calls when either or both of updateMovingMean/Variance  or/and saveResultMean/InvVariance are required
