# feat(tile_window): print content of tile window for easier debugging

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2827](https://github.com/ROCm/composable_kernel/pull/2827) · **Merged:** 2025-09-16 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'include/ck_tile/core/tensor/tile_window.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

This PR adds a function print_tile_window_range() in/for tile_window_with_static_lengths that will let the kernel developer print contents of the tile window provided a range [start_row, end_row) and [start_col, end_col).
This makes it easier to print the contents of a tile window when debugging kernels.
This function might need further improvement in the future to make it more generalized to ALL supported datatypes. Currently, It has only been tested on fp16 and the developer will need to make adjustments inside the function if custom data types such as pk_int4_t, int4, int8, etc. are used.
