# Add a flag to enable/disable debug output in many kernels.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#549](https://github.com/ROCm/composable_kernel/pull/549) · **Merged:** 2023-01-12 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/impl/device_batched_gemm_multiple_d_gemm_multiple_d_xdl_cshuffle.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

We had about a dozen kernels that had some debug output, mostly commented out with "#if 0" conditions, but sometimes it was enabled and annoying some of the customers.
I have introduced a DEBUG_LOG macro in ck.hpp header and tried to catch every instance of the output and disable it by default with the DEBUG_LOG set to 0.
