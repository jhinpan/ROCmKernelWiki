# Build codegen as standalone

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1556](https://github.com/ROCm/composable_kernel/pull/1556) · **Merged:** 2024-10-15 · **Author:** @pfultz2

**Inclusion reason:** kernel path 'codegen/test/rtc/include/rtc/compile_kernel.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

Refactor codegen to be built standalone for now. In MIGraphX, we only want the codegen library built and nothing from the ck library. This also makes it easier for developement since ck library is a little complicated to build. A Job needs to be added to jenkins to build and run the tests:
mkdir build
cd build
CXX=/opt/rocm/llvm/bin/clang++ cmake ../codegen
make -j$(nproc) check
