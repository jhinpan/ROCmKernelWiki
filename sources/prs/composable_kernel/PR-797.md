**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#797](https://github.com/ROCm/composable_kernel/pull/797) · **Merged:** 2023-08-10 · **Author:** @rocking5566

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Forward of average pool is similar to depthwise conv, but all the weight are 1 / XY.
Therefore, backward of avgpool is also similar to conv backward data.
This PR imitate the implementation of conv bwd data, but replace gemm with reduce sum.
