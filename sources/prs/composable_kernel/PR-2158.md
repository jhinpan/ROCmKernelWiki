# [CK_TILE] Add type traits to detect tile window types at compile time

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2158](https://github.com/ROCm/composable_kernel/pull/2158) · **Merged:** 2025-05-07 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'include/ck_tile/core/tensor/tile_window.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
Motivation: In scenarios like CompV4 policy, tile_window_linear is not compatible with LDS swizzle BlockDescriptor. This PR gives programmer a way to check at compile time what tile_window is being manipulated.
This PR adds compile-time type traits to detect specific tile_window variants in CK Tile, including:
tile_window_with_static_distribution

tile_window_with_static_lengths

tile_window_linear

All traits default to false_type and specialize to true_type for valid tile window types.
Added Doxygen-style documentation for all traits.
Example Usage
static_assert(is_tile_window_with_static_distribution_v<decltype(window)>);
