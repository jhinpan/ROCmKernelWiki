**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2963](https://github.com/ROCm/composable_kernel/pull/2963) · **Merged:** 2025-10-30 · **Author:** @SamiAario-AMD

## Summary (from upstream PR description)

Proposed changes
This PR implements and tests fixed precision fp8 x bf8. I discovered early on that fp8 x bf8 does not work on the V3 pipeline, but it does work on V4. Investigation into getting it to work on V3 is on a separate feature branch. For this PR, I added the test for fp8 x bf8, converted all the GEMM tests to use gtest, added testing of V4 for the universal GEMMs, and marked the failing V3 fp8 x bf8 test to be skipped. This way, we have a working implementation of fp8 x bf8 and a unit test for it.
I also added fp8 x bf8 and tests for the weight preshuffle GEMM as a POC/sanity check, but this can be omitted from this PR if necessary.
Lastly, the PR also contains minor code cleanup.
