## Summary (from upstream PR description)

Proposed changes
This PR adds a bunch of debug utilities to a new header, ck_tile/builder/testing/debug.hpp. The idea here is that during debugging failed tests, its always useful to be able to dump a tensor to your terminal. At least, personally, this is always the first thing that I do. Now, I've noticed that these sorts of utilities tend to accumulate bitrot quite quickly, because while nobody is debugging, the code is unused! Fortunately, the solution is pretty staight forward: make the debugging utilities a first-class feature of the library by adding tests.

ckt::print_descriptor(name, desc, ostream) is used to print a quick overview of a tensor descriptor. This yields the internal information (data type, shape, strides) and some additional computed properties (total size in bytes, whether the tensor is packed). Example output:
Descriptor "test":
  data type: I32
  size:      1'320 elements
  space:     1'320 elements (5'280 bytes)
  lengths:   [10, 11, 12]
  strides:   [132, 12, 1]
  packed:    yes
