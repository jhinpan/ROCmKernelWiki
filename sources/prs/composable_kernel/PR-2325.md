# Fix amd_ck_fp8.hpp macro definitions

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2325](https://github.com/ROCm/composable_kernel/pull/2325) · **Merged:** 2025-06-25 · **Author:** @xli

**Inclusion reason:** keyword 'fp8'

## Summary (from upstream PR description)

Proposed changes

Remove CK_USE_FNUZ_FP8 and CK_USE_OCP_FP8 definitions, they are default behavior of preprocessor before compilation. Undefined macro is replaced with 0 when used in #if. In rocm 6.4, there is include/ck/config.h header file defines both CK_USE_FNUZ_FP8 and CK_USE_OCP_FP8 as ON, the current definition inside amd_ck_fp8.hpp will cause macro-redefined error.
Prefix __assert_fnuz_support and __assert_ocp_support with namespace fp8_impl to avoid redefined error when building with rocm 6.4 (include/hip/amd_detail/amd_hip_fp8.h)
