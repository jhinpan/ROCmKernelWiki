## Summary (from upstream PR description)

Proposed changes
Improve coverage of MX GEMM by testing more combinations of tensor layouts.
Given C = A * B, we are currently testing for row-major A, column-major B, and row-major C (RCR) combination of layouts.
Proposed changes add tests for RRR and CCR combinations.
Checklist
