# Split GEMM instance library & enable pipeline v2 optimization

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#783](https://github.com/ROCm/composable_kernel/pull/783) · **Merged:** 2023-07-06 · **Author:** @poyenc

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/grid/gridwise_gemm_pipeline_selector.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

By splitting the instance library, we can apply various compilation setting on separated source files (also speed up compilation time by ~40s).
Jeffrey had made a new IGLP strategy (D149773) which is waiting for review. Before the patch lands into upstream, we can re-organize CK in advance to better accommodating the design.
GEMM pipeline optimization comprises changes:

LLVM option: -amdgpu-enable-max-ilp-scheduling-strategy
kernel attribute: amdgpu_waves_per_eu()
HIP intrinsic function: __builtin_amdgcn_iglp_opt()

Following are performance numbers before & after enabling pipeline v2 optimization. In this PR, I only added 4 optimized instances (tile size: 64x128, block size: 256) for each layouts.
