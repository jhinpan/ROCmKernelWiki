# Fix race conditions in ck_tile remod

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3061](https://github.com/ROCm/composable_kernel/pull/3061) · **Merged:** 2025-10-21 · **Author:** @johannes-graner

## Summary (from upstream PR description)

Proposed changes
Fixes a race condition in the remod script run by pre-commit that occasionally leads to truncated files.
See failed and successful runs for the same commit as an example.
The fix consists of two parts:

Making sure that dos2unix is run before clang-format for a given file.
Waiting for all subprocesses to finish before generating headers (include) or exiting (examples).

Thanks @DDEle for bringing this to my attention!
