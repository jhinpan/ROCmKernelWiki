Proposed changes
This modification to the Jenkinsfile will automatically generate a screen capture of a build trace file and send the image and other related data to the Teams channel.
This new flow will only trigger at the end of the CK build stages if a build trace file was generated.
The adaptive card that is sent to the Teams channel includes a link to the screen capture, trace file, and relevant Jenkins job information.
