## Summary (from upstream PR description)

In this PR:

Fix lowest and min value of int4 in NumericLimits
Add more UT which showcase that int4_t and int8_t has different bitwise representation

[ RUN      ] Int4.BitwiseRepresentation
0x3, 0x3
0xd, 0xfffffffd
/devel/composable_kernel/test/data_type/int4.cpp:150: Failure
Expected equality of these values:
  bit8_t{static_cast<std::uint64_t>(a_i8)}
    Which is: 00001101
  bit8_t{static_cast<std::uint64_t>(b_i8)}
    Which is: 11111101
It looks that negative int4 values bitwise representation has filled with zeros second half byte, whereas int8 is filled with ones.
The usage of static_cast correctly converts the values.
