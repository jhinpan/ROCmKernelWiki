## Summary (from upstream PR description)

All our platforms support C++20 now, so update to C++20 standard for language features such as concepts, designated initializers, range-based for initializers, and consteval.
This PR just changes the C++ standard from 17 to 20 in the build configuration. No other changes, and it's already tested in CI, including our oldest supported build platforms .
