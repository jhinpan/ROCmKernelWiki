**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#82](https://github.com/ROCm/composable_kernel/pull/82) · **Merged:** 2022-03-05 · **Author:** @qianfengz

## Summary (from upstream PR description)

In general, the support of generic reduction will be added to C.K.  Following changes are involved:

Adding C++ Device interface for Reduction
Adding C++ HIP kernels for Reduction
Adding Profiler module for Reduction
Adding C++ library which enumerates the Device interface instances to be used by the Profiler
Adding C++ host layer Reduction for reference
Adding Max/AVG pooling device interface using Reduction kernel
Adding Examples using Max/AVG pooling and BlockWise Reduction
Other possible adding/change to composable kernel
