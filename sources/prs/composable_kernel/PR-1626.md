## Summary (from upstream PR description)

This pull request is for adding int8 support for 2d grouped convolution fwd on gfx9 architecture using xdlops. The following instances are added:
For layout GNHWC/GKYXC/GNHWK
grouped_conv2d_fwd_xdl_gnhwc_gkyxc_gnhwk_int8_instances
For layout NHWGC/GKYXC/NHWGK
grouped_conv2d_fwd_xdl_nhwgc_gkyxc_nhwgk_int8_instances
grouped_conv2d_fwd_xdl_large_tensor_nhwgc_gkyxc_nhwgk_int8_instances
grouped_conv2d_fwd_xdl_merged_groups_nhwgc_gkyxc_nhwgk_int8_instances
grouped_conv2d_fwd_xdl_nhwgc_gkyxc_nhwgk_int8_comp_instances
grouped_conv2d_fwd_xdl_nhwgc_gkyxc_nhwgk_int8_mem_intra_instances
grouped_conv2d_fwd_xdl_nhwgc_gkyxc_nhwgk_int8_mem_inter_instances
For layout NGCHW/GKYXC/NGKHW
grouped_conv2d_fwd_xdl_nhwgc_gkyxc_nhwgk_int8_instances
grouped_conv2d_fwd_xdl_merged_groups_ngchw_gkyxc_ngkhw_int8_instances
grouped_conv2d_fwd_xdl_ngchw_gkyxc_ngkhw_int8_comp_instances
grouped_conv2d_fwd_xdl_ngchw_gkyxc_ngkhw_int8_mem_intra_instances
grouped_conv2d_fwd_xdl_ngchw_gkyxc_ngkhw_int8_mem_inter_instances
