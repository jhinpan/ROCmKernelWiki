## Summary (from upstream PR description)

Proposed changes
This PR adds an example to perform GEMM Split-K using reduction instead of atomics. To enable this functionality, some modifications are made to the universal_gemm_kernel.hpp. These changes maintain backward compatibility and provide a way to calculate an output pointer offset through a method in the TilePartitioner. This offset can be used for Split-K operations and may also be useful for other purposes if needed.
