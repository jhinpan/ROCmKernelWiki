**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1911](https://github.com/ROCm/composable_kernel/pull/1911) · **Merged:** 2025-02-26 · **Author:** @rocking5566

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/codegen/ops/fmha_bwd.py'; keyword 'kernel'

## Summary (from upstream PR description)

Proposed changes
This PR focus on the change of code generation of cktile FMHA
I apply the filter to every kernel
Ex:
fmha bwd has 3 kernel

fmha_bwd_dot_do_o
fmha_bwd_convert_dq
fmha_bwd
But we only have one filter, but each kernel has different name, it cannot to apply to all kernel for now.
In this PR, I use , and @ to separate filter

In this PR, we could use following command to generate kernel
python 3rdparty/composable_kernel/example/ck_tile/01_fmha/generate.py -d fwd --list_blobs bwd_blob_list.txt
python 3rdparty/composable_kernel/example/ck_tile/01_fmha/generate.py -d fwd --list_blobs bwd_blob_list.txt  --filter *fp16*_bias*
python 3rdparty/composable_kernel/example/ck_tile/01_fmha/generate.py -d bwd --list_blobs bwd_blob_list.txt --receipt 300 --filter *fp16*@*fp16*@*fp16*_alibi*
python 3rdparty/composable_kernel/example/ck_tile/01_fmha/generate.py -d fwd_splitkv --list_blobs bwd_blob_list.txt --filter *fp16*@*fp16*_nbias*
python 3rdparty/composable_kernel/example/ck_tile/01_fmha/generate.py -d fwd,fwd_splitkv --list_blobs bwd_blob_list.txt --receipt 200 --filter *fp16*_nbias*,*fp16*@*fp16*_nbias*
