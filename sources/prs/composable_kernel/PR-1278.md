# Enable logging in CK with environment variable.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1278](https://github.com/ROCm/composable_kernel/pull/1278) · **Merged:** 2024-05-07 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck/host_utility/kernel_launch.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This change allows enabling of the debugging output from multiple kernels and ckProfiler by setting an environment variable "CK_LOGGING" instead of rebuilding the code with DEBUG_LOG macro set to 1.
The new EnvVar class will allow using other environment variables for other purposes, e.g., replacing the current macro CK_TIME_KERNEL with an environment variable as well.
