# Ck tile/complete k prefetch

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1941](https://github.com/ROCm/composable_kernel/pull/1941) · **Merged:** 2025-03-07 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'include/ck_tile/ops/fmha.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

This PR adds a pipeline called qr_ks_vs_whole_k_prefetch which is used for the case where kM0 <= 64  so that enough vgprs are available for prefetching the whole k tile for better performance.  kM0 == 64 is usually used to increase the number of work-groups when the product of  num_batches * num_heads * seqlen_q / 128 is not big enough to cover the whole number of Compute Units.
The qr_ks_vs_whole_k_prefetch  also includes the implementation of a pipeline very similar to the qr_ks_vs_async pipeline, which only prefetch one slice of k_tile in advance for next iteration.
This PR does not add any example for testing qr_ks_vs_whole_k_prefetch,  but it is completely tested/verified by Xformers. ROcm xformers 
The smoke_fmha_fwd_test.sh in ck_tile is not affected.
