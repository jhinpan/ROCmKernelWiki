# Streamk functional tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2974](https://github.com/ROCm/composable_kernel/pull/2974) · **Merged:** 2025-10-11 · **Author:** @cgmillette

**Inclusion reason:** kernel path 'include/ck_tile/ops/gemm/kernel/streamk_gemm_kernel.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes

Adds tests to ck tile StreamK in terms of smoke, regression and extended functional tests.
Adds fp16 and bf16 datatype support
Smoke tests cover MT of 256x256x32 and WG of 2x2x1 and WaveTile of 32x32x16, compv3 pipe
Extended tests cover additional 128x128x32 and WG of 2x2x1 WaveTile of 32x32x16 mem pipe
Added preprocessor macros to help control the combinatorial expansions
Updated the streamK test kernel to skip if the arguments check fails.
Small test cases spread over several cpp files for quick build speed.

Fixes:

Small fix in the stream-K kernel to account for stride when computing k offsets as this allows us to support layouts other than Row for A and Col for B.

Expected build times < 1 min with 16 threads for both smoke and extended.
Expected run time < 30 sec for smoke tests, < 1min for extended tests (subject to change)
