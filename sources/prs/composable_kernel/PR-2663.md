# ck_tile kernel for gemm with groupwise quantized B tensor.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2663](https://github.com/ROCm/composable_kernel/pull/2663) · **Merged:** 2025-08-29 · **Author:** @vj-krish

**Inclusion reason:** kernel path 'example/ck_tile/38_block_scale_gemm/CMakeLists.txt'; keyword 'mfma'

## Summary (from upstream PR description)

Aquant and Bquant were split out from original PR (#2362).
Aquant was merged with (#2473), and this PR is for Bquant.
This change introduces new pipelines with Intrawave scheduler and block gemm primitives that loads the scale tensor to registers to perform dequantization post MFMA on C tensor in registers.
Scale tensor data, BQ is spliced across threads in registers and not stored in LDS.
Current support is for the following combinations, but it should be fairly straightforward to extend support to more formats.
fp8, fp8 -> f32
bf8, bf8 -> f32
fp8, i4 -> f32
bf8, i4 -> f32
Group size can go down to as low as K length of underlying WarpGemm primitive.
