# Label CMakeLists message() as DEBUG or STATUS for clean build output

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2301](https://github.com/ROCm/composable_kernel/pull/2301) · **Merged:** 2025-06-10 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
This PR subdivides the message() output from CMake files. We label important messages such as HIP_VERSION, Python version, etc., as STATUS, and classify the rest as DEBUG.
When building composable_kernel with the CMake log level set to DEFAULT or STATUS, only a short, relevant set of messages appears in the terminal. If the log level is set to DEBUG, a larger, more detailed set of messages is shown, which can help in debugging for advanced users.
Example for build with DEBUG
cmake -D CMAKE_PREFIX_PATH=/opt/rocm \
      -D CMAKE_CXX_COMPILER=/opt/rocm/llvm/bin/clang++ \
      -D CMAKE_BUILD_TYPE=Release \
      -D GPU_TARGETS="gfx942" \
      --log-level=DEBUG \
      ..
Building with STATUS
cmake -D CMAKE_PREFIX_PATH=/opt/rocm \
      -D CMAKE_CXX_COMPILER=/opt/rocm/llvm/bin/clang++ \
      -D CMAKE_BUILD_TYPE=Release \
      -D GPU_TARGETS="gfx942" \
      --log-level=STATUS\
      ..
