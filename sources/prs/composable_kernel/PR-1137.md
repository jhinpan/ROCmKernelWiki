# Implement direct loads split-K GEMM kernel

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1137](https://github.com/ROCm/composable_kernel/pull/1137) · **Merged:** 2024-02-07 · **Author:** @bwroblew

**Inclusion reason:** kernel path 'example/35_splitK_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This PR implements a new split-K GEMM kernel that uses LDS direct loads for loading A and B matrices.
Benchmarked it on 30 important split-K GEMM cases using fp16 datatype and MK NK layout (the only one supported by direct loads).
Compared to the best already existing instance, new instances are on average 22% faster with some cases being sped up by 40-95%.
