**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2255](https://github.com/ROCm/composable_kernel/pull/2255) · **Merged:** 2025-06-11 · **Author:** @bartekxk

## Summary (from upstream PR description)

Proposed changes
This PR should remove all SetZero functions usage from ckProfiler and move this inside the kernel. Each device op knows when SetZero is need.
It will allow MIOpen to remove SetZero from their code for ck kernels.  Specifically, it eliminates performance problems caused when SetZero was called unnecessarily.
