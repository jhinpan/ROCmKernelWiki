**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#813](https://github.com/ROCm/composable_kernel/pull/813) · **Merged:** 2023-07-25 · **Author:** @poyenc

## Summary (from upstream PR description)

The buffer_load instructions used in CK GEMM kernel spend ~50% more time on reading data then those in Tensile. So I try to make the thread mapping (of reading A/B tiles) more closer to Tensile (but cannot be identical due to the ThreadwiseTensorSliceTransfer design).
I only update the ThreadClusterLengths tuning parameters of 2 instances which will compile with GEMM v2 pipeline optimization (layout=NN, TN). So the bold numbers are exclusively achieved by those touched instances.
