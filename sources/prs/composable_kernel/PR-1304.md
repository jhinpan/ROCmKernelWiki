# Select appropriate GPU targets for instances, tests, and examples.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1304](https://github.com/ROCm/composable_kernel/pull/1304) · **Merged:** 2024-05-22 · **Author:** @illsilin

**Inclusion reason:** keyword 'wmma'

## Summary (from upstream PR description)

These changes will make sure that any instances, tests, or examples with "xdl" suffices will get built only for gfx9 targets, while the ones with "wmma" will only get built for gfx11 targets.
This will reduce build times and library sizes for the cases where CK is built for all supported GPU architectures.
