## Summary (from upstream PR description)

Summary of Changes
This PR refactors tile_window.hpp and tile_window_linear.hpp to improve code reusability, maintainability, and structural clarity through a cleaner inheritance hierarchy.
Key Changes


Introduced a common base struct
A new ultimate base struct, tile_window_base, is added to encapsulate data members and methods shared across all tile window types:
template <typename TileWindowType_, typename BottomTensorView_, typename WindowLengths_>
struct tile_window_base {};



Added an intermediate base for distributed tile windows
A new intermediary struct, tile_window_with_tile_dstr_base, is introduced to group functionality specific to tile windows that utilize static tile distributions:


template <typename TileWindowType_, typename BottomTensorView_, typename WindowLengths_, typename StaticTileDistribution_>
struct tile_window_with_tile_dstr_base : public tile_window_base<TileWindowType_, BottomTensorView_, WindowLengths_> {};

Refactored inheritance hierarchy


tile_window_with_static_distribution and tile_window_linear now inherit from tile_window_with_tile_dstr_base.
