# Handle JSON boolean values in gemm_instance_builder.py

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3008](https://github.com/ROCm/composable_kernel/pull/3008) · **Merged:** 2025-10-14 · **Author:** @msaffari-amd

**Inclusion reason:** kernel path 'tile_engine/ops/gemm/gemm_instance_builder.py'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
Support both JSON booleans and string values for padding and persistent
config values. Previously only string "true" was recognized, causing JSON
boolean true to be treated as false.
This affects:

kPadM/N/K flags (padding coverage now work)
UsePersistentKernel flag (persistent kernels now supported)

Changed comparisons from 'pad_m == "true"' to 'pad_m in [True, "true"]'
to handle both Python booleans (from JSON) and string values.
