**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2810](https://github.com/ROCm/composable_kernel/pull/2810) · **Merged:** 2025-09-11 · **Author:** @linqun

## Summary (from upstream PR description)

Proposed changes
Reduce2dShape calculate ThreadPerWarp_M/N according to template parameter Warp_M/N and ThreadTile_M/N.
It causes ThreadPerWarp_M * ThreadPerWarp_N can't equal to warpSize in both wave32 and wave64 mode.
This PR add RepeatInWarp to adjust  ThreadPerWarp_M/N according to warpSize.

we assume template parameter is calculated in wave64 mode, i.e. in wave64 mode, RepeatInWarp is 1, and in wave32 mode, RepeatInWarp is 2.
