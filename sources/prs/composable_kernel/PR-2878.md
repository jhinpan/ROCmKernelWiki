# [CK-Tile] Add the API to load SGPR with any byte size

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2878](https://github.com/ROCm/composable_kernel/pull/2878) · **Merged:** 2025-09-23 · **Author:** @ThomasNing

**Inclusion reason:** kernel path 'include/ck_tile/core/arch/amd_buffer_addressing.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
Previously, CK Tile has to call the builtin instruction multiple times depending on the byte size of the memory. Now with the SGPR calling API, user can call any size of the data to SGPR.
