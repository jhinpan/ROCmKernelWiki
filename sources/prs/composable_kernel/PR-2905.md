# [CK_TILE] Share partition index across threads and specify offset in load_tile()/async_load_tile()/load_tile_transpose()

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2905](https://github.com/ROCm/composable_kernel/pull/2905) · **Merged:** 2025-11-12 · **Author:** @poyenc

**Inclusion reason:** kernel path 'include/ck_tile/core/container/sequence.hpp'; keyword 'lds'

## Summary (from upstream PR description)

Proposed changes

Allow specifying a replacement partition index for the tile_window_with_static_distribution<> template, with the resulting offset applied as an immediate offset in the instructions.
Allow specifying an additional offset for the load_tile(), async_load_tile() and load_tile_transpose() calls to ensure that each thread reads the correct data, even when sharing the same partition index.
Use warp-uniform LDS offset in tile_window::async_load() to avoid unnecessary VOPs and readfirstlane.
Allow specifying pre-computed partition_index to the tile window utilities and the Default2DEpilogue<>.
