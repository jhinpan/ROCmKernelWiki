# Overhaul to Reducton and its dependants

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#237](https://github.com/ROCm/composable_kernel/pull/237) · **Merged:** 2022-05-24 · **Author:** @qianfengz

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

This PR is a big update (overhaul) to Reduction, it includes the following:

Merge the reduction kernels to reduce the kernel files.  Only two reduction kernels are left.
Merge the reduction device interface to reduce the files.  Only two reduction device interfaces are left.
Removing useless reduction device instances to reduce instance files.  Only reduction device instances for three categories are left,  files are greatly reduced.
Corresponding updates due to the change in device/kernel merging and change in latest develop branch
Adding of one reduction example to show the using of hierarchical reduction (two calls to device interface) based on current implementation.
Some updates in host layer codes (eg. moving common used functions to one header)
Naming improvement (eg.  int to int32_t or int to ck::index_t)
