# [CK Tile] Fix FMHA LSE calculation and potential division by zero

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3326](https://github.com/ROCm/composable_kernel/pull/3326) · **Merged:** 2026-01-13 · **Author:** @Jeff-Huang

**Inclusion reason:** kernel path 'include/ck_tile/ops/fmha/pipeline/block_fmha_pipeline_qr_ks_vs.hpp'

## Summary (from upstream PR description)

This commit addresses numerical stability issues in the BlockFmhaPipelineQRKSVS pipeline when bias has -inf masking values:
Proposed changes

Explicitly handle the case where the accumulated exponential sum (l) is zero. In this case, the LSE is now correctly set to negative infinity, preventing log(0) errors.
Extend the zero-check protection in the normalization step to cover the ELEMENTWISE_BIAS case, preventing potential division by zero.
