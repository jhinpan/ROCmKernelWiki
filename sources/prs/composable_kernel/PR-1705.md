# [CK_TILE] Add fmha fwd N-Warp S-Shuffle pipeline (fmha fwd splitkv pipeline variant)

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1705](https://github.com/ROCm/composable_kernel/pull/1705) · **Merged:** 2024-12-20 · **Author:** @poyenc

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/codegen/cpp_symbol_map.py'; keyword 'mfma'

## Summary (from upstream PR description)

Add new fmha fwd splitkv pipeliene: N-Warp S-Shuffle. This pipeline was specificly otimized for small seqlen_q (<= 16)

N-Warp: use block warps=<1, 4, 1> both for gemm0 & gemm1. Parallelize computation on kN0 (seqlen_k) & kN1 (hdim_v) direction
S-Shuffle: use LDS to shuffle gemm0 output S to meet gemm1 input register layout requirement


Use more # warps in splitkv combine kernel. Decide the kM0 tile size automatically
Add small warp gemms: 4x64x16 & 64x4x16 (implemented by 4x4x4 mfma intrinsics)

thanks to @qianfengz for helping opitmize the pipelines
