# Add hipTensor build and test to CK CI.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#990](https://github.com/ROCm/composable_kernel/pull/990) · **Merged:** 2023-10-16 · **Author:** @illsilin

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

This PR will enable the following changes:


two new Jenkins parameters "hipTensor_test" (ON by default) and "hipTensor_branch" ("mainline" by default) will be added;


with the hipTensor_test=ON, in the stage that builds CK on MI100/200, we will pull the latest version of selected hipTensor branch into the docker where the latest CK was just built and installed; build hipTensor and run the tests.


This would allow us to coordinate changes with hipTensor in the future, e.g., when we need to change some of our instances, we can build a feature branch along with the modified hipTensor branch to make sure all conflicts are resolved before promoting changes into develop branches.
