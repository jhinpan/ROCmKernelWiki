**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3325](https://github.com/ROCm/composable_kernel/pull/3325) · **Merged:** 2025-12-01 · **Author:** @CongMa13

## Summary (from upstream PR description)

Proposed changes
As a CK Tile customer, I want to be able to use block_scale_gemm example with the block tile size MNK 128 128 128. These block tile sizes are faster for shapes desired for my usef case (prefill).
Along with adding the support, I want the team to add GemmConfig structs in example's hpp file as well as unit tests for these block tile sizes for future proofing the implementation.
The original implementation was too difficult to follow, so I refactored the code.
