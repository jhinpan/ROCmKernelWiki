# Split the static library into several files.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1044](https://github.com/ROCm/composable_kernel/pull/1044) · **Merged:** 2023-11-28 · **Author:** @illsilin

**Inclusion reason:** kernel path 'client_example/01_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Our latest static library, when built for all supported architectures has exceeded 4.1 Gb and required linker script to link successfully. Splitting it into several files by operation types will allow us to avoid any linker issues in the future.
This PR must be coordinated with hipTensor and MIOpen teams. I have created the branches and PRs in hipTensor and MIOpen that will need to be merged simultaneously.
