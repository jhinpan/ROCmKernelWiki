# Batchnorm inference instances, external API, client examples and gtests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#531](https://github.com/ROCm/composable_kernel/pull/531) · **Merged:** 2023-01-25 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'client_example/03_gemm_layernorm/gemm_add_add_layernorm.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

This P.R provides:

Instances of DeviceElementwiseImpl for batchnorm-infer
External API to collect all instances for batchnorm-Infer
Client example to use the example API and Device Op API to do batchnorm-infer
Gtests to cover a wile range of batchnorm-infer instances


This P.R set an example for how to use generic C.K device op (element-wise op on 1d tensors) to implement specific functions (eg. batchnorm-infer)
This P.R also provides example on using  dimension expanding on tensor by using 0-stride value on the added dimensions. The applications need to expand the dimensions of scale, bias, mean, variance from 1 to 4, enable their lengths the same as xyLengths, since the DeviceElementwise API assumes all the inputs have the same dimensions
