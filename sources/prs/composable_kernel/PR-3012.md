## Summary (from upstream PR description)

Proposed changes
Implements an example (along with required infrastructure) for running a forward convolution pipeline where the epilogue adds a bias to the output and clamps it to an interval.
Argument passing to element-wise function in epilogue
In order to specify the bias and clamping interval, it is necessary to be able to pass those parameters to the element-wise functions. In old CK, element-wise functions can be instantiated with arguments, essentially currying e.g. { x -> x + 5 } = Bias(x, 5) = BiasCurried(5)(x), so a variant of this is implemented here as well.
This is currently only implemented in the forward convolution kernel and CShuffle epilogue, but the implementation is generic enough to easily be copied to other kernels as well, the main implementation work is to make sure the arguments are passed all the way to the epilogue and used in the element-wise function instantiation.
