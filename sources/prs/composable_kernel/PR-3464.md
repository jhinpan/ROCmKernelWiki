# [CI, CK examples] Disable time_kernel for CI tests and examples

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3464](https://github.com/ROCm/composable_kernel/pull/3464) · **Merged:** 2026-01-07 · **Author:** @johannes-graner

**Inclusion reason:** kernel path 'example/02_gemm_bilinear/gemm_bilinear_wmma_fp16.cpp'; keyword 'wmma'

## Summary (from upstream PR description)

Proposed changes
CI test times are long, and it's unnecessary to time the kernels when running in CI since we only run for verification.
This PR disables the time_kernel parameter for three tests and all examples in old CK. Those examples are run as part of the CI test suite, and it's only the default argument to the examples that are changed, so they can still be manually run with kernel timing enabled for performance testing.
