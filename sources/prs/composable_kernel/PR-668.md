**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#668](https://github.com/ROCm/composable_kernel/pull/668) · **Merged:** 2023-04-10 · **Author:** @rocking5566

## Summary (from upstream PR description)

This PR create the instances of groupnorm + swish, external api and client example.
The swish of this PR is swish(x) = x * sigmoid(-beta * x)
PS: there are another simpler version of swish in pytorch, swish(x) = x * sigmoid(-x), this PR implement the beta version
