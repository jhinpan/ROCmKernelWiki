**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3235](https://github.com/ROCm/composable_kernel/pull/3235) · **Merged:** 2025-11-24 · **Author:** @johannes-graner

## Summary (from upstream PR description)

Proposed changes
The ck tile example for conv fwd with bias and clamp was failing in three ways:

Clamp was not being applied correctly.
1D convolutions resulted in segfaults.
2D and 3D convolutions with group size larger than 1 were failing during verification.

The solution for 1. is to properly pass the instantiated element-wise function to the epilogue (this was done in the PR that added this example, but must have been affected by a later change).
The solution for 2. and 3. is to apply the group offsets to the Ds tensor in the forward kernel.
