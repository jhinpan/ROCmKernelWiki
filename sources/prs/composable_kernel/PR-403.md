# Batchnorm-forward implemented using welford method to calculate variance

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#403](https://github.com/ROCm/composable_kernel/pull/403) · **Merged:** 2022-10-28 · **Author:** @qianfengz

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

The P.R includes

One fused kernel which does both Block-wise Welford Reduction, Normalization and/or updating moving mean/variance and/or saving mean/invvariance
One kernel to do partial Multi-block Welford Reduction (so called first-half of the Welford Multi-block method)
One fused kernel to do both the final Welford Reduction (so called second-half of the Welford Multi-block method) and the Normalization and/or updating moving mean/variance and/or saving mean/invvariance
Device interface for BatchNorm-forward
Update to the examples

At present the MaxCountPerThread is calculated using a functor passed from the device layer, which is aware of how the [M, K] 2d tensor is merged and padded
