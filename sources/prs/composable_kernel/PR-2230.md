**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2230](https://github.com/ROCm/composable_kernel/pull/2230) · **Merged:** 2025-06-04 · **Author:** @ex-rzr

## Summary (from upstream PR description)

Proposed changes

Blockwise pipeline v1, interwave and intrawave (BlockGemmPipelineVersion::v1)
mixed precision support and instances:

f8_f16, f16_f8 (they require a workaround for a compiler issue with packed conversion observed on ROCm 6.4, the recent staging build of clang works correctly)
f16_i4, bf16_i4


instances with GEMM specializations other than Default (KPadding, MNPadding, MNKPadding)
tests for mixed precision
examples for WMMA GEMM universal
