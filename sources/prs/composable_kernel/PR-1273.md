# Avoid using MI100 nodes for CK CI.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1273](https://github.com/ROCm/composable_kernel/pull/1273) · **Merged:** 2024-05-01 · **Author:** @illsilin

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

We've been having a lot of trouble with the last few remaining MI100 CI nodes.
They tend to lose connection in the middle of the build and the CI jobs hang.
I had to manually kill and restart each job, sometimes multiple times a day, to get them to finish successfully.
This change will make the CI jobs run the builds and tests on MI200 nodes only.
