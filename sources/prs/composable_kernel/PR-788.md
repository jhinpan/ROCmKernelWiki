# Grouped Gemm with looping over the tiles.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#788](https://github.com/ROCm/composable_kernel/pull/788) · **Merged:** 2023-10-11 · **Author:** @aosewski

**Inclusion reason:** kernel path 'client_example/17_grouped_gemm_fastgelu/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This PR introduces:

new work distribution mechanism for GroupedGEMM with SplitK algorithm where each workgroup loops over the set of all output matrices tiles.
Changed grouped-gemm instances, such that they use KPerBlock=64, changed thread-cluster-lengths and maximum load vector length whenever possible.

Additionally in this PR there is a bunch of documentation style improvements.
