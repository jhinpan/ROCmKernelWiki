# Add CMake Option 'USE_OPT_NAVI3X'

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#647](https://github.com/ROCm/composable_kernel/pull/647) · **Merged:** 2023-03-29 · **Author:** @aska-0096

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

To make navi3x only performance optimize compile option into a CMake Option "USE_OPT_NAVI3X"

-mcumode, the option to limit the LDS access scope of each CU to its own part, access to another part of LDS in same WGP is not allowed. That option give a lot performance gain if kernel code use LDS.
-mno-wavefrontsize64, the option to ask the GPU run in wave32 mode, the primitive thread group of GPU composed of 32 threads (Native support of Navi Series silicon) instead of 64 (Native support of MI Series silicon).
