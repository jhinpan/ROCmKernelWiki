# Add full QA with verification option, few other changes.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#331](https://github.com/ROCm/composable_kernel/pull/331) · **Merged:** 2022-07-21 · **Author:** @illsilin

**Inclusion reason:** kernel path 'profiler/include/profile_batched_gemm_reduce_impl.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This is the list of the changes:

add new jenkins parameter: RUN_FULL_QA. By default set to false, so regular CI process won't be affected, but jenkins will trigger a run of develop branch with RUN_FULL_QA=true every day at 23:00. This will cause the Performance Tests stage to launch all possible kernels to run with verification=1. The performance times will be posted to the database for all those kernels, as usual. Once we have the first results, I will also modify the python script to check for the tests correctness, report errors, and alert the developers assigned to maintain specific kernels.
Replaced the older "check_error" function with "check_err" everywhere.
Split the scripts that run performance tests into 2 parts: run tests and process results, so the latter part can be launched on the master node that won't have problems connecting to the database.
Disabled the conv2d_bwd_weights test that was generating wrong results. Will create a bug ticket to be fixed later.
Halved the number of threads used by jenkins in order to improve the CI stability. This may result in slightly longer build times, but hopefully will prevent the pipelines from crashing every other time.
