# Disable building device_mha_operations by default.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2225](https://github.com/ROCm/composable_kernel/pull/2225) · **Merged:** 2025-05-22 · **Author:** @illsilin

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Proposed changes
These changes will disable building the libdevice_mha_operations.a by default. It seems the only customer using the static lib for flash attention was MIOpen, and MIOpen is going to disable that functionality. Skipping building this lib in CK will reduce a typical CK build from ~5770 files to ~2200 files and from ~1hour30min to ~1hour on 128 threads for gfx942.
The library can be re-enabled by setting a build argument "-DBUILD_MHA_LIB=ON" on the cmake command line.
