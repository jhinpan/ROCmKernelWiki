## Summary (from upstream PR description)

Proposed changes
Performance profiling of the GEMM BlockScale kernel revealed a major bottleneck caused by inefficient instruction scheduling, leading to excessive pipeline bubbles/stalls and subsequent performance degradation.
Testing
./tile_example_gemm_quant -m=32768 -n=4096 -k=2048 -quant_mode=bquant -preshuffleb=true -v=1
The result improved from 769us -> 619us.
The improvement rate is approximately 20%.
