## Summary (from upstream PR description)

Proposed changes
The clang-format-12 is becoming obsolete and is no longer available to install in the recent ubuntu versions, so it may be time to upgrade to clang-format-18 (current compiler versions we use are clang19 and clang20). I will keep both clang-format-12 and clang-format-18 installed in our development dockers for a smooth transition.
