# add --squash flag when building dockers

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1686](https://github.com/ROCm/composable_kernel/pull/1686) · **Merged:** 2024-11-23 · **Author:** @illsilin

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

This should reduce the size of the dockers with staging and mainline compilers from ~45Gb to ~15Gb and reduce the times to push/pull those images from ~15min to ~3-4 min.
On the systems where the docker daemon does not support the "--squash" flag it will be ignored, but at least it will not cause CI builds crashing.
