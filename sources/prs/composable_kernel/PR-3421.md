## Summary (from upstream PR description)

Proposed changes
All contraction instances are based on MPerXDL =32 and NPerXDL=32, it causes all instance doesn't work on gfx11 and gfx12.
solution:

Add function GetWarpTileConfig to map {32,32} to {16,16} automatically in wave32 mode.
