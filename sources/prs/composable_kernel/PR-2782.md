**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2782](https://github.com/ROCm/composable_kernel/pull/2782) · **Merged:** 2025-09-04 · **Author:** @illsilin

## Summary (from upstream PR description)

Proposed changes
These changes will fix the latest compilation issue for AITER tests and will run more AITER tests in CK CI.
The root cause of the failure was a new header that was placed in a path that AITER could not pick (/examples/include).
I've moved the offending header json_dump.hpp to the path that will be automatically included by any downstream library (/include/ck_tile/utility).
Added several more AITER tests for several variations of test_moe.
