## Summary (from upstream PR description)

Proposed changes
Byte is the smallest unit for transposition. When tensor A has data type i4, ck must internally convert it to the same data type as B for transposition.
This PR refactors that conversion by introducing a new type alias for the data type that i4 is converted to, rather than using BDataType directly, which can be confusing.
