**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2375](https://github.com/ROCm/composable_kernel/pull/2375) · **Merged:** 2025-06-26 · **Author:** @linqun

## Summary (from upstream PR description)

…

When conv spec is 1x1 stride1 pad0, nchw is equal with matrix A + column major, we only need minor change in conv transformer to support it.
when out is NKHW, it is equal with matrix C with column major. we need swap A & B to get best performance.
Add new instance device_grouped_conv_fwd_xdl_f16_nchw_instances for nchw.
