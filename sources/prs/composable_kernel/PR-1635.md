# [generate.py] Override blob list if it already exists

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1635](https://github.com/ROCm/composable_kernel/pull/1635) · **Merged:** 2024-11-05 · **Author:** @jmmartinez

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/generate.py'; keyword 'layernorm'

## Summary (from upstream PR description)

Before, generate.py appended the list at the end of the output file. When running the cmake configuration steps multiple times on the examples, the blob list (such as fwd_blob_list.txt) would grow at every configuration.
library/src/tensor_operation_instance/gpu/mha/CMakeLists.txt worked around this issue by removing the output file if it exists.
Now, generate.py overrides the content of the output file. There is no need for the workaround in the CMakeLists.txt; and the issue is solved for the example projects too.
