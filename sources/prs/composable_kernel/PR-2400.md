# Enhancements in precommit_install.sh for Python and CK Tile code

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2400](https://github.com/ROCm/composable_kernel/pull/2400) · **Merged:** 2025-07-01 · **Author:** @AviralGoelAMD

## Summary (from upstream PR description)

Proposed changes
This PR addresses several issues with the precommit_install.sh

precommit_install.sh would throw “error: externally-managed-environment" when install a pip package into Ubuntu 24.04.
Why?


Since Ubuntu 23.04, it recommends Python-specific package management tools (e.g., pip) to install packages using a virtual environment, to avoid conflicts to packages installed by OS package managers. https://ubuntuhandbook.org/index.php/2024/03/pip-install-error-ubuntu-2404/

Fix: Setup a python3 virtual environment and then install pre-commit (+ related dependencies)

composable_kernel has several python scripts that are not automatically formatted. We don't want this (#2267 (comment))

Fix: We integrate ruff linter and formatter into pre_commit. It runs whenever a py file is part of a commit.

composable_kernel also has an internal formatting tool for include/ck_tile & example/ck_tile. It does the following:


clang-format-12 every .hpp file recursively under current folder
dos2unix those files
guarantee include/ck_tile/op/* folder structure, will automatically structure the op folder so that:
everything under include/ck_tile/op/<some_op/*.hpp will automaticaly put inside inc
