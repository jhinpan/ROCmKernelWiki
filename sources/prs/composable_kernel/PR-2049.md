# Split env.hpp header from the ck.hpp header.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2049](https://github.com/ROCm/composable_kernel/pull/2049) · **Merged:** 2025-04-03 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck/host_utility/kernel_launch.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
This will remove the env.hpp header which is required for logging and debugging purposes in just about 40 places from the ck.hpp header which is included in thousands of files (similar situation in ck_tile, where logging functionality is currently only used in gemm). This should reduce the build time and memory consumption.
