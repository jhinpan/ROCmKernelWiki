## Summary (from upstream PR description)

The GEMM + Layernorm implementation is a specialized kernel which allows fusing both layers together given the condition that GEMM extent N of MNK is spanned by a single workgroup. For example, a kernel configured with NPerBlock = 128 is allowed to operate on GEMM sizes with N <= 128
Full data path: GEMM -> bias -> activation -> add -> layernorm
