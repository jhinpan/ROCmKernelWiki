## Summary (from upstream PR description)

This P.R is following P.R 82, it has the following added/implemented

Using cluster descriptor to get thread cluster IDs of m or k dimension, and use 2d M_K tensor to describe the Blockwise LDS reduction buffer, making the codes simpler (kernels)
Change to all the reduction device interfaces to use NumReduceDims as template parameter to replace the old method of using ReduceDims,  this change will simply the numeration of the add_device_reduce_xxx method instances (devices)
Add Readme files for the pool2d_fwd and reduce_blockwise examples (examples)
Update to the Reduction testing scripts to make them aligned with the style of other test scripts (test)
Other possible updates in names
