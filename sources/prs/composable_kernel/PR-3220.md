# Add support for RDNA1 GPUs

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3220](https://github.com/ROCm/composable_kernel/pull/3220) · **Merged:** 2025-11-20 · **Author:** @GZGavinZhao

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/impl/device_batched_gemm_multiple_d_dl.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
Support compiling and running CK on RDNA1 GPUs (including the new gfx10-1-generic target). This just involves

Relaxing some #if defined(__gfx10x__) guards to include defined(__gfx101__)
Some small CMake changes to fix a linking error where ckProfiler "unable to find -ldevice_quantization", since device quantization instances seem to be incompatible/unavailable for RDNA1 GPUs.

Fixes #2411.
Fixes #3185.
Test plan
Built CK on an AWS g4ad.xlarge instance (gfx1011) and ran tests as follows:
cmake -B build -S . -GNinja \
        -DCMAKE_PREFIX_PATH=/opt/rocm \
        -DCMAKE_CXX_COMPILER=/opt/rocm/llvm/bin/clang++ \
        -DCMAKE_BUILD_TYPE=RelWithDebInfo \
        -DGPU_TARGETS=gfx1011 \
        -DBUILD_TESTING=ON \
ctest --test-dir build -j1 --output-on-failure

109/110 tests reliably pass. test_batchnorm_infer_rank_4 fails (<1% has wrong values) due to a compiler bug documented at the end..
