**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2000](https://github.com/ROCm/composable_kernel/pull/2000) · **Merged:** 2025-03-24 · **Author:** @andriy-ca

## Summary (from upstream PR description)

Proposed changes
Introduces new GEMM implementation for MX FP8 data type.
This is work in progress towards supporting MX FP 4/6/8 GEMMs.
The "v3_mx" pipeline is an adaptation of the "v3_b_scale" pipeline, which is derived from "v3.".
The evolution is evident by comparing:
device_gemm_xdl_cshuffle_v3_mx.hpp <-> device_gemm_xdl_cshuffle_v3_b_scale.hpp <-> device_gemm_xdl_cshuffle_v3.hpp
gridwise_gemm_xdl_cshuffle_v3_mx.hpp <-> gridwise_gemm_xdl_cshuffle_v3_b_scale.hpp <-> gridwise_gemm_xdl_cshuffle_v3.hpp
blockwise_gemm_pipeline_xdlops_v1_mx.hpp <-> blockwise_gemm_pipeline_xdlops_v1_b_scale.hpp <-> blockwise_gemm_pipeline_xdlops_v1.hpp
