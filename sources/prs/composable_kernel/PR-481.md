**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#481](https://github.com/ROCm/composable_kernel/pull/481) · **Merged:** 2022-11-02 · **Author:** @poyenc

## Summary (from upstream PR description)

This PR include following works

Example for grouped conv2d backward data (without bias)
Instances for grouped conv2d backward data
Client example for grouped conv2d backward data

I created new interface DeviceGroupedConvBwdData to abstract the problem, and let DeviceGroupedConvBwdDataMultipleD conditionally derive from it if both DsLayout & DsDataType are empty (Tuple<>). Thus we can employ DeviceGroupedConvBwdDataMultipleD_Xdl_CShuffle_v1 template to define instance objects.
I planned to add client_example/08_grouped_conv2d_fwd client example next.
