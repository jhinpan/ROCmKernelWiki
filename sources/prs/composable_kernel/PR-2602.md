# update the switch condition for buffer built-ins

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2602](https://github.com/ROCm/composable_kernel/pull/2602) · **Merged:** 2025-08-01 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck_tile/core/config.hpp'; keyword 'layernorm'

## Summary (from upstream PR description)

Proposed changes
This is a fix for a temporary "clang_major == 20" condition for switching from the raw buffer store/load intrinsics to the built-ins, which was caused by the compiler staging branch not supporting the built-ins for some time after getting promoted to clang21 (plus, there was a temporary confusion about the intrinsics name conventions).
Now that both the mainline and the staging compiler branches fully support the new built-ins, we can update the condition (staging branch is currently already at clang22).
