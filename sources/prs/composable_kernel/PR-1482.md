# [CK_TILE] float -> bf16 inline asm rtn

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1482](https://github.com/ROCm/composable_kernel/pull/1482) · **Merged:** 2024-08-30 · **Author:** @danyao12

**Inclusion reason:** kernel path 'include/ck_tile/core/config.hpp'

## Summary (from upstream PR description)

Implement tensile's rtn in CK Tile using inline assembly to improve performance while maintaining accuracy.
tensile round to nearest even:
v_mov_b32 v14, 0xffff0000                          // mask for pack two bfloat16 element to 32bit
v_mov_b32 v15, 0x7fff0000                          // fp32 Nan
v_mov_b32 v16, 0x7fff                              // rounding bias for bfloat16
v_cmp_u_f32 s[60:61], v[vgprValuC+40], v[vgprValuC+40] // check Nan
v_bfe_u32 v13, v[vgprValuC+40], 16, 1              // Non-Nan case: store lsb of bf16
v_add3_u32 v13, v[vgprValuC+40], v13, v16          // Non-Nan case: add lsb and the increment for rounding
v_cndmask_b32 v[vgprValuC+40], v13, v15, s[60:61]
v_lshrrev_b32 v[vgprValuC+40], 16, v[vgprValuC+40] // convert C to bf16
v_cmp_u_f32 s[60:61], v[vgprValuC+41], v[vgprValuC+41] // check Nan
v_bfe_u32 v13, v[vgprValuC+41], 16, 1              // Non-Nan case: store lsb of bf16
v_add3_u32 v13, v[vgprValuC+41], v13, v16          // Non-Nan case: add lsb and the increment for rounding
v_cndmask_b32 v[vgprValuC+41], v13, v15, s[60:61]
v_and_or_b32 v40, v[vgprValuC+41], v14, v[vgprValuC+40] // pack two bf16 to dword
