# Rangify STL algorithms

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#438](https://github.com/ROCm/composable_kernel/pull/438) · **Merged:** 2022-11-14 · **Author:** @poyenc

**Inclusion reason:** kernel path 'example/30_grouped_conv_fwd_multiple_d/run_grouped_conv_fwd_example.inc'; keyword 'quant'

## Summary (from upstream PR description)

This commit adapts rangified std::copy(), std::fill() & std::transform() (C++20)
Before this PR
std::fill(begin(a), end(a), 1);
std::copy(begin(a), end(a), std::back_inserter(b));
std::transform(begin(a), end(a), begin(b), [](auto v) { return v * 2; });
After this PR
ck::ranges::fill(a, 1);
ck::ranges::copy(a, std::back_inserter(b));
ck::ranges::transform(a, begin(b), [](auto v) { return v * 2; });
