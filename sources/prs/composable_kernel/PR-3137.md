## Summary (from upstream PR description)

Proposed changes
Summary:

Fix splitk for gemm_multiply_multiply_wp and gemm_universal_b_preshuffle
Add tests for gemm_multiply_multiply_wp, gemm_universal_b_preshuffle and gemm_blockscale_wp (does not support splitk)
Fix conditions for supported arguments in gemm_universal_b_preshuffle based on gemm_multiply_multiply_wp
Fix tolerances in profiler for gemm_multiply_multiply_wp and gemm_universal_b_preshuffle (in order to work with splitK and large K)
Fix strides in profiler for gemm_multiply_multiply_wp, gemm_universal_b_preshuffle and gemm_blockscale_wp

Explanation for splitK fix: for matrix B (preshuffled) it is not possible to shift the pointers, so in this case the same approach used for convolution is applied. The grid descriptor is shifted.
