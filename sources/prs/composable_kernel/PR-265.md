# example for convnd bwd weight bf16 splitk

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#265](https://github.com/ROCm/composable_kernel/pull/265) · **Merged:** 2022-06-16 · **Author:** @shaojiewang

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/grid/gridwise_gemm_xdlops_bwd_weight.hpp'; keyword 'mfma'

## Summary (from upstream PR description)

Example for convnd bwd weight bf16 split-k kernel.
Background
We already have bwd weight split-k kernel for fp32/fp16 using gfx908/90a's fp32/fp16 atomic add instructions. But gfx908/90a do not have bf16 atomic add instruction. So the split-k method for bf16 is different.
Method
As bf16 mfma result is stored with fp32 type, we can do fp32 atomic add to sum all of the split-k part, and then do a fp32->bf16 type conversion.

using a workspace of size K*C*Y*X*sizeof(float) to store the fp32 convolution result.
using a unary element-wise type conversion kernel to do workspace(fp32)->weight_buffer(bf16) conversion.
