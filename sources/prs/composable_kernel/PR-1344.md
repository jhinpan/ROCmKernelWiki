# Hacking  ck_tile fmha Dropout facility

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1344](https://github.com/ROCm/composable_kernel/pull/1344) · **Merged:** 2024-06-19 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'include/ck_tile/ops/fmha/block/block_dropout.hpp'; keyword 'attention'

## Summary (from upstream PR description)

This PR makes two changes in ck_tile BlockDropout facility and forward kernel:

Add NullBlockDropout, which is used to reduce the vgprs/sgprs when kHasDropout is false (pure inference path)
Change in BlockDropout::Run() to reduce the conditional checking for is_store_randval


From xformers testing, the change is able to improve the fmha forward performance when dropout_prob == 0 visibly, like
