**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2964](https://github.com/ROCm/composable_kernel/pull/2964) · **Merged:** 2025-12-18 · **Author:** @krithalith

## Summary (from upstream PR description)

This pull request adds support for WMMA-based convolution forward (conv fwd) by new instances with also ScaleAdd operations on A and B tensors, targeting multiple data types (fp16, bf16, int8). It introduces new example executables, updates the common header to select the correct device implementation based on a macro, and makes several improvements and fixes in the core library to support these new examples and improve robustness.
New WMMA-based convolution examples:

Added three new example executables for WMMA-based conv fwd with ScaleAdd on A and B:

conv_fwd_wmma_cshufflev3_scaleadd_ab_fp16.cpp
conv_fwd_wmma_cshufflev3_scaleadd_ab_bf16.cpp
conv_fwd_wmma_cshufflev3_scaleadd_ab_int8.cpp
[1] [2] [3]


Updated CMakeLists.txt to build and manage dependencies for the new WMMA-based examples under a custom target.

Device implementation selection and configuration:

Modified convnd_fwd_activ_multi_ab_common.hpp to select between WMMA and non-WMMA device implementations using the EXAMPLE_USE_WMMA macro, and defined a new WMMA-based DeviceGroupedConvNDMultiABFwdInstance with appropriate template parameters and block sizes. [1] [2] [3]
