# feat(grouped_gemm): add preshuffle v2 support to grouped gemm example

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2721](https://github.com/ROCm/composable_kernel/pull/2721) · **Merged:** 2025-09-07 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'example/ck_tile/17_grouped_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
This PR brings following changes to ck_tile/example/12_grouped_gemm.

We bring back support to use non persistent kernels for group_gemm which was mistakenly removed in #2655
We integrate include/ck_tile/ops/gemm/pipeline/wp_pipeline_agmem_bgmem_creg_v2.hpp  into include/ck_tile/ops/gemm/kernel/grouped_gemm_kernel.hpp to extend support for preshuffling tensor B on host.
A lot of refactoring has been done to both grouped_gemm files to improve readability and integrate preshuffle pipeline v2.
Fix minor issues in other related files, update CHANGELOG.md & README.md, clang formatting etc.

We now have a new example that can be build and run by
root:~/workspace/build# make tile_example_grouped_gemm_preshuffle -j
Built target tile_example_grouped_gemm_preshuffle
root:~/workspace/build# ./bin/tile_example_grouped_gemm_preshuffle
