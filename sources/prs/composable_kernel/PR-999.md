# Add basic support for direct loads from global to LDS

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#999](https://github.com/ROCm/composable_kernel/pull/999) · **Merged:** 2023-11-25 · **Author:** @bwroblew

**Inclusion reason:** kernel path 'example/01_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This PR adds a new transfer class that copies data from global to LDS memory using direct loads -- no need for intermediate steps through registers. A new kernel is also added.
Works best for MK NK layout. For layouts with either M or N being the contiguous dimension in global memory, the kernel is not able to use coalesced reads because of the instruction limitations.
For datatypes other than fp32, the MK NK is the only supported layout since each thread reads more than one element. K is a contiguous dimension in LDS and must be contiguous in global to allow for direct DWORD read/write by every thread.
For some fp32 cases from profile_gemm.sh it's already the fastest GEMM kernel on CDNA2 arch.
