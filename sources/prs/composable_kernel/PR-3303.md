**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3303](https://github.com/ROCm/composable_kernel/pull/3303) · **Merged:** 2026-01-07 · **Author:** @ErwinTerpstra

## Summary (from upstream PR description)

Proposed changes
This PR adds element-wise operator support to the Grouped Gemm WMMA device struct, and adds instances for the fastgelu operator. It contains:

Added support for element-wise operators to DeviceGroupedGemm_Wmma_CShuffleV3
Instances for FastGelu FP16 to match the XDL instances.
GTests for FastGelu instances

Note: XDL instances previously had no tests associated. They are now included in the test as well.


Changed profile_grouped_gemm_impl to allow element-wise operators

This change makes the specific profile_grouped_gemm_fastgelu_impl implementation superfluous. It has been changed to reuse the generic version, but the interface is kept for compatibility.



Note that while DeviceGroupedGemm_Wmma_CShuffleV3 supports SplitK, this is not supported in combination with an element-wise operator on the output tensor. Tests for these are excluded and instances will indicate that this is not supported.
