# Add new instances and support for small cases in DPP8 GEMM

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#896](https://github.com/ROCm/composable_kernel/pull/896) · **Merged:** 2023-09-12 · **Author:** @bwroblew

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/warp/dpp_gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This PR extends the DPP8 GEMM kernel by adding support for cases smaller than the default ones.
It also adds new instances that maximize the performance on the set of known important cases.
For these cases DPP kernels are around 80% faster than DL ones on Navi2, and around 30% -- on Navi3.
Attached full performance numbers to the ticket - LWPCK-825.
