# [CK_TILE][CORE] enhance slice_tile api

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2430](https://github.com/ROCm/composable_kernel/pull/2430) · **Merged:** 2025-07-07 · **Author:** @carlushuang

**Inclusion reason:** kernel path 'include/ck_tile/core/container/sequence.hpp'

## Summary (from upstream PR description)

As described in #2384, currently ck_tile API has limitation that the slice length can't cross P dim. This PR fix this by allowing slice cross P. The majority of the code change is inside internal api detail::slice_distribution_from_x()
After this PR. the distributed tensor slice API is very close to standard torch slicing API

 support cross P dim
 support let -1 be the end of length, similar to torch slice
 support slice origin different from zero
 support Y dim with arbitrary order
 support R dim exist in the distribution (and pointed by P)

After this PR, cases like below will be supported (:
length:sequence<2, 4, 4, 2, 2>
//              Y  P  Y  P  Y

slice_length:16
=> out:sequence<1, 4, 1, 2, 2>
//              Y  P  Y  P  Y
