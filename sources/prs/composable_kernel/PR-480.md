# Gemm standalone bench executable

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#480](https://github.com/ROCm/composable_kernel/pull/480) · **Merged:** 2022-10-27 · **Author:** @rosenrodt

**Inclusion reason:** kernel path 'test/gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Added standalone gemm bench executable that depends on its own set of gemm instance / problem size pairs. Those pairs are arranged so that there's 110 workgroups or 104 workgroups.
Currently standalone gemm bench is fp16 only.
#build
$ cmake --build build -t test_gemm_standalone_xdl_fp16 -j
#run
$ build/bin/test_gemm_standalone_xdl_fp16
