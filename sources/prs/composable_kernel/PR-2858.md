## Summary (from upstream PR description)

Proposed changes
This adds B tensor pk_int4_t support for the CK Tile weight preshuffle GEMM kernel, with tests for A tensor type fp8, and minor code cleanup in related areas of the code base.
Four of the added tests are skipped, and these correspond to four pre-existing tests for A tensor type fp8 that are also already skipped. All of these have K tensor size 128 in common, indicating a general problem with A tensor type fp8 and K tensor size 128.
