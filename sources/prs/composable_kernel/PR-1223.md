# Split the instances by architecture.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1223](https://github.com/ROCm/composable_kernel/pull/1223) · **Merged:** 2024-04-02 · **Author:** @illsilin

**Inclusion reason:** kernel path 'client_example/02_gemm_add_add_fastgelu/CMakeLists.txt'; keyword 'wmma'

## Summary (from upstream PR description)

CK used to build all instances for all architectures. Many of the original instances are generic and that's fine.
However, we now have several groups of instances which are architecture specific, such as xdl and wmma.
These changes will make sure that the xdl instances get built only if the gfx9 architectures are on the target list and wmma instances will only get built if gfx11 are on the target list.
