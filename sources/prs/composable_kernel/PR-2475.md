# [CK_TILE] Avoid compile kernel in host pass

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2475](https://github.com/ROCm/composable_kernel/pull/2475) · **Merged:** 2025-07-09 · **Author:** @DDEle

**Inclusion reason:** kernel path 'include/ck_tile/host/kernel_launch.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

Proposed changes
Avoid compiler kernel functions in host pass (i.e. __HIP_DEVICE_COMPILE__ undefined), benefiting

speedups compilation up to 50% in theory (usually 5% - 30%, e.g.1 42s->30s , e.g.2 10m30s->9m45s)
Avoid unexpected static assertion error (i.e. developers no longer need to won't worry that none of gfx identifier (e.g. __gfx950__) is defined). Solving problem like the below example:
inline __device__ void f()
#if defined(__950__)
  static_assert(something_only_true_on_gfx950);
#else
  static_assert(something_only_true_before_gfx950);
  // 👆failed even if GPU_TARGETS=gfx950 is set
#endif
