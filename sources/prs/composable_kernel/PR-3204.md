## Summary (from upstream PR description)

Proposed changes
Since Tile Partitioner's responsibility is limited at block tile scope, it shouldn't include the full gemm shape, as well as its clients shouldn't use the full gemm shape. It makes instantiating the tile partitioner more complicated than necessary
