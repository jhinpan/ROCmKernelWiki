# Fused attention instances & padding tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#395](https://github.com/ROCm/composable_kernel/pull/395) · **Merged:** 2022-09-06 · **Author:** @rosenrodt

**Inclusion reason:** kernel path 'example/32_batched_gemm_scale_softmax_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Added padding tests
Added more attention kernel instances; showing improvements in mainline 9110 and even more so in 10768 compiler (kernels having compiler issue in 10768 compiler are not added)
Streamlined usage where ResetNaNToMinusInf is now hidden from user facing device op; closes #391
Minor changes in attention kernel: use compile-time conditionals to load OOB value as NaN only after padding is enabled so we can still leverage buffer_load intrinsic's OOB trick (automatic zeroing) when padding is not needed
Disabled KPadding for now since it is unimplemented

New instances improved some sizes over #345 (MI250; hipclang mainline 9110)
