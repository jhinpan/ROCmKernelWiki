## Summary (from upstream PR description)

The target of this P.R is described by  Issue 267
The following changes in the codes are involved:

Remove class template of  Reduction accumulator operations by using data type as template with operator() and member functions
Remove class template of Unary and Binary element-wise operations by using data type as template with operator()
Many corresponding changes due to using of element-wise operations and reduction accumulator operations
