# Add support for more Navi2x and Navi3x models.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1152](https://github.com/ROCm/composable_kernel/pull/1152) · **Merged:** 2024-02-02 · **Author:** @illsilin

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/impl/device_batched_contraction_multiple_d_wmma_cshuffle.hpp'; keyword 'wmma'

## Summary (from upstream PR description)

While I added a few new targets, I've tried to simplify the pre-compiler and run-time checks.
I define a "general macro" for the entire group of models, e.g. "gfx11" if any of the "gfx1100", "gfx1101", "gfx1102", or "gfx1103" are defined.
For the run-time checks, I use a function "is_navi3_supported" which returns "true" if the device name matches any of the models on the list.
I applied the same process to the navi2 and mi300 models.
This way if we need to add or remove any targets in the future we will only have to do it in a couple of places instead of 100 places.
