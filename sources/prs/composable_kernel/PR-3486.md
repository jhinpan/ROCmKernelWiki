# [CK_TILE] Align FMHA BWD Reference with Kernel Implementation

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3486](https://github.com/ROCm/composable_kernel/pull/3486) · **Merged:** 2025-12-25 · **Author:** @DDEle

## Summary (from upstream PR description)

Proposed changes
We are suffering from the FMHA BWD accuracy problems. After throughout investigation of the failed cases, I noticed that the key difference between reference and kernel implementation is how the undropout reciprocal (rp_undrop) is applied. The dropout implementation for fmha bwd is different: it only mark (using minus sign; note that all P elements should be positive as softmax output) dropped elements without rp_undrop scaling. Instead, the dropped mark is used by following step in FMHA BWD pipelines and the rp_undrop scaling is applied at the end of fmha bwd pipelines. This PR trys to eliminate this difference which introduces different rounding behaviors between the reference and kernel implementation.
