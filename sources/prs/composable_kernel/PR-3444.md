# [CK-TILE] Guard against compiler lexer diagnostic

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3444](https://github.com/ROCm/composable_kernel/pull/3444) · **Merged:** 2025-12-20 · **Author:** @jplehr

**Inclusion reason:** kernel path 'include/ck_tile/core/utility/static_counter.hpp'

## Summary (from upstream PR description)

Proposed changes
A recent change to Clang added a lexer-level diagnostic about that C2y language feature. Since that is lexer level, the __extension__ compiler built-in does not work as it is only respected after the lexer when parsing.
This change adds guarding pragmas to disable the diagnostic in the lexer and not lead to warnings being treated as errors.
