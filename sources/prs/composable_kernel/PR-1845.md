**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1845](https://github.com/ROCm/composable_kernel/pull/1845) · **Merged:** 2025-02-06 · **Author:** @kylasa

**Inclusion reason:** kernel path 'example/ck_tile/03_gemm/gemm_basic.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
Implemented the following changes,

Updated the default options for the command line execution for the A and B matrices which are supported by the gemm kernel.
Updated the benchmark scripts and smoke test scripts to include the newly supported data types.
Updated the error checking to use type_convert instead of static casting when validating the GPU results
Updated the newly introduced tolerance methods, by earlier PRs, to include the newly supported data types
Added new structures in the gemm.hpp and related files to support newly added data types support
Added methods to support atomic addition of the newly supported data types.
Updated the Tile sizes, to match the newly supported data types, Please note that the Vector size is not updated which forces us to update the tile size accordingly.
