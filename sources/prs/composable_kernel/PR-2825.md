# implement device batched gemm b scale for wmma

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2825](https://github.com/ROCm/composable_kernel/pull/2825) · **Merged:** 2025-10-16 · **Author:** @kabrahamAMD

**Inclusion reason:** kernel path 'example/65_gemm_multiply_multiply/moe_gemm1_xdl_pk_i4.cpp'; keyword 'wmma'

## Summary (from upstream PR description)

Proposed changes

Added batched b scale instances for wmma.
Add option to simulate split-k in reference gemm
Fixed issues with testing specific to I4
During the implementation, I noticed that the testing didn't properly initialize the tensors for INT4. The method used for testing, apparently copied from the FP method initialized a matrix with all 0's. Fixing this surfaced bugs with the reference CPU implementation, which were also fixed in the process.
The same (false) initialization was also used for gemm_universal INT4 tests, which were also fixed in the process.
To address large differences encountered in some tests, the option to simulate split k-batching was added to the reference gemm (to replicate the order of fp operations as the gpu would do it)
