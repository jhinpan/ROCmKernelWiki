## Summary (from upstream PR description)

Instead of using individual device macros like gfx940 or gfx1100 in multiple places all over the code, we'll define common ones like gfx9 or gfx11 for the similar models, so if we need to add or remove support for certain architectures in the future, we can do this in one place.
