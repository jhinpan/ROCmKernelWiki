# Reduce redundant space in bias tensor

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2024](https://github.com/ROCm/composable_kernel/pull/2024) · **Merged:** 2025-03-28 · **Author:** @rocking5566

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/fmha_fwd.cpp'; keyword 'kernel'

## Summary (from upstream PR description)

Proposed changes
Tensor shape of fwd and bwd is mismatch for group mode
fwd: [1, nhead, total_q, total_k]
bwd: [1, nhead, total_q, max_seqlen_k]
we need to sync them. I found fwd might spend extra space in this case (because total_k is too large).
In this PR, I change bias of fwd into [1, nhead, total_q, max_seqlen_k]
Checklist
./bin/tile_example_fmha_fwd -v=1 -mode=1 -b=4 -h=4 -s=4,4,4,4 -s_k=4,4,4,4 -d=32 -d_v=32 -bias=1 -lse=1 -prec=bf16 -iperm=0 -operm=0 -vlayout=r -kname=1
