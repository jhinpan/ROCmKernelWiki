# Standalone sweep once softmax kernel w/ ckProfiler

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#295](https://github.com/ROCm/composable_kernel/pull/295) · **Merged:** 2022-06-30 · **Author:** @rosenrodt

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

Add profile_normalization() for standalone softmax profiling. Can extend to standalone layernorm/batchnorm as well
Add int8 softmax instances. However, it's not for real use cases as quantized data doesn't scale linearly after applying exp() so is neither able to requantize nor dequantize in any trivial way
Add "sweep once" kernel. Will try to load data from global mem just once when problem size permits. 130% speedup (30% gain) is observed.

Sweep-once softmax kernel supporting limited reduction size; basically limited by block tile size
$ build/bin/ckProfiler softmax 1 0 1 0 1 --length 512 512 512 --reduce 2
Perf: 0.546594 ms, 982.211 GB/s, DeviceReduceSoftmax<256,M_C4_S1,K_C64_S8,InSrcVectorDim_1_InSrcVectorSize_8_OutDstVectorSize_8>

Generic softmax supporting unlimited large reduction size
Perf: 0.705778 ms, 760.679 GB/s, DeviceReduceSoftmax<256,M_C4_S1,K_C64_S8,InSrcVectorDim_1_InSrcVectorSize_8_OutDstVectorSize_8>

Reduce add bandwidth:
$ build/bin/ckProfiler reduce --half -D 1,512,512,512 -R 3 -O 0 -C 1 -v 0 1 10
Best Perf: 0.281361 ms, 955.925 GB/s
