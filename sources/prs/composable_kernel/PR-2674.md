# Fix builds with mainline/staging compilers

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2674](https://github.com/ROCm/composable_kernel/pull/2674) · **Merged:** 2025-08-12 · **Author:** @illsilin

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

Proposed changes
This PR fixes the test failures for the builds with latest mainline and staging compiler branches. The compressed package format had been changed in the latest compilers, which causes a conflict when running those tests with older hip runtime libraries. Setting the environment variable COMPRESSED_BUNDLE_FORMAT_VERSION=2 before the cmake call resolves this issue.
