**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3598](https://github.com/ROCm/composable_kernel/pull/3598) · **Merged:** 2026-01-20 · **Author:** @evedovelli

## Summary (from upstream PR description)

Proposed changes
Enables hipTensor to access the WMMA HW functionalities for datatype FP16 + compute type FP16 and datatype BF16 + compute type BF16 on gfx11 and gfx12.
The low level implementation already existed, and this PR adds the interface to the WMMA functions to the API used by hipTensor.
