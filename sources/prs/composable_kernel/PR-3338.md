# Disable gemm_blockscale_f8 on gfx90a by default.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3338](https://github.com/ROCm/composable_kernel/pull/3338) · **Merged:** 2025-12-02 · **Author:** @illsilin

**Inclusion reason:** kernel path 'library/src/tensor_operation_instance/gpu/gemm_blockscale_wp/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
These changes will disable building gemm_blockscale_f8 instances on gfx90a by default. Since gfx90a does not have native support for fp8 operations, the build times and performance for those kernels are terrible.
I also disabled some of the messages generated by cmake (turned the message type from STATUS to DEBUG to declutter our builds a bit).
