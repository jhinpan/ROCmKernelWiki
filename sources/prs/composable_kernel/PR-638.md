**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/device_grouped_gemm_softmax_gemm_permute_xdl_cshuffle.hpp'; keyword 'wmma'

## Summary (from upstream PR description)

Following a request from the MIOpen team, I've appended a few extra optimization parameters to the string generated by the GetTypeString function so that each kernel's string becomes unique. This set of changes has at least all the convolution and gemm+reduction kernels covered (confirmed by MIOpen team).
