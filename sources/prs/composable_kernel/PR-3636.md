# ck: add CK_USE_GFX950 macro

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3636](https://github.com/ROCm/composable_kernel/pull/3636) · **Merged:** 2026-01-26 · **Author:** @yingluAMD

**Inclusion reason:** keyword 'gfx950'

## Summary (from upstream PR description)

Proposed changes
PR #3248 introduced a GPU architecture related template config in conv_bwd_data instances. It lead to MIOpen CI fail because this filed is used as host code in MIOpen which doesn't have __gfx950__ macro.
This PR defined a new macro CK_USE_GFX950 to fix this issue. MIOpen will also enable this macro on gfx950 platform.
PS: Due to we want set TF32/GFX950 macros "Off" as default. Those macros are removed from config.h.in.
