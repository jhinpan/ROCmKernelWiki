## Summary (from upstream PR description)

Proposed changes

Added various layouts (RRR, CRR and CCR) for AQuant/BQuant grouped gemm to the examples and test.
Refactored the example structure to split instances to separate files, to aid in parallel compilation.
NOTE: Re-enabled the test test_grouped_gemm_quant_bquant, which was disabled due to slow compilation. The problem seems to be due to using the PreshuffleB pipeline (WPQuantBPipelineAgBgCrV2) with a tile size of 256. Reducing the tile size to 128 seems to not have the issue.
