**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1397](https://github.com/ROCm/composable_kernel/pull/1397) · **Merged:** 2024-08-16 · **Author:** @danyao12

## Summary (from upstream PR description)

Based on ck_tile programming method,  this PR  provides improvement for Fmha backward.  Specifically, it does

Big performance improvement to generally all input shapes for the  FMHA backward problem
Add support of  Headdim256 (head-dimension sizes bigger than 128 but less/equal to 256)
Improve accuracy of output grad_query for  both fp16 and bf16 input data  by using fp32 for AtomicAdd based accumulation
Complete API supports for the requirements from ROCM/TriDao FlashAttention
