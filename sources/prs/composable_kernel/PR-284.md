## Summary (from upstream PR description)

@qianfengz Softmax standalone kernel ready for review. The other requirement, adding kernel instances to ck profiler, can be quickly added once we have softmax user interface detail reviewed and confirmed.
cc @asroy @zjing14
There's an issue for now: it uses NaN trick to avoid accumulating out-of-bound values as detailed in comments below. This trick works great for floating points and pays little extra cost. The problem is NaN doesn't exist for integer types, so a bitmask indicating OOB values in the thread buffer is required to fully support integer type reduction with arbitrary unary operation, obtained from blockwise and threadwise copy.
https://github.com/ROCmSoftwarePlatform/composable_kernel/blob/7b0ec89c7337084eabfad054b6560823e0fa23c9/include/ck/tensor_operation/gpu/grid/gridwise_softmax.hpp#L261-L275
