**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2864](https://github.com/ROCm/composable_kernel/pull/2864) · **Merged:** 2025-09-29 · **Author:** @ecamartins

## Summary (from upstream PR description)

Proposed changes
Recently, an initial implementation of Stream-K has been added to CK Tile with a gtest suite covering initial cases for fp16 and bf16. Thus, this PR aims to add a minimal example for Stream-K in example/ck_tile. Specifically, the example allows users to run Stream-K with either b16 or fp16 with options to configure number of Stream-K blocks, reduction strategy, etc. At this time, only the atomic reduction strategy is supported (see  include/ck_tile/ops/gemm/kernel/streamk_gemm_kernel.hpp for the guard in IsSupportedArgument for details).
There are plans to add more gtests cases to the Stream-K unit tests, which will test for variants, including more pipelines. These examples will be expanded once more unit tests are in place.
Note:
Similarly to Split K, there may be >=1 workgroup contributing to the same macro tile in C via atomic adds. Unlike Split-K, the number of workgroups contributing to a macro tile in C may vary per macro tile. Thus, I have added a function called estimate_num_wgs_per_tile to estimate the number of workgroups per macro tile to allow us to determine a relative and absolute tolerance for validating results.
