# [CK Tile] Improve the Layout, Padding, and Alignment features of CK Tile GEMM

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1651](https://github.com/ROCm/composable_kernel/pull/1651) · **Merged:** 2024-11-12 · **Author:** @ThomasNing

**Inclusion reason:** kernel path 'example/ck_tile/03_gemm/README.md'; keyword 'gemm'

## Summary (from upstream PR description)

Modify the layout code to complete the shuffle tile when it reading to the lds by calling store_tile function based on the transposed layout.
Modify the Alignment code to have the correct and largest alignment memory reading granularity by different layouts.
Modify the padding architecture to padding with the dimension instead of the matrix to improve the detailed features programmability and performance.

Improved the performance when A is in column layout by 40% or B is in row layout in the tile_example_gemm_basic.
