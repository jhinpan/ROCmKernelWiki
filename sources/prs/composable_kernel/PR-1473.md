## Summary (from upstream PR description)

Adding examples and required instances for enabling the following workflow:

input: FP8
weights: FP8
input_scale: FP32 scalar
weights_scale: FP32 scalar
output_scale: FP32 scalar
output: tuple of FP8 tensor and FP32 scalar (AMAX)

serialized_graph = 23:[f32]conv();15:[f32]scale(23);25:[f32]scale(15);33:[f8]scale(25);37:[f32]amax(25)
Also, refactored usage of combined element-wise operations.
