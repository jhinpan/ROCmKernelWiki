# [flatmm] implement basic fp16 flatmm

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2089](https://github.com/ROCm/composable_kernel/pull/2089) · **Merged:** 2025-04-16 · **Author:** @solinzby1

**Inclusion reason:** kernel path 'example/ck_tile/18_flatmm/CMakeLists.txt'; keyword 'mfma'

## Summary (from upstream PR description)

add basic flatmm based on ck_tile :
flatmm is placed in a separate example folder
flatmm is using dependent kernel and pipeline and block function
flatmm is designed to re-use gemm warp funcitons
in this change, we only implement basic flatmm function and framwork:
support fp/bf16 input datatype
support 1x4 warp shape with different tile size
future feature will be added in following changes:
support fp8/bf8 data type
support block scale
support more tile size, warp shape and mfma instr
