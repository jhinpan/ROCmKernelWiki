# Tests for CK Tile Flatmm and MOE Smoothquant

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2458](https://github.com/ROCm/composable_kernel/pull/2458) · **Merged:** 2025-07-20 · **Author:** @ecamartins

**Inclusion reason:** kernel path 'test/ck_tile/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
This PR is meant to contribute to adding tests for ck tile. The goal was to ensure that cases covered in smoke tests are tested in CI to help prevent regressions. This PR contains tests for flatmm and MOE Smoothquant. These migrated tests will be built and run by CI.
For each of flatmm and MOE Smoothquant, the following procedure was followed:

Copied relevant files from example/ck_tile directory to the test/ck_tile directory

Note: I have added comments to denote which files have not been modified


Modified the main cpp file to run test cases covered in the example's smoke tests
Created necessary cases/files for various precisions
Updated CMakeLists accordingly with a key modification being the use of add_test_executable

Notes:

All files in example/ck_tile/14_moe_smoothquant/instances were copied to test/ck_tile/moe_smoothquant/instances (i.e. these files were not modified other than updating license)
I have currently commented out the addition of the MOE Smoothquant subdirectory in the tests' CMakeLists.txt. There is a problem with the original smoke tests on gfx90a resulting in "GPU core dump." Additionally, this issue occurs with sequential kernel invocation
