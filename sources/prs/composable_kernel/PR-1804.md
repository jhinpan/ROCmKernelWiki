# Disable building DPP kernels by default

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1804](https://github.com/ROCm/composable_kernel/pull/1804) · **Merged:** 2025-01-08 · **Author:** @darren-amd

## Summary (from upstream PR description)

Proposed changes
This feature is aimed at adding a flag to enable DPP kernels and otherwise disabling them. These gemm instances are only useful on Navi2x cards so they should be disabled unless explicitly needed. As a plus, this also enables gfx908/gfx90a users to build CK without optimization flags.
