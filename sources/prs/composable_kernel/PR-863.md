# Redesign the DPP8 GEMM kernel to use warp-wise component

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#863](https://github.com/ROCm/composable_kernel/pull/863) · **Merged:** 2023-09-06 · **Author:** @bwroblew

**Inclusion reason:** kernel path 'example/01_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This PR is a redesign of an existing DPP8 GEMM that utilizes thread-wise architecture into one that uses warp-wise component. New kernel is based on XDL GEMM, so it also utilizes gridwise GEMM pipelines.
This change removes the implementation, example and instances of the old kernel.
