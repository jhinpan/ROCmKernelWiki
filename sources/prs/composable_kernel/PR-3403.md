## Summary (from upstream PR description)

Proposed changes
Update AMD buffer coherency for GFX12
This pull request refactors and enhances the handling of AMD buffer coherency across the codebase, improving architecture compatibility and maintainability. It introduces new, architecture-aware enumerations for buffer coherence, removes redundant code, and updates includes and logic to use the new definitions. Additionally, it extends GPU target support and enforces specific configurations for grouped convolution kernels.
AMD Buffer Coherency Refactor and Architecture Support:

Introduced new header files ck/utility/amd_buffer_coherence.hpp and ck_tile/core/arch/amd_buffer_coherence.hpp that define architecture-aware enumerations for AMD buffer coherency, supporting GFX9, GFX11, and GFX12 targets, and providing compatibility aliases. [1] [2]
Removed legacy AmdBufferCoherenceEnum and amd_buffer_coherence_enum definitions from amd_buffer_addressing.hpp, amd_buffer_addressing_builtins.hpp, and their ck_tile equivalents, consolidating coherency logic into the new headers. [1] [2] [3] [4]
