# [CK_TILE] Fix the Wrong Output Generated by Gemm Examples on GFX11/12

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2713](https://github.com/ROCm/composable_kernel/pull/2713) · **Merged:** 2025-08-25 · **Author:** @tywuAMD

**Inclusion reason:** kernel path 'example/ck_tile/03_gemm/gemm_basic.cpp'; keyword 'mfma'

## Summary (from upstream PR description)

Proposed changes
After #2466 got merged, concerns have been raised by several CK users that tile_example_gemm_universal and tile_example_gemm_basic generate wrong output on GFX11/12. To resolve it, this PR introduces a new macro CK_TILE_USE_WMMA in order to separately compile examples for MFMA/WMMA cases with different configs accordingly.
With this PR, tile_example_gemm_universal and tile_example_gemm_basic can provide correct output without any extra compiling flag or argument:
(Note: out-of-memory would be observed when running tile_example_gemm_universal with the default rotating_count=1000. Please check #2690)
