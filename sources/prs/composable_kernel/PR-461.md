# BatchNorm backward implementation

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#461](https://github.com/ROCm/composable_kernel/pull/461) · **Merged:** 2022-11-29 · **Author:** @qianfengz

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

This P.R provides the complete implementation of BatchNorm backward, specially it computes the variance using welford method.
In details, the following are provided:

Single Blockwise BatchNorm-backward kernel
Multiblock BatchNorm-backward kernels which include three kernels and using fusions among two of them



Multiblock Welford first-half kernel (partial Welford for Mean/variance)
Multiblock Welford second-half (final Welford for Mean/Variance) and Reduction first half kernel (partial reduction for ScaleDiff/BiasDiff)
Reduction second half (final reduction for ScaleDiff /BiasDiff) and computing of diffX



Device interface for BatchNorm-backward
Host reference interface for BatchNorm-backward
Example

Both the blockwise and multi-block paths support using saved mean/inv-variance as option
