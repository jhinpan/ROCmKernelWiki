# Statically Cast Pointer Offset

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1631](https://github.com/ROCm/composable_kernel/pull/1631) · **Merged:** 2024-11-05 · **Author:** @darren-amd

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/grid/gridwise_gemm_multiple_d_wmma_cshuffle.hpp'; keyword 'wmma'

## Summary (from upstream PR description)

This is aimed to be a solution for: #1551 where there is an issue with calls to amd_wave_read_first_lane. I found that most calls to
amd_wave_read_first_lane(compute_ptr_offset_of_batch.GetEPtrOffset(g_idx))
were statically cast as:
amd_wave_read_first_lane(static_cast<long_index_t>(compute_ptr_offset_of_batch.GetEPtrOffset(g_idx)));
which would avoid this issue. Staticly casting the remaining calls to avoid this issue.
