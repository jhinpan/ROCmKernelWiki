# fix(grouped_gemm): pipeline selection when tail_num varies per group and leads to numerical error

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2863](https://github.com/ROCm/composable_kernel/pull/2863) · **Merged:** 2025-09-17 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'example/ck_tile/17_grouped_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
In this PR, we fix a numerical issue with the grouped_gemm example on MI350 and MI300. Two root causes are addressed

For FP8 on MI350, needed FP8 MACRO is enabled for fp8 prec to work on MI350
Pipeline selection bug is fixed by calculating tail_num value for every group instead of resuing from group 0. Since this value can vary per group depending on size of K of that group.
