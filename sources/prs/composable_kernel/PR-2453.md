## Summary (from upstream PR description)

Proposed changes
This PR is meant to contribute to adding tests for ck tile. The goal was to ensure that cases covered in smoke tests are tested in CI to help prevent regressions. This PR contains tests for Batched Transpose and Smoothquant. These migrated tests will be built and run by CI.
For each of Batched Transpose and  Smoothquant, the following procedure was followed:

Copied relevant files from example/ck_tile directory to the test/ck_tile directory
Modified the main cpp file to run test cases covered in the example's smoke tests
Created necessary cases/files for various precisions
Updated CMakeLists accordingly with a key modification being the use of add_test_executable

Note: I have added comments to indicate which files were not modified (other than license update).
