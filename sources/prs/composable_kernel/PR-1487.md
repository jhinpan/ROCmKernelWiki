# Enable daily ninja build traces.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1487](https://github.com/ROCm/composable_kernel/pull/1487) · **Merged:** 2024-08-26 · **Author:** @illsilin

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

This PR will generate ninja traces on gfx90a during daily builds with staging and mainline compiler branches, which will be saved as artifacts in json format, so they can be easily downloaded and visualized.
These traces can also be enabled manually for any normal build. However, the user must remember to disable the sccache.
