**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2419](https://github.com/ROCm/composable_kernel/pull/2419) · **Merged:** 2025-07-07 · **Author:** @andriy-ca

Adds support for MX FP6 data type in MX GEMM block pipeline version v1.
Provides an example of MX FP6 GEMM algorithm.

Discussion
Current GEMM implementation accepts FP6 data in packed storage of 16 6-bit numbers. To accommodate direct transfer from Global to LDS, the 12-byte packed storage is aligned on a 128-bit boundary. This results in an additional 4 bytes of storage per 16 entries.
