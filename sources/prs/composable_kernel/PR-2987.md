# Add Memory pipeline for AQuant Block Scale GEMM

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2987](https://github.com/ROCm/composable_kernel/pull/2987) · **Merged:** 2025-10-09 · **Author:** @AviralGoelAMD

## Summary (from upstream PR description)

Proposed changes
The example/ck_tile/38_block_scale_gemm currently has several compute bound pipelines (CompV3) for when we have an AQaunt or a BQuant matrix. This PR bring a new pipeline AQuantGemmPipelineAgBgCrMem for memory bound workloads.
The memory pipeline ping pongs between two sets of tiles for all A, B and AQ matrices.
Set 1 is loaded into memory while Set 2 is used for gemm computation and in the subsequent iterations the role of tiles are reversed.
