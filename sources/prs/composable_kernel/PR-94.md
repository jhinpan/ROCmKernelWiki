# Conv3d new

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#94](https://github.com/ROCm/composable_kernel/pull/94) · **Merged:** 2022-02-23 · **Author:** @j4yan

**Inclusion reason:** kernel path 'composable_kernel/include/config.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

3D convolution:

 Added DeviceConv3dFwdNaive_Input_N_Di_Hi_Wi_C_Weight_K_Z_Y_X_C_Output_N_Do_Ho_Wo_K. This implementation doesn't use GridwiseBatchedGemm. Instead, the passed-in pointers, p_a_grid and p_c_grid, are shifted based on the batches that a wave-group falls in.
 Added a naive conv3d implementation, DeviceConv3dFwdNaive_Input_N_Di_Hi_Wi_C_Weight_K_Z_Y_X_C_Output_N_Do_Ho_Wo_K for verification.
 Added a template paraemter, Block2CTileMap to GridwiseGemm::Run. The old GridwiseGemm::Block2CTileMap is renamed to DefaultBlock2CTileMap.
 Moved overloaded arithmetic operators of integral_constant/Number to integral_constant, since the implementations covers more types.
 Added a new transform primitive, Modulo. It's not efficient because of the modulo operations involved.  Also it's not used in current implementation, so can be safely removed.
 Fixed some coding style issues; renamed some variables for consistency (see variables with name c_blockid_to*).
