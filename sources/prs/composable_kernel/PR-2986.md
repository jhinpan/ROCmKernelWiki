**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2986](https://github.com/ROCm/composable_kernel/pull/2986) · **Merged:** 2025-10-29 · **Author:** @vpietila-amd

## Summary (from upstream PR description)

Proposed changes
Added an option to merge multiple convolution groups into a single GEMM batch. Added some unit tests for the components involved. Integration tests for the grouped convolutions are pending the integration of the CK tile engine. The functionality is implemented for the backwards weight convolution. Convolution group merging for the forward direction and potentially for the backwards data direction will be added in separate PRs.
