# [CK_BUILDER] Improve CK Builder and CK Builder tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3382](https://github.com/ROCm/composable_kernel/pull/3382) · **Merged:** 2025-12-11 · **Author:** @vpietila-amd

**Inclusion reason:** kernel path 'experimental/builder/include/ck_tile/builder/README.md'; keyword 'fp8'

## Summary (from upstream PR description)

Proposed changes
This PR addresses the comments left in PR #3331.
Improvements to CK Builder code

Improved the << operator overload for CK Builder primitive types by creating toString methods to handle the different types. These methods are used to overload  << , but can be used also elsewhere (e.g. in tests).
Unified handling of boolean parameters in the instance strings. Now all boolean template parameters are printed as true/false in the instance string.

Improvements/changes to CK Builder test code

using enum ... in various places reduces repetition of namespaces.
For the fwd convolutions from CK, created utilities to create expected parameter strings that can be compared against the instance string provided by the instance traits. This allows testing that all transfer parameters are passed via the builder to the CK instance.
Updated expected strings for the conv instance traits tests after changing the handling of the boolean flags.
