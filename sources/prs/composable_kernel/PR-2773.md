## Summary (from upstream PR description)

Proposed changes
The EpilogueChainer allows to stack epilogues one after the other and run them sequentially.
The EpilogueChainer implementation is demonstrated using the cshuffle epilogue by breaking and chaining it. The breaking and testing of the cshuffle epilogue is taken from #2729, hence this also has the row/col scaling. The example shows how the epilogues are modular and can sort of plugged-in if needed.
