## Summary (from upstream PR description)

Depends on #436 #429
This PR aims to update BatchedGemmSoftmaxGemmPermute and GroupedGemmSoftmaxGemmPermute in line with device_batched_contraction_multiple_d_xdl_cshuffle.hpp. The old arguments will be replaced by vector of lengths and strides of each tensor, and provides "Packed" tensor specialization for degenerating each N-D tensor into 3D form [G, M, N] when permutation isn't needed.
"Packed" in a sense that each inner dimension in a dimension group (eg [G0, G1] in Gs, [M0, M1, M2] in Ms, etc.) are contiguous and ordered. Not in a sense that the tensor [G0, G1, ..., M0, M1, ..., N0, N1...] can be permuted while still being a contiguous, unpadded tensor.
