# Remove 'basic' and universal GEMM tests, and incorporate their test cases into the GEMM pipeline tests

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3094](https://github.com/ROCm/composable_kernel/pull/3094) · **Merged:** 2025-11-13 · **Author:** @SamiAario-AMD

**Inclusion reason:** kernel path 'include/ck_tile/core/tensor/tile_window.hpp'; keyword 'wmma'

## Summary (from upstream PR description)

Proposed changes
The "basic" GEMM tests do not test the basic GEMM (pipelines V1 and V2), but rather the V3 pipeline, which is tested by the universal GEMM tests. As for the universal GEMM tests, they have overlapping coverage with the GEMM pipeline tests. The pipeline tests, on the other hand, offer more test coverage per parameter set. Therefore remove the "basic" and universal GEMM tests, and incorporate their test cases into the GEMM pipeline tests.
