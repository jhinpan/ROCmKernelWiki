# [CK TILE] Stream-K tile partitioner

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2708](https://github.com/ROCm/composable_kernel/pull/2708) · **Merged:** 2025-09-03 · **Author:** @arai713

## Summary (from upstream PR description)

Proposed changes
This PR introduces a new struct, StreamKTilePartitioner, in the gemm_tile_partitioner file as part of Stream_K's integration into CK Tile. This implementation is derived from the original Stream-K implementation in old CK, which can be found at example/01_gemm/gemm_xdl_streamk.cpp. The Stream-K algorithm has an emphasis on mapping, therefore the tile partitioner requires more functions than a typical gemm tile partitioner. As the Stream-K algorithm will require information from the tile partitioner at various points, most of the functions from this tile partitioner are non-static, in contrast to the other gemm tile partitioners.
