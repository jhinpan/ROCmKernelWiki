# Add build trace diagnostics to CI.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3432](https://github.com/ROCm/composable_kernel/pull/3432) · **Merged:** 2025-12-16 · **Author:** @illsilin

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
These changes will enable generating a ninja build trace for every architecture and every branch during the standard CI builds. The traces will be analyzed to catch any files that take more than certain threshold (15 min) to build.
The warnings about build times will appear in the jenkins output and for the time being are not going to cause the pipelines to fail. They will looks something like this:
[2025-12-15T20:35:25.146Z] + python3 ../script/parse_ninja_trace.py ck_build_trace_gfx90a.json
[2025-12-15T20:35:25.146Z] JSON parsed successfully!
[2025-12-15T20:35:25.146Z] build duration of example/ck_tile/18_flatmm/CMakeFiles/tile_example_moe_flatmm.dir/moe_flatmm.cpp.o  exceeds 15 minutes! actual build time: 17.23 minutes!
[2025-12-15T20:35:25.146Z] build duration of example/ck_tile/03_gemm/CMakeFiles/tile_example_gemm_basic.dir/gemm_basic.cpp.o  exceeds 15 minutes! actual build time: 19.55 minutes!
[2025-12-15T20:35:25.146Z] build duration of library/src/tensor_operation_instance/gpu/grouped_conv3d_fwd_bias_clamp/CMakeFiles/device_grouped_conv3d_fwd_bias_clamp_instance.dir/xdl/comp/device_grouped_conv3d_fwd_bias_clamp_xdl_ndhwgc_gkzyxc_ndhwgk_fp16_comp_instance.cp
