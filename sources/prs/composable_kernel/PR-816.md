# Disable DL kernels by default.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#816](https://github.com/ROCm/composable_kernel/pull/816) · **Merged:** 2023-07-26 · **Author:** @illsilin

**Inclusion reason:** kernel path 'library/include/ck/library/tensor_operation_instance/gpu/batched_gemm_multi_d.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

We have a couple of dl kernels, gemm_dl and batched_gemm_multi_d_dl, that take a very long time to build on all platforms.
It has been decided to disable them by default and add a cmake flag "DL_KERNELS" that will need to be set to "ON" in order to build them.
With this change, build times across all platforms should drop by approximately 2x and building CK instances for all platforms can be completed in ~30 minutes.
We will still continue to build and test these kernels in our CI on navi21.
