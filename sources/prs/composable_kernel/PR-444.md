# Rangify check_err()

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#444](https://github.com/ROCm/composable_kernel/pull/444) · **Merged:** 2022-11-11 · **Author:** @poyenc

## Summary (from upstream PR description)

By rangifying check_err(), we can not only compare values between std::vector<>s, but also compare any ranges which have same value type.
Synopsis
template <typename Range, typename RefRange>
typename std::enable_if<
    std::is_same_v<ranges::range_value_t<Range>, ranges::range_value_t<RefRange>> &&
        std::is_floating_point_v<ranges::range_value_t<Range>> &&
        !std::is_same_v<ranges::range_value_t<Range>, half_t>,
    bool>::type
check_err(const Range& out,
          const RefRange& ref,
          const std::string& msg = "Error: Incorrect results!",
          double rtol            = 1e-5,
          double atol            = 3e-6)
{
    // other codes
}
Before this PR
std::vector<float> out, ref;

check_err(out, ref);
After this PR
std::vector<float> out;
std::list<float> ref;

check_err(out, ref);
