# [CK_TILE] Stream-K Tree Reduction and Cache Skipping Integration

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3371](https://github.com/ROCm/composable_kernel/pull/3371) · **Merged:** 2025-12-14 · **Author:** @ecamartins

## Summary (from upstream PR description)

Proposed changes
This PR makes 2 main changes. A high-level description of the changes is as follows:

Adds a Tree Reduction strategy to CK Tile Stream-K:
In the original Stream-K reduction (implemented in PR3107), when there are N workgroups contributing to the same C tile, the first workgroup of the tile is responsible for reading and accumulating all partial results of the other N-1 workgroups from a global buffer. This takes O(N) steps, which can become a bottleneck when N is large. This PR introduces a new reduction strategy that avoids placing the burden on a single workgroup to accumulate all results for a C tile. This new strategy is a Tree Reduction, where all workgroups contributing to a C tile cooperatively accumulate results in parallel, reducing the number of steps for the reduction from O(N) to O(logN).
