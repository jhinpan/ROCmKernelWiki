# Rangify constructor of HostTensorDescriptor & Tensor<>

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#445](https://github.com/ROCm/composable_kernel/pull/445) · **Merged:** 2022-11-11 · **Author:** @poyenc

**Inclusion reason:** kernel path 'example/01_gemm/gemm_xdl_skip_b_lds_fp16.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

With rangified constructors, we can create HostTensorDescriptor & Tensor<> objects by any ranges
Synopsis
struct HostTensorDescriptor
{
    template <typename X,
              typename Y,
              typename = std::enable_if_t<std::is_convertible_v<X, std::size_t> &&
                                          std::is_convertible_v<Y, std::size_t>>>
    HostTensorDescriptor(const std::initializer_list<X>& lens,
                         const std::initializer_list<Y>& strides)
        : mLens(lens.begin(), lens.end()), mStrides(strides.begin(), strides.end())
    {
    }
};
Before this PR
HostTensorDescriptor(std::vector<std::size_t>({row, col}),
                     std::vector<std::size_t>({stride, 1}));
After this PR
HostTensorDescriptor({row, col}, {stride, 1_uz});
