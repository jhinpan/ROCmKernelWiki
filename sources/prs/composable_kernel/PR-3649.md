## Summary (from upstream PR description)

Proposed changes
NOTE: Targetting #3618 merge that one first!!
This integrates builder/testing/validation.hpp with CK gpu_verification.hpp, so to reduce code duplication across the codebase a little bit. Initially I didn't really want to replace the CKB implementation since it was only a few lines, but decided to do it anyway following a request to also expose a variant of ValidationReport::check that accepts number_of_accumulations and automatically derives tolerances from that and the data type/compute type/accumulation type.
Design
One of the main problems when trying to integrate these two is that the functionality in gpu_verification.hpp only accepts linear tensors, and validation.hpp deals with multi-dimensional tensors too. Initially, I considered copying the tensor to a linear buffer (as you can see from copy_tensor still being in this PR, I figured it might be useful), but in the end decided to write an iterator adopter which lets one index a tensor using a flat index. Its basically a combination of the NdIter introduced recently and a pointer to the device memory.
