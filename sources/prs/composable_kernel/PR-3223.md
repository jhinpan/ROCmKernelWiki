## Summary (from upstream PR description)

Proposed changes
This is a continuation of the work done in #3071. Now that the remaining reflection code has been merged, the remaining tests can be implemented. I just quickly did this using some tooling that I already wrote before.
This branch is based on top of #3222 as its required to get the tests properly working. I'll rebase it once that has been merged. Rebased
Review suggestions
Check that there is no test which expects the string "". The empty string means that there is a device operation which does not have reflection implemented yet.
Testing
Simply build the CK factory tests and run them all:
$ ninja -t targets | grep factory | cut -d: -f1 | xargs ninja
$ for f in $(ls bin/ | grep factory); do bin/$f; done

This builds the device ops library, so it might take a while.
