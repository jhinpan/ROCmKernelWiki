# Add a CMake property for c++ standard (17 or 20)

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2736](https://github.com/ROCm/composable_kernel/pull/2736) · **Merged:** 2025-08-26 · **Author:** @shumway

## Summary (from upstream PR description)

Add a CMake property for c++ standard (17 or 20).
We had hard-coded c++20, but we need to test builds of c++17 until all downstream libraries are migrated.
This PR adds a CMake variable CK_CXX_STANDARD that can be set to 17 or 20, with a default of c++20.
