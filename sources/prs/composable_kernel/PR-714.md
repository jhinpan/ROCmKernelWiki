# Enable gemm_dl and other kernels on Navi3x.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#714](https://github.com/ROCm/composable_kernel/pull/714) · **Merged:** 2023-05-23 · **Author:** @illsilin

**Inclusion reason:** kernel path 'example/02_gemm_bilinear/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This PR includes several changes:

enable gemm_dl and some other kernels on Navi3x.
filter out the tests and examples that are supported on Navi21 so that we can run them during CI.
change the jenkins pipeline so that we can build and run the tests on Navi21; we will also build for MI300 during the daily QA runs so that our packaged ckProfiler can be used on MI300.
I've discovered that our current code takes ridiculously long time to build on Navi3x, so I've disabled building for this target for now until I manage to reduce the build time to some reasonable value.
