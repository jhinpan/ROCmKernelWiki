# [CK_TILE][FMHA] Add FP8 support for batch_prefill kernel

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3425](https://github.com/ROCm/composable_kernel/pull/3425) · **Merged:** 2025-12-24 · **Author:** @poyenc

## Summary (from upstream PR description)

Proposed changes
Summary
This PR adds FP8 (float8_e4m3) support to the batch_prefill FMHA kernel, enabling mixed-precision computation with FP8 inputs and BF16 outputs.
Key Changes

FP8BF16 kernel mode: Add support for FP8 input (Q, K, V) with BF16 output in batch_prefill operation
Per-tensor quantization: Support descale parameters for FP8 dequantization in the qr_async pipeline
Extended kernel coverage: Add FP8 kernel instances with logits soft-capping support

Implementation Details

Uses qr_async pipeline with FP8 tensor core operations
Supports per-tensor quantization via descale parameters
Output dtype restricted to BF16 for FP8 inputs (fp8bf16 mode)

Testing
Validated against BF16 reference implementation with accuracy threshold < 0.055
