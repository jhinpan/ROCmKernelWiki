# CSV-driven convolution test pipeline

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2581](https://github.com/ROCm/composable_kernel/pull/2581) · **Merged:** 2025-08-13 · **Author:** @JH-Leon-KIM-AMD

**Inclusion reason:** kernel path 'test_data/generate_model_configs.py'; keyword 'kernel'

## Summary (from upstream PR description)

Updates (2025-08-06)
Summary
Generate convolution test datasets from real PyTorch models by capturing MIOpen commands.
What Changed
Pipeline Flow
PyTorch Models → MIOpen Commands → CSV Test Cases → CK GTest
Main Script
generate_test_dataset.sh: Generate convolution test datasets

Check for existing files before running
Configurable MAX_ITERATIONS (0=unlimited, 10=quick test, default=20)
Combine individual CSVs into final datasets

Components


generate_model_configs.py: Generate model configurations

2D models: ResNet, VGG, MobileNet, DenseNet, AlexNet, GoogleNet,
SqueezeNet, ShuffleNet
3D models: R3D, MC3, R(2+1)D
Input sizes: 64x64 to 512x512, plus rectangular inputs
Single precision (fp32) only



run_model_with_miopen.py: Execute PyTorch models

Run models with MIOPEN_ENABLE_LOGGING_CMD=1
Capture convolution commands to log files



miopen_to_csv.py: Convert MIOpen commands to CSV

Parse MIOpen driver commands
Generate CK test format: NDim, Groups, BatchSize, Channels, Kernel,
Stride, Padding



Output (test cases for test_grouped_convnd_fwd_dataset_xdl)

conv_test_set_2d_dataset.csv: 2D convolution test cases
conv_test_set_3d_dataset.csv: 3D convolution test cases
Format: CSV
