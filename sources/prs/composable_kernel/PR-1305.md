# Make the library which generates CK instances for pytorch2 inductor's CK backend usage

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1305](https://github.com/ROCm/composable_kernel/pull/1305) · **Merged:** 2024-05-22 · **Author:** @tenpercent

**Inclusion reason:** kernel path 'python/ck4inductor/__init__.py'; keyword 'gemm'

## Summary (from upstream PR description)

We probably do not want to put the code which generates the ck instances into pytorch repository since it creates unnecessary coupling. With this PR, we can provide an interface for generating CK instances via a python package.
This PR also bundles the CK library and include files with the pip package.
The package is pip-installable with
pip install git+https://github.com/tenpercent/composable_kernel@enable-pip
(substitute the repo path and branch if necessary)
Testing
myenv/bin/python3 -m ck4inductor.universal_gemm.gen_instances
(prints a list of instances)
tree myenv/lib/python3.12/site-packages/ck4inductor
(observe the list of sources along the installed package)
myenv/bin/pip3 uninstall rocm-composable-kernel
(cleans up the installed package)
In REPL,
>>> from ck4inductor.universal_gemm.gen_instances import *
>>> gen_ops_library()

(prints a list of instances)
