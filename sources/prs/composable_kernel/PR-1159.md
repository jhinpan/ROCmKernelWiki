# Split-up instances to improve build times.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1159](https://github.com/ROCm/composable_kernel/pull/1159) · **Merged:** 2024-02-07 · **Author:** @illsilin

**Inclusion reason:** kernel path 'library/include/ck/library/tensor_operation_instance/gpu/device_gemm_xdl_c_shuffle_fp8_fp8_fp8_mk_kn_mn_instance.hpp'; keyword 'wmma'

## Summary (from upstream PR description)

Just splitting up the large instance files into smaller ones to improve the parallelization of the build and reduce the build times.
This should bring the build time on MI100/200/300 from ~33 minutes to ~17 minutes (when using ~200 threads).
