**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2233](https://github.com/ROCm/composable_kernel/pull/2233) · **Merged:** 2025-05-27 · **Author:** @DDEle

## Summary (from upstream PR description)

Proposed changes
Add operator/instance filters to ckProfiler:

Example 1: to profile gemm_multiply_multiply only:
​sh ../script/cmake-ck-dev.sh ../ gfx950 -DCK_PROFILER_OP_FILTER='^gemm_multiply_multiply$'
cmake --build . -- ckProfiler
./bin/ckProfiler ... 

Example 2: to profile gemm_multiply_multiply and profile_gemm_multiply_multiply_wp:
sh ../script/cmake-ck-dev.sh ../ gfx950 -DCK_PROFILER_OP_FILTER='^gemm_multiply_multiply'
cmake --build . -- ckProfiler
./bin/ckProfiler ...

Example 3: to profile normalization
​sh ../script/cmake-ck-dev.sh ../ gfx950 -DCK_PROFILER_OP_FILTER='groupnorm' -DCK_PROFILER_INSTANCE_FILTER='normalization'
cmake --build . -- ckProfiler
./bin/ckProfiler ...


In addition, enable gfx95 for all gfx94 cases in ckProfiler.
