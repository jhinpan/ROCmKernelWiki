## Summary (from upstream PR description)

Use math functions naming ck_abs(),  ck_isnan(), ck_sqrt() under namespace ck::math for both host and kernel
Remove host_reduce_util.hpp which is not needed
Change to host reduction, profiler reduce,  reduce and pooling examples to use the changed math naming and use uniform interfaces as reduction kernels
