**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3391](https://github.com/ROCm/composable_kernel/pull/3391) · **Merged:** 2026-01-20 · **Author:** @ErwinTerpstra

## Summary (from upstream PR description)

Proposed changes
Add support for batched gemm gemm with multiple D instances on RDNA4. This MR contains:

Device struct for batched gemm gemm with multiple D (DeviceGroupedGemmMultipleD_Wmma_CShuffle_TileLoop_V3)
Support for multiple D in the existing GridwiseBatchedGemmGemm_wmma
General-use instance and a fallback instance with padding and support for odd sizes
Added WMMA version for example 37: batched_gemm_add_add_relu_gemm_add

Note that this example has a double add on gemm 0, instead of the single add I added instances for. There was no example for the single add and it seemed excessive to add one which would be extremely similar to the double add version.


New tests for batched_gemm_add_relu_gemm_add

Note that XDL instances were previously not covered by tests, but are included in these new tests.


Profiler implementation (profile_batched_gemm_multiple_d_gemm_multiple_d_impl )
