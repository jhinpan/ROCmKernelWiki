# Fix fmha fwd precision issue on MI3XX series

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2285](https://github.com/ROCm/composable_kernel/pull/2285) · **Merged:** 2025-06-10 · **Author:** @MHYangAMD

**Inclusion reason:** kernel path 'include/ck_tile/core/config.hpp'; keyword 'async'

## Summary (from upstream PR description)

Proposed changes
For fmha fwd fp16 cases, we found that using impl::cast_tile_pk_fp16_fp32 for casting P would lead to precision issues, since it uses __builtin_amdgcn_cvt_pkrtz, which is round to zero.
For examaple, fixing K,V to be all 1, and Q is random, which outputs are expected to be all 1. But we found that it would have some incorrect outputs 0.9995, whose errors are smaller than the atol 0.001. (1 - 0.9995 = 0.0005 < 0.001) Thus, this error is hard to report by ck, but it does cause potential accuracy issues.
