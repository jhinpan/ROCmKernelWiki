# Add support for specifying valid flag when fetching elements for tile_scatter_gather

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2332](https://github.com/ROCm/composable_kernel/pull/2332) · **Merged:** 2025-06-16 · **Author:** @ruanjm

**Inclusion reason:** kernel path 'include/ck_tile/core/tensor/tile_scatter_gather.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

User can specify a valid array which stores flags indicate whether the corresponding element is valid when load/store. This flag is for the case that the kernel internal fixed tile size along gather dim is not aligned with the actual tile size. E.g. seqlen_k is 21 while blockN0 of gemmQK must be power of 2.
