# [CK Grouped Gemm] Disable split-k kernel for split-k > 1 with non-contiguous strides

## Summary (from upstream PR description)

Proposed changes
The split-k grouped gemm kernel fails when split-k > 1 and the strides are not contiguous.
This caused a crash when running the profile_grouped_gemm.sh test with layout 0 or 1, which no longer occurs after this restriction.
