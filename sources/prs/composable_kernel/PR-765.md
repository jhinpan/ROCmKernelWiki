# Disable XDL kernels on unsupported HW; Add `ck::is_xdl_supported` function

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#765](https://github.com/ROCm/composable_kernel/pull/765) · **Merged:** 2023-06-20 · **Author:** @bwroblew

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/device_gemm_xdl_waveletmodel_cshuffle.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This PR introduces ck::is_xdl_supported function that can be used to check if present HW supports XDL operations. It simplifies many checks in IsSupportedArgument methods and makes it easier to add new architectures - they can now be added in a single place rather than in every XDL instance.
This change also adds this check to some instances where it was missing.
Resolves #762.
