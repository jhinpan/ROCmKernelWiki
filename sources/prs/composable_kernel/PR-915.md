# Use hipGraph capturing and replaying method for forward verification in examples/52_xxx

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#915](https://github.com/ROCm/composable_kernel/pull/915) · **Merged:** 2023-09-19 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'example/52_flash_atten_bias/run_batched_multihead_attention_bias_forward.inc'; keyword 'attention'

## Summary (from upstream PR description)

Some findings from the work of this PR:

Actual device memory allocation (eg. call hipMalloc) could not be included inside the hipGraph capturing for hipStreamCaptureModeGlobal, but can be included inside for hipStreamCaptureModeRelaxed
Memory-setting and memory-copying have to be asynchronous to use the same stream as the hipGraph. So the following changing is necessary
Host memory used for hipMemcpyAsync should be persistent when hipGraph capturing is active



hipMemcpy() to hipMemcpyAsync()
hipMemset() to hipMemsetAsync()
