**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3018](https://github.com/ROCm/composable_kernel/pull/3018) · **Merged:** 2025-10-16 · **Author:** @ecamartins

## Summary (from upstream PR description)

Proposed changes
CK Tile's current Stream-K Tile Partitioner does not align with the original Stream-K paper. Thus, this PR, done in collaboration with @arai713, introduces a new Stream-K Tile Partitioner that better aligns with the Stream-K paper. There are also other AMD teams working on Stream-K; thus, some of our new design considerations are more in line with what other teams are doing. The differences between the old and new CK Tile Stream-K Tile Partitioners are as follows:

The grid size calculation now falls into 3 cases: (1) Stream-K only, (2) Data-parallel (DP) only, (3) DP + 2 Tile Stream-K
When we perform a hybrid of DP and Stream-K, we perform the DP section before the Stream-K section
We add a tile partitioner that supports a DP sections that are fully persistent or non-persistent (i.e. 1 C macro tile per work group).

We introduce a Stream-K Tile Partitioner base and derived class. There are two different template specializations for the derived class: one where persistent is true and another where persistent is false.
