# [CK_TILE] Low CU utilization optimization for fMHA fwd kernels

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2402](https://github.com/ROCm/composable_kernel/pull/2402) · **Merged:** 2025-07-09 · **Author:** @poyenc

## Summary (from upstream PR description)

Proposed changes
Set environment variable CK_TILE_FMHA_FWD_CUSTOM_FACTORY to 1 to enable the optimization (default value is 0).
Currently the optimization only works for hdim=128 cases. If CU utilization is below 80% (estimate using kM0=128), switch to use kM0=64 kernels to run more blocks simultaneously.
This PR also makes the following design change: the body of the fmha_fwd() function in the CK C++ API is generated by a script. It contains a large if-else structure that decides which kernel to launch. For example, when data_type=fp16 and hdim=128:
if (t.data_type.compare("fp16") == 0) {
  if (t.hdim_q <= 128 && t.hdim_v <= 128) {
    if (cond0) {
      // run kernel0
    } else if (cond1) {
      // run kernel1
    } else if (cond2) {
      // run kernel2
    }
    // other cases...
  }
}
This PR adds two customizable condition checks:

One is attached to the FmhaFwdTileSize objects
The other is attached to the FmhaFwdPipeline objects
