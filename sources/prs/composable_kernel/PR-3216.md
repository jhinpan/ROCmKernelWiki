# [CK, CK_TILE] Add GPU Reference Implementations for Grouped Convolution

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3216](https://github.com/ROCm/composable_kernel/pull/3216) · **Merged:** 2025-12-03 · **Author:** @JH-Leon-KIM-AMD

**Inclusion reason:** kernel path 'example/09_convnd_fwd/run_convnd_fwd_example.inc'; keyword 'attention'

## Summary (from upstream PR description)

Proposed changes
Implements GPU reference kernels for both CK Tile and Old CK convolution operations to enable fast verification with GPU instead of slow CPU references.
Problem: CPU verification is too slow for large tensors (>2GB). GPU verification was missing or broken.
Solution: Implemented GPU references for all three convolution directions in both CK Tile and Old CK.
Result: 50-100x faster verification. 162 total tests passing (120 CK Tile + 42 Old CK).
Related Issues: LWPCK-4043 (CK Tile), LWPCK-4042 (Old CK)
