# Changes to allow MIOpen to build CK as part of its build.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2247](https://github.com/ROCm/composable_kernel/pull/2247) · **Merged:** 2025-05-28 · **Author:** @adickin-amd

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

Proposed changes
I want to make it so CK can be built as part of MIOpen.  Currently MIOpen builds CK as a static lib and installs it in /opt/rocm.  MIOpen build then pulls those static libs from /opt/rocm.  These changes will allow us to build the static libs during the MIOpen build and /opt/rocm will be ignored.  The main reason for the changes is that several targets such as check and inclusions like clangTidy also exist in MIOpen so I needed a way to turn those off.
