# Add mechanism to build CK for select data types, add Navi3x CI.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#790](https://github.com/ROCm/composable_kernel/pull/790) · **Merged:** 2023-07-18 · **Author:** @illsilin

**Inclusion reason:** kernel path 'example/01_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

This change adds a mechanism to build CK for select data types by adding -DDTYPES="fp16;fp32;pf64;fp8;bf16;int8", or any subset thereof, on the cmake command line.
We are going to parse the values of the DDTYPES and set macros, such as, "int8", "fp16", etc, so that any specific instances can be enclosed in the #ifdef int8 conditions to enable or disable during the build.
By default, if DTYPES flag is not set, the code will just build everything as before.
In the current commit, only a handful of int8 instances are actually being affected by this new flag, because they have a detrimental effect on the build times for the gfx11 architectures: quantization_int8, gemm_dl_int8, batched_gemm_dl_int8.
We may eventually go over all the remaining instances for all data types and isolate them, but it may require some time, since there are so many instances by now.
With this change we are also going to enable the CI stage of building and testing CK on Navi32 nodes (with the exception of tests and examples using the instances mentioned above).
