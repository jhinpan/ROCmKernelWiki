## Summary (from upstream PR description)

These changes will enable a new stage in daily CI jobs that will build and run ck_tile fmha_fwd and fmha_bwd tests on gfx90a and gfx942 systems.
The build and execute times for these tests are ~3 hours, so it's not practical to perform this stage in every routine CI job.
