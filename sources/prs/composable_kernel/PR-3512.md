**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3512](https://github.com/ROCm/composable_kernel/pull/3512) · **Merged:** 2026-01-07 · **Author:** @CongMa13

## Summary (from upstream PR description)

Problem:
In theory, this ternary operation is trivial: return buffer_load_dwordx4 results for valid address and zeros for others. In practice, the compiler is generating assembly that bloats VGPR usage. This overhead is putting unnecessary pressure on our kernel's register allocation.
Impact:

Increased VGPR usage per thread
Reduced kernel occupancy and potential performance degradation

Hardware: MI300X
