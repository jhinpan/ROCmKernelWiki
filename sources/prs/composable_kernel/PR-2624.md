# Preshuffle AQ matrix in block scale gemm

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2624](https://github.com/ROCm/composable_kernel/pull/2624) · **Merged:** 2025-08-13 · **Author:** @CongMa13

## Summary (from upstream PR description)

Proposed changes
Preshuffle of AQ means put block tile of the AQ matrix in a consecutive memory area in host code.
for example, AQ matrix is [ 17 x 16] and block tile is [16 x 2]. There are [2 x 8] block tiles in AQ.

After preshuffle, data of each block tile are consecutive. The loading is faster than before.

transform:

One block tile in each row
Pad the row to multiple times of wave size

When loading AQ block tile, thread[i] will load shuffled_aq[block_m , i]. block_m is determined by the position of the block in C.
When a thread needs to use shuffled_aq[block_m , i], just pulls it from thread[i].
