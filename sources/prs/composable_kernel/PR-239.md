# Tensile-style block to C tile map

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#239](https://github.com/ROCm/composable_kernel/pull/239) · **Merged:** 2022-05-25 · **Author:** @rosenrodt

**Inclusion reason:** kernel path 'include/ck/tensor_operation/gpu/device/device_grouped_gemm_xdl.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This PR depends on #235. See diff against #235

Add 2 more tile map variants. M01"Adapt" means the bottom-most M01-by-N0 group can shrink on M01 dimension so that all mapped index is within C matrix boundary. So any "adapted" C tile map instance can apply to all problem sizes.

BlockToCTileMap_M00_N0_M01Adapt for gemm and batched gemm
BlockToCTileMap_KSplit_M00_N0_M01Adapt for split-k gemm


Apply new tile map to all XDL gridwise gemm implementations
Quick benchmark on MI100 @1087mhz shows gemm_xdl_fp16 improves from 113 Tflops to 116 Tflops (7680 x 8192 x 8192)
