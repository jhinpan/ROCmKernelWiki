# feat: Add Interwave scheduler for aquant memory pipeline

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3540](https://github.com/ROCm/composable_kernel/pull/3540) · **Merged:** 2026-01-26 · **Author:** @AviralGoelAMD

**Inclusion reason:** kernel path 'example/ck_tile/38_block_scale_gemm/gemm_aquant_quantgrouped.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
In example/ck_tile/38_block_scale_gemm for quant_mode=aquant the current memory pipeline only supports one scheduling mechanism (intrawave) where each wave works independently of other waves to compute resultant wave tile for matrix C.
In this PR, we add interwave scheduling mechanism that orchestrates all the waves to work in lockstep and over finer grained chunks to compute resultant wave tile.
INTRAWAVE SCHEDULING (Independent Waves)
=========================================
Each wave loads full K dimension independently and computes its warp tile

Wave 0: [════════ Load K=0→32 ════════] → [══════ Compute ══════]
Wave 1: [════════ Load K=0→32 ════════] → [══════ Compute ══════]
Wave 2: [════════ Load K=0→32 ════════] → [══════ Compute ══════]
Wave 3: [════════ Load K=0→32 ════════] → [══════ Compute ══════]
         
        Time →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→


INTERWAVE SCHEDULING (Lockstep Waves)
======================================
All waves synchronized, process K in chunks (MAC clusters)

         ┌─── MAC Cluster 0 ───┐  ┌─── MAC Cluster 1 ───┐
         │                      │  │                      │
Wave 0: [Load K=0→8] [Compute] ╫
