# [CK_BUILDER] group transfer concepts

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3217](https://github.com/ROCm/composable_kernel/pull/3217) · **Merged:** 2025-11-20 · **Author:** @Snektron

**Inclusion reason:** kernel path 'experimental/builder/include/ck_tile/builder/conv_algorithm_concepts.hpp'; keyword 'fp8'

## Summary (from upstream PR description)

Proposed changes
Grouping transfer operations per tensor makes it easier to constrain on and operate with the transfer operations. As an example, we can now deduplicate the logic for translating the transfer operations from the ck-builder interface to the old ck interface for the A and B tensors.
The concepts are still grouped as before, this mainly just changes the structure for those operations.
Fixes
I had to fix some uses of hip_check_error in CK Tile, as they were conflicting with the CK headers also included in CK Builder. My guess that one side of this was probably introduced in #3183, though I don't know if it worked when that was merged. Implemented and merged in in #3222 now.
