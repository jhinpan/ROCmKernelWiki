## Summary (from upstream PR description)

Proposed changes
This PR adds new layout support for input tensors provided to example/38_block_scale_gemm quant_mode=aquant.
The acceptable layouts for tensor A, B, C and Aquant are

Row-Row-Row-Row
Col-Row-Row-Row
Col-Col-Row-Col

Along with new layout support, we add new unit tests and then refactor the existing unit tests into multiple cpp files for faster compilation.
