# Switch to the new rocm5.6 compiler.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#681](https://github.com/ROCm/composable_kernel/pull/681) · **Merged:** 2023-04-21 · **Author:** @illsilin

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

This change will cause our CI to start using the new rocm5.6 version compiler by default.
We will still have 3 daily builds for develop branch:

using default compiler and running performance profiling for large number of kernels;
using latest release version of rocm (currently still 5.4.3);
and one more using the latest version of the amd-stg-open compiler.
