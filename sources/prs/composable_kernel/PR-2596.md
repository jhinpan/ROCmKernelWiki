## Summary (from upstream PR description)

Proposed changes
In previous work (see PRs #2417, #2453, #2458, #2421), cases covered in CK tile smoke tests were migrated to test/ck_tile as ctests for quick way to help prevent regressions in our develop branch. After merging, there was a request (see comments in #2421 and #2417) for us to use the GoogleTest framework; thus, this PR is the first of this work to refactor ctests of MOE sorting and smoothquant to use the GoogleTest framework. Future PRs will refactor other ctests.
