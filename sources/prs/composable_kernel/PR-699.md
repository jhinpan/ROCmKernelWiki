# initial stream-k implementation with example

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#699](https://github.com/ROCm/composable_kernel/pull/699) · **Merged:** 2023-07-26 · **Author:** @carlushuang

**Inclusion reason:** kernel path 'example/01_gemm/CMakeLists.txt'; keyword 'gemm'

## Summary (from upstream PR description)

streamk implementation with example, use make example_gemm_xdl_streamk to build.

support both atomic and reduction mode for the partial acc accumulation cross wgs
for reduction mode use less workspace for partial acc (compared with cutlass)
atomic version is better than splitk, but reduction mode still need performance optimization. So now by default use atomic version.
