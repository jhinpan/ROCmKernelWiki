## Summary (from upstream PR description)

Proposed changes
This PR adds a new tile size configuration for the async FMHA pipeline and relocates a buffer load fence to address a compiler bug in ROCm 7.1.1.
Changes:
Moved buffer_load_fence(0) call earlier in the masked tile handling path to prevent compute errors in ROCm 7.1.1
Added a new 64x128 tile size configuration for hdim=128, hdim_v=128 cases with CU constraint
Modified the sequence tuning logic to include bm0=64 as a fallback tile size
