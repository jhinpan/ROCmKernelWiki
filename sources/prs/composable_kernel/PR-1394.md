# Replace the using of __expf by __ocml_exp_f32  when defining __device__ exp()

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1394](https://github.com/ROCm/composable_kernel/pull/1394) · **Merged:** 2024-07-17 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'include/ck_tile/core/numeric/bfloat16.hpp'; keyword 'kernel'

## Summary (from upstream PR description)

This is a work-around of the issue mentioned in SWDEV-454902, where with some compiler version, using __expf() or __ocml_native_exp_f32() can lead to the failure of test_softmax_rank4.
To work-around,  in all definitions of __device__ exp(),  __expf is replaced by __ocml_exp_f32. Several header files are involved under both ck and ck_tile including folders
With this work-around, the performance of ck softmax kernel will be affected.  The ck_tile fmha fwd/bwd kernels are not affected since they are using exp2
