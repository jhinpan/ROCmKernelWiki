## Summary (from upstream PR description)

Proposed changes
Remove usage of warpSize as compile time constant by providing a workaround as warpSize has been removed from HIP headers from 7.0 onwards.  This is more like a workaround to unblock the build failures with composable_kernel with hip breaking changes.
