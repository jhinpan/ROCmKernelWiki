# Replace inline assembly with builtins in FHMA

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2067](https://github.com/ROCm/composable_kernel/pull/2067) · **Merged:** 2025-04-10 · **Author:** @jmmartinez

**Inclusion reason:** kernel path 'include/ck_tile/core/arch/amd_buffer_addressing.hpp'

## Summary (from upstream PR description)

Proposed changes
Replace uses of inline assembly with clang builtins when these are available.
The v_cmpx+buffer_load/store combination is replaced by an if (...) [[likely]] { /*then*/ }. With this hint, the compiler can remove the s_cbranch_execz that skips the "then" block that would otherwise be created.
Instead of relying on the clang version; in this patch we rely on the availability of the relevant builtins (which seems like a better idea if we ever backport them to older versions).
