## Summary (from upstream PR description)

This PR enables the native compilation of CK for MIOpen on Windows (CMake switch -DINSTANCES_ONLY=ON). It is a minimal set of changes in the single PR. However, please let me know if you prefer to split it into smaller PRs.
I changed the name cmake/googletest.cmake to cmake/gtest.cmake because the filesystem on Windows is case insensitive, and the name collide with GoogleTest from CMake.
