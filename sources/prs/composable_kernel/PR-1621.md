# Reduce build time.

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1621](https://github.com/ROCm/composable_kernel/pull/1621) · **Merged:** 2024-11-01 · **Author:** @illsilin

## Summary (from upstream PR description)

This PR will disable building FP8 gemm_universal and FP8 gemm_multiply_multiply instances for GPU targets such as MI100/MI200 that do not have native support for FP8 data type. These instances take ~1.5 hours to build for those targets and can only provide functional support.
The user can re-enable those instances for these targets by setting the build argument "-DCK_USE_FP8_ON_UNSUPPORTED_ARCH=ON" .
