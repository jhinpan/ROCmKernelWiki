# Padded Generic Kernel Instance

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#730](https://github.com/ROCm/composable_kernel/pull/730) · **Merged:** 2023-06-17 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'client_example/03_gemm_layernorm/gemm_add_add_layernorm_naive.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

This is for solving the Issue 709.  It does the following changes

Add NumReduceDim template parameter to DeviceSoftmax so that the collected instances by GetInstances() are restricted to those ones satisfying NumReduceDim
For Softmax, Elementwise-Normalization, GroupNorm,  add generic instance to a separate tuple and collect it as the first instance by GetInstances()
Use DeviceOperationInstanceFactory to collect instances for Elementwise-Normalization
Update to the corresponding client-example to add assertion of IsSupportedArgument() for the generic instance
