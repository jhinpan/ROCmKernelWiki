**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2622](https://github.com/ROCm/composable_kernel/pull/2622) · **Merged:** 2025-08-14 · **Author:** @ecamartins

## Summary (from upstream PR description)

Proposed changes
In previous work (see PRs #2417, #2453,#2458, #2421), cases covered in CK tile smoke tests were migrated to test/ck_tile as ctests for quick way to help prevent regressions in our develop branch. After merging, there was a request (see comments in #2421 and #2417) for us to use the GoogleTest framework; thus, this PR refactors ctests of permute and MOE smoothquant to use the GoogleTest framework.
Note: While ctests for MOE smoothquant were refactored, there is still a bug with sequential kernel execution; this bug was found in initial work (see PR #2458). Thus, the MOE smoothquant tests are not currently run (see test/ck_tile/CMakeLists.txt).
