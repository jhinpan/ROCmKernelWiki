Proposed changes
When TransposeC and QuantPreshuffle are both true, Aquant generates correct result.
How to get VGPR offset and lane offset

VGRP offset is mIter. See the diagram below
Lane offset is lane_id % warp.N * AQPerBlock + kQScale.
This is kind of converting 2D coordinate (i, j) to 1D k. lane_id % warp.N is i, kQScale is j. And AQPerBlock is stride.
