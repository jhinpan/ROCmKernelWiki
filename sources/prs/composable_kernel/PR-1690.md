# Change in fwd-splitkv kernel to support num_splits=1 case

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#1690](https://github.com/ROCm/composable_kernel/pull/1690) · **Merged:** 2024-11-25 · **Author:** @qianfengz

**Inclusion reason:** kernel path 'example/ck_tile/01_fmha/codegen/ops/fmha_fwd_splitkv.py'; keyword 'kernel'

## Summary (from upstream PR description)

Due to the versatile functionality of the fwd-splitkv kernel which includes

Fundamental KV splitting to improve the CUs coverage for fmha-fwd
Paged KV cache
Non-Paged KV cache

We need well support the case where num_splitkv==1,  this PR is for implementing that goal.
It has been verified through xformers for both num_splitkv > 1 and num_splitkv == 1 paths.  And for num_splitkv == 1, the splitkv combine kernel will not be called.
