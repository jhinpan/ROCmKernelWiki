# poc convert fnuz fp8 to non-native dtype similar to ocp

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2871](https://github.com/ROCm/composable_kernel/pull/2871) · **Merged:** 2025-09-19 · **Author:** @tenpercent

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Proposed changes
on gfx942, ck::f8_t is aliased to _BitInt(8) which cannot be demangled from binaries. As a result, we don't have pretty kernel names in kernel traces and object dumps. This is not the case on gfx950 where ck::f8_t aliases to ck::f8_ocp_t which is a struct which we define ourselves.
This PR attempts to reimplement f8_fnuz_t similar to f8_ocp_t
Testing
fp8 related tests are passing in CI
Locally some of them are not passing (e.g. ctest -R example_gemm_multiply_multiply_xdl_fp8_ab_scale ), but neither they pass before this change
