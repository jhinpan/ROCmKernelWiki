# CI Skip and Status Checks Fix

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#2952](https://github.com/ROCm/composable_kernel/pull/2952) · **Merged:** 2025-10-08 · **Author:** @amd-anclark

## Summary (from upstream PR description)

Proposed changes
There are three issues this PR addresses:

Modifications to files that do not impact the code (e.g. .github files, docs, licenses, .md) trigger a rebuild and test. This unnecessarily uses resources. Now, if the only changes are non-relevant files, CI will skip builds and tests. If there are any files included that do impact code, CI will execute builds and tests as usual.
The repository has a list of required checks that must pass to satisfy branch protection rules. If any required checks are skipped, they will not satisfy the branch protection rules. Now, if a stage is skipped, it will set the appropriate status of the required check.
After CI has finished executing, some GitHub PR checks remain in the pending (yellow) status. If you click on the link to the Jenkins job, you will see that it has actually finished. This causes confusion and is not a good experience. Now, the status of the  troublesome checks are updated to reflect the true status in GitHub.
