## Summary (from upstream PR description)

Proposed changes
Refactor the register GEMM block method to be called with following new pipeline and fixed the CI CD issue of previous code.
Currently:
Pipeline: DRAM tile -> register tile -> LDS Tile. // single tile owned by whole workgroup
Block GEMM: LDS Tile -> register tile (warp tile) // single tile owned by wavefront
Epilogue: register tile -> (potentially LDS) -> GMEM // single tile
In Future:
We should move the register tile coding to the Pipeline level and focus the block with command warp execution.
