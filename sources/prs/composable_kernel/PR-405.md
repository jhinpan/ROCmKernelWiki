# embedding fuse layernorm

**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#405](https://github.com/ROCm/composable_kernel/pull/405) · **Merged:** 2022-09-09 · **Author:** @carlushuang

**Inclusion reason:** keyword 'layernorm'

## Summary (from upstream PR description)

add embedding fused with layernorm example and device instances.
Current limitation: embedding-dim must be equal to the template parameter ( we need to do layernorm later), and it must be multiple of BlockSize (256)
Currently manually implemented the buffer_load operation instead of using that in any version of threadwise_copy, the main reason is we need to accumulate the row-index to the base pointer, in order to support larger GPU tensor > 4G.
Below test on a gfx90a machine, with index-length = 2048, table-length = 65536, psudo-random initialize row index.
