**Repository:** [ROCm/composable_kernel](https://github.com/ROCm/composable_kernel) · **PR:** [#3460](https://github.com/ROCm/composable_kernel/pull/3460) · **Merged:** 2025-12-30 · **Author:** @ApoorvaKalyani

## Summary (from upstream PR description)

Proposed changes
This  MR is to add the wmma support for Grouped convolution backward data.

The changes are inline with WMMA v3.
Added new device implementation for WMMA v3.
Modified a gridwise implementation to support the new WMMA v3 implementation.
Added initial  round of  vanilla instances , tests and examples for FP16 and BF16 types.
All the instances and tests just support NHWGCxGKYXC layout.
FP32 is unsupported.
Extended to adding support bilinear and scale flavours with new device implementation.
Ran some performance benchmarks for vanilla, bilinear and scale instances, tuned and tested on RDNA4 and updated tuned instances.
Tested the tuned instances on RDNA3.
