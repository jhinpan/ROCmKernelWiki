**Repository:** [ROCm/flash-attention](https://github.com/ROCm/flash-attention) · **PR:** [#141](https://github.com/ROCm/flash-attention/pull/141) · **Merged:** 2025-05-16 · **Author:** @Chi-Chu319

## Summary (from upstream PR description)

Change the grid order for triton flash attention bwd.
The grid is changed to head, seq, batch. It provides the following benefits

having head as the first dim with the assumption of head % 8 (number of XCD) == 0 keeps each entire sequence on one XCD so good causal load balancing between XCDs. and good sequence locality
having the batch as the last makes sure all the XCD gets all the batches so the THD load balancing is achieved.

suppose we have head // num_XCD = x
each XCD would get (xcd_id * x + (xcd_id + 1) * x, ..., ...), with the grid (head, seq, batch) (we know that the first dim moves the first).
