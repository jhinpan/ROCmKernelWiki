1. Motivation
Enable Decode Context Parallel (DCP) for MLA decode path, bf16 for now. It enables both the native ATOM engine and the vLLM plugin mode. Now It is compatible with eager/toch.compile/cuda graph.
DCP is a parallelism strategy that partitions the KV cache across the tensor-parallel GPUs during decode, allowing each rank to attend over only a local slice of the KV sequence. DCP is like the distributed version of flash decoding. This reduces the per-GPU memory footprint of the KV cache (For DCP times) and enables serving longer contexts without increasing world size.
For example, for DeepSeek V3/R1 TP8 bf16, enable DCP8 can serving 8x longer contexts in in ideal conditions. Performance results can be found in the test section.
