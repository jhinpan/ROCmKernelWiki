# fix(car): sglang prefill launch error kernel

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2745](https://github.com/ROCm/aiter/pull/2745) · **Merged:** 2026-04-16 · **Author:** @TennyWang1223

**Inclusion reason:** kernel path 'aiter/dist/device_communicators/communicator_cuda.py'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
sglang dispatch allreduce kernel by function should_custom_allreduce in custom_all_reduce.py
However, the scheduling logic of aiter is in the communicator_cuda.py file, but sglang does not call this file.
Therefore, when determining whether to use custom allreduce for prefill, a dispatch error will occur.
The calling logic of sglang is shared by AMD and NVIDIA. Therefore, it cannot be modified randomly. Instead, the judgment code should be migrated from the aiter layer to the should_custom_allreduce function.
Technical Details
Move the judgment and call logic of prefill from communicator_cuda.py to custom_all_reduce.py
