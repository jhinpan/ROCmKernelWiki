## Summary (from upstream PR description)

Core Features:

with_custom_metadata_path() decorator for custom kernel metadata storage
Thread-safe global registry for kernel-to-directory mappings
Automatic patching of CompiledKernel.init method
Full backward compatibility with existing @triton.jit usage

Usage
Dump Custom .json/.hsaco Files to a Custom Directory
First you need to dump the metadata files to a custom directory(copy ~/.triton/cache/{hash}/{kernel_name}.json and ~/.triton/cache/{hash}/{kernel_name}*.hsaco to a custom directory).
For JIT Compilation (Using Decorator)

import triton
