## Summary (from upstream PR description)

Motivation
A follow up  to PR: #2279
This change introduces asm kernels for 32x128 and 64x128 to support qwen3-next in TP4 mode.
Technical Details
2 more assembly kernels are being added. to process 32 and 64 tokens per thread group respectively when h_dim is restricted to 128.
Test Plan
Run aiter tests  with h_dim=128. There is a clear double digit benefit over CK kernels with token count  > 32.
