# Blockwise Sparse Sage Attention

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2579](https://github.com/ROCm/aiter/pull/2579) · **Merged:** 2026-04-09 · **Author:** @ksikiric

**Inclusion reason:** kernel path 'aiter/ops/triton/_triton_kernels/attention/block_lut.py'; keyword 'attention'

## Summary (from upstream PR description)

Add block-wise sparse attention support to SageAttention v1 and v2 (MXFP4)
Motivation
Recent video diffusion models (e.g. HunyuanVideo 1.5) are trained with spatially sparse attention, the model learns to attend only to structurally relevant token subsets rather than the full sequence. These models expose their sparsity pattern as a block-level attention mask at inference time. Without kernel-level support, serving these models still requires computing the full dense attention over long sequences (e.g. 75,600 tokens), leaving significant performance on the table. This PR adds block-wise sparse attention to SageAttention v1 and v2 (MXFP4) so we can directly exploit the sparsity patterns these models were trained with, skipping entire Q-KV block pairs and translating the model's learned sparsity into real latency and compute savings.
Technical Details
Block-wise sparse attention for SageAttention v1 (fav3_sage) and v2/MXFP4 (fav3_sage_mxfp4): Adds a ragged block LUT mechanism that allows Q blocks to skip masked-out KV blocks entirely, avoiding unnecessary computation. The kernel is split into mask and no-mask subkernels for optimal performance.
