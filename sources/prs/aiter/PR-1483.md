# [TRITON] Add a8w8 blockscale MoE

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1483](https://github.com/ROCm/aiter/pull/1483) · **Merged:** 2026-01-12 · **Author:** @nsusanto

**Inclusion reason:** kernel path 'aiter/ops/triton/_triton_kernels/moe/moe_op_gemm_a8w4.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
This PR adds a new kernel for fp8 x fp8 blockscale MoE GEMM. This kernel config is tuned for DeepSeek R1-0528 shapes and blockscaling (1 scale = 1x128 or 128x128 elements). Deepseek currently uses per-row blockscaling (1 scale = 1x128) but internally we tested that a 2D blockscaling (1 scale = 128x128) should also work for activation.
Test Plan
Testcases are in op_tests/triton_tests/test_moe_gemm_a8w8_blockscale.py which includes cases for both per-row blockscaling activations (1x128), 2D blockscaling activations (128x128), mixed quantization (i.e. fp8 x bs8, bs8 x fp8, etc), and non-even K cases.
Test Result
Test results using TP1 MOE1 shapes with per-row blockscaling for activation (1x128)
