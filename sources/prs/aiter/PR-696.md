authors: @juuso-oskari @Chi-Chu319
Extend attention
This PR tunes the _fwd_kernel found in extend_attention.py. It changes the grid traversal order to be heads first, so each XCD gets balanced work and we achieve load balance when in causal mode. We also provide tuned configs for MI350X (and add the large_head_or_fp32 config for MI300X aswell; tuning for MI300X is left for another PR).
MLA decode

Added the benchmark utils for MLA decode.
Changed the grid to traverse (head, kv_split, batch) for stage1 so balanced work load is achieved
Changed the grid to traverse (head, batch) for stage2 so balanced work load is achieved
