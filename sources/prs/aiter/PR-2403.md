# [TRITON] Fix unit tests on `gfx950`

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2403](https://github.com/ROCm/aiter/pull/2403) · **Merged:** 2026-03-24 · **Author:** @brunomazzottiamd

**Inclusion reason:** kernel path 'aiter/ops/triton/configs/moe/gfx950-MOE_ROUTING_SIGMOID_TOPK1.json'; keyword 'moe'

## Summary (from upstream PR description)

Motivation
Triton test suite isn't passing on gfx950. This PR fixes test_moe_routing_sigmoid_top1_fused.py, test_gather_kv_b_proj.py and test_causal_conv1d.py, slightly improving the situation.
Technical Details

Fix test_moe_routing_sigmoid_top1_fused.py: The kernel's tuning config JSON file contained trailing commas after the last entry, which is invalid JSON.
Fix test_gather_kv_b_proj.py: Use gfx950 FP8 type instead of gfx942 one (torch.float8_e4m3fn instead of torch.float8_e4m3fnuz).
Fix test_causal_conv1d.py: Relax bf16 absolute tolerance from 5e-2 to 6e-2 for marginal precision differences on gfx950.

Test Plan
