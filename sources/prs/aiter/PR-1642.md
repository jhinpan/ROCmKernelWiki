**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1642](https://github.com/ROCm/aiter/pull/1642) · **Merged:** 2025-12-13 · **Author:** @JohnNikolay84

## Summary (from upstream PR description)

Motivation
New kernel is introduced with bigger tiling to improve prefill cases on the model where inter_dim is a multiple of 384 such as qwen3 235B. The uplift compared to 32x256 tiling on bigger token input is expected to be in the area of 20%.
The kernel has been tested on Qwen3 235B and achieved 2.5% total uplift with CONC=256.
Technical Details
This change extends size of a tile processed by 1 tg for assembly fmoe fp8 blockscale kernel.
Test Plan
