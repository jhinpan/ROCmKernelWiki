## Summary (from upstream PR description)

Motivation
This PR adds a benchmark script for the unified attention kernel covering bf16, FP8, and mixed-precision modes for PR #2360 and  fixes the reduce_segments kernel bug that contains an undefined variable bug that would crash the 3D kernel path when HEAD_SIZE_PADDED != HEAD_SIZE
Technical Details

The benchmark script (op_tests/op_benchmarks/triton/bench_unified_attention.py)


Supports multiple precision modes via CLI flags:

fp8: Quantizes Q, K, V to FP8 e4m3 with per-tensor descales (q_descale, k_descale, v_descale)
fp8_kv: Quantizes only K, V to FP8 (Q stays bf16) with k_descale, v_descale
fp8_output: Outputs in FP8 with configurable -out_scale factor


Default (no flags): bf16 baseline
Supports equal (-equal_seqlens) and random variable-length sequence modes
Correctness verification via -test using torch.testing.assert_close (atol=0.15, rtol=0.15) against the ref_paged_attn reference implementation, printing PASS/FAIL with max absolute diff per shape
Default sweep: batch=[1,4,8], heads=[16,48], seq_q=[1,1024,4096], seq_k=[8192], head_dim=128
Custom shapes via -b, -hq, -hk, -sq, -sk, -d, -dv
Additional options: -decode, -sliding_window, -metric
