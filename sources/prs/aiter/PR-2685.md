# [Triton]Integrate mla_decode_gluon kernel

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2685](https://github.com/ROCm/aiter/pull/2685) · **Merged:** 2026-05-01 · **Author:** @Dewei-Wang-sh

## Summary (from upstream PR description)

Summary

Add mla_decode_gluon, a Gluon-based MLA decode kernel for CDNA4 (gfx950). Uses 3-stage async copy pipeline with double-buffered page numbers and KV tiles, achieving ~600 TFLOPS vs ~480 TFLOPS ASM baseline on mi350 (batch=128, ctx=10000, nhead=128 bf16).
Auto-select buffer_load_to_shared (≤ 2 GB) vs global_load_to_shared (> 2 GB) for KV caches.
Add Gluon kernel usage README with quick-reference table, constraints, and test commands.
