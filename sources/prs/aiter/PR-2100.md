# Fix CI prebuild: use build_ext so kernels are actually compiled

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2100](https://github.com/ROCm/aiter/pull/2100) · **Merged:** 2026-02-25 · **Author:** @okakarpa

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

Since PR #1973 (Feb 12), setup.py develop no longer triggers NinjaBuildExtension.run() because pip intercepts it as an editable install via pyproject.toml. This means the Docker image ships without any prebuilt kernels, causing JIT compilation at runtime on GPU nodes and 30-min timeouts in ATOM benchmarks.
Split into explicit build_ext --inplace (which fires the prebuild logic) followed by pip install -e . for the editable install.
Fixes #2099
