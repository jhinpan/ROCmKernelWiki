# Remove sorting for fmoe

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3001](https://github.com/ROCm/aiter/pull/3001) · **Merged:** 2026-05-29 · **Author:** @JohnNikolay84

## Summary (from upstream PR description)

Motivation
moe perf improvement for Q3N decode.
Technical Details
This commit is introducing a flat fmoe kernel.  A flat kernel is designed around an idea of processing only 1 token per thread group. In that case  sorting is redundant, the grid is designed in such way that tgy directly selects which expert this thread group should pick up. max topk supported is 16.
Sorting cost is high for smaller batches 1,2,4,8. Beyond that sorting cost becomes small < 5% compared to moe cost so it does not give a lot of win getting rid of sorting in those cases.
Test Plan

aiter perf tests.
