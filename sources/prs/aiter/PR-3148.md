# Rchamber/optimised dynamic per group scaled quant v2

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3148](https://github.com/ROCm/aiter/pull/3148) · **Merged:** 2026-05-25 · **Author:** @RichardChamberlain1

**Inclusion reason:** kernel path 'csrc/kernels/quant_kernels.cu'; keyword 'fp8'

## Summary (from upstream PR description)

Summary

Optimize `dynamic_per_group_scaled_quant_kernel` by promoting runtime parameters (`group_size`, `shuffle_scale`, `block_size`) to
compile-time template parameters, enabling the compiler to eliminate dead branches, unroll loops, and replace divisions with bit-shifts
Narrow row/group index types from `int64_t` to `int32_t` and move `oob_size` computation to the host to avoid redundant per-thread work
Deduplicate the three per-dtype (FP8, INT8, FP4) launch paths into a shared lambda via `DISPATCH_GROUP_SIZE` macro and type-erased
`launch_group_quant` helper
Add `launch_bounds` annotation with compile-time `block_size` for improved register allocation
Add opt-in `KERNEL_BENCH_ITERS` macro (default 1, no-op in production) for in-kernel launch benchmarking


Note: The `KERNEL_BENCH_ITERS` scaffolding is temporary — it will be removed in a follow-up commit once benchmarking is complete.
