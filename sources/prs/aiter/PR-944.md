# Add hip kernels for symmetric matrix tridiagonalization

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#944](https://github.com/ROCm/aiter/pull/944) · **Merged:** 2025-09-04 · **Author:** @kaiyang-1

**Inclusion reason:** kernel path 'csrc/kernels/solver/Makefile'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Provide an efficient HIP implementation of symmetric tridiagonal reduction (SYTRD) algorithm optimized to outperforms rocSOLVER on AMD GPU. The SYTRD algorithm is one of LAPACK functions, which is used by symmetric eigenvalue/vector decomposition and shampoo optimizer.
Technical Details
The optimized SYTRD implementation incorporates the following enhancements::

various kernel fusions for reduce_sum, gemv and element-wise operations
specialized single-wavefront fused kernel for efficient handling of small matrices
vectorized load/store
several rocblas functions are called for outer product of vectors ger and matrix multiplication gemm

Test Plan
A benchmark code is included to validate correctness and compare performance against rocSOLVER.
Test Result
Accuracy is verified and performance speedup is achieved for a wide range of matrix size and both fp32 and fp64 precision. Please see README.md for more details.
