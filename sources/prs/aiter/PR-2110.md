## Summary (from upstream PR description)

Summary
Enhance opus::cast() with scalar fp8 support, transparent auto-fold flattening, numeric_limits, and comprehensive dtype_convert test coverage.
1. Scalar fp8 <-> fp32 cast
Add fp32_to_fp8() and fp8_to_fp32() using hardware intrinsics:

fp32 -> fp8: __builtin_amdgcn_cvt_pk_fp8_f32(x, 0.0f, w, 0) — packs into the lo slot of pk intrinsic, extracts the low byte
fp8 -> fp32: __builtin_amdgcn_cvt_f32_fp8(w, 0) — reads byte 0 from a word

Registered as cast<fp8_t>(fp32_t) and cast<fp32_t>(fp8_t) via OPUS_CAST_DEFINE.
2. unfold_from_container<OrigS> — transparent auto-fold flattening
Previously, opus::cast() on wide vectors (e.g. fp32x8_t -> fp8) internally auto-folds the input into a tuple<fp8x4_t, fp8x4_t> and returns it as-is — a std::tuple instead of the expected fp8x8_t. Callers had to manually unpack.
New impl::unfold_from_container<OrigS>(tup) helper (paired with fold_as_container_of_vec/arr) flattens the tuple-of-sub-results back into the original container type:

OrigS is vector → vector_t<elem, total>
OrigS is array → array<elem, total>
OrigS is tuple → tuple<elem, elem, ...>
