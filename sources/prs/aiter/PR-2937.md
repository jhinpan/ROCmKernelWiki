# [FIX] Update fmha bwd recompile kernel for sbhd layout

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2937](https://github.com/ROCm/aiter/pull/2937) · **Merged:** 2026-04-29 · **Author:** @JaxChen29

**Inclusion reason:** kernel path 'csrc/cpp_itfs/mha_bwd.cu'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
For a16 case, rtne kernel will always be selected in spite of the input is rtz or rtna.
-v3_bf16_cvt was being ignored on gfx950 (rtne always selected), so even after rebuilding the
.co, requests for rtna / rtz could not actually reach those kernels.
Some recompile kernels for gfx950 were not been rebuilt to co files in sbhd layout issue.
Technical Details
Kernel Dispatcher: honor bf16_cvt on every arch
csrc/cpp_itfs/mha_bwd.cu had two short-circuit conditions in get_heuristic_kernel() that made cfg.bf16_cvt unreachable on gfx950:

((arch_id == "gfx950") || ((data_type == "fp16") || (cfg.bf16_cvt == bf16_cvt))) &&


((cfg.bf16_cvt == 3) || (cfg.bf16_cvt == bf16_cvt)) &&

Test Plan
verify the rtz kernel was correctly called.
verify the recompiled kernel all passed in sbhd layout
Test Result
all passed
