# Optimize topksoftmax WARPS_PER_TB for higher occupancy and remove redundant precision conversion

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#652](https://github.com/ROCm/aiter/pull/652) · **Merged:** 2025-07-13 · **Author:** @CuiCu-618

**Inclusion reason:** kernel path 'aiter/fused_moe.py'; keyword 'moe'

## Summary (from upstream PR description)

Description:
This PR improves the topksoftmax kernel by:

Tuning WARPS_PER_TB to boost occupancy and throughput.
Eliminating the explicit precision conversion step before launch, since the kernel now handles all necessary type casting internally (significant performance gains on bf16 and fp16).

No functional changes.
Note: The planned topk optimization was not included because it introduced precision issues that would require additional handling—and thus too much overhead. @valarLip @junhaha666
