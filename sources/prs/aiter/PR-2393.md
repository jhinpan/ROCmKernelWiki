# [TRITON] fix TILE_SIZE pow2 error if block_size is not pow2

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2393](https://github.com/ROCm/aiter/pull/2393) · **Merged:** 2026-03-20 · **Author:** @juuso-oskari

**Inclusion reason:** kernel path 'aiter/ops/triton/attention/unified_attention.py'; keyword 'attention'

## Summary (from upstream PR description)

If block_size is not a pow2 currently unified attention kernel crashes. This PR fixes it by setting the TILE_SIZE still based on block_size, but assures that its a power of 2 and does not overflow:
TILE_SIZE = min(64, triton.next_power_of_2(block_size))
