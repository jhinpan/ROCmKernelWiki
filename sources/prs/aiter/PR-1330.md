# Add Fused RMSNorm + FP8 Per-tensor Static Quantization Triton Kernel

## Summary (from upstream PR description)

Motivation

This PR adds a new Triton fusion kernel. The fused kernel performs an RMSNorm and an FP8 per-tensor static quantization. The RMSNorm and quantization kernels are short-running kernels that are bound by the kernel launch latency. Fusing these two kernels together can hide the extra kernel launch latency as a result of launching two separate kernels.
