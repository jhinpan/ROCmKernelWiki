# Add MI355X tuned GEMM configs for FP4 and FP8

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2037](https://github.com/ROCm/aiter/pull/2037) · **Merged:** 2026-02-12 · **Author:** @sunway513

**Inclusion reason:** kernel path 'aiter/configs/a4w4_blockscale_tuned_gemm.csv'; keyword 'gemm'

## Summary (from upstream PR description)

Summary

FP4 (a4w4_blockscale): Add 53 new shapes and update 10 shapes with better-performing kernel configs (924 -> 977 entries)
FP8 (a8w8): Add 32 new FP8 (torch.float8_e4m3fn) shapes (550 -> 582 entries)

All shapes are from production LLM inference workloads benchmarked on MI355X (gfx950, 256 CUs). Tuning was performed using the existing gemm_a4w4_blockscale_tune.py and gemm_a8w8_tune.py scripts.
FP4 highlights

53 new shapes covering M=128-1033728, N=128-957568, K=128-941696
10 existing shapes re-tuned with 1-32% TFLOPS improvement
Peak FP4 performance: 5,775 TFLOPS on MI355X, 5,094 TFLOPS on MI350X

FP8 highlights

32 new float8_e4m3fn shapes covering the standard F8F8BBS benchmark suite
No regressions on existing shapes

Validation

Configs verified on both MI355X and MI350X (gfx950, 256 CUs)
Built and benchmarked from public rocm/pytorch:latest Docker image

Test plan

 Verify tuned configs load correctly: python -c "from aiter.ops.gemm import get_gemm_config; print('ok')"
 Spot-check a few shapes with op_tests/test_gemm_a8w8.py
