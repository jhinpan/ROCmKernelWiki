## Summary (from upstream PR description)

Summary
Add OPUS (AI Operator Micro Std) unit test infrastructure and fix compiler warnings in opus.hpp.
Changes
OPUS Unit Tests (op_tests/opus/)
Host-only C++ test (test_opus_basic.cpp)

Tests OPUS core primitives on the host (no GPU): numbers/sequences, arrays, tuples, static_for/static_ford, type traits, and layouts
Built via build.sh using hipcc

GPU device kernel tests (device/)
Built as a single PyTorch extension (opus_device_test):



Kernel
File
What it tests




MFMA 32x32x8 fp16
test_mfma.cu
make_tiled_mma, partition_layout_a/b/c, make_gmem, mfma_adaptor_swap_ab in a matrix_core_kernel_block_v2-style kernel. Computes C = A @ B^T and validates against torch.mm. Guarded for gfx942 (MI300) only.


Vector addition
test_vector_add.cu
make_gmem vectorized load/store (load<VECTOR_SIZE> / store<VECTOR_SIZE>) in a grid-stride loop. Validates against PyTorch element-wise addition.




Single pybind module (opus_device_test_ext.cpp) exposes both kernels to Python
Single test script (test_opus_device.py) runs all device tests with automatic extension build and GPU architecture detection

Test infrastructure

run_tests.sh — runs host test + device tests
run_tests_in_docker.sh — runs t
