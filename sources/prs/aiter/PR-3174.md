# [TRITON][GLUON] Add fp8_mqa_logits gluon kernel for gfx950 and gfx1250

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3174](https://github.com/ROCm/aiter/pull/3174) · **Merged:** 2026-05-14 · **Author:** @cagrikymk

**Inclusion reason:** kernel path 'aiter/ops/triton/_gluon_kernels/gfx1250/attention/fp8_mqa_logits.py'; keyword 'attention'

## Summary (from upstream PR description)

This PR adds fp8_mqa_logits kernels for gfx950 and gfx1250.
Other related changes:

Add clean_logits flag, when set to False, the values beyond the limits will be untouched. This saves computation as we dont have to fill them with -inf. However, the topk kernel needs to be mindful of that and onlu read the inbound values.
Extend benchmark and tests based on this flag and other small changes
On gfx950, certain features are not available in the latest triton release so I have hacks to extract if they are present in the existing installation and gate them accordingly. While this is hacky, it is needed for backward compat. and performance
ops/triton/attention/fp8_mqa_logits acts as the main router, the calls are routed to the gluon kernels if the arch. is supported
