**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2096](https://github.com/ROCm/aiter/pull/2096) · **Merged:** 2026-03-02 · **Author:** @sahirema

## Summary (from upstream PR description)

Motivation
Thie PR adds torch.compile and manual hipgraph support to flash_attn_with_kvcache.
Technical Details

For torch.compile compatibility, flash_attn_with_kvcache is registered as a custom op by implementing the necessary fake tensor function.
To enable manual hipgraph capture, cache update logic causing graph breaks in fwd_decode was updated

Test Plan

Unit tests based on the upstream flash-attention is implemented in test_flash_attn_kvcache.py. It contains the following tests:
test_flash_attn_kvcache (basic functionality)
test_flash_attn_kvcache_torch_compile (compile compatibiltiy)
test_flash_attn_kvcache_hipgraph_capture (hipgraph enablement)
