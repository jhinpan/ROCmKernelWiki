# [OPUS] [ATOM] Add pa_sparse_prefill_opus kernel for DeepSeek-V4 prefill on gfx950

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3225](https://github.com/ROCm/aiter/pull/3225) · **Merged:** 2026-05-21 · **Author:** @kaiyang-1

**Inclusion reason:** kernel path 'aiter/__init__.py'; keyword 'attention'

## Summary (from upstream PR description)

This pull request introduces support for OPUS-based sparse paged prefill attention, specifically optimized for DeepSeek-V4 on AMD gfx950 GPUs. The main addition is a new operator, pa_sparse_prefill_opus, which enables efficient sparse attention computation over paged and flat key-value sources. The implementation includes Python bindings, kernel code, and configuration for JIT compilation. The most important changes are:
New OPUS-based Sparse Prefill Attention Operator:

Added aiter/ops/pa_sparse_prefill_opus.py, implementing the user-facing pa_sparse_prefill_opus function and its interface to the JIT-compiled HIP kernel. This operator performs two-region sparse scaled-dot-product attention with support for bf16/fp16 and a fixed head dimension of 512.
Registered the new operator in the main package by importing it in aiter/__init__.py.

Kernel and JIT Compilation Support:

Introduced the HIP kernel implementation in csrc/py_itfs_cu/pa_sparse_prefill_opus_kernels.cu, handling shape/dtype validation, argument preparation, and kernel launch logic.
Added JIT compilation configuration for the new module in aiter/jit/optCompilerConfig.json, specifying sources and compilation flags.
