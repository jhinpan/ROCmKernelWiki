# [FlyDSL] import flydsl implement of a4w4 moe

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2113](https://github.com/ROCm/aiter/pull/2113) · **Merged:** 2026-03-01 · **Author:** @lalala-sh

**Inclusion reason:** kernel path 'aiter/configs/model_configs/dsv3_fp4_tuned_fmoe.csv'; keyword 'mfma'

## Summary (from upstream PR description)

Motivation
Integrate FlyDSL MOE a4w4 stage2 kernels into the MOE tuner and fused_moe tunner hits pipeline.
Technical Details

Added flydsl_moe_stage2 with the same interface as fused_moe, supporting both atomic and reduce modes.
Modified get_2stage_cfgs to dispatch stage2 to flydsl_moe_stage2 when kernelName2 starts with "flydsl_", otherwise fallsback

Test Plan

 Run gemm_moe_tune.py --last --verbose to verify FlyDSL kernels are profiled correctly alongside CK kernels
 Verify tuned result in tuned_fmoe.csv selects FlyDSL reduce kernel as best stage2

Test Result

Tuner profiling (profile_fmoe.csv):

Kernel	Mode	Block_M	Time (us)	Error
FlyDSL t64x256x256	atomic	64	3204	1.2%
FlyDSL t64x256x256	reduce	64	2444	0.1%
FlyDSL t32x256x256	reduce	32	2340	0.1%

Tuner selection: FlyDSL reduce t64x256x256 selected as best stage2 (2444 us, 0.1% err), ~18% faster than best moe kernel.
