## Summary (from upstream PR description)

Motivation
Add a regex kernel filtering functionality to the bench_models.py script.
Technical Details
The new --kernel arg expects a case-insensitive regex to be matched against all the available kernel names.
E.g. 'gemm' to include any kernel name containing gemm, 'moe|rmsnorm' for MoE and RMSNorm kernels, '^(?=.*gemm)(?!.*batched)' to include GEMM and exclude batched GEMM kernels.
