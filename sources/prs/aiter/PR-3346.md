# Unify gemm solution function signatures in tuned_gemm.py

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3346](https://github.com/ROCm/aiter/pull/3346) · **Merged:** 2026-05-26 · **Author:** @carlushuang

**Inclusion reason:** kernel path 'aiter/tuned_gemm.py'; keyword 'gemm'

## Summary (from upstream PR description)

Summary

Unified all six gemm solution functions (torch_gemm, hipb_gemm, skinny_gemm, asm_gemm, triton_gemm, flydsl_gemm) to share the same call interface: (inp, weights, solidx, bias, otype, scale_a, scale_b, scale_c, bpreshuffle, config)
asm_gemm now extracts kernelName and splitK from the config dict internally, instead of receiving them as separate args
flydsl_gemm now resolves flydsl_config from config["kernelName"] internally, instead of receiving the pre-resolved config
Added flydsl to solMap, eliminating the special-case dispatch branches in gemm_a16w16
The dispatch in gemm_a16w16 is now a single unified code path through solMap for all solution types

Test plan

 Run existing gemm unit tests (op_tests/test_gemm_a16w16.py)
 Verify asm_gemm path works with bpreshuffle configs
 Verify flydsl_gemm path works when flydsl is available
 Run tuning tests (op_tests/tuning_tests/test_asm_splitk_guard.py)
