## Summary (from upstream PR description)

Changes:

 Add -fc1, -fc2, -tp (tensor parallel), and -no_glu (whether or not the model's using a GLU activation) flags to GEMM benchmarking scripts. To run, do: python op_tests/op_benchmarks/triton/bench_gemm_a8w8.py
 Remove code repetition (see updates to utils/benchmark_utils.py and utils/argparse.py)
 Broadcast changes to all GEMM benchmarking scripts.
 Add extra flags to Attn, norm, and MOE benchmarks.
