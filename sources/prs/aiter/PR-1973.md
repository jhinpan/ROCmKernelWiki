# Defer expensive build operations to build_ext.run()

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1973](https://github.com/ROCm/aiter/pull/1973) · **Merged:** 2026-02-12 · **Author:** @paradigm

**Inclusion reason:** keyword 'lds'

## Summary (from upstream PR description)

Previously, setup.py imported jit modules and performed build detection at module load time, causing metadata-only operations (egg_info, --version, etc.) to trigger the full build process.
Move heavy imports (jit.core, cpp_extension, torch) and build logic into NinjaBuildExtension.run(), which only executes during actual build commands. Directory copies for aiter_meta remain at module level as they're needed for setuptools package validation.
This reduces metadata operation time from ~45 minutes to ~1 second.
Motivation
Make non-build operations significantly faster by avoiding unnecessary builds.
Technical Details

Moved build logic into build hook
Some very minor code clean-ups, e.g. changed conditional if cond: var = true else: var = false into a straight var = cond assignment.

Test Plan

Ran metadata-only operation python ./setup.py --name
Ran a build

Test Result
