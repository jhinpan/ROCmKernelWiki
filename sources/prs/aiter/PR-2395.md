# refactor(pa): use ctypes binding for pa_fwd and pa_ps_fwd

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2395](https://github.com/ROCm/aiter/pull/2395) · **Merged:** 2026-03-23 · **Author:** @sijyang

**Inclusion reason:** kernel path 'aiter/ops/attention.py'; keyword 'attention'

## Summary (from upstream PR description)

Summary
Migrate pa_fwd and pa_ps_fwd ASM paged-attention kernels from pybind11 to ctypes binding.

Convert torch::Tensor& / std::optional<torch::Tensor> signatures to AiterTensor* + hipStream_t with extern "C" exports
Replace TORCH_CHECK → AITER_CHECK, at::ScalarType → AITER_DTYPE_*, torch.itemsize() → element_size()
Replace at::hip::OptionalHIPGuardMasqueradingAsCUDA with manual hipGetDevice/hipSetDevice
Remove attention_asm.h header and attention_asm_pybind.cu (pybind entry point no longer needed)
Add Python-side _pa_fwd_asm / _pa_ps_fwd_asm ctypes wrappers; existing public API (pa_fwd_asm, pa_ps_fwd_asm) now allocates output and calls the ctypes function
Update optCompilerConfig.json: remove pybind source from module_attention_asm
