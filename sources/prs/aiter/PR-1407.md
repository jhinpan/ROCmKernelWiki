## Summary (from upstream PR description)

Motivation
Fix a Triton compilation error that occurs when OUTPUT_Q_NOPE_ZEROS is False and q_nope_zeros_out_ptr is None. The error manifests as:
Technical Details
When OUTPUT_Q_NOPE_ZEROS (a tl.constexpr parameter) is False, the Triton compiler still parses the entire conditional expression in the original code. This causes it to evaluate q_nope_zeros_out_ptr.dtype.element_ty even though the branch won't execute, leading to an AttributeError when the pointer is a constexpr None.
