# Fix kernel filter patterns in mha_fwd() and mha_varlen_fwd()

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1883](https://github.com/ROCm/aiter/pull/1883) · **Merged:** 2026-01-21 · **Author:** @poyenc

**Inclusion reason:** kernel path 'aiter/ops/mha.py'; keyword 'fp8'

## Summary (from upstream PR description)

Motivation

Fix incorrect kernel filter patterns in mha_fwd() and mha_varlen_fwd() that caused unnecessary kernels to be compiled

Changes

Add missing _ prefix to dtype filter patterns (_fp16, _bf16, _fp8bf16)
Fix mask filter pattern from _mask* to _m* for accepting more mask types

Technical Details
The kernel filter patterns were missing the leading underscore (_) prefix for dtype filters (e.g., fp16* instead of _fp16*). This caused the filter to match more kernels than intended, resulting in:

Unnecessary kernel compilation during codegen
Wasted compute resources

Test Plan
Run the op_tests/test_mha.py and op_tests/test_mha_fp8.py scripts to see if all test cases pass
