# fix(batch_prefill): OOB page table read fix + regression tests (AICK-1171)

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3032](https://github.com/ROCm/aiter/pull/3032) · **Merged:** 2026-05-11 · **Author:** @Jeff-Huang

**Inclusion reason:** kernel path '3rdparty/composable_kernel'; keyword 'kernel'

## Summary (from upstream PR description)

Summary

Bump composable_kernel submodule to 10cb6916c (rocm-libraries#6932) to pull in the upstream fix for an out-of-bounds page-table read in the batch-prefill kernel (AICK-1171).
Add two regression tests that exercise the failure modes the upstream fix targets, so we catch any future re-regression in CI / local runs.

Changes

3rdparty/composable_kernel: fdf4bb7fc → 10cb6916c — contains the OOB page table read fix on the develop branch.
op_tests/test_batch_prefill.py:

test_batch_prefill_aick1171_hard_fault_via_guard_page — uses HIP VMM guard pages to deterministically convert any OOB page-table read into a hard fault, isolating the failure from soft mismatches.
test_batch_prefill_4gb_boundary_targeted + a new KV_BLOCKSCALE parametrize axis on large_kvcache — exercises tensor offsets that cross the 4 GiB boundary, the original AICK-1171 trigger.



Test plan

 pytest op_tests/test_batch_prefill.py -k aick1171_hard_fault_via_guard_page on gfx950 (MI350X) — must pass (no GPU fault) with new CK.
 pytest op_tests/test_batch_prefill.py -k 4gb_boundary_targeted on gfx950 — must pass.
 pytest op_tests/test_batch_prefill.py -k large_kvcache on gfx950 — covers the new KV_BLOCKSCALE axis
