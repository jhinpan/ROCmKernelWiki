# Add nhead4 & nhead32 case to support `mla_reduce_v1` used in `pa_persistent_fwd`

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1779](https://github.com/ROCm/aiter/pull/1779) · **Merged:** 2026-01-09 · **Author:** @sammysun0711

**Inclusion reason:** kernel path 'csrc/kernels/mla/reduce.cu'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
This PR aim to add nhead4 & nhead32, head_dim=128 case to support mla_reduce_v1 used in pa_persistent_fwd used for Qwen3-Omni (TP=8/1)
Technical Details
pa_persistent_fwd will invoke pa_reduce_v1 -> mla_reduce_v1, mla_reduce_v1 implementation itself does not require specific limitation for nhead & head_dim, but inherit a strict constraint for supported nhead & head_dim due to aiter mla kernel support.
Based on https://huggingface.co/Qwen/Qwen3-Omni-30B-A3B-Instruct/blob/main/config.json, Qwen3-Omni model num_attention_head=32, head_dim=128. For TP=8, the nhead will be shared as 32/8=4. If pa_persistent_fwd enabled, it will trigger following error:
kn_mla_reduce_v1 doesn't support the specified settings: #heads: 4, head dimension: 128.
After add this patch, it will fix the runtime error above for Qwen3-Omni in TP=8/1 case.
