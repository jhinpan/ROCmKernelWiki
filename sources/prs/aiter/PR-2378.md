# Add LSE-aware kernel dispatch for MLA

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2378](https://github.com/ROCm/aiter/pull/2378) · **Merged:** 2026-03-20 · **Author:** @fangche123

**Inclusion reason:** kernel path 'csrc/py_itfs_cu/asm_mla.cu'; keyword 'fp8'

## Summary (from upstream PR description)

Motivation
Add LSE-aware kernel dispatch for MLA fp8 persistent decode
Technical Details
Add lse column to mla_asm.csv (gfx950/gfx942) and extend get_heuristic_kernel_mla() with a default lse=0 parameter to
distinguish between the standard persistent kernel (mla_a8w8_qh64_qseqlen4_gqaratio16_ps.co) and the LSE-output variant
(mla_a8w8_qh64_qseqlen4_gqaratio16_lse_ps.co).
In mla_decode_stage1_asm_fwd, the lse flag is automatically derived from the lse output pointer: when the caller requests final LSE output (lse != nullptr), the _lse_ps kernel is selected; otherwise the original _ps kernel is used. This is fully backward-compatible as the new parameter defaults to 0.
