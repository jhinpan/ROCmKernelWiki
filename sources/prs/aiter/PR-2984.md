# [TRITON] Split `test_mha.py` into smaller test files

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2984](https://github.com/ROCm/aiter/pull/2984) · **Merged:** 2026-05-04 · **Author:** @brunomazzottiamd

**Inclusion reason:** kernel path 'aiter/test_mha_common.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
Smaller test files improve CI granularity for parallelization across multiple shards. This practice also helps engineers in their daily routine, facilitating debugging and local development. test_mha.py is the most time consuming Triton test, taking about 40 minutes to run in gfx950 machines.
Technical Details
This PR splits test_mha.py into smaller test files:

test_mha_with_pe.py: New file containing the Positional Encoding (PE) tests of test_mha.py.
test_mha_fp8.py: New file containing the FP8 tests of test_mha.py.
Reduced test_mha.py: Keeps vanilla MHA BF16 tests.
