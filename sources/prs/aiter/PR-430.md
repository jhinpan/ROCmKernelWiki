# [TRITON]: Mha fused backward kernels

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#430](https://github.com/ROCm/aiter/pull/430) · **Merged:** 2025-06-14 · **Author:** @juuso-oskari

**Inclusion reason:** kernel path 'aiter/ops/triton/mha.py'; keyword 'attention'

## Summary (from upstream PR description)

Authors: @juuso-oskari @Chi-Chu319
This PR adds 2 fused backward kernel implementations for multihead-attention (aiter/ops/triton/mha.py):
_flash_attn_fused_backward:
This backward implementation combines the dk, dv and dq computations into one kernel (_bwd_kernel_dkdvdq_causal) using atomics to do shared update of the key, value and query gradients between workgroups. This way we avoid the cost of recomputing values for dq, which is done in the baseline two kernel solution (_bwd_kernel_dkdv_causal & _bwd_kernel_dq_causal). This costs us however the atomic overhead, which we've tried to mitigate using smart remapping of wid -> pid (less contending pids for concurrent workgroups).
_flash_attn_onekernel_backward:
This backward implementation takes advantage of the fact that _bwd_kernel_dkdv_causal & _bwd_kernel_dq_causal share a similar grid, and combines them to be launched as one kernel with one grid.
