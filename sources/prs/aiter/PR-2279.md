# 64x256 fmoe

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2279](https://github.com/ROCm/aiter/pull/2279) · **Merged:** 2026-03-15 · **Author:** @JohnNikolay84

**Inclusion reason:** kernel path 'aiter/fused_moe.py'; keyword 'moe'

## Summary (from upstream PR description)

Motivation
This change introduces a new blockscale FP8 fmoe assembly kernel variant that support 64x256 tiling. In comparison to predecessors, this tiling format improves bandwidth, which is essential to achieve highest possible performance in the memory bound operations. The kernel targets prefill stage and has shown 2% e2e improvement in the top tier customer model qwen3 next.
Technical Details
New kernel binaries with silu and gelu activation function + modification to aiter's kernel selection interface in order for the kernel to be picked up in relevant workloads.
Test Plan
Internal assembly kernel team testing framework has been used to verify correctness of the new kernel. The aiter interface change was tested with internal aiter/op_tests API and correctness of the kernel was confirmed with this test also. e2e model tests also confirmed correctness of the kernel and performance uplift.
Test Result
Above mentioned tests confirm that correctness is preserved.
