## Summary (from upstream PR description)

Motivation

Following the approach in PR #3309 , this PR optimizes prefill and decoding
for Qwen3.5-122B (PTPC FP8 MoE, TP8) and Qwen3.5-35B (PTPC FP8 MoE, TP4).

steps for gen co and tune configs
generate co and csv

# clone code and install pyhip
git clone https://github.com/tingqli/pyhip/ -b moe_prefill_fp8_308
cd pyhip && pip install -e .
# update test according to the case see pyhip test example below
...

# run pyhip and generate co
rm ~/.pyhip/ -rf
cd pyhip/tests/contrib/moe
PYHIP_SIMPLE_GEN_FILENAME=1 python3 test_moe.py
cp ~/.pyhip/*.co aiter/hsa/gfx942/fmoe_asmjit/
