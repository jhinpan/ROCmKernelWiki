# [feature] [rocm] add quick allreduce

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#801](https://github.com/ROCm/aiter/pull/801) · **Merged:** 2025-09-09 · **Author:** @haoyangli0109

**Inclusion reason:** kernel path 'aiter/__init__.py'; keyword 'fp8'

## Summary (from upstream PR description)

1.Add quickreduce alternative to aiter custom allreduce. (At different tp counts and different sizes, qr and aider cr have different advantageous scenarios, you can refer to the results of kernel tests.)
2.The collective is only enabled on AMD, MI300, for fp16/bf16 inputs and when custom allreduce is enabled. The kernels support full precision and quantized fp8, int6, int4 (symmetric quantization with group size 32) all reduce collective quantization algorithm.
3.The quickreduce can be enabled by setting AITER_QUICK_REDUCE_QUANTIZATION=[NONE|FP|FP8|INT6|INT4] env variable. quickreduce supports fp8, int6, int4 quantization. NONE means turn off quick allreduce.
4.PR supports fp16 and bf16 kernels but given the lack of intrinsics of bf16 math operations, bf16 kernels performance is worse , so by default we convert bf16 all reduce input to fp16. To disable this behavior, set the environment variable AITER_QUICK_REDUCE_CAST_BF16_TO_FP16=0.
5.The default maximum input size of quickreduce is 2GB, for users with limited video memory, the preset buffer may be a bit too large, you can adjust the value in MB by AITER_QUICK_REDUCE_MAX_SIZE_BYTES_MB.
