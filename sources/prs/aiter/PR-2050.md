# [TRITON] Add Model Benchmarking Tool

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2050](https://github.com/ROCm/aiter/pull/2050) · **Merged:** 2026-03-04 · **Author:** @lucas-santos-amd

**Inclusion reason:** kernel path 'op_tests/op_benchmarks/triton/bench_batched_gemm_a8w8.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Provide a script to benchmark multiple GEMM, MoE, RMSNorm and RoPE Kernels easily.
Technical Details

The called benchmarks were modified to accept arguments from the caller script.
The shapes to be benchmarked are stored into a JSON file, making it easy to add new kernels and shapes (as long as their output format is already supported by the script).
It's possible to benchmark the shapes for a list of specific models or all of the available ones.
At the end, the results are printed to the CLI and saved to a CSV file.

Help text of bench_models.py:
usage: bench_models.py [-h] [--M M [M ...]] [--TP {1,2,4,8}] [--metric {throughput,bandwidth,time}] [--model MODEL] [--layout {TN,TT,NN,NT}]
                       [--output_file OUTPUT_FILE]
 
Model benchmarking tool
 
options:
  -h, --help            show this help message and exit
  --M M [M ...]         Input size M (seq_len for RoPE). Accepts:
                          Single value:            --M 512
                          Multiple values:         --M 256 512 1024
                          Range start:stop:step:   --M 128:1024:128
                          Combinations of values and ranges are also accepted.
