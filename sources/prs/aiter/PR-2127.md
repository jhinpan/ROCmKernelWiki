# [OPUS] opus device test speed up

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2127](https://github.com/ROCm/aiter/pull/2127) · **Merged:** 2026-02-27 · **Author:** @carlushuang

## Summary (from upstream PR description)

[OPUS] 10x device test build speedup: ctypes, parallel hipcc, hip_host_minimal.h
Summary
Reduces the OPUS device test build time from 18.4s to 1.7s (10.5x) and the full run_tests.sh wall clock from ~20s to ~6.9s by applying HIP compile-time best practices from csrc/include/opus/README.md.

Key changes
