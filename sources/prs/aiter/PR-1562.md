# Enhance MLA Reduce for Prefill

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1562](https://github.com/ROCm/aiter/pull/1562) · **Merged:** 2025-12-05 · **Author:** @ruanjm

**Inclusion reason:** kernel path 'aiter/mla.py'; keyword 'attention'

## Summary (from upstream PR description)

This PR introduces 3 aspects which can greatly improve MLA prefill while MLA decode can benefit from them as well.

Now mulitple work groups are used to handle a seq if seqlen is larger than 1 and there is idle CU(s).
Introduce a simple pipeline (the original one is renamed as massive). Simple pipeline is more efficient in handling the cases that #splits is small while the original pipeline is more good at handling massive split cases.
Removed some unimportant temp args for saving time consumed by JIT compiling and simplify code.
