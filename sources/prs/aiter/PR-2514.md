## Summary (from upstream PR description)

Motivation
Enable automated nightly wheel publishing for aiter, making pre-built wheels available for users without requiring them to build from source. This provides:

Automated nightly builds — Wheels built daily at 3 AM UTC
Quality gate — Wheels are tested on single-GPU runners (MI300, MI355) before promotion
Easy installation — Users can install pre-built wheels via pip/uv with --extra-index-url
Multiple release channels — Support for nightlies and devreleases

Technical Details
Workflows Added
1. nightly.yaml (Orchestration)

Scheduled to run daily at 3 AM UTC via cron
Triggers on PRs that modify workflow files (as devreleases) for CI validation
Supports manual workflow_dispatch with configurable docker images, GPU architectures, and skip flags (skip_tests, skip_promote)
Orchestrates the full pipeline: Build → Test → Promote
Promotion is gated on github.repository_owner == 'ROCm' and skipped for pull requests

2. aiter-release.yaml (Reusable Build Workflow — updated)

Added workflow_call trigger so it can be reused by nightly.yaml
Builds wheels with PREBUILD_KERNELS=1 for gfx942/gfx950 architectures
Added date-stamped versioning (+yyyymmdd) via SETUPTOOLS_SCM_PRETEND_VERSION
