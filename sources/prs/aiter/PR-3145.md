Technical Details

Non-temporal (NT) load/store for act_and_mul_kernel
Added a compile-time AUX template parameter to act_and_mul_kernel. The dispatch macro passes GROUP_NT (non-temporal hint), which tells the hardware to bypass L2 cache for both loads and stores. Since activation kernels are streaming workloads with no data reuse, skipping L2 avoids cache pollution and improves effective HBM bandwidth.
Vectorized NT store + NT load for scaled_act_and_mul_kernel
The original kernel wrote fp8 output with per-element scalar stores (out[idx] = ...), which generated one 1-byte store instruction per element. Replaced with:
store_vector_nbytes for vectorized stores (up to 16 bytes per store instruction)
GROUP_NT hint on both loads and stores
This reduces total store instruction count by up to 16x and avoids L2 cache thrashing.
Block-size specialization for scaled_silu_and_mul
