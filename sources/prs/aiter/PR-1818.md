## Summary (from upstream PR description)

FAv3 sage attn kernel
Coauthors: @Chi-Chu319 @juuso-oskari @anhminhnguyenhoang @waqahmed-amd-fi @hellozhuo-amd
This PR adds a quantization scheme on top of the Triton fav3 fp8 kernel. The quantization scheme in short:

K is smoothed (mean reduced per token), Q and K is per block quantized to INT8, Q*K is done in INT8.
V is per channel quantized to FP8, P*V is done in FP8, accumulation is done in FP32.

This quantization scheme is inspired by the sage attention: https://github.com/thu-ml/SageAttention.
Using this quantization scheme, we are able to match the fav3 fp8 speed, but increase the accuracy in video generation examples. Here is a generated video frame from Wan2.2 showing our fav3 sage kernel not having the artifacts of fav3 fp8:
