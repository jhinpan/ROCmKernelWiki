# Update gfx942&gfx950 PA PS kernels and write stride_scale_page in asm_pa

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2796](https://github.com/ROCm/aiter/pull/2796) · **Merged:** 2026-04-22 · **Author:** @fangche123

**Inclusion reason:** kernel path 'csrc/py_itfs_cu/asm_pa.cu'; keyword 'fp8'

## Summary (from upstream PR description)

Motivation
PA PS kernels were updated to support page-level scale addressing, so host-side kernel arguments need to pass both block stride and page stride for scale tensors.
This avoids scale addressing mismatch in persistent decode paths.
Technical Details

Updated PA PS kernel artifacts for gfx942/gfx950.
Extended PsKernelArgs in csrc/py_itfs_cu/asm_pa.cu to include stride_scale_page.
In pa_ps_fwd, compute and pass:

stride_scale_blk from K_QScale->stride(1) * K_QScale->element_size()
stride_scale_page from K_QScale->stride(0) * K_QScale->element_size()


Kept existing dispatch logic and kernel selection flow unchanged.

Test Plan
