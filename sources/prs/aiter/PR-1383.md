## Summary (from upstream PR description)

Motivation
This PR adds high-performance paged attention decode kernels optimized for AMD CDNA3 architecture (MI300 series GPUs) using Triton's Gluon framework. The implementation addresses the need for:

Efficient Long-Context Inference: Paged attention mechanism enables handling long sequences by efficiently managing KV cache in memory-efficient blocks
FP8 Quantization Support: Native support for FP8 data types reduces memory bandwidth requirements and improves performance on AMD MI300 GPUs
AMD GPU Optimization: Leverages AMD MFMA (Matrix Fused Multiply-Add) instructions and CDNA3-specific memory layouts for optimal hardware utilization
AOT Compilation: Provides ahead-of-time compilation infrastructure for deployment scenarios requiring pre-compiled kernels
