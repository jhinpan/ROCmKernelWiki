# [Kernel] flydsl fused_compress_attn for V4-Pro/V4-Flash CSA+HCA

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3357](https://github.com/ROCm/aiter/pull/3357) · **Merged:** 2026-05-26 · **Author:** @valarLip

**Inclusion reason:** kernel path 'aiter/ops/flydsl/kernels/fused_compress_attn.py'; keyword 'mfma'

## Summary (from upstream PR description)

Summary
Adds two flydsl GPU kernels for the V4 attention compressor boundary (online-softmax pool → RMSNorm → GPT-J RoPE → optional FP8 + MFMA 16×16 preshuffle → paged kv_cache scatter), plus a pure-PyTorch reference and a unit test.

flydsl_fused_compress_attn — single-kernel dispatch covering all three shape configs:

CSA Main: D=512, RD=64, ratio=4, overlap=True, BF16
CSA Indexer: D=128, RD=64, ratio=4, overlap=True, FP8 + ue8m0 + MFMA 16×16 preshuffle
HCA Main: D=512, RD=64, ratio=128, overlap=False, BF16


flydsl_hca_compress_attn — HCA-only 2-kernel split (multi-wave LDS K-split + norm_rope_scatter). On V4-Pro HCA Main beats single 1.06–3.7× post slice_size + VEC=8 refactor.
hca_per_n_config — exposed tuning table dispatching on plan_capacity (CUDAGraph-stable). flydsl_hca_compress_attn auto-picks when caller passes None.

Coverage
Pure-PyTorch reference at aiter/ops/torch_ref/fused_compress_attn.py mirrors kernel semantics 1:1 (online softmax, RMSNorm, GPT-J RoPE, FP8 + ue8m0 + preshuffle, paged scatter).
Unit test at op_tests/test_flydsl_compress_attn.py (test_quant.py style — standalone script with argparse + @benchmark + pandas summary) sweeps:

3 shapes × 10 batch sizes
