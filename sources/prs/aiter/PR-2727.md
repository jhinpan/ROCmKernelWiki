# MI350 mla ps mode suppport nhead128,1 128,2 128,3 128,4 64,4 64,2 32,4 through kernel mla_a16w16_qh32_qseqlen4_gqaratio32_ps.co

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2727](https://github.com/ROCm/aiter/pull/2727) · **Merged:** 2026-04-17 · **Author:** @minmengdie

**Inclusion reason:** kernel path 'aiter/mla.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
This PR extends MI350 (gfx950) MLA persistent-scheduling (ps) support to additional (nhead, seqlen) combinations by routing more bf16/bf16 cases through a new precompiled gfx950 kernel and updating the related kernel selection/metadata logic.
Technical Details
Add a new gfx950 bf16/bf16 ps kernel entry to hsa/gfx950/mla/mla_asm.csv and include the new .co binary.
Broaden gfx950 “natively supported” gating in Python tests/runtime and in the C++ metadata generator using the (num_heads * max_seqlen) % 128 == 0 rule for bf16/bf16.
Adjust MLA ASM dispatch logic to select the new kernel configuration on gfx950 for eligible bf16/bf16 persistent cases.
