# Fix missing gradlib directory copy for PREBUILD_KERNELS=1 builds

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1097](https://github.com/ROCm/aiter/pull/1097) · **Merged:** 2025-09-29 · **Author:** @andre-motta

**Inclusion reason:** kernel path 'setup.py'; keyword 'kernel'

## Summary (from upstream PR description)

Summary
This PR fixes a build failure that occurs when PREBUILD_KERNELS=1 is set by adding the missing gradlib directory copy to the setup process.
Problem
When building aiter with PREBUILD_KERNELS=1, the build fails with an AssertionError because required source files in gradlib/csrc/ and header files in gradlib/include/ are not available in the aiter_meta package.
Solution
Add shutil.copytree("gradlib", "aiter_meta/gradlib") to setup.py, similar to how other directories (3rdparty, hsa, csrc) are already copied.
Changes

Modified setup.py to copy the gradlib directory to aiter_meta/gradlib during package setup

Testing

Verified the fix resolves build failures when PREBUILD_KERNELS=1 is set
Build completes successfully with all required gradlib source files available
