## Summary (from upstream PR description)

Motivation
Simplify and optimize triton_kernels moe code and move it into aiter.
Technical Details

Reduce complexity and amount of OOP used which makes readability difficult.
Remove support unrelated to AMD
Follow AITER repo standards as much as possible
Optimize routing by fusing kernels and moe gemm by not doing computations on padding

Test Plan
Correctness and performance unit tests.
Test Result
Correctness tests pass and performance is similar or improved compared to original triton_kernels repo.
