# Add fused AR + RMSNorm + per-group FP8 quant: optional bf16 side-output

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2823](https://github.com/ROCm/aiter/pull/2823) · **Merged:** 2026-04-29 · **Author:** @hubertlu-tw

**Inclusion reason:** kernel path 'aiter/dist/communication_op.py'; keyword 'fp8'

## Summary (from upstream PR description)

Motivation

ar_fusion_epilogue_per_group arg order — Declared (…, output, scale_out, bf16_output, active) but callers passed 11 args ending in (…, scale_out, active), binding bool to T* (invalid). The bf16 path never compiled; this PR fixes parameter order and threads optional bf16_output through 1-stage / 2-stage / split per-group kernels, dispatch, host op, pybind, and Python.
GDN-style layers need FP8 + normed bf16 (e.g. gating) without a second kernel — today that required fused AR+RMS + separate per_1x128 quant. With emit_bf16=True, one kernel writes fp8+scale from the same fp32 accumulators as an optional bf16 side-output.
