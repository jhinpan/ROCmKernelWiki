# chore(release): sync release/v0.1.12 with v0.1.12.post1 commits from rc0.1.12-26w15

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2841](https://github.com/ROCm/aiter/pull/2841) · **Merged:** 2026-04-21 · **Author:** @sunway513

**Inclusion reason:** kernel path '.github/workflows/flash_attention_integration.yaml'; keyword 'mfma'

## Summary (from upstream PR description)

Why
release/v0.1.12 was cut early at the v0.1.12 tag commit (05f2869) and then the actual post1 sprint work landed on a parallel rc0.1.12-26w15 branch (HEAD 7b570738 = v0.1.12.post1 tag). This left release/v0.1.12 stale by 23 commits and downstream consumers consuming v0.1.12.post1 wheels that don't trace back to the named release branch.
We're consolidating: from now on, one release branch per version (release/v0.1.12 for the entire 0.1.12 line including post-releases). After this PR merges, rc0.1.12-26w15 will be abandoned and all post2+ work goes on release/v0.1.12.
What
Merges 23 commits from rc0.1.12-26w15 into release/v0.1.12:

Post1 fixes and features: FlyDSL bf16 GEMM updates, FP8 RDNA4 support, fused gated rmsnorm + group_quant (#2499), Sparse Sage Attention (#2579), shuffle value cache rope (#2568), QK norm group quant fix (#2637), kimi2 bf16 tuned config, etc.
CI hardening: clang toolchain timeout extension (#2650), prebuilt CK checkout reuse (#2659), hipconfig path fix (#2660)
Release prep: ctypes C-ABI error bridging (#2498), tuner accelerator error fix (#2662)

The single divergent commit on release/v0.1.12 (05f2869 "Prepare v0.1.12 release") is preserved via merge co
