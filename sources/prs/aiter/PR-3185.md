# Add fused DeepSeek-V3.2 indexer cache kernel

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3185](https://github.com/ROCm/aiter/pull/3185) · **Merged:** 2026-05-15 · **Author:** @XiaobingSuper

**Inclusion reason:** kernel path 'aiter/ops/cache.py'; keyword 'fp8'

## Summary (from upstream PR description)

Summary

Add indexer_qk_rope_quant_and_cache, a fused DeepSeek-V3.2 indexer helper that applies Q/K RoPE, K RMSNorm, Q FP8 per-1x128 quantization, indexer weight scaling, and K cache insertion in one kernel path.
Expose the new kernel through the Python cache ops API.
Add runtime validation for the fused path's supported layout and shape constraints so unsupported model shapes fail at the kernel boundary instead of silently producing wrong results.

Validation

Built and JIT-loaded through ATOM DeepSeek-V3.2 serving runs.
Re-validated with the companion ATOM integration on MI355, TP=4, DeepSeek-V3.2, ISL=1000, OSL=100.
ATOM fused-vs-fallback performance re-validation showed consistent Total Token Throughput gains: CON=4 +5.6%, CON=8 +5.7%, CON=16 +3.5%.
ATOM fused path accuracy on gsm8k, 3-shot: flexible-extract 0.9462, strict-match 0.9469.

Notes

Companion ATOM PR: ROCm/ATOM#788 wires this kernel into DeepSeek-V3.2 behind ATOM_ENABLE_DS_INDEXER_QK_ROPE_CACHE_FUSION with fallback to the original path when disabled or unsupported.
