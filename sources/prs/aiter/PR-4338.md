Summary
Ports two project-local Claude Code skills from the FlyDSL repo into aiter's .claude/skills/, so FlyDSL kernel work done inside aiter has the same guidance available as in the FlyDSL repo.
Skills added

flydsl-kernel-authoring — full reference for authoring FlyDSL GPU kernels: layout algebra, tiled copy/MMA atoms, SharedAllocator (LDS), loop-carried range loops, autotuning, and common patterns. Cross-links the code-cleanup skill for modernizing existing kernels.
kernel-code-cleanup — migrate legacy/deprecated constructs to the current fx.* surface: ArithValue / index helpers, fx.Index, redundant fx.* wrapping, buffer_ops, raw MLIR dialects (arith/scf/vector/llvm/memref/math), SmemPtr/SmemAllocator, per-tile *_atom_call, and raw rocdl.mfma_*. Also trims comments/dead code and applies the _run_compiled fast launch path.
