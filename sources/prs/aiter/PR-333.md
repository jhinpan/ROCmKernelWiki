# [Triton] [FA] Compute max after SCALE multiplication

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#333](https://github.com/ROCm/aiter/pull/333) · **Merged:** 2025-04-24 · **Author:** @zhanglx13

**Inclusion reason:** kernel path 'aiter/ops/triton/mha.py'

## Summary (from upstream PR description)

We have the following simple flow of computation
qk += tl.dot(q, k)
qk *= SCALE
m_ij = tl.maximum(m_i, tl.max(qk, 1))
p = exp2(qk - m_ij)
The max separates multiplication of SCALE and subtract of max apart, therefore we need both v_fma and v_sub instructions.
This PR changes the computation into
qk += tl.dot(q, k)
m_ij = tl.maximum(m_i, tl.max(qk, 1))
q_shifted = qk * SCALE - (m_ij * SCALE)[:, None]
m_ij * SCALE is a single f_mul. Then q_shifted can be lowered to
v_fma v_qk, v_qk, s_scale, -m_ij*SCALE
v_sub is folded into v_fma
