**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1362](https://github.com/ROCm/aiter/pull/1362) · **Merged:** 2025-11-14 · **Author:** @luocheng25

## Summary (from upstream PR description)

Motivation
Add sliding window feature for paged_attention_v1 which is used in gemma3.
Technical Details
When VLLM_ROCM_USE_AITER is used it turns on VLLM_ROCM_USE_AITER_MHA by default and the performance of attention will be better than other backends. But paged_attention_v1 used for decoding does not support sliding window feature. This PR will address it.
