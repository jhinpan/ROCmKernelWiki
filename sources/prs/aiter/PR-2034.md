## Summary (from upstream PR description)

Summary
This PR optimizes the top-k/top-p sampling kernel and adds comprehensive correctness tests.

Core Contributions
1. Kernel Optimization
This PR addresses a performance bug in the TopKTopPSamplingFromProbKernel kernel. It reduces the number of BlockReduce calls and __syncthreads() from O(iterations) to O(1) by accumulating per-thread partial sums before performing a single block-wide reduction. This provides significant speedup for realistic vocabulary sizes.
2. Unit Tests

Controlled deterministic tests: Use well-separated probability distributions where floating-point variations cannot affect outcomes, enabling exact output validation.
Statistical distribution test: Runs 50,000 samples and uses chi-squared goodness-of-fit to verify the kernel's output distribution matches the theoretical top-k/top-p constrained distribution.
Note: This test is configured to print warnings rather than fail, since statistical tests are expected to occasionally fail by chance. Repeated warnings across multiple runs can be used to determine issues with the code.
