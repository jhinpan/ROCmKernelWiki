## Summary (from upstream PR description)

Motivation
This PR adds a new kernel for fp8 x fp8 MoE GEMM with precision of fp8 e4m3. Both weights and attention can use mx8 scaling. This kernel config is tuned for DeepSeek R1-0528 shapes.
Test Plan
Test cases are implemented in aiter/op_test/triton_tests/test_moe_gemm_a8w8.py
