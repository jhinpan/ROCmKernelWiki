## Summary (from upstream PR description)

Summary

Remove blanket gfx950 tg_div=1 override in get_grid_dim() — only FP8 ASM kernels need it (PR #2911). BF16 ASM kernels support causal tile-skipping and should use tg_div=2.
Halve FLOP count for causal mask in C++ fwd benchmark to align with standard TFLOPS convention.
