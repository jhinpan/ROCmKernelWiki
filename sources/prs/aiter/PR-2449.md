# [OPUS] gfx1250 support for opus wmma scale and moe_sorting kernel

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2449](https://github.com/ROCm/aiter/pull/2449) · **Merged:** 2026-03-25 · **Author:** @carlushuang

**Inclusion reason:** kernel path 'aiter/jit/core.py'; keyword 'wmma'

## Summary (from upstream PR description)

Summary

Add gfx1250 support to aiter's JIT infrastructure and opus kernels
Fix opus moe_sorting kernel for gfx1250 wave32 ISA (s_waitcnt_lgkmcnt -> s_wait_dscnt)
Add 4 WMMA scale instructions to opus.hpp with full device test coverage:

wmma_scale[16]_f32_16x16x128_f8f6f4 (fp8/fp4 via format code, BX32/BX16 scale)
wmma_scale[16]_f32_32x16x128_f4 (dedicated fp4, BX32/BX16 scale)


Add multi-wave tiled MMA tests (1x1, 2x2, 4x1 wave configurations)
