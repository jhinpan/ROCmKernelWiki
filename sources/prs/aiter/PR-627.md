# Fix Precision Issue in RoPE Tests

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#627](https://github.com/ROCm/aiter/pull/627) · **Merged:** 2025-07-15 · **Author:** @ruanjm

**Inclusion reason:** kernel path 'csrc/kernels/rope/general_bwd_kernels.cu'; keyword 'kernel'

## Summary (from upstream PR description)

Kernel is correct but there is precision issue in reference code:

All the computation in kernel is conducted with fp32 but with fp16 or bf16 in reference code.
In the case of cached cases, the pre-computated cos/sin are truncated. Reference code need to simulate such cases.

Besides, this PR also move the code about RoPE to a new place.
This PR is for #620.
