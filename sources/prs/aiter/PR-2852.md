# MLA PS mode support nhead8,2 in MI308

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2852](https://github.com/ROCm/aiter/pull/2852) · **Merged:** 2026-04-23 · **Author:** @minmengdie

**Inclusion reason:** kernel path 'aiter/mla.py'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
Adds MI308 (gfx942) MLA persistent-mode support for the bf16/bf16 configuration with 8 heads and decode qlen=2 by wiring a new precompiled asm kernel into the runtime selection and relaxing frontend gating.
Technical Details
Extend gfx942 native-support gating in Python (aiter/mla.py) and reference test helpers to allow (nhead=8, max_seqlen_q=2) bf16/bf16.
Register a new gfx942 MLA asm kernel in hsa/gfx942/mla/mla_asm.csv and add the corresponding .co blob.
Update device-side MLA metadata validation to accept the new (8,2) bf16/bf16 case.
Test Plan
python3 op_tests/test_mla_persistent.py -d bf16 -kvd bf16 -n 8,2
python3 op_tests/test_mla_persistent.py -d bf16 -kvd bf16 -n 8,2 -b 1 64 128 -c 1024 8192 16384
