## Summary (from upstream PR description)

author: @Chi-Chu319 @juuso-oskari
Fixed the precision issue in extend attention test with bf16
The einsum basically takes in two same dtype and output in the same dtype. So with bf16 it's doing bf16 x bf16 => bf16. Which causes precision issue because bf16 has so little mantissa
Casting them to float makes them output fp32 as well which prevents the overflow with mantissa
