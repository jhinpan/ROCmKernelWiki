## Summary (from upstream PR description)

Changes:
See https://github.com/ROCm/triton-internal/issues/937

 Added bench_schema.yaml to specify benchmark output format.
 When -o is specified, the output csv file must be named as the same as the benchmark script except the extension is .csv.
 Renamed the output column from "Triton" to a unit based on the metric (e.g ms, TFLOPS, GB/s).
 Fix bug for extend_attn on gfx950 + add -print_vgpr flag to scripts missing it.
