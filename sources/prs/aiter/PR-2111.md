# [TRITON] Create script to benchmark attention kernels with shapes of LLM models

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2111](https://github.com/ROCm/aiter/pull/2111) · **Merged:** 2026-03-05 · **Author:** @brunomazzottiamd

**Inclusion reason:** kernel path '.github/scripts/select_triton_tests.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
The introduction of async copy feature into Triton compiler (controlled by TRITON_HIP_USE_ASYNC_COPY environment variable) motivated the creation of an attention benchmarking script. The idea is to develop a comprehensive benchmarking routine, capable of measuring the Triton attention kernels performance for a variety of popular LLM models.
Technical Details
Attention Benchmarking Script
This PR add op_tests/op_benchmarks/triton/bench_attn_models.py script, a single entry-point that benchmarks attention kernels using real LLM shapes (number of heads and head dimensions) across batch / sequence sweeps (sequence length expressed in K tokens), tensor-parallel degrees, and MHA layouts (BSHD and THD). It writes a normalized CSV of results and tracks failures without stopping the sweep.
