# feat(fused_kv_cache): support value_cache 5D shuffle layout and add gpt-oss-120b precision tests

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2217](https://github.com/ROCm/aiter/pull/2217) · **Merged:** 2026-03-09 · **Author:** @PerryZhang01

**Inclusion reason:** kernel path 'aiter/ops/triton/_triton_kernels/fusions/fused_kv_cache.py'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
Add support for the 5D value_cache shuffle layout [num_blocks, num_kv_heads, block_size//x, head_size, x] in fused_qk_rope_reshape_and_cache, while keeping compatibility with the existing 4D layout.
Technical Details

Python wrapper: Detects 5D layout when value_cache.ndim == 5, computes strides, and passes VALUE_SHUFFLE_LAYOUT and the new stride args to the kernel.
Triton kernel: Adds VALUE_SHUFFLE_LAYOUT and stride params; when true, writes value_cache using slot_chunk = pid_b // X_SIZE, x_off = pid_b % X_SIZE.

Test Plan

New unit test for 5D value_cache (vs reference).
New gpt-oss-120b config test comparing 4D vs 5D at atol/rtol=1e-3.
Existing fused_kv_cache tests run to check for regressions.

Test Result
All tests pass; 4D and 5D outputs match within 1e-3, no precision issues.
