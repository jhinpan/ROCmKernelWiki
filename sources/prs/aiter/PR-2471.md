# Fix precision bug and add gelu kernels for 64x256

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2471](https://github.com/ROCm/aiter/pull/2471) · **Merged:** 2026-03-28 · **Author:** @JohnNikolay84

## Summary (from upstream PR description)

Motivation
It was reported by Samsung that on mi300 64x256 kernels have bad precision. This PR is fixing this issue and also introducing same kernels for gelu activation.
Technical Details
One wait instruction was incorrect in assembly kernel causing data overwrite.
Test Plan

Test Result
Precision in aiter internal tests now for 64x256 match 32x256 precision.
