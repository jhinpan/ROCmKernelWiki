# Respect AITER_LOG_LEVEL for C++ stdout prints

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2086](https://github.com/ROCm/aiter/pull/2086) · **Merged:** 2026-03-03 · **Author:** @copilot-swe-agent

## Summary (from upstream PR description)

Several C++ std::cout statements fired unconditionally, bypassing AITER_LOG_LEVEL and making them impossible to suppress at runtime.
Approach
Introduces csrc/include/aiter_logger.h — a lightweight C++ logging header that reads AITER_LOG_LEVEL once at startup (static local, thread-safe init) and exposes stream-compatible macros aligned with Python's logging levels:
// AITER_LOG_LEVEL=WARNING suppresses DEBUG and INFO prints
AITER_LOG_DEBUG("LRUCache created with capacity: " << capacity);
AITER_LOG_INFO("hipModuleLoad: " << hsa_path << " GetFunction: " << name);
AITER_LOG_WARNING("fmha_v3_bwd: unsupported mask type for asm kernels.");
Default level is INFO, matching the Python-side default.
