# Add a new kernel that supports decode mla with sub_kv=64 and sub_qh=8

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2917](https://github.com/ROCm/aiter/pull/2917) · **Merged:** 2026-05-01 · **Author:** @JohnNikolay84

**Inclusion reason:** kernel path 'aiter/mla.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Customers have been asking for a mla decode kernel with the following config:
qType bf16
kvType bf16
QH 8
ps 0
prefill 0
causal 0
seqlen 1
Technical Details
This is really a cosmetic change to the existing qh16 kernel. with seqlen1 whether we use 8 or 16 lanes in matrix Q does not really matter. It is still an M=16 gemm and those extra lines will be just zeroes and dropped.
QH8 non-persistent kernels are introduced for mi300 and mi350.
Test Plan
modify existing aiter mla test to support qh=8 and make sure it passes with the new kernel.
Test Result
python op_tests/test_mla.py     -n 8,1     -k 512 -qn 192 -qr 64 -vh 256     -d bf16 -kvd bf16     -b 1 4 16     -c 64 256
PASS
