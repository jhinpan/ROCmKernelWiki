**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1272](https://github.com/ROCm/aiter/pull/1272) · **Merged:** 2025-12-16 · **Author:** @LJ-underdog

## Summary (from upstream PR description)

Motivation
Add sink_size parameter for mha_fwd&varlen_mha_fwd api, because ck fmha support attn_sink. ck pr:ROCm/composable_kernel#3368
Technical Details


This PR adds support for the sink_size parameter to the MHA (Multi-Head Attention) forward APIs (mha_fwd and varlen_mha_fwd) to enable attention sink functionality, aligning with the CK FMHA implementation.


Key Changes:




Added sink_size parameter to all MHA forward function signatures


Updated mask construction to include sink size information


Modified window_size tuples from 2-element to 3-element (adding sink_size as third element)


Test Plan
Aiter currently has no tests, testing is on ck
Test Result
Local mha op test is successful.
