## Summary (from upstream PR description)

Quick PR to merge a few updates to the blockscale a8w8 GEMM.
Changes:

 Converted the Split-K reduction kernel for the blockscale GEMM over to Gluon.

 Tests pass.


 Updated the Gluon kernel's configs to speed up small-M kernels with split-K.
 Quick bugfix for bench_gemm_a16w16 not working with --print_vgpr.
 Add preset layouts for different values of num_warps to allow config tuning without modifying the kernel file.
 Add Deepseek tuning shapes.

Note: The tuning branch for the Deepseek shapes is incompatible (code-wise) with the current branch due to differences in layouts needed for different numbers of warps per block. Will have a follow-up PR from the Deepseek branch that expands the config for Gluon kernels to include layout params.
