# Optimize sigmoid activation with AMD fast math intrinsics for 20% average speedup on MI300X

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1879](https://github.com/ROCm/aiter/pull/1879) · **Merged:** 2026-01-21 · **Author:** @irvineoy

**Inclusion reason:** kernel path 'csrc/kernels/unary_operator.cu'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
The baseline implementation uses standard expf() which doesn't fully leverage AMD MI300X hardware capabilities. This PR optimizes sigmoid by replacing standard math functions with AMD-specific fast math intrinsics (__builtin_amdgcn_exp2f and __builtin_amdgcn_rcpf), achieving 20% average speedup with perfect numerical accuracy.
Technical Details
Key changes:


Replace expf(-x) with __builtin_amdgcn_exp2f(neg_x * LOG2E)

Converts exp(x) = exp2(x × log₂(e)) to leverage AMD's hardware exp2 instruction
Direct mapping to VALU exp2 operation on CDNA3 architecture



Replace 1.0f / denom with __builtin_amdgcn_rcpf(denom)

Uses AMD's fast reciprocal approximation instruction
Single VALU instruction instead of full IEEE 754 division



Implementation:
// Before:
return static_cast<T>(1.0f / (1.0f + expf(static_cast<float>(-x))));

// After:
float neg_x = static_cast<float>(-x);
constexpr float LOG2E = 1.442695040888963407359924681001892137426645954152985934135449406931f;
float exp_val = __builtin_amdgcn_exp2f(neg_x * LOG2E);
float denom = 1.0f + exp_val;
float result = __builtin_amdgcn_rcpf(denom);
return static_cast<T>(result);
