## Summary (from upstream PR description)

Motivation
As #3390 revealed causal  masking is broken in f8 mha kernels for mi355.
This commit removes patching done in PR 3390 and now  properly integrates causal  f8 mha kernels with tg_div=2 optimization.
Technical Details
causal f8 mha kernel was doing a full non causal PV run. That kernel was technically giving us correct output but had no causal masking applied at all.
