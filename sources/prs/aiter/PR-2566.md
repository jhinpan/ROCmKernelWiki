## Summary (from upstream PR description)

Motivation
background:
the data type of positions is int32 for a customer model( blaze-o1 LUM3 model).
The data type of the positions parameter in the rope kernel is int64.
if calling this rope kernel in the blaze-o1 framework, need to cast int32 to int64. it will takes 7us.
so we want to optimize this data conversion operation. rope kernel positions parameter supports int32
