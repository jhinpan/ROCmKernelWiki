## Summary (from upstream PR description)

Motivation
Top-k selection is a fundamental operation in modern ML workloads (LLM inference, recommendation systems, attention mechanisms).
This PR provides a high-performance top-k implementation optimized specifically for AMD GPU architecture,  with better scaling for large-scale workloads.
Technical Details
This PR's implementation is primarily based on the WarpSelect algorithm, as detailed in the following works:


J. Johnson, M. Douze, and H. Jégou, “Billion-scale similarity search with GPUs,” IEEE Transactions on Big Data, vol. 7, no. 3, pp. 535–547, 2019. Available: https://arxiv.org/pdf/1702.08734


C. Zhang and Y. Wang. (2020) Accelerating top-k computation on GPU. NVIDIA. Available: https://live.nvidia.cn/gtc-od/attachments/CNS20315.pdf


We opted not to use algorithms related to Radix Select. This is because Radix Select relies heavily on atomicAdd operations on LDS to build histograms. On our target AMD GPU, these LDS atomic operations perform poorly, so we chose the WarpSelect path for better performance.
