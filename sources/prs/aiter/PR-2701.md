**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2701](https://github.com/ROCm/aiter/pull/2701) · **Merged:** 2026-04-13 · **Author:** @carlushuang

## Summary (from upstream PR description)

Summary
Optimize opus.hpp template metaprogramming to reduce device-only compile time by 70% (4829ms → 1465ms) for GQA flash attention kernel on gfx950. Reduce total function template instantiations from ~3800 to ~738 (81% fewer). All changes preserve codegen quality: VGPRs=251, Spills=0, Occupancy=2, ~930 TFlops.
