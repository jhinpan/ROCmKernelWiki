# FP16 Paged Attention & Fused MoE

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#97](https://github.com/ROCm/aiter/pull/97) · **Merged:** 2025-02-07 · **Author:** @mawong-amd

**Inclusion reason:** kernel path 'csrc/ck_gemm_a8w8/include/gemm_a8w8_common.cuh'; keyword 'gemm'

## Summary (from upstream PR description)

This PR adds FP16 support for some high-touch kernels, namely Paged Attention (including FP8/INT8 KV cache and unquantized variants) and Fused MoE (unquantized only). Accuracy and performance have been verified to be in line with the BF16 kernels.
It also contains a few miscellaneous tidy-ups, including adding device guards to prevent issues such as #89. These changes are independently useful even if the FP16 kernels are ultimately not merged.
