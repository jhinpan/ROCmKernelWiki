# [MOE] special path for moe fp8/bf16, batch 1~16

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#1747](https://github.com/ROCm/aiter/pull/1747) · **Merged:** 2026-01-09 · **Author:** @luocheng25

**Inclusion reason:** kernel path 'aiter/fused_moe.py'; keyword 'moe'

## Summary (from upstream PR description)

Motivation
Optimization for small batches performance of moe.
Technical Details
Major optimization:

batch1: a new special kernel can directly use topk_ids and topk_weight and there is no dependency on moe_sorting
fp8: since it's memory bound, a new kernel will do weight decompression instead of additional dynamic quantization kernels.

The function is disabled by default, should use AITER_MOE_SMALL_BATCH=1 to enable (maybe need to delete aiter/jit/module_moe_asm.so to recompile).
The corresponding source file for .co is moe.py.
Test Plan
AITER_MOE_SMALL_BATCH=1 python3 ./test_moe_2stage.py --use-raw-for-ref t 
Test Result
BF16: The accuracy is no change.
FP8: due to no dynamic quantization error, the accuracy is better than the exists (To verify should use --use-raw-for-ref in testcase to check).
