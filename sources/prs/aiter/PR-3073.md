# bump composable_kernel to include rocm-libraries PR #6914

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3073](https://github.com/ROCm/aiter/pull/3073) · **Merged:** 2026-05-15 · **Author:** @arthurliu1998

**Inclusion reason:** kernel path '3rdparty/composable_kernel'; keyword 'fp8'

## Summary (from upstream PR description)

Motivation
Bring the ck_tile FMHA fix from ROCm/rocm-libraries#6914 into aiter so that StreamLLM-sink + sliding-window batch-prefill works correctly for the fp8(KV) / bf16(QO) path. Without this bump,
op_tests/test_batch_prefill.py (fp8 / bf16_dequant with sink>0, win_left>0) either fails to dispatch (no sink-aware fp8bf16 kernel emitted) or returns wrong numerics (sink un-mask leaks future columns into queries 1..sink-1).
Technical Details
3rdparty/composable_kernel: fdf4bb7fc → 33b62ed08
33b62ed08 is the composable_kernel mirror commit for rocm-libraries#6914, which contains:

fmha: emit sink kernels for fp8bf16 batch_prefill — extends example/ck_tile/01_fmha/codegen/ops/fmha_batch_prefill.py to emit the mask=mask_enum::generic_with_sink variant for the fp8(KV)/bf16(QO) path.
fmha: respect right-window in IsOutOfSinkBound — replaces the (i_y + x) > 1 gate (which conditioned on the row index) with i_x < i_y + x so every query only sees sink columns up to its own right-window boundary.
fmha: clarify IsOutOfSinkBound predicate comment — doc-only.

Because the mirror is linear, this bump also pulls in 9 unrelated rocm-libraries PRs that landed on the mirror between fdf4bb7fc and 33b6
