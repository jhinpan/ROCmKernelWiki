## Summary (from upstream PR description)

[OPUS] Enhance opus.hpp, add moe_sorting_opus, workgroup_barrier, and device tests
Summary

Add a self-contained opus-based MOE sorting kernel (moe_sorting_opus) that eliminates the CK header dependency, enabling faster JIT compilation while maintaining bit-exact correctness and matching runtime performance
Enhance opus.hpp with new utilities (workgroup_barrier, mdiv, runtime query APIs) and documentation on the HIPCC two-pass compilation model
Add device tests for workgroup_barrier covering inter-workgroup synchronization patterns

moe_sorting_opus
A standalone MOE sorting kernel built entirely on opus.hpp primitives — no Composable Kernel (CK) dependency. This means:

No submodule needed: CK submodule checkout is not required for this path
Faster JIT build: fewer headers to parse, comparable compile time to CK path
Drop-in replacement: identical API signature, bit-exact output on all valid fields

Correctness & Performance (MI300X, gfx942)
