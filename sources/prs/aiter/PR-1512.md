## Summary (from upstream PR description)

Motivation
This PR optimizes the topk_per_row implementation for the case where the logits only span a small dynamic range (effectively within 11 LSBits).
In this regime we can safely use a one-pass radix kernel, which reduces global memory traffic and synchronization overhead.
