# [Gluon] Unified Attention 3D development for gfx12

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2048](https://github.com/ROCm/aiter/pull/2048) · **Merged:** 2026-02-16 · **Author:** @k50112113

## Summary (from upstream PR description)

This PR provides Unified Attention 3D with baseline, async_copy, tdm.async_copy, and tdm.async_gather version.
The tdm.async_gather version requires reordering of key_cache and value_cache, it doesn't not require sorting the block_table but the random gather feature is not hardware verified yet. Another issue with tdm.async_gather hits OOB LDS write if block_size * head_size >= 1024, so for now the UT only tested block_size * head_size = 512. The ticket related to this issue is ROCm/triton-internal#1643
