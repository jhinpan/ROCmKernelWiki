# Add native qh32 qseqlen2 MLA PS kernel for gfx950 fp8 decode

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2676](https://github.com/ROCm/aiter/pull/2676) · **Merged:** 2026-04-10 · **Author:** @fangche123

**Inclusion reason:** kernel path 'aiter/mla.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
Add native persistent MLA kernel for gfx950 FP8 decode with nhead=32, decode_qlen=2. Previously this configuration was handled by qseqlen-fold, which reshapes (nhead=32, qlen=2) into (nhead=16, qlen=4) and dispatches to the qh16 kernel. The new native qh32_qseqlen2 kernel avoids the fold overhead and provides a direct execution path.
Technical Details

Add two new compiled kernel objects: mla_a8w8_qh32_qseqlen2_gqaratio32_v3_ps.co (with and without LSE).
Register them in mla_asm.csv and add dispatch logic in asm_mla.cu for gqa_ratio=32, max_seqlen_q=2.
Mark (num_heads=32, max_seqlen_qo=2) as natively supported in metadata generation (v1_2_device.cuh), Python API (mla.py), metadata sizing (attention.py), and test reference (test_mla_persistent.py).
Exclude this configuration from use_qseqlen_fold to prevent incorrect fold-to-nhead16 behavior.

Test Plan
python3 op_tests/test_mla_persistent.py --nhead 32,2 -d fp8 -kvd fp8 -c 1024 8192 32768 -b 64
python3 op_tests/test_mla_persistent.py --nhead 16,4 32,2 32,4 128,1 64,2 -d fp8 -kvd fp8 -c 1024 8192 32768 -b 64
