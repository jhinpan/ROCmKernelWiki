## Summary (from upstream PR description)

Add FlyDSL GEMM AOT precompile support so tuned HGEMM and preshuffle kernels can be compiled into the runtime cache ahead of execution. This also reuses shared FlyDSL AOT helpers across GEMM, MoE, and setup prebuild to keep job collection, deduplication, and COMPILE_ONLY handling consistent.
