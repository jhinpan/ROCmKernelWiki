# add tuner test suite

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2734](https://github.com/ROCm/aiter/pull/2734) · **Merged:** 2026-04-21 · **Author:** @yzhou103

**Inclusion reason:** kernel path 'aiter/configs/tuned_fmoe.csv'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Add a multi-level test suite for validating the aiter tuning infrastructure, along with several robustness improvements to the tuning framework.
Technical Details
Test Suite (op_tests/tuning_tests/)


Level 0 (no GPU): test_csv_validation.py — validates tuned CSV integrity (duplicates, invalid times, errRatio, git conflicts)


Level 1 (no GPU): test_tuner_infra.py — tests base_tuner utilities (CSV I/O, merge, dedup, calculate, post_process topk); test_mp_tuner_logic.py — tests mp_tuner polling (timeout, AcceleratorError, KeyError, pool restart)


Level 2 (GPU): test_tune_pipeline.py — end-to-end pipeline smoke test for each tuner on small shapes; test_run_config.py — runs --run_config on all existing tuned CSVs (configs + model_configs) for every tuner family


Covers all 9 families: a8w8, a8w8_bpreshuffle, a8w8_blockscale, a8w8_blockscale_bpreshuffle, a4w4_blockscale, batched_a8w8, batched_bf16, fmoe, gradlib_bf16


Config resolution via AITER_CONFIGS (same production path) validates that env var names, default file paths, and model_configs merging all work correctly
Benchmark results saved to CSV (/tmp/tuning_test_reports/) for performance comparison across runs
