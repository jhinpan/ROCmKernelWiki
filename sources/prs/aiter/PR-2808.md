# fix(mha_bwd): pass independent strides for do in _bwd_preprocess

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2808](https://github.com/ROCm/aiter/pull/2808) · **Merged:** 2026-04-27 · **Author:** @RuibinCheung

**Inclusion reason:** kernel path 'aiter/ops/triton/_triton_kernels/attention/mha_fused_bwd.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
In sink attention kernel, _bwd_preprocess computed delta = rowsum(O * dO) using only *o_strides to address both O and dO, implicitly assuming the two tensors share the same memory layout. When a caller passes a dO whose stride differs from O (e.g. a BSHD-shaped but SBHD-strided dO against a BSHD-contiguous O produced by the forward kernel), the dO load is mis-addressed and delta is garbage.
This propagates into the main backward kernel and corrupts dQ, dK and dSink (via ds = p * (dp - delta) and dsink = -sum(exp(sink-m) * delta)), while dV = P^T @ dO is unaffected because it does not depend on delta and reloads dO with its own strides inside _bwd_dkdv_inner.

Technical Details

Fixed by:

adding independent stride_do_b/h/m/k parameters to _bwd_preprocess and addressing dO with them;
passing *do_strides (already computed in the wrapper) alongside *o_strides when launching the preprocess kernel.
