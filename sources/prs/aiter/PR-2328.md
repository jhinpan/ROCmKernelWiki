**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2328](https://github.com/ROCm/aiter/pull/2328) · **Merged:** 2026-03-18 · **Author:** @JohnNikolay84

## Summary (from upstream PR description)

Motivation
This PR fixes OOB access for GU and D quants for 64x128 kernels: both silu and gelu
Technical Details
When switching  SUB_GU from 256 to 128 I forgot to account for a fact that scales cannot be accessed in hidden_dim 128:255 anymore. This commit fixes it.
