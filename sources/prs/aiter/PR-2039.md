# Introduce HipKittens based nhead=128 MLA Kernel

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#2039](https://github.com/ROCm/aiter/pull/2039) · **Merged:** 2026-03-09 · **Author:** @ruanjm

**Inclusion reason:** kernel path 'aiter/dist/device_communicators/custom_all_reduce.py'; keyword 'attention'

## Summary (from upstream PR description)

I'd like to introduce the HipKittens based nhead=128 MLA Kernel and replace it with asm kernel in some of cases.
For MI30x, the perf of HK kernel is better or equal to ASM kernel in almost all the cases. Thus, I'd like to use HK kernel for gfx942.
For MI35x, the perf of HK kernel is better than ASM kernel in most cases. However, HK kernel cannot beat ASM kernel for the cases that the problem size is very large. So I keep the previous choice.
Tell me if you think it is good to switch to HK kernel for gfx950.
