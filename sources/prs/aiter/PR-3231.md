# [TRITON] Use tl.dot(..., acc=...) accumulator form

**Repository:** [ROCm/aiter](https://github.com/ROCm/aiter) · **PR:** [#3231](https://github.com/ROCm/aiter/pull/3231) · **Merged:** 2026-05-20 · **Author:** @vgokhale

**Inclusion reason:** kernel path 'aiter/ops/triton/_triton_kernels/attention/extend_attention.py'; keyword 'gemm'

## Summary (from upstream PR description)

Convert acc += tl.dot(...) and acc += tl.dot_scaled(...) to acc = tl.dot(..., acc=acc) / acc = tl.dot_scaled(..., acc=acc) so the matrix multiply accumulates directly into acc without a separate add.
