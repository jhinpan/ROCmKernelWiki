## Summary (from upstream PR description)

Motivation
Skip ModelOpt quantization tests (FP8 + NVFP4) on AMD ROCm.

ModelOpt FP8: torch._scaled_mm returns HIPBLAS_STATUS_NOT_SUPPORTED on ROCm
ModelOpt NVFP4: Requires flashinfer or sgl_kernel FP4 kernels, which are CUDA-only
