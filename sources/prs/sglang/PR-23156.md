# [AMD] prepare for MI300x PR runner pool: registry mirror, runner routing, threshold tuning

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23156](https://github.com/sgl-project/sglang/pull/23156) · **Merged:** 2026-04-21 · **Author:** @bingxche

**Inclusion reason:** kernel path 'test/registered/amd/test_deepseek_v32_basic.py'; keyword 'moe'

## Summary (from upstream PR description)

Motivation
Prepare the AMD CI to run PR tests on the new linux-mi300-*gpu-sglang runner pool while keeping scheduled runs on linux-mi325-*gpu-sglang. This involves three coupled changes:

In-network image mirror so PR jobs don't hammer Docker Hub
Runner pool routing that picks MI300x for PRs, MI325x for schedules, user-selectable for workflow_dispatch
MI300x-specific test budget tuning — perf thresholds, est_time, step timeouts, and a couple of skips for known kernel-precision issues


Modifications
1. In-network Docker registry (avoid Docker Hub rate limits)

release-docker-amd-nightly.yml / release-docker-amd-rocm720-nightly.yml: after publishing the nightly rocm/sgl-dev image, an extra push_local_registry job re-tags it with 172.29.8.23:5000/ prefix and pushes to the in-network registry.
scripts/ci/amd/amd_ci_start_container.sh and amd_ci_start_container_disagg.sh:

Lookup order is now (a) local docker cache, (b) Docker Hub manifest probe.
Pull step tries the LAN mirror first via docker pull "${LOCAL_DOCKER_REGISTRY}/${IMAGE}" (which goes through the host docker daemon and inherits its insecure-registries config), and only falls back to public Docker Hub with a 6-attempt exponen
