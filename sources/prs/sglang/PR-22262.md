# [AMD] Fix DLPack Error in Aiter flydsl GEMM by Detaching MoE Gate Weight

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22262](https://github.com/sgl-project/sglang/pull/22262) · **Merged:** 2026-04-08 · **Author:** @bingxche

**Inclusion reason:** kernel path 'python/sglang/srt/layers/rocm_linear_utils.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
The new aiter flydsl GEMM backend exports tensors via DLPack, which raises BufferError on tensors with requires_grad=True. MoEGate.weight is an nn.Parameter (requires_grad=True by default), causing crashes during CUDA graph capture.
Detach the weight before passing to tgemm.mm. This is a zero-copy operation that shares the same GPU memory, with no precision or performance impact.
Fixes: nightly-8-gpu-mi35x-kimi-k25 crash
