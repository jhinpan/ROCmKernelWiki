# [AMD] Add peft>=0.18.0 to diffusion_hip deps for transformers 5.x compat for AMD diffusion model

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21442](https://github.com/sgl-project/sglang/pull/21442) · **Merged:** 2026-03-29 · **Author:** @yichiche

**Inclusion reason:** keyword 'kernel'

## Summary (from upstream PR description)

Motivation
Solve dependency issue introduced in latest sglang upgrade, which cause wan2.2 fail to launch.
The ROCm Docker image ships transformers==5.3.0, but peft==0.17.0 (pulled in by diffusers) tries to import HybridCache from transformers, which was removed in v5.x. This causes an ImportError at startup when running diffusion workloads (e.g. Wan2.2 T2V):
from transformers import Cache, DynamicCache, EncoderDecoderCache, HybridCache, PreTrainedModel
ImportError: cannot import name 'HybridCache' from 'transformers'
transformers v5 requires peft>=0.18.0 (huggingface/transformers#41889), which drops the HybridCache import.
Modifications
Added "peft>=0.18.0" to the diffusion_hip optional dependencies in pyproject_other.toml.
