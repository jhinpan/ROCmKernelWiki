# [AMD]: Support MLA with nhead<16 and FP8 KV cache for TP=8 (Kimi K2.5…

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21213](https://github.com/sgl-project/sglang/pull/21213) · **Merged:** 2026-04-05 · **Author:** @ZiguanWang

**Inclusion reason:** kernel path 'python/sglang/srt/layers/attention/aiter_backend.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation

Modifications

Support AITER MLA for num_heads < 16 (e.g., TP=8 with Kimi K2.5 giving 8 heads/rank). Uses head-repeat to expand to 16 heads before calling the AITER MLA decode kernel, then contracts the output back. This reuses the existing optimized gqa_ratio=16 ASM kernel without requiring new kernel variants.
Relax head-count assertion to accept num_heads of 4, 8, or any multiple of 16 in [16, 128]. Previously only {16, 128} were accepted.
