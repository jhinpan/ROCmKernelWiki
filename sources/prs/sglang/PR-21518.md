# [AMD] Fix Handle missing rope_theta in get_rope_config for Grok-1

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21518](https://github.com/sgl-project/sglang/pull/21518) · **Merged:** 2026-03-31 · **Author:** @michaelzhang-ai

**Inclusion reason:** keyword 'fp8'

## Summary (from upstream PR description)

Motivation
The AMD nightly CI jobs nightly-8-gpu-grok1-int4 and nightly-8-gpu-mi35x-grok1-int4 both crash during Grok-1 model loading with:
AttributeError: 'Grok1Config' object has no attribute 'rope_theta'

This was introduced in #21135, which migrated grok.py from a safe getattr(config, "rope_theta", 10000) to the shared get_rope_config(config) helper. However, the Grok-1 INT4 model (amd/grok-1-W4A8KV8) uses a custom Grok1Config class (via trust_remote_code) that does not define rope_theta — neither in config.json nor in configuration_grok1.py — so get_rope_config() raises AttributeError on the v4 fallback path (config.rope_theta).
Why Grok-1 FP8 passes on the same commit: The FP8 test uses lmzheng/grok-1 which has model_type: "mixtral", so transformers loads it as MixtralConfig which defines rope_theta as a default class attribute. The INT4 model uses model_type: "grok-1" → custom Grok1Config → no rope_theta.
