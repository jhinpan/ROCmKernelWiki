# [AMD] Add MoE weights and scales padding

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21097](https://github.com/sgl-project/sglang/pull/21097) · **Merged:** 2026-04-13 · **Author:** @mqhc2020

**Inclusion reason:** kernel path 'python/sglang/srt/layers/moe/fused_moe_triton/fused_moe.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
Right now, Aiter MoE requires weights and scales to align with a fixed number. Since some models have intermediate sizes that don't fit this rule, we need to add extra padding to the weights so they can be processed by the Fused MoE.
Modifications
Add padding for the weights. Below listed are the models and configurations that has been verified with:

Qwen/Qwen3-235B-A22B-Instruct-2507-FP8 : TP=8
amd/Qwen3-235B-A22B-Instruct-2507-MXFP4: TP=8
amd/Qwen3.5-397B-A17B-MXFP4: TP=8
zai-org/GLM-4.7: TP=8

Accuracy Tests
We run GSM8K accuracy test for models below:
Qwen/Qwen3-235B-A22B-Instruct-2507-FP8 (TP8):
Serve command:
SGLANG_USE_AITER=1 python3 -m sglang.launch_server \
	--model-path ${MODEL_PATH} \
	--tp-size 8 \
	--ep-size 1 \
	--trust-remote-code \
	--chunked-prefill-size 131072 \
	--mem-fraction-static 0.9 \
	--attention-backend aiter

Accuracy: 0.980
Invalid: 0.000
Latency: 10.525 s
Output throughput: 2663.037 token/s
