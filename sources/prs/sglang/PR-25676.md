## Summary (from upstream PR description)

Summary

Upgrade SGLang xgrammar pins to 0.2.1 across Python package variants and NPU workflow installs.
Remove the local DeepSeek-V3.2 structural-tag workaround and route DeepSeek-V3.2/V4 through xgrammar native structural tags now that mlc-ai/xgrammar#638 is released.
Route Kimi-K2 required/named tool choices through xgrammar native structural tags now that mlc-ai/xgrammar#623 keeps Kimi auto-mode tool calls section-wrapped.
Keep Kimi non-strict required/named tool arguments object-shaped with a loose {"type":"object"} schema, so xgrammar generation remains compatible with Kimi parser expectations without enforcing field-level strictness.

Kimi behavior

Explicit chat_template_kwargs={"thinking": False} still disables reasoning.
