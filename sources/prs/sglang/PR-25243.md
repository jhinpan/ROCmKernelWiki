## Summary (from upstream PR description)

Summary

Add H100 (FP4) as a new hardware option in the DeepSeek-V4 interactive deployment command generator (docs_new/src/snippets/autoregressive/deepseek-v4-deployment.jsx). H100 uses the Marlin FP4 runner (like the existing H200 (FP4) path) but with higher TP and, for Pro, a 2-node deployment:

Flash: TP=8 single-node — low-latency / balanced / max-throughput
Pro: TP=16 across 2 nodes with SGLANG_SHARED_EXPERT_TP1=1, --mem-fraction-static 0.9; low-latency / balanced additionally cap --cuda-graph-max-bs 8 --max-running-requests 32
cp / pd-disagg are disabled on H100 (Marlin-only path). Refactored the H200 (FP4) unsupported-recipes constant into a shared MARLIN_HARDWARE / MARLIN_UNSUPPORTED_RECIPES so H100 reuses the same UI disable + auto-fallback logic.
