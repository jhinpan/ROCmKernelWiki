**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23954](https://github.com/sgl-project/sglang/pull/23954) · **Merged:** 2026-04-30 · **Author:** @JustinTong0323

## Summary (from upstream PR description)

Motivation
Closes #23949.
sglang.bench_serving --backend sglang-oai-chat reports zero TTFT/ITL and Total generated tokens (retokenized): 0 against reasoning models even when the backend completes real work:
Total generated tokens:                  4220
Total generated tokens (retokenized):    0
Mean TTFT (ms):                          0.00
Median TTFT (ms):                        0.00
Mean ITL (ms):                           0.00
Median ITL (ms):                         0.00
Peak output token throughput (tok/s):    1.00

Root cause: async_request_openai_chat_completions only inspects delta.content. Reasoning models (DeepSeek-R1, MiMo-V2.5, Qwen3 reasoning, Kimi-K2, …) stream their chain-of-thought via delta.reasoning_content, leaving generated_text / text_chunks empty and TTFT / ITL stuck at their default zeros. The headline numbers look like valid benchmark data but are placeholder zeros — easy to copy into docs by mistake.
Modifications
