# [AMD] Support AMD MXFP4 Qwen3.5-397B-A17B model

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21234](https://github.com/sgl-project/sglang/pull/21234) · **Merged:** 2026-03-30 · **Author:** @hubertlu-tw

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Motivation
Enable and validate Qwen3.5 MXFP4 model support on AMD GPUs
This PR aims to preserve acceptable accuracy while improving serving performance versus the FP8 baseline.
Modifications

Added SGLang changes to support amd/Qwen3.5-397B-A17B-MXFP4 inference on AMD GPUs.


Server command: FP8 baseline
SGLANG_USE_AITER=1 python3 -m sglang.launch_server \
  --model-path Qwen/Qwen3.5-397B-A17B-FP8 \
  --tp 4 \
  --attention-backend aiter \
  --trust-remote-code \
  --model-loader-extra-config '{"enable_multithread_load": true}' \
  --watchdog-timeout 1200 \
  --mem-fraction-static 0.9 \
  --host 0.0.0.0 --port 9000


Server command: MXFP4 model
SGLANG_USE_AITER=1 python3 -m sglang.launch_server \
  --model-path amd/Qwen3.5-397B-A17B-MXFP4 \
  --tp 4 \
  --attention-backend aiter \
  --trust-remote-code \
  --model-loader-extra-config '{"enable_multithread_load": true}' \
  --watchdog-timeout 1200 \
  --mem-fraction-static 0.9 \
  --host 0.0.0.0 --port 9000
