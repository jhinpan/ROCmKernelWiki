# [MUSA] apply_vocab_mask support musa device

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21296](https://github.com/sgl-project/sglang/pull/21296) · **Merged:** 2026-03-26 · **Author:** @froststeam

## Summary (from upstream PR description)

Motivation
The xgrammar backend currently supports several hardware accelerators, including CUDA, NPU, and XPU, for constrained decoding. This pull request adds support for Moore Threads (MUSA) devices to enable efficient constrained decoding features using the xgrammar backend on MUSA hardware.
Modifications

Updated the device check logic in xgrammar_backend.py to include musa as a supported device type.
This change ensures that the apply_vocab_mask method correctly identifies MUSA devices and proceeds to apply the token bitmask using the available triton kernels, allowing constrained decoding to function on Moore Threads GPUs.
