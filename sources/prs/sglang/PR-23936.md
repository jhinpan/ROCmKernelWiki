# mimo v2.5 pro sglang-jax cookbook

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23936](https://github.com/sgl-project/sglang/pull/23936) · **Merged:** 2026-04-29 · **Author:** @JamesBrianD

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Motivation
Add a TPU deployment recipe for MiMo-V2.5-Pro to the cookbook, served via sgl-jax. This documents the verified v7x (16 chips / 4 nodes) and v6e (64 chips / 16 nodes) topologies and lets users generate the launch command from the existing variant/hardware panel instead of copy-pasting from a separate sglang-jax doc.
Modifications

docs_new/cookbook/autoregressive/Xiaomi/MiMo-V2.5.mdx: add 3.3 TPU Deployment with the verified topology table, port requirements, and the JAX TPU container + sgl-jax install steps. Launch commands and tuning flags are produced by the panel above, so this section stays short.
docs_new/src/snippets/autoregressive/mimo-v25-deployment.jsx: extend the deployment panel with two new hardware options (TPU v7x, TPU v6e). On TPU the generator switches to  python -m sgl_jax.launch_server, forces modelVariant=Pro and EP=on, disables EAGLE MTP / DeepEP (CUDA-only), and emits per-recipe values (mem-frac 0.95/0.92, swa ratio 0.25/0.15, attention backend, page-size 256, --disable-radix-cache, etc.). DP attention and the Reasoning / Tool Call parsers remain user-toggleable.
