# [SMG] Expand K8s integration tests: cross-namespace, lifecycle, multi-model

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#24375](https://github.com/sgl-project/sglang/pull/24375) · **Merged:** 2026-05-14 · **Author:** @Kangyan-Zhou

## Summary (from upstream PR description)

Summary
Builds on the K8s integration test scaffolding from #24278 with five new tests covering service-discovery paths the original suite didn't reach.

test_cross_namespace.py — cluster-wide watch via ClusterRole + no --service-discovery-namespace. Validates that pods in two distinct namespaces are both registered, asserting per-pod IP membership (not just count) so the test actually proves the cluster-wide path rather than coincidentally landing 2 pods.
test_lifecycle.py — three lifecycle scenarios:

Gateway pod restart: kill the gateway, verify the new pod re-lists existing workers without duplicates AND that the post-restart watch loop picks up a freshly-deployed worker (proves it isn't relist-only).
Pod IP change: force-delete + recreate same pod name, verify the registry switches to the new IP and drops the old URL. Skips on the rare CNI-IP-reuse case rather than silently false-passing.
Graceful drain: verify deregistration fires on the deletionTimestamp event well before the grace period elapses (elapsed < grace_secs), with a still_exists guard so a slow CI run doesn't lucky-pass through pod-gone reconciliation. Asserts on URL membership rather than total count to tolerate
