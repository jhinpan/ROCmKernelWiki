# Cache gfx95 quant format detection in DeepseekV2DecoderLayer

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22143](https://github.com/sgl-project/sglang/pull/22143) · **Merged:** 2026-04-06 · **Author:** @merrymercy

**Inclusion reason:** keyword 'fp8'

## Summary (from upstream PR description)

Summary

Extract the repeated quant_format detection logic from forward() into a dedicated _detect_gfx95_quant_format() method
Cache the result so it is computed once instead of on every forward call
On non-gfx95 platforms, the value is set to empty string immediately in init with zero runtime overhead
On gfx95, it is lazily computed on the first forward call (after weights are loaded) and cached

Test plan

 Verify no regression on gfx95 AMD GPUs with mxfp4/fp8 quantized models
 Verify no regression on non-gfx95 platforms (CUDA, CPU)
