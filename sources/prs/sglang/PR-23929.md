## Summary (from upstream PR description)

Motivation
This patch is to enable sdma path for moriep through env MORI_ENABLE_SDMA.
cc @Duyi-Wang @HaiShaw

Modifications

Added enable_sdma parameter to init_mori_op(), which activates MoRI's low-latency mode when SDMA is enabled.
Added MORI_ENABLE_SDMA env var (default false) in _MoriEPDispatcherImplBase to toggle the SDMA path at runtime.
In _MoriEPDispatcherImplNormal, when SDMA is enabled:

Dispatch: calls dispatch_send() + dispatch_recv() (split send/recv) instead of the fused dispatch().
Combine: calls combine_send() + combine_recv() instead of the fused combine().
