# [AMD][bugfix] add gate rocm >= 7.2 for bpreshuffle

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23671](https://github.com/sgl-project/sglang/pull/23671) · **Merged:** 2026-04-24 · **Author:** @RolaoDenthu

**Inclusion reason:** kernel path 'python/sglang/srt/layers/quantization/fp8.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
gemm_a8w8_blockscale_bpreshuffle (added for gfx95 in #23319) is miscompiled by the ROCm 7.0 hipcc, which drops GLM-5.1 FP8 accuracy on MI35x in the rocm700-0423 nightly docker. ROCm 7.2 is fine.
Modifications

Add get_hip_version() in srt/utils/common.py
Gate the bpreshuffle path on get_hip_version() >= (7, 2, 0) in fp8_utils.py (aiter_w8a8_block_fp8_linear) and fp8.py
(Fp8LinearMethod.process_weights_after_loading). ROCm < 7.2 gfx95 falls back to the tuned Triton GEMM that was used before #23319.
