Motivation
Migrate and consolidate the SGLang documentation from the separate sgl-docs and sgl-cookbook repositories into the main sglang repo under docs_new/. This provides a single source of truth for all SGLang documentation, powered by Mintlify, and simplifies the maintenance workflow by eliminating cross-repo syncing.
Modifications

Add docs_new/ directory containing the full Mintlify-based documentation site (319 files, ~97k lines)
Getting Started: Introduction, installation, quickstart guides
