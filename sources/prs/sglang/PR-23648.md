# [diffusion] model: Fix FLUX.1/2 graph breaks

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23648](https://github.com/sgl-project/sglang/pull/23648) · **Merged:** 2026-04-25 · **Author:** @avjves

**Inclusion reason:** keyword 'flash'

## Summary (from upstream PR description)

Motivation

Currently two graph breaks significantly reduce the performance of at least FLUX.1 and also somewhat FLUX.2. Other models might be affected as well, but are not tested. This PR fixes the the two graph breaks without changing the model behavior.
Modifications


In case where FlashInfer is not installed (Non-NV HW at least), a warning caused a critical graph break. This log is separated to a torch.compile compatible function.
current_platform.is_amp_supported() check itself causes a graph break due to the lru_cache. Rather than checking this during compile, it's now checked at startup.
