# Reduce unnecessary kernels and copies in the NSA indexer

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22232](https://github.com/sgl-project/sglang/pull/22232) · **Merged:** 2026-04-07 · **Author:** @1am9trash

**Inclusion reason:** kernel path 'python/sglang/srt/layers/attention/nsa/nsa_indexer.py'; keyword 'gemm'

## Summary (from upstream PR description)

cc @Jacob0226
Motivation

The NSA indexer currently launches several unnecessary kernels:

_project_and_scale_head_gates and _get_logits_head_gate use multiple element-wise kernels.
Query/key updates force clone() to avoid self-aliasing errors, which introduces extra copy kernels.

Modifications


Enabled torch.compile on HIP for _project_and_scale_head_gates and _get_logits_head_gate.

The element-wise kernels are now fused into triton_poi_fused__to_copy_gemm_a16w16_0.
This change affects the AMD path only.


Added helper _update_rope_guarded to avoid redundant rope update.

If the previous kernel already performed the update in-place, skip the extra update.
This change affects both AMD/NV path.
