# [ROCM][RL] Shuffle Weight In-Place to Preserve Parameter Attributes

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21825](https://github.com/sgl-project/sglang/pull/21825) · **Merged:** 2026-04-03 · **Author:** @zyzshishui

**Inclusion reason:** keyword 'quant'

## Summary (from upstream PR description)

Motivation
Several ROCm/aiter post-processing paths were replacing existing weight objects with newly constructed ones after shuffle_weight(...). That drops custom attributes attached to the original parameters, such as weight_loader, and breaks RL workflows that call load_weights() again after model initialization.
AttributeError: 'Parameter' object has no attribute 'weight_loader'

Modifications
Switche those paths to in-place .data updates to make original Parameter objects and their custom attributes remain intact.
