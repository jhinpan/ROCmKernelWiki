**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21524](https://github.com/sgl-project/sglang/pull/21524) · **Merged:** 2026-04-03 · **Author:** @michaelzhang-ai

## Summary (from upstream PR description)

Summary

Add bench_one_batch performance benchmark tests for MiniMax-M2.5 (TP=8, EP=8, aiter backend) on both MI30x and MI35x
Perf steps run after the existing accuracy tests in the same CI job, following the established combined accuracy+perf pattern (Grok1-INT4, Grok2, DeepSeek-V3, etc.)
If accuracy fails, perf is skipped; if accuracy passes but perf fails, job still passes (continue-on-error: true)
Covers both default ROCm and ROCm 7.2 nightly workflows
