# [perf] prepare_prefill_qkv hook + fp8 quantize jit kernel

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#25460](https://github.com/sgl-project/sglang/pull/25460) · **Merged:** 2026-05-20 · **Author:** @Qiaolin-Yu

**Inclusion reason:** kernel path 'python/sglang/jit_kernel/fp8_quantize.py'; keyword 'attention'

## Summary (from upstream PR description)

Adds a model-side prepare_prefill_qkv extension point on the MLA attention backends so backends can quantize/pack/rope Q/K/V before the prefill kernel call, and ships a tokenspeed_mla-side fp8 quantize jit kernel as one such producer:

python/sglang/jit_kernel/fp8_quantize.py (new) — fp8 e4m3 quantize helper used by the new prepare path.
python/sglang/srt/layers/attention/tokenspeed_mla_backend.py — prepare_prefill_qkv path that lands FP8-quantized Q/K/V into the tokenspeed_mla prefill kernel (BF16 Q/K/V → FP8 single shot, no model-side staging).
python/sglang/srt/models/deepseek_common/attention_forward_methods/ forward_mha.py — call backend.prepare_prefill_qkv(...) when the active attention backend exposes it; otherwise fall through to the existing path.
