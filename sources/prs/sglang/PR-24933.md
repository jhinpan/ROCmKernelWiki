Co-authored-by: @1am9trash @RolaoDenthu @yichiche @hubertlu-tw @sogalin @HaiShaw @yctseng0211 @bingxche @amd-danli103 @Raiden-Makoto
Motivation
Enable deepseek v4 model support (merge to main) to ROCm platform.
This is a first PR to add ROCm deepseek v4 model support on SGLang main.
After this PR merged, we can run the v4 flash/pro model on MI35x in eager mode. Then will have subsequent PRs to merge remaining DSv4 optimizations from amd/deepseek_v4 branch.
Some following tasks is under cooking, included

https://github.com/sgl-project/sglang/tree/amd/deepseek_v4 migration into the main. This branch includes the most optimization work before.
Compression flow fusion
Multiple stream enablement

Modifications

Use is_hip, use_aiter flag to scope the path of ROCm
Some deepseek v4 jit fused kernels not support on ROCm, replace them with triton kernels implementation
Add hip attention backend for dsv4 attention hadling

Accuracy Tests

export SGLANG_OPT_USE_FUSED_HASH_TOPK=false
