# [AMD] Use tgemm.mm for MoEGate router gemm in deepseek_v2.py

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21657](https://github.com/sgl-project/sglang/pull/21657) · **Merged:** 2026-03-31 · **Author:** @1am9trash

**Inclusion reason:** kernel path 'python/sglang/srt/layers/rocm_linear_utils.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation

When running the GLM-5-fp8 model, the MoEGate router GEMM is a major bottleneck, taking about ~30% of a single layer's time.
Modifications

Following the ATOM approach, this change switches MoEGate router GEMM to use aiter.tuned_gemm dispatcher (tgemm.mm) so kernel selection is done automatically.
Accuracy Tests

GLM and DeepSeek models share the same code path here, so both were validated.
