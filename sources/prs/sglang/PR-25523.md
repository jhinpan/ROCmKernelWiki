# [Diffusion] Default NVFP4 backend to FlashInfer TRTLLM

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#25523](https://github.com/sgl-project/sglang/pull/25523) · **Merged:** 2026-05-25 · **Author:** @BBuf

## Summary (from upstream PR description)

Summary

This PR follows #25857 (49be0c617f9b6fafc9b742d022ded04dbc565295), which is now merged into main at ccbbae00eaeaff7f7c5cf3ded5877831f0db8239; current PR head is 26ef8b15a2ff8f4673488c8e339f92b2c0240368.
The conflict resolution rebased only this PR's single commit on top of latest main, so #25857's changes are not replayed or duplicated.
Keep #25857's Wan2.2 NVIDIA FP8/NVFP4 checkpoint reland, then make diffusion ModelOpt NVFP4 default to FlashInfer TensorRT-LLM FP4 GEMM (flashinfer_trtllm) when SGLANG_DIFFUSION_FLASHINFER_FP4_GEMM_BACKEND is unset.
Keep sgl_kernel.cutlass_scaled_fp4_mm as the fallback only when flashinfer.mm_fp4 is unavailable, and keep checkpoint weight-scale layout tracking for NVFP4.

NVFP4 Validation
Generated on ion-b200 (innomatrix-us-adc-smb200-0003) with one NVIDIA B200 GPU and the SGLang native diffusion backend. Baseline rows use #25857 with explicit backend envs (cudnn for FLUX, trtllm for Wan2.2). PR rows leave SGLANG_DIFFUSION_FLASHINFER_FP4_GEMM_BACKEND unset, so they exercise this PR's default backend.
