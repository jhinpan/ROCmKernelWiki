# [AMD] Fix test_kimi_k25_mxfp4.py : stage-c-test-large-8-gpu-amd-mi35x (linux-mi35x-gpu-8, 1)

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22188](https://github.com/sgl-project/sglang/pull/22188) · **Merged:** 2026-04-07 · **Author:** @yctseng0211

## Summary (from upstream PR description)

Motivation
Pin amd/Kimi-K2.5-MXFP4 model revision in test_kimi_k25_mxfp4.py to fix CI weight loading failure.
The HuggingFace model was updated (commit 94d8c1bd) to quantize additional layers and changed its exclude list format from regex to explicit per-layer names, which exposed a prefix mismatch in KimiK25ForConditionalGeneration causing AssertionError during weight loading. Pinning to the last known-good revision (b071bc6f) avoids the issue while a proper fix is prepared in a follow-up PR.
Modifications

Add --revision b071bc6f8eb042e093e14f3b8bdbad71c18e09d3 to the test server launch args
This ensures CI always uses a consistent model snapshot unaffected by upstream HF model updates

Root Cause (for follow-up)
The new model's explicit exclude list entries (e.g. language_model.model.layers.0.self_attn.kv_a_proj_with_mqa) do not match SGLang's internal layer prefixes (model.layers.0.self_attn...) due to prefix="" in KimiK25ForConditionalGeneration. Additionally, the fused layer fused_qkv_a_proj_with_mqa cannot be resolved to its shards without packed_modules_mapping. These will be addressed in a separate PR.
