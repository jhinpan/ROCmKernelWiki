# Migrate all callers from /get_server_info to /server_info

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21463](https://github.com/sgl-project/sglang/pull/21463) · **Merged:** 2026-04-02 · **Author:** @sawsa307

**Inclusion reason:** kernel path 'test/registered/attention/test_hybrid_attn_backend.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
Fix #21054.
The /server_info endpoint was introduced as the canonical replacement for /get_server_info. The server-side deprecation wrapper (with warning log) is already in place. This PR migrates all remaining callers to use /server_info.
Modifications

Update all client-side HTTP calls from /get_server_info to /server_info across:

Python SDK (runtime_endpoint.py)
Benchmarking scripts (bench_serving.py, bench_one_batch_server_internal.py, bench_speculative.py)
Profiler (profiler.py)
Test utilities (kl_test_utils.py, nightly_utils.py, cache_hit_kit.py)
All registered test files (spec decoding, MLA, EP, DP, HiCache, quantization, AMD, Ascend)


Update sgl-model-gateway:

Add /server_info route alias in server.rs and mini_lb.py (keeping /get_server_info for one release-cycle deprecation window)
Update internal gateway calls to use /server_info (pd_router.rs, router.rs)
Update mock workers and test assertions to use /server_info


Update documentation (server_arguments.md, sgl_model_gateway.md, native_api.ipynb, bench_serving.md)
Add TODO comments for subsequent removal of /get_server_info aliases

 Format your code according to the Format code with pre-commit.
