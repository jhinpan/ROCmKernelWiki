## Summary (from upstream PR description)

Summary

Use the existing JIT kernels for clamp_position and _resolve_future_token_ids when running on AMD/ROCm (is_hip()), instead of torch.compile fallbacks.
Extend TensorMatcher device options to kDLCUDA, kDLROCM in clamp_position.cuh and resolve_future_token_ids.cuh (consistent with kvcache.cuh).

Context
load_jit already compiles these sources with HIP when torch.version.hip is set; SRT previously only wired the Python entry points for NVIDIA.
Test plan

 CI / local: pytest python/sglang/jit_kernel/tests/test_clamp_position.py python/sglang/jit_kernel/tests/test_resolve_future_token_ids.py on CUDA or ROCm if available.
