# [Bugfix] Fix incorrect dp-attention parallel info in bench_one_batch

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21519](https://github.com/sgl-project/sglang/pull/21519) · **Merged:** 2026-04-03 · **Author:** @lviy

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Motivation
bench_one_batch is intended for low-level profiling, but when DP-Attention is enabled it does not pass the correct
attention parallel metadata into prepare_mlp_sync_batch_raw(). In particular, attn_tp_size is hardcoded to 1 and
attn_cp_size is not forwarded, which makes the DP-Attention preparation path inconsistent with the normal scheduler
path.
This becomes visible when profiling models with DP-Attention enabled, for example:
python3 -m sglang.bench_one_batch \ --model-path /gfs/space/chatrl/public/models/ZhipuAI/GLM-4.7-Flash-0309 \ --tp-size 8 --dp-size 8 --enable-dp-attention \ --enable-dp-lm-head \ --max-running-requests 256 \ --batch-size 32 --input-len 1024 --output-len 64 \ --profile --profile-activities CUDA_PROFILER --profile-stage decode
This PR updates _maybe_prepare_mlp_sync_batch to pass correct DP-Attention metadata. With this change, bench_one_batch could correctly run with enabling dp-attention.
