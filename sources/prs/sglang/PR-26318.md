# [diffusion][jit_kernel] perf: varlen FA fast path for USPAttention masked branch

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#26318](https://github.com/sgl-project/sglang/pull/26318) · **Merged:** 2026-05-28 · **Author:** @mispa-ms

**Inclusion reason:** kernel path 'python/sglang/jit_kernel/diffusion/triton/varlen_pack_pad.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
When attn_mask is supplied to USPAttention.forward (joint self-attention with text + image streams of differing valid lengths, e.g. Qwen-Image), PyTorch SDPA cannot use FlashAttention with a non-None mask and falls back to the EFFICIENT (fmha_cutlassF_*_sm80) kernel. On Blackwell (B200, SM 10.0) this SM80 path is ~7× slower per call than the native FA4 (flash_fwd_sm100) path, dominating the denoise loop.
This PR replaces the SDPA-with-mask path with flash_attn_varlen_func after packing Q/K/V at valid positions via a fused Triton kernel pair, plus a per-request precompute hook so the cu_seqlens / indices metadata is built once and reused by every block.
Approach
build_varlen_mask_meta(mask)            # once per request, in pipeline
  → joint_attention_kwargs["attn_mask_meta"]
    → USPAttention.forward
        if mask path eligible (bool/int 2D mask, matching Q/K/V):
            fused_pack_qkv(Q, K, V, indices)         # 1 Triton launch
            flash_attn_varlen_func(...)               # FA4 / FA3
            fused_scatter_to_padded(out, inv_idx)    # 1 Triton launch
        else (no meta or all-False mask):
            fall back to SDPA (unchanged)
