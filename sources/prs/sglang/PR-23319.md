# [AMD] Use bpreshuffle FP8 blockscale GEMM to replace ABScale GEMM

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#23319](https://github.com/sgl-project/sglang/pull/23319) · **Merged:** 2026-04-23 · **Author:** @RolaoDenthu

**Inclusion reason:** kernel path 'python/sglang/srt/layers/quantization/fp8.py'; keyword 'gemm'

## Summary (from upstream PR description)

Motivation
AITER's gemm_a8w8_blockscale_bpreshuffle is a faster FP8 block-scaled GEMM that requires preshuffled weights. By preshuffling once at load time, we pay the layout cost upfront and speed up every forward pass.
This PR wires up the preshuffled kernel as the FP8 block-scale path on AMD, yielding +8–11% throughput and −8 to −10% TPOT on MI355X
Modifications

fp8_utils.py: route aiter_w8a8_block_fp8_linear to gemm_a8w8_blockscale_bpreshuffle, and convert x_scale into the layout it expects.
fp8.py: in process_weights_after_loading, run shuffle_weight(w, (16, 16)) once after loading so forward doesn't re-shuffle every call.
