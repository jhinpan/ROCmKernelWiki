# Add runai-model-streamer into Python packages installed in Dockerfile and fix NotADirectoryError Docker regression

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22537](https://github.com/sgl-project/sglang/pull/22537) · **Merged:** 2026-04-14 · **Author:** @amacaskill

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Motivation
Currently, when using --load-format=runai_streamer to load a model from Google Cloud Storage (gs://...) using the official SGLang Docker image, the server crashes with the following error:
  File "/usr/local/lib/python3.12/dist-packages/runai_model_streamer/s3_utils/s3_utils.py", line 137, in gcs_pull_files
    raise ImportError("GCS files module not found. Please install the required package.")
ImportError: GCS files module not found. Please install the required package.
This happens because the runai-model-streamer package recently separated its cloud provider dependencies into extras. To natively support GCS (and Azure) out of the box, these dependencies need to be explicitly requested during the image build process.
Modifications
Updated docker/Dockerfile to install "runai-model-streamer[s3,gcs,azure]>=0.15.7", ensuring all necessary cloud provider dependencies are baked into the image. This PR also fixes a regression that was introduced in PR #22160.
Regression
I am struggling to build image before or after this PR because I believe PR #22160 caused a regression. I can successfully start up inference server with the inference-server yaml below with image lmsysorg/sg
