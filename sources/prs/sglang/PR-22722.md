# [AMD] Add MiniMax-M2.7 accuracy and performance nightly tests

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22722](https://github.com/sgl-project/sglang/pull/22722) · **Merged:** 2026-04-14 · **Author:** @michaelzhang-ai

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Summary

Add MiniMax-M2.7 (https://huggingface.co/MiniMaxAI/MiniMax-M2.7) accuracy (GSM8K 5-shot) and performance (bench_one_batch) nightly CI tests for AMD MI30x (MI325/MI300X)
MiniMax-M2.7 shares the same MiniMaxM2ForCausalLM architecture as M2.5 with identical MoE config (256 experts, 8 active), using TP8+EP8 server configuration with aiter attention backend
Replace M2.5 nightly CI jobs with M2.7 on MI30x (M2.5 test files kept in repo, just not run in nightly)
MI35x test files created but not wired to nightly jobs yet (pending more MI35x runners)
Fix broken import in minimax_m2.py: get_bool_env_var was imported from sglang.srt.distributed but is defined in sglang.srt.utils.common (introduced by #20673, breaks all MiniMax M2 models on current main — M2.5 also fails)
