# [XPU] Add registry mechanism for XPU CI tests

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#25405](https://github.com/sgl-project/sglang/pull/25405) · **Merged:** 2026-05-27 · **Author:** @vshekhawat-hlab

**Inclusion reason:** kernel path 'python/sglang/test/ci/ci_register.py'; keyword 'attention'

## Summary (from upstream PR description)

Motivation
XPU (Intel GPU) CI uses a legacy hardcoded test list (suite_xpu dict in test/srt/run_suite.py) with a single flat job in pr-test-xpu.yml.
This PR aligns XPU CI with the AMD and Nvidia registry architecture.
Modifications
python/sglang/test/ci/ci_register.py

Add HWBackend.XPU to the enum
Add register_xpu_ci() function (identical signature to register_amd_ci)
Add "register_xpu_ci": HWBackend.XPU to REGISTER_MAPPING

test/run_suite.py

Add "xpu": HWBackend.XPU to HW_MAPPING
Add HWBackend.XPU suites to PER_COMMIT_SUITES: stage-a-test-1-gpu-xpu, stage-b-test-1-gpu-xpu
Add HWBackend.XPU to _SUITE_CHECKED_BACKENDS for suite name validation

test/srt/run_suite.py

Clear legacy suite_xpu = {} (tests now register via register_xpu_ci)

test/registered/xpu/ (moved from test/srt/xpu/)

test_intel_xpu_backend.py → register_xpu_ci(est_time=600, suite="stage-b-test-1-gpu-xpu")
test_deepseek_ocr.py → register_xpu_ci(est_time=360, suite="stage-b-test-1-gpu-xpu")
test_deepseek_ocr_triton.py → register_xpu_ci(est_time=360, suite="stage-b-test-1-gpu-xpu", disabled="Temporarily disabled until Triton-XPU upgrade") (mirrors existing @unittest.skip)
