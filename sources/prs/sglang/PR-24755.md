## Summary (from upstream PR description)

Summary

Add an architecture-aware vectorized path for large add_constant tensors: 16-byte vectors on pre-Blackwell / AMD, and 32-byte vectors on Blackwell when supported by the CUDA toolchain.
Keep the scalar kernel for small tensors and for inputs/outputs that are not aligned to the selected vector type.
Add an add_constant benchmark and extend correctness coverage for larger aligned and unaligned inputs.
