# Unify GSM8K eval path to Chat API for regression CI readiness

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#21667](https://github.com/sgl-project/sglang/pull/21667) · **Merged:** 2026-04-02 · **Author:** @hnyls2002

**Inclusion reason:** kernel path 'test/manual/ep/test_moe_deepep_eval_accuracy_large.py'; keyword 'attention'

## Summary (from upstream PR description)

Summary
Consolidate 3 separate GSM8K eval implementations into a single run_eval.py path with api="completion", enabling automatic dump_metric coverage (score, latency, output_throughput) for all NVIDIA test files. Behavior is identical to the old few_shot_gsm8k.py — same Completion API, no chat template wrapping, same thresholds.

GSM8K had 3 independent code paths doing the same thing:
