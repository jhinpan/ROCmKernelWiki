# [AMD][diffusion] Temporal-unfolded batched Conv2D for ROCm VAE decode

**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#22971](https://github.com/sgl-project/sglang/pull/22971) · **Merged:** 2026-05-08 · **Author:** @yctseng0211

**Inclusion reason:** kernel path 'python/sglang/multimodal_gen/envs.py'; keyword 'kernel'

## Summary (from upstream PR description)

Motivation
This PR adds an optional Conv3D→Conv2D transformation (mathematically equivalent) for the ROCm VAE decode path. The key idea is temporal unfolding: a 3D convolution with kernel (Kt, Kh, Kw) can be decomposed into a batched 2D convolution by unfolding the input along the temporal axis.
Usage
Controlled by two new environment variables (default off):

SGLANG_USE_ROCM_VAE_CONV2D=1 — replace CausalConv3d with batched Conv2D (same dtype)
SGLANG_USE_ROCM_VAE_CONV2D_BF16=1 — replace with BF16 compute (recommended, implies Conv2D)

Modifications

envs.py: Add SGLANG_USE_ROCM_VAE_CONV2D and SGLANG_USE_ROCM_VAE_CONV2D_BF16 env vars
rocm.py: Add _conv3d_as_batched_conv2d() and _replace_conv3d_with_conv2d() in RocmPlatform.optimize_vae(), following the same pattern as the existing AITer GroupNorm replacement
