**Repository:** [sgl-project/sglang](https://github.com/sgl-project/sglang) · **PR:** [#26383](https://github.com/sgl-project/sglang/pull/26383) · **Merged:** 2026-05-27 · **Author:** @kkHuang-amd

## Summary (from upstream PR description)

Co-authored-by: @1am9trash @RolaoDenthu @yichiche @hubertlu-tw @sogalin @HaiShaw @yctseng0211 @bingxche @amd-danli103 @Raiden-Makoto
Motivation
The long-standing draft #25552 collected 85 commits of AMD / DSV4 work over several rebases. Most of the optimization PRs it tracked (compressor opts, fused topk, sparse MLA kernels, fused compress, etc.) have already been merged into main through smaller follow-up PRs (e.g. #26208, #25251, #25878, #25977, #26014). What remains is a small but meaningful set of changes needed to:

Make DSV4 + EAGLE/MTP speculative decoding work correctly under CUDA-graph capture on ROCm. The current HIP radix backend mis-handles per-step draft out_cache_loc slicing and trips planner invariants inside init_forward_metadata_target_verify when SGLANG_PREP_IN_CUDA_GRAPH is on, leading to graph-capture failure / wrong KV slots being written during target verification.
Land the last round of ROCm performance wins for DSV4 decode/extend that did not make it into the previously merged sub-PRs:

Fused Triton mhc_post_pre for low concurrency (enabled behind SGLANG_OPT_USE_TRITON_FUSED_MHC).
aiter.greedy_sample fast path for all-greedy sampling on ROCm.
Enable w_qkv fu
