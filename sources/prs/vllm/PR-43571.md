# [BugFix][Platform] Fix import vllm.platforms.rocm error on non-CUDA test_gpt_oss.py

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#43571](https://github.com/vllm-project/vllm/pull/43571) · **Merged:** 2026-05-30 · **Author:** @Liangliang-Ma

**Inclusion reason:** keyword 'gfx950'

## Summary (from upstream PR description)

vllm/platforms/rocm.py calls torch.cuda.get_device_properties("cuda").gcnArchName
at import time. On XPU/CPU torch builds this raises
AssertionError: Torch not compiled with CUDA enabled, breaking any
import vllm.platforms.rocm — e.g. pytest collection of
tests/models/quantization/test_gpt_oss.py (which does
from vllm.platforms.rocm import on_gfx950).
Fix: wrap the fallback in try/except, return "" on failure.
Empty arch → all _ON_GFX* flags False, which is correct on non-AMD boxes.
NVIDIA already returned "" here; ROCm path unchanged.
Test
