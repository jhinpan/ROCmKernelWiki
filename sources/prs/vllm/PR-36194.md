# Replace shape_invariants with simpler apprach in dynamic_arg_dims utilizing shape_id property.

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#36194](https://github.com/vllm-project/vllm/pull/36194) · **Merged:** 2026-04-29 · **Author:** @laithsakka

**Inclusion reason:** keyword 'rope'

## Summary (from upstream PR description)

Purpose
Add support for specifying shape relationships in dynamic_arg_dims and  utilize shape_id parameter in mark_unbacked to establish the relationship instead of using shape_invariants.
Instead of:
def qwen_2_model_invariants(
    input_ids: torch.Tensor,
    positions: torch.Tensor,
    intermediate_tensors: IntermediateTensors | None = None,
    inputs_embeds: torch.Tensor | None = None,
):
    torch._check(input_ids.size()[0] == positions.size()[-1])
    if intermediate_tensors is not None:
        torch._check(
            input_ids.size()[0] == intermediate_tensors["hidden_states"].size()[0]
        )
    ....

@support_torch_compile(
    dynamic_arg_dims={
        "input_ids": 0,
        "positions": -1,
        "intermediate_tensors": 0,
        "inputs_embeds": 0,
    },
    shape_invariants=qwen_2_model_invariants,
)

We do:
@support_torch_compile(
    dynamic_arg_dims={
        "input_ids": {0: "b"},
        "positions": {-1: "b"},
        "intermediate_tensors": {0: "b"},
        "inputs_embeds": {0: "b"},
    }
)

All dims with same name "b" will use the same symbol.
