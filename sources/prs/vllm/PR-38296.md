# [ROCm] aiter_unified_attn fp8 q scale refactor

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#38296](https://github.com/vllm-project/vllm/pull/38296) · **Merged:** 2026-05-06 · **Author:** @divakar-amd

## Summary (from upstream PR description)

(To be merged after ROCm/aiter#2360 - aiter PR cleans up fp8 attention & adds native support for q scale)
The absorption logic for fp8xfp8 attention computation introduced in #36927 can now be natively handled by the aiter kernel.

The aiter kernel now has support for q_scale
We would no longer need to absorb  layer._q_scale_float * layer._k_scale_float in softmax_scale
Instead of using post multplication of out scale after the kernel, let the kernel handle it. (Need to follow-up on fp8 clamping)
