**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#36263](https://github.com/vllm-project/vllm/pull/36263) · **Merged:** 2026-03-09 · **Author:** @cong-or

## Summary (from upstream PR description)

Summary
Extracts KV-cache update from FlexAttention, one of the last backends still doing it inline. Part of #32335.
What this does
FlexAttention was still calling reshape_and_cache_flash inside forward(). This PR pulls it out into do_kv_cache_update() and sets the flag to False, same as FlashAttn, FlashInfer,
Triton, and the ROCm backends already do.
Test plan

tests/v1/attention/test_attention_backends.py already handles the split path based on the flag
tests/kernels/test_flex_attention.py compares FlexAttention output against the default backend
