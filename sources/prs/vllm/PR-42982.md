Changes
(1) Router bf16 dispatch — vllm/model_executor/models/deepseek_v2.py
Eliminate bfloat16tofloat32_copy_kernel_cuda (58 launches/step on DSv3.2 TP4) on the ROCm AITER MoE routing path. The cast exists only because vLLM was asking the gate to emit fp32 router logits, while AITER's biased_grouped_topk kernel dispatches over VLLM_DISPATCH_FLOATING_TYPES and accepts bf16 directly (it promotes to fp32 internally during accumulation).
# Before
self.gate.set_out_dtype(torch.float32)
# After
self.gate.set_out_dtype(self.gate.weight.dtype)   # bf16
The existing post-init cast at lines 358–362 then casts e_score_correction_bias from fp32 to bf16 at startup, satisfying the AITER kernel's same-scalar_t contract.
(2) Sparse-MLA metadata cache — vllm/v1/attention/backends/mla/rocm_aiter_mla_sparse.py
