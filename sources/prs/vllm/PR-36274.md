# [Bugfix][ROCm] Strip block_size before attention backend validation

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#36274](https://github.com/vllm-project/vllm/pull/36274) · **Merged:** 2026-03-11 · **Author:** @jennyyyyzhen

**Inclusion reason:** keyword 'attention'

## Summary (from upstream PR description)

Purpose
The ROCm attention backend refactor (#35246) introduced validate_configuration calls that reject irregular block_size because it is not in the BlockSize type (1, 8, 16, 32, 64, 128, 256). The CUDA platform avoids this by stripping block_size before validation. Apply the same fix to the ROCm platform.
