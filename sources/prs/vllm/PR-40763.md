## Summary (from upstream PR description)

AITER MLA implementation requires num_heads>=16. Add padding when necessary for both regular MLA and sparse MLA;
An AITER bug will cause divided_by_zero error when num_heads is too small. Set it to num_heads to circumvent, and will remove it when corresponding AITER PR gets merged.
