# [Model Refactoring] Remove torch compile dependency in DSv4

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#43746](https://github.com/vllm-project/vllm/pull/43746) · **Merged:** 2026-05-28 · **Author:** @WoosukKwon

## Summary (from upstream PR description)

This PR removes the torch compile dependency in the DS V4 model. It uses the breakable CUDA graph #42304 to support PW CUDA graph without torch compile.
