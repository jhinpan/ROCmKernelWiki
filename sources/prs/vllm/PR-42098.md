## Summary (from upstream PR description)

Aligns hidden_pad / intermediate_pad passed into the ROCm Aiter fused MoE path with the padding convention expected by the kernel stack, matching the logic discussed in vllm#34301. On GPT-OSS-120B (openai/gpt-oss-120b) with tensor parallel size 1 and vLLM on MI355X, this improves throughput per GPU across InferenceX shapes and concurrency levels, with ~8% geomean speedup vs baseline.
