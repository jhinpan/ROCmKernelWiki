# [Deprecation] Mark env vars covered by --moe-backend / --linear-backend

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#43148](https://github.com/vllm-project/vllm/pull/43148) · **Merged:** 2026-05-21 · **Author:** @mgoin

**Inclusion reason:** kernel path 'vllm/envs.py'; keyword 'gemm'

## Summary (from upstream PR description)

Summary
Centralizes deprecation notices in vllm/envs.py via a new deprecated_env helper that wraps a getter and emits a FutureWarning (visible to end users by default — addressing the gemini-code-assist review on the first iteration) on first read when the var is explicitly set in the environment. Removal target v0.23.
Deprecated env vars
MoE side — covered by --moe-backend (#33807) and --quantization_config.moe.activation (#41566):



Env var
Replacement




VLLM_USE_FLASHINFER_MOE_FP8
--moe-backend flashinfer_trtllm / flashinfer_cutlass


VLLM_USE_FLASHINFER_MOE_FP4
--moe-backend flashinfer_{trtllm,cutlass,cutedsl}


VLLM_USE_FLASHINFER_MOE_FP16
--moe-backend flashinfer_trtllm / flashinfer_cutlass


VLLM_FLASHINFER_MOE_BACKEND
Pass --moe-backend flashinfer_{trtllm,cutlass,cutedsl} directly


VLLM_USE_FLASHINFER_MOE_MXFP4_BF16
--moe-backend flashinfer_trtllm / flashinfer_cutlass


VLLM_USE_FLASHINFER_MOE_MXFP4_MXFP8
--moe-backend flashinfer_trtllm + --quantization_config.moe.activation mxfp8


VLLM_USE_FLASHINFER_MOE_MXFP4_MXFP8_CUTLASS
--moe-backend flashinfer_cutlass + --quantization_config.moe.activation mxfp8


VLLM_MXFP4_USE_MARLIN
--moe-backend marlin / --linear-backend marl
