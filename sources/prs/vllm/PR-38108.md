# Fix Device Index for ROCm Ray Workers in MoE Benchmark

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#38108](https://github.com/vllm-project/vllm/pull/38108) · **Merged:** 2026-03-28 · **Author:** @li-liwen

**Inclusion reason:** kernel path 'benchmarks/kernels/benchmark_moe.py'; keyword 'moe'

## Summary (from upstream PR description)

Purpose
Single-line fix torch.AcceleratorError: CUDA error: invalid device ordinal when running benchmarks/kernels/benchmark_moe.py --tune on ROCm (AMD GPU) systems with Ray.
Test Plan
Run the MoE autotuner on a multi-GPU AMD system:
python benchmarks/kernels/benchmark_moe.py \
  --model <any-MoE-model> \
  --tp-size <num-gpus> \
  --trust-remote-code \
  --tune \
  --save-dir ./
Before fix: crashes immediately with torch.AcceleratorError: CUDA error: invalid device ordinal on every Ray worker.
After fix: all workers run successfully and produce tuned config JSON.
Test Result
Tested on 8× AMD Instinct MI100 (gfx908), ROCm 7.2, vLLM v0.18.0 built from source, tuning MiniMax-M2.5-AWQ (E=256 MoE).
Before the fix:
$ python benchmarks/kernels/benchmark_moe.py \
    --model MiniMax-M2.5-AWQ --tp-size 8 --trust-remote-code --tune --save-dir ./
