# [ROCM][Bugfix] Use correct stride in cp_mha_gather_cache_kernel for hybrid model (#37228)

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#37228](https://github.com/vllm-project/vllm/pull/37228) · **Merged:** 2026-03-26 · **Author:** @jennyyyyzhen

**Inclusion reason:** kernel path 'vllm/v1/attention/backends/rocm_aiter_fa.py'; keyword 'attention'

## Summary (from upstream PR description)

Problem
_update_hybrid_attention_mamba_layout uses as_strided_() to reorder KV blocks into a interleaved pattern. But cp_mha_gather_cache_kernel Triton kernel used hardcoded pointer arithmetic assuming contiguous memory. For hybrid models, this reads from wrong memory locations, producing garbage values and NaN in attention outputs.
Memory layout
Original Assumption: [K_all][V_all]
Hybrid model: [K_0][V_0][K_1][V_1] ...
Fix
passed correct kernel stride to triton kernel.

Currently, shuffle KV path also have the same issue. Need to fix it if it's needed for hybrid model
