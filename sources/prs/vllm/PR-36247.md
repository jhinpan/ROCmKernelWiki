# [Bugfix] Fix compressed-tensors quantization failure for DeepSeek-R1 on MI300x

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#36247](https://github.com/vllm-project/vllm/pull/36247) · **Merged:** 2026-03-07 · **Author:** @vllmellm

**Inclusion reason:** keyword 'fp8'

## Summary (from upstream PR description)

Purpose
When running DeepSeek-R1 FP8 on MI300x, vLLM crashed during model initialization with:
ValueError: Unable to find matching target for model.layers.0.self_attn.fused_qkv_a_proj in the compressed-tensors config.

The compressed-tensors quantization config matches layers by checking if a target string (e.g. "Linear") is a substring of the module's class name.
Because DeepSeekV2FusedQkvAProj doesn't contain "Linear", all three matching steps in find_matched_target failed. Renaming the class to DeepSeekV2FusedQkvAProjLinear fixes the substring match.
