# [Bugfix]Fix EP precision for Qwen3.5, Qwen3-Next

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#39181](https://github.com/vllm-project/vllm/pull/39181) · **Merged:** 2026-04-08 · **Author:** @USTCKAY

**Inclusion reason:** kernel path 'vllm/model_executor/models/qwen2_moe.py'; keyword 'flash'

## Summary (from upstream PR description)

Purpose
Do not shard shared experts weights when sequence parallel is enabled to fix precision issue for Qwen3.5/Qwen3-Next with EP. At present, when sequence_parallel is enabled, shared experts would apply tensor parallel and do not do all reduce at the end of calculation, which results in the precision issue.
