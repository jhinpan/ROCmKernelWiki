# [bugfix] Use only onlines CPUs in lscpu

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#40161](https://github.com/vllm-project/vllm/pull/40161) · **Merged:** 2026-04-20 · **Author:** @Galigator

**Inclusion reason:** kernel path 'vllm/utils/cpu_resource_utils.py'; keyword 'mfma'

## Summary (from upstream PR description)

lscpu -Je outputs '-' for offline CPUs which is invalid JSON.
Adding -b (online-only) flag fixes the JSONDecodeError on systems with offline/disabled CPU cores.
The regexp in cpu_ressource_utils.py did not manage to transform the JSON into valid one.
Th correct way to go is to avoid CPUs that aren't online.
