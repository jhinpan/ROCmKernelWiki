# [Model] Use AutoWeightsLoader for AXK1

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#41901](https://github.com/vllm-project/vllm/pull/41901) · **Merged:** 2026-05-07 · **Author:** @wenyili

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Purpose
Part of #15697.
Moves load_weights from AXK1ForCausalLM to AXK1Model and delegates through AutoWeightsLoader, following the same pattern as Llama, Gemma2/3, Qwen2, and other already-converted models.
Key changes:

Add load_weights to AXK1Model with the full weight-loading logic (stacked params, MLA/MHA mapping, EPLB expert params, ROCm AITER fusion shared-expert splitting, spec-decode layer skipping).
Add use_mha, fuse_qkv_a_proj, and num_redundant_experts attributes to AXK1Model.__init__ so the model-level loader has everything it needs. num_redundant_experts is derived directly from vllm_config.parallel_config.eplb_config.num_redundant_experts to be safe for all Pipeline Parallelism configurations.
Replace AXK1ForCausalLM.load_weights with a two-liner that calls AutoWeightsLoader(self).load_weights(weights).
Add one-line fix: get_spec_layer_idx_from_weight_name expects a model.layers.* prefix, but AutoWeightsLoader strips model. before calling AXK1Model.load_weights, so the call is wrapped with f"model.{name}".
