## Summary (from upstream PR description)

Summary
Aligns all CUDA 13 pins to 13.0.2, the version that PyTorch 2.11.0 (currently pinned in requirements/cuda.txt) is built against per pytorch/pytorch at v2.11.0 (.ci/docker/build.sh, .ci/docker/common/install_cuda.sh, .github/scripts/generate_binary_build_matrix.py all pin 13.0.2).
Also closes drift between the Dockerfile default (previously 13.0.0), the Buildkite release pipeline (which was overriding to 13.0.1 after #39878), and the GB300 docs example (also 13.0.1). After this PR all CUDA 13 pins are consistent at 13.0.2.
