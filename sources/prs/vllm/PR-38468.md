## Summary (from upstream PR description)

Purpose
Add platform manual_seed_all API to remove cuda bindings for tests and benchmarks.
After this PR, we recommend using set_random_seed in torch_utlis when need fixed seed for case reproduce. torch.manual_seed , torch.random.manual_seed, np.random.seed, random.seed are not forbidden as it won't bring cuda binding.
