## Summary (from upstream PR description)

Summary
Add an optional tensor-descriptor (TD) load/store path to the Triton
unified attention kernel in vllm/v1/attention/ops/triton_unified_attention.py.
The TD path uses tl.make_tensor_descriptor for Q/K/V loads and the
output store, which enables HW 2D block reads on Intel Xe2/Xe3.
The non-TD branch is preserved and stays bit-for-bit identical — both
USE_TD and USE_TD_QO are tl.constexpr so the dead branch is
eliminated at Triton compile time, giving zero overhead when disabled.
This PR rides on top of the 2D/3D kernel unification in #40631; the
new TD helpers mirror that structure.
