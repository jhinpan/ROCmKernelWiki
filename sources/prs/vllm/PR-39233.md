# [NVIDIA] Add sm_110 (Jetson Thor) to CUDA 13.0 build targets

**Repository:** [vllm-project/vllm](https://github.com/vllm-project/vllm) · **PR:** [#39233](https://github.com/vllm-project/vllm/pull/39233) · **Merged:** 2026-04-23 · **Author:** @johnnynunez

**Inclusion reason:** kernel path 'tools/flashinfer-build.sh'; keyword 'flash'

## Summary (from upstream PR description)

Summary

Add compute capability 11.0 (sm_110, Jetson Thor) to all TORCH_CUDA_ARCH_LIST configurations that feed CUDA 13.0+ builds
The official vllm/vllm-openai:v0.19.0-cu130 image ships without sm_110 kernels, making it completely unusable on Jetson Thor — precompiled CUDA kernels for Marlin (GPTQ-INT4), CUTLASS (cutlass_scaled_mm, FP8), and flash-attn (BF16) all fail with CUDA error: no kernel image is available for execution on the device
For CUDA < 13.0 builds, the CMake cuda_archs_loose_intersection() in CMakeLists.txt safely filters 11.0 out since it is not in CUDA_SUPPORTED_ARCHS for those toolkit versions
