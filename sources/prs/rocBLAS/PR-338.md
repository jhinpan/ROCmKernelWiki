## Summary (from upstream PR description)

Call Tensile API from gemm_ex  in place of calling rocblas_hgemm, rocblas_sgemm, rocblas_dgemm.
Add chunking for m and n to gemm_ex. This prevents the offset for m and n from exceeding the size that can fit in a 32 bit register.
