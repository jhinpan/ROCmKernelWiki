## Summary (from upstream PR description)

Add hgemm to rocBLAS.
Only works for gfx900. There are __fp16 instructions in gfx900 that are not in gfx803. This initial checkin builds assembly hgemm with the gfx900 __fp16 instructions. CMakeLists.txt needs to change to allow for both gfx803 and gfx900. This change will build source code hgemm for gfx803.
