# Make profiling code type-safe and simpler

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#1031](https://github.com/ROCm/rocBLAS/pull/1031) · **Merged:** 2020-03-04 · **Author:** @leekillough

**Inclusion reason:** kernel path 'library/src/blas_ex/rocblas_gemm_ex.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

hipEvent_t can be pre-declared in rocblas-types.h so that it can be used in the declaration of rocblas_gemm_ex_profile's event parameters. This avoids needing to use void* and casting them to hipEvent_t*.
#include "rocblas-profile.h" should be added to rocblas.h so that it's always included, rather than requiring the user to #include <rocblas-profile.h>.
The code
    if(startEvent && stopEvent)
        return handle->host->runContractionProblem(problem, startEvent, stopEvent);
    else
        return handle->host->runContractionProblem(problem);

... is redundant, since runContractionProblem already checks for nullptr startEvent and stopEvent, and is declared to always have startEvent and stopEvent parameters, so there is nothing gained by calling it two different ways. If the overhead of checking startEvent and stopEvent were significant, then two separate overloads of runContractionProblem, one with and one without startEvent and stopEvent, could be used, but that is not the case here.
