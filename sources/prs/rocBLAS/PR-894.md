# Make tensile_helper explicit instantiations inline

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#894](https://github.com/ROCm/rocBLAS/pull/894) · **Merged:** 2020-01-02 · **Author:** @leekillough

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

The tensile_helper() function has explicit instantiations, which means you'll get multiple definitions if you put them in a header file that's included in multiple places.
The reason it doesn't occur in rocBLAS is that rocBLAS includes the header only once, and thus only gets one definition.
If rocSOLVER uses rocBLAS headers, it will create multiple definitions.
We simply declare the instantiations inline to get around the One Definition Rule.
tensile_helper() will be removed when we move to the new Tensile client.
