# Add rocblas_status_to_string() to public API, fix compiler warnings, rename _ex functions properly

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#772](https://github.com/ROCm/rocBLAS/pull/772) · **Merged:** 2019-11-01 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/gtest/gemm_batched_gtest.yaml'; keyword 'gemm'

## Summary (from upstream PR description)

Changes:

Add rocblas_status_to_string() function to the public C API. Move it from clients/include/rocblas_test.hpp to library/src/rocblas_auxiliary.cpp, and make it completely handle every possible value of rocblas_status.
Rename *_ex_batched and *_ex_strided_batched functions and test names to *_batched_ex and *_strided_batched_ex. _ex must appear last, and not in the middle, of names.
Do not use default: in switch statements which are supposed to list all values of an enum, so that the compiler will make sure that all enum cases are handled in the switch. If you use default:, then a subset of enum values can be listed with no warning from the compiler, because the unlisted values will be considered by the compiler to be handled by the default: case. In case the enum value is invalid and not one of the defined cases, we fall-through the switch statement to take the default action. Enabling these warnings by removing default: found one case where we did not list all of the possible enum values.
