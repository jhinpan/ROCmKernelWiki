# Automatically update copyright dates in text files upon commit

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#600](https://github.com/ROCm/rocBLAS/pull/600) · **Merged:** 2019-07-02 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/gtest/gemm_gtest.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

This adds a one-liner Perl script to .githooks/pre-commit to automatically update the copyright date at the top of text files. If approved, feel free to copy it to other repositories.
(Perl is the best language for this; Python would be much, much harder to do. This is a Perl one-liner. Perl is installed on almost all Linux systems, so it's not a new dependency.)
It takes the old date range as either being a single year or a year range. It converts it to a single year if the starting year is the same as the current year. It converts it to a range if the starting year is earlier than the current year.
The file must be a text file (as determined by Perl heuristic), and the copyright message must occur on the first 9 lines, and it is expected to be inside of a C/C++/shell/Perl/Python/Cmake/etc. comment. The only allowed characters on the line before Copyright are whitespace, /, * and #.  This virtually eliminates the chances of false positives. The search for Copyright is case-insensitive, but it is always replaced with the capitalized Copyright.
Some alternative spellings, like Copyright (C) are canonicalized.
