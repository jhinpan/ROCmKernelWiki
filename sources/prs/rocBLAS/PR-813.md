**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#813](https://github.com/ROCm/rocBLAS/pull/813) · **Merged:** 2019-11-13 · **Author:** @leekillough

## Summary (from upstream PR description)

This finishes porting of rocBLAS to the new Tensile client interface. This required a lot of phases:
Phase 1 (Bill):  Interface rocBLAS with the new Tensile client, developing a PIMPL interface which bridges rocBLAS and Tensile without requiring them to share headers. All connections from rocBLAS to Tensile are now done through tensile_host.hpp and tensile_host.cpp, without requiring any Tensile headers to be #included in any other rocBLAS files.
Phase 2 (Lee): Combine GEMM and GEMM_STRIDED_BATCHED contraction problems, cache the loading of the "host" across multiple rocBLAS handles, replace the *kernel_names functions with functions which simply return rocblas_status_not_implemented, make rocBLAS search for Tensile Code Object files relative to the librocblas.so directory found at runtime, and refactor rocBLAS in preparation for Phase 4.
Phase 3 (Bill): Package the Tensile files, dividing them up according to GPU architecture, and change rocBLAS to adapt to the new directory structure.
