## Summary (from upstream PR description)

adding updated logic files which are the result of tuning using the new flexible batch feature in tensile.
This is a the first round of tuning related to this, it contains a subset of the full tuning for this feature.
The performance gains for many cases are as much as 10 - 50 % for the cases that don't meet the assertion and over 100% for cases the do.
The cases the do meet the assertion we are seeing 85 - 92 % efficiency.
