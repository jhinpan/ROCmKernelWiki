## Summary (from upstream PR description)

A subsequent PR to reduce build memory footprint is needed.
Full rocblas-test passing on both gfx900 and gfx906 using both ROCm 2.6 and BKC-369.
The second memory footprint reduction commit enables rocBLAS build to succeed on CI machines with 16GB physical memory and at least 16GB swap space.  The build with -lasm_ci succeeded on a local desktop with 16GB mhysical memory and 8GB swap space.
The third commit corrected the missing copy in commit 2ebfd90 from asm_full/hip* to hip_lite/.  This makes -lhip_lite build pass full rocblas-test.
