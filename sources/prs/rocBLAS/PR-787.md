# Make rocBLAS compatible with GCC clients

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#787](https://github.com/ROCm/rocBLAS/pull/787) · **Merged:** 2019-11-09 · **Author:** @leekillough

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/Logic/archive/vega10_Cijk_Ailk_Bjlk_SB.yaml'; keyword 'lds'

## Summary (from upstream PR description)

Make rocBLAS client examples code compile under GCC, by refining criteria which determine whether _Float16 is defined.
Remove #pragma once from rocBLAS public header files, using only the include guards, which also exist

#pragma once interferes with header_compilation_tests.sh on earlier versions of GCC -- GCC gives an error when a file with #pragma once is compiled but isn't #includeed, even when -xc-header is specified to say that we're precompiling header files.


Add GCC tests to header_compilation_tests.sh, if /usr/bin/gcc exists, to detect the original _Float16 header file compilation failure, and cause it to fail rocBLAS builds.
Use "$(dirname "$0")/.git/hooks/" to determine the hooks directory inside the invocation of install.sh.
