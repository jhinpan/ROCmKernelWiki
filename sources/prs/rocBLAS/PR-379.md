# Test hpa arithmetic and update hip hpa files

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#379](https://github.com/ROCm/rocBLAS/pull/379) · **Merged:** 2018-10-08 · **Author:** @amcamd

**Inclusion reason:** kernel path 'clients/include/testing_gemm_ex.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Modify test to confirm that hpa_hgemm is using 32 bit arithmetic.
This is done by initializing leading 2x2 blocks of matrix A and matrix B to cause IEEE NaN result for 16 bit arithmetic, but correct result for 32 bit arithmetic.
The change results in multiplication of two large numbers. The numbers are correctly represented in 16 bit, but their product overflows in 16 bit, and does not overflow in 32 bit.
The product is then subtracted, so the result of the reduction sum will fit in 16 bit.

The hip_Cijk_A..k_B..k_HBH.yaml files are also updated.
