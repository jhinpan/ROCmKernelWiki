# add updated logic files for inception-1x1 tuning

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#529](https://github.com/ROCm/rocBLAS/pull/529) · **Merged:** 2019-04-03 · **Author:** @wbgilmartin

## Summary (from upstream PR description)

Adds updated logic files which are tuned for inception 1x1 sizes.
The efficiencies generally fall between 60 and 85 percent. After several days of experimenting this seems like this is the best we are going to do. The poor performance cases are related to sizes with smaller dimension. (the TN cases are particularly problematic.
This tuning includes tuning for vega20 fp32 batch64 inception cases.
