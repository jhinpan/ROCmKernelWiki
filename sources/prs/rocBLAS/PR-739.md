## Summary (from upstream PR description)

Adds:

trsm_batched
trsm_ex_batched
trsm_strided_batched
trsm_ex_strided_batched

Potentially supports arrays of alphas at the _template level, although this is not tested as it is not supported in the API.
It also appears that moving gemm_ex functions into a shared _template function made its way into this PR as well.
This PR moves around code from files (mainly moving code from rocblas_trsm.cpp to rocblas_trsm.hpp) so it may be hard to follow the changes on GitHub. The most interesting code changes are likely located in rocblas_trsm.hpp. The memory management code was changed to support the batched version which is a little complicated, so extra review on that would be appreciated.
