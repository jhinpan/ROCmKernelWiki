# Refactor logging, tuple handling, and argument handling

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#922](https://github.com/ROCm/rocBLAS/pull/922) · **Merged:** 2020-04-03 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/include/testing_gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

This makes several changes

Make logging entries atomic in the presence of multiple threads (currently they are interleaved)
Splits rocblas_arguments.hpp into rocblas_arguments.hpp and rocblas_arguments.cpp
Puts Arguments fields in one single place
Move std::tuple helper functions out of logging.h and into tupler_helper.hpp
Rewrite argument validation, dumping of new Tensile host and printing arguments, in terms of tuples and functions to apply to their pairs
Change tuple helper functions to operate on their elements in-order rather than backwards

This is a work-in-progress; it does not build 100% right now; it is not ready for review, and it will be modified some more, with a final refactoring change at the end to move stuff around files, remove unnecessary #includes, etc.
It is being submitted to show that there would be many conflicts with another recent PR.
