## Summary (from upstream PR description)

This adds into blas1 the batched and strided_batched for reduction based asum and nrm2 functions (shared templates).    Follows feedback and pattern from PR #686
It defers the merging of the batched and strided_batched kernels into a single more complicated template as it seemed complicated enough already.  It can likely reuse some code from scal_batched helpers if this refactor is done.   Also requires unification of testing parameter stride_scale with the scal routine (and others).   stride_x parameter checking will also require updating after we decide on API specification.
