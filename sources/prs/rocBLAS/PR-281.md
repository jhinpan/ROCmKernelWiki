# initial code: chunk n to avoid n*ldc > numeric_limits<int>max()

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#281](https://github.com/ROCm/rocBLAS/pull/281) · **Merged:** 2018-06-08 · **Author:** @amcamd

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/gemm.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

To avoid   n*ldc > std::numeric_limits::max() chunk gemm in the n dimension.
Note that the following variables can be changed:

int_limit
chunk_size_min
The code should keep  n*ldc  less than int_limit, and it is set to the biggest possible int. Maybe it should be set to the largest   unsigned_int   .
Also, the   chunk_size_min   is arbitrary. It is to prevent an artificially small chunk_size
