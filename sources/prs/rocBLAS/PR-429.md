# Complete refactoring of rocBLAS test framework

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#429](https://github.com/ROCm/rocBLAS/pull/429) · **Merged:** 2018-12-10 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/gtest/gemm.yaml'; keyword 'gemm'

## Summary (from upstream PR description)

Total refactoring and cleanup of rocBLAS test framework


Make Google Tests data-driven instead of hard-coded in C++ files
Convert all existing test data into YAML files
Make Google Test names depend on test arguments
Make test code for rocBLAS functions as small as possible, abstracting out common features and distilling test code down to only the minimum required to define the test
Make test code more easily expandable to new data types, without copying-and-pasting
Handle dispatching functions by type in one place (type_dispatch.hpp), rather than in every individual test file
Write documentation on how to add rocBLAS tests (clients/gtest/README.md)
Remove unnecessary or duplicated code, using templates or macros to factor copy-and-paste code
Replace simple functions with inlined code in headers (e.g. flops.cpp, unit.cpp, near.cpp, arg_check.cpp and rocblas_template_specialization.cpp are eliminated and replaced with simpler and smaller code in their respective headers)
Split up large utility.h header into smaller functional headers, to reduce dependencies
Simplify code, using C++14 where possible (e.g. auto return types, non-trivial constexpr functions, variable templates)
