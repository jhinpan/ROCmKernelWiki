# fix rocblas-bench for half gemm

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#348](https://github.com/ROCm/rocBLAS/pull/348) · **Merged:** 2018-08-31 · **Author:** @amcamd

**Inclusion reason:** kernel path 'clients/gtest/gemm_gtest.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

rocblas-bench was not reproducing a known_bug from rocblas-test for
rocblas-bench -f gemm -r h -m 3 -n 1 -k 5 -v 1
There was one main bug in the code:

in clients/include/testing_gemm.hpp rocblas_error was declared with type equal to template type T. It is now correctly declared with type double.

There was also incorrect conversion from rocblas_half to float using static_cast . The following typedef is used
typedef uint16_t rocblas_half;
This is corrected using the function half_to_float() in place of static_cast() for the conversion.
