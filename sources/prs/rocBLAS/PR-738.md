# integration of the new tensile client

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#738](https://github.com/ROCm/rocBLAS/pull/738) · **Merged:** 2019-10-21 · **Author:** @wbgilmartin

## Summary (from upstream PR description)

This will add the initial hooks to call the new tensile client host library.
I am still testing locally to see if the last set of changes added did not break anything but this will enable the start of the code review.
to build I added a switch -s, so use ./install.sh -cds
by default the build will build the old client.
when running using the new host (In this iteration) add a -lib option to the call to rocblas-bench i.e.
./rocblas-bench ...  -lib /path/to/host/library.
a normal rocblas build will create the library and place it in rocBLAS/build/release/Tensile/library
