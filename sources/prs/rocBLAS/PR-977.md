# Change rocBLAS tests to accept rounded or truncated Bfloat16

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#977](https://github.com/ROCm/rocBLAS/pull/977) · **Merged:** 2020-02-05 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/include/testing_gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Change the GEMM BFloat16 tests to allow either rounding or truncation of BFloat16 results.
Change the test infrastructure to allow float and rocblas_bfloat16 to be compared, with the rounded or truncated BFloat16 value of the float value being acceptable.
Remove the old code which tried to model Tensile's BFloat16 rounding behavior based on problem sizes.
Enhance host_vector to allow conversions from host_vector<rocblas_bfloat16> to host_vector<float>, and massage the other functions.
