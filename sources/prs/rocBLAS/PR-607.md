# Avoid including hip/hip_runtime.h in public header files. Clean up #includes.

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#607](https://github.com/ROCm/rocBLAS/pull/607) · **Merged:** 2019-07-09 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/include/testing_gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

Avoid including hip/hip_runtime.h in public header files. Only include hip/hip_runtime_api.h.
Remove rocblas_bfloat16.h implementation from public header files. Only include implementation when _ROCBLAS_INTERNAL_BFLOAT16_ macro is defined during builds. Add back constexpr implementation, since it is only used during internal C++14 builds.
Clean up #includes to avoid dependence on clang-format order, and remove blank lines. Now each header #includes its dependencies, and does not depend on another header being #included before it.
Move status.cpp into a header file, to make it simpler.
Fix a potential type safety issue by always converting float_to_half and not assuming that the integer 0 represents 0 in rocblas_half. Always convert from float to rocblas_half.
Remove header file dependencies from CMakeLists.txt, since CMake figures them out automatically.
