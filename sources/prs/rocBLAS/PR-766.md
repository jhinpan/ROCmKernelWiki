# trmm, gemm based

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#766](https://github.com/ROCm/rocBLAS/pull/766) · **Merged:** 2019-11-11 · **Author:** @amcamd

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

Add gemm based trmm


only for precisions float and double


no batched or strided_batched


code is functional, algorithm will need to be modified to improve performance


Inside of trmm there are calls to

rocblas_set_pointer_mode
rocblas_scal_template
rocblas_copy_template
rocblas_gemv_template
rocblas_gemm_template

if any of the internal calls return status other than rocblas_status_succcess, then
the trmm will return rocblas_status_internal_error. In addition the macro
CHECK_INTERNAL_ROCBLAS_ERROR will print to stderr

error string
error number
filename
line number

For the definition of the macro, see line 254 of library/src/include/utility.h.


Device memory is allocated for work arrays dt1[RB,CB] and dt2[CB,CB]. CB and RB are

constexpr rocblas_int RB = 128;
constexpr rocblas_int CB = 128;

See line 140 of rocblas_trmm.cpp for memory device memory allocation.
