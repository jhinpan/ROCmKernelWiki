# add 'Device 66af' for Radeon VII

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#595](https://github.com/ROCm/rocBLAS/pull/595) · **Merged:** 2019-06-27 · **Author:** @zaliu

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/Logic/archive/vega20_Cijk_Ailk_Bjlk_DB.yaml'

## Summary (from upstream PR description)

Resolves SWDEV-190051

when /usr/share/misc/pci.ids is missing on the system, Radeon VII presents itself as 'Device 66af', not 'Vega 20'.  This fix brings 'Device 66af' into the 'Vega 20' fold.
