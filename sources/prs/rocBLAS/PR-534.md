**Inclusion reason:** kernel path 'clients/benchmarks/dgemm_genperf.py'; keyword 'gemm'

## Summary (from upstream PR description)

Allow ROCBLAS_LAYER=4 logging output to be input to roccblas-test and rocblas-bench with --yaml.
Port rocblas_gentest.py from Python 2 to Python 3. Also changed CI Docker container to install Python 3.
Rename tests in YAML files, removing the testing_ prefix. testing_gemm_ex becomes gemm_ex, for example.
Also some cosmetic changes.
