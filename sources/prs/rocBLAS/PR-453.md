# use string in place of char to extend rocblas-bench datatypes

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#453](https://github.com/ROCm/rocBLAS/pull/453) · **Merged:** 2019-01-18 · **Author:** @amcamd

**Inclusion reason:** keyword 'gemm'

## Summary (from upstream PR description)

For function gemm_ex in rocblas-bench use std::string in place of char for

a_type
b_type
c_type
d_type
compute_type


This allows for strings like i8_r, i32_r, f16_r, f32_4 f64_r in place of characters h,s,d. The characters do not cover new types like int8 and int32.
The multi-character strings correspond to those in rocblas_datatype enum values rocblas_datatype_i8_r, rocblas_datatype_i32_r, ....
