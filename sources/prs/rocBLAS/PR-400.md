# Refactoring of rocBLAS testing and benchmarking to be data-driven

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#400](https://github.com/ROCm/rocBLAS/pull/400) · **Merged:** 2018-11-02 · **Author:** @leekillough

**Inclusion reason:** kernel path 'clients/benchmarks/dgemm_genperf.py'; keyword 'gemm'

## Summary (from upstream PR description)

Summary of proposed changes:

Starting with [SDH]GEMM, refactor the correctness and performance tests to be data-driven based on YAML files.
Remove some redundant code, such as the old code which used ranges (start:stop:step).
Cleanup white space (convert tabs to spaces and remove trailing whitespace) -- incidental change for when other changes were made to a file.
Make function-like macros use do {} while(0) idiom so that they are syntactically equivalent to function calls, as in if (test) MACRO(x); else MACRO(y);
