## Summary (from upstream PR description)

This is PR will allow separate jobs in Jenkins for Nightly and PreCheckin. Jenkins will now record the correct number of tests in the test history for the separate jobs. You will also be able to trigger the nightly jobs manually if required.
An separate view in Jenkins will be created for a convinient place to track rocBLAS testing as there are will be 3 rocBLAS test jobs, Nightly, PreCheckin and TensileTip.
Test information is arranged around a Common.groovy file with individual tests using customizing based on loading functions from the Common file.
