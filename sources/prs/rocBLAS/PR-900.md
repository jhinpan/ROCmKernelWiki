## Summary (from upstream PR description)

This is purely a reformatting change. It is not very important, but should be done from time to time near our releases. It can be done right after the 3.1 release if desired, but it needs to be done semi-regularly.
It does not affect functionality.
It slightly changes the pre-commit script to allow a --reformat option to reformat the entire rocBLAS source tree, such as around a release. Normally pre-commit is only invoked from Git on files with pending changes.
The pre-commit script removes trailing whitespace (including ^M) from lines of known text files, changes the copyright date ranges to include or append the current year (Happy New Year!), adds missing newlines at the end of files, and runs clang-format on C/C++ files and their headers/include files.
