Add the following to the rocBLAS API:

rocblas_hgemm_kernel_name
rocblas_sgemm_kernel_name
rocblas_dgemm_kernel_name

These have the same arguments as:

rocblas_hgemm_strided_batched
rocblas_sgemm_strided_batched
rocblas_dgemm_strided_batched

Also added the following to rocblas_bench:

gemm_kernel_name
gemm_strided_batched_kernel_name

These can be called with:

rocblas_bench -f gemm_kernel_name -r s -m 1024 -n 1024 -k 1024
rocblas_bench -f gemm_strided_batched_kernel_name -r s -m 1024 -n 1024 -k 1024 -batch 64
