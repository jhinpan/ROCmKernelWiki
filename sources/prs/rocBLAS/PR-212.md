# default logging stream to std::cerr

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#212](https://github.com/ROCm/rocBLAS/pull/212) · **Merged:** 2018-03-28 · **Author:** @amcamd

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/gemm.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

Change the default stream for logging to std::cerr.
Alternatively, if the user sets the environment variable ROCBLAS_LOG_TRACE_PATH to a full path name, open a file in the full path name, and stream trace logging to that file. If the environment variable ROCBLAS_LOG_BENCH_PATH is set to a full path name, open  a file in the full path name, and stream bench logging to that file.
If opening the files fails, try to open files stream_trace.csv or stream_bench.txt in the current working directory. If opening the files fails, default to streaming to std::cerr.
Additional Information
The environment variable ROCBLAS_LAYER is a bit mask as follows:

if ROCBLAS_LAYER is not set there is no logging
if ROCBLAS_LAYER is set to 1, then there is trace logging
if ROCBLAS_LAYER is set to 2, then there is bench logging
if ROCBLAS_LAYER is set to 3, then there is both trace and bench logging

trace logging outputs a line each time a rocBLAS function is called, the line contains the function name, and the values of arguments
bench logging outputs a line each time a rocBLAS function is called. The line can be used with the executable rocblas-bench to execute the function with the same arguments.
