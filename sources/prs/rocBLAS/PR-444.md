## Summary (from upstream PR description)

rocBLAS functionality changes:
Implement Profile Logging
Profile logging keeps count of the number of times each rocBLAS routine is called with specific arguments.
Profile logging is enabled with ROCBLAS_LAYER=4. Profile output file is controlled with ROCBLAS_LOG_PROFILE_PATH, and like trace and bench logging, defaults to stderr.
At the end of program execution, a YAML log file is output which lists each rocBLAS function call, its performance-important arguments, and the number of times it was called with those arguments:
