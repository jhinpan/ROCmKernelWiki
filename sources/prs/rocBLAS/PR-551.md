# Following DR2387, explicitly declare const[expr] variable templates static

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#551](https://github.com/ROCm/rocBLAS/pull/551) · **Merged:** 2019-05-08 · **Author:** @leekillough

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/gemm.cpp'; keyword 'gemm'

## Summary (from upstream PR description)

Resolves: SWDEV-188303
In DR2387, it was recently decided that unlike regular const-qualified variables, const-qualified variable templates do not have internal linkage by default.
Most compilers up to now have made const-qualified variable templates have internal linkage by default, all the way back to C++14. The standard was unclear.
This change declares all const-qualified variable templates in rocBLAS as static.
Recent changes to clang for DR2387, which change the default linkage of const-qualified variable templates from internal to external.
