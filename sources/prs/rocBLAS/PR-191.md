# Log bench

**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#191](https://github.com/ROCm/rocBLAS/pull/191) · **Merged:** 2018-01-29 · **Author:** @amcamd

**Inclusion reason:** kernel path 'clients/include/testing_gemm.hpp'; keyword 'gemm'

## Summary (from upstream PR description)

If the environment variable ROCBLAS_LAYER has the 0b0000000010 bit  set, log a string for each rocblas function called. The string can be used to run the standalone executable rocblas-bench. This allows user to run an application that calls rocblas functions. For any rocblas function called, the user can call the standalone executable rocblas-bench with the string. This will call the function with the same parameters as used in the application.
Also improve rocblas-bench to:

output all parameters
run hot and cold loops. The performance is calculated based on averaging the performance in the hot loops. This should give more repeatable performance measurements.
