**Repository:** [ROCm/rocBLAS](https://github.com/ROCm/rocBLAS) · **PR:** [#546](https://github.com/ROCm/rocBLAS/pull/546) · **Merged:** 2019-05-03 · **Author:** @zaliu

**Inclusion reason:** kernel path 'library/src/blas3/Tensile/Logic/archive/README.txt'

## Summary (from upstream PR description)

For each release where one of the 8 vega20 SB or DB logic files need to be updated, the updated unmassaged logic file(s) are first stored in Tensile/Logic/archive/ directory, then all 8 logic files are copied over to Tensile/Logic/asm_full/, and massage.py is executed in Tensile/Logic/asm_full to create the 8 massaged vega20 SB and DB logic files.
